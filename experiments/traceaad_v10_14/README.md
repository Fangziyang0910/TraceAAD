# TraceAAD V10.14 正式版运行说明

**TraceAAD V10.14** 的实现位于 `traceaad/v10_14/`，运行入口位于 `experiments/traceaad_v10_14/`。

最终正式实验批次为 `20260928_v1014`，五个任务各四路、每路 1,000 次候选尝试，并完成独立选择集评价。正式结果目录为 `experiments_result/traceaad_v10_14/`，包含批次清单、20 路运行目录及 held-out 汇总。当前本地档案的逐文件校验见[完整性清单](../../experiments_result/traceaad_v10_14/analysis/archive_integrity.json)。结果解释见[正式实验分析](../../docs/03-机制探索与验证/2026-09-29-V10.14-正式实验结果与分析.md)。

## 正式协议

- **初始化**：默认 8 次混合提案，前半独立生成、后半可参考先前有效根。有效唯一根最多获得一次 Refine bootstrap。失败、重复和无效提案计入预算。
- **交付**：普通文本 `Idea:` 加完整 Python `code:`。代码是必要交付，Idea 可缺省；完整响应和实际评价源码分别保存。正式实验固定完整代码模式。
- **父代**：所有有效候选参与竞争；相同 AST 语法组共享机会计数，AST 去除注释与格式影响，不声称行为等价。按经验中分位质量加 `1/sqrt(使用次数+1)` 选父代，同分优先使用少、记录早的组。
- **动作**：从可用的 Refine、Tune、Pivot、Transfer 中等概率选择。Tune 需要数值参数；Transfer 需要不同语法组 donor。普通 Pivot 使用独立上下文，不给模型父代源码或历史。
- **历史与探针**：额外历史最多 4,000 token、6 个事件、深度 6；Idea 完整保存，提示视图受 tokenizer 限制。固定训练探针只作诊断，不改变分数或父代资格。
- **隔离**：默认关闭在线局部重验、固定三步开发票和行为区域调度。候选尝试预算包含失败与重复。搜索结束后冻结最多五个不同 AST 候选，用独立选择集决定最终程序；held-out 不参与搜索或选择。

## 运行入口

运行命令：

```bash
uv run python -m experiments.traceaad_v10_14.run \
  --task tsp_construct --run-name trial_1 --budget 1000 --dry-run
```

去掉 `--dry-run` 才会发起模型调用。新运行使用独立 run name 和目录；不得覆盖最终批次的原始结果。候选尝试是预算单位，不等同于评价次数或模型调用次数。
