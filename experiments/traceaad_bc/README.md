# TraceAAD B/C 预算与上下文对照实验

本批次固定比较两个组合，每个组合 5 个任务 × 3 个重复，共 15 路；B、C 合计 30 路。搜索机制、任务契约、评价预算和冻结运行时保持不变，只有预算分配与参考上下文组合改变。

## 并发槽位

| 用户可读名称 | 服务端点 | 并发槽位 |
| --- | --- | ---: |
| server1 | `222.201.145.8:8080` | 7 |
| server3-1 | `222.201.145.6:8000` | 10 |
| server3-2 | `222.201.145.6:8001` | 10 |
| local | `127.0.0.1:8001` | 3 |
| 合计 |  | **30** |

`server3-1` 和 `server3-2` 是同一台 server3 上的两路服务。程序内部保留历史路由键以兼容已有运行目录，批次清单、监控和工作记录使用上表名称。

调度器按任务重复交错生成计划，并在每个任务的重复之间分散后端；因此生成较长的任务与较短的任务会同时进入不同服务槽位。只有显式传入 `--cvrp-last` 时才会把 CVRP 延后，本批次不使用该选项。

## 启动与监控

两个批次分别使用 `--arm B` 和 `--arm C`、各 15 路，调度器使用 `--direct` 一次填满当前空闲槽位，并按容量自动排队。统一可视化监控合并 V10.11、V11.0、B 和 C 的结果目录，固定使用 **8765** 端口：

```text
http://<主机>:8765
```

监控版本选择器中的 B、C 标签分别为“V11 预算 + V10 上下文”和“V10 预算 + V11 上下文”。
