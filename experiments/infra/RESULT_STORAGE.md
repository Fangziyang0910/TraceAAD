### 查阅或恢复原格式

原档位置为 `experiments_result/.archive/storage_20261006/<实验>/<任务>/<运行>.tar.gz`。解到单独目录，例如：

```bash
mkdir -p /tmp/traceaad-original-run
tar -xzf <原档.tar.gz> -C /tmp/traceaad-original-run
```

原始文件的名字和内容保存在压缩包中；跨目录的研究文档及派生分析仍留在原位置。迁移前的硬链接恢复清单不再对应当前布局，勿对已经转换的目录运行旧恢复命令。当前追加写入会先分离共享 inode，避免改变已封存副本。
