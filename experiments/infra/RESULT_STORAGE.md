# 实验结果存储与恢复

清理了可再生成的缓存，并对已完成实验的重复 JSON 产物做存储去重。候选程序、配置、原始轨迹、测试结果和每个迭代文件名均保留，正在执行的 server3 held-out 队列及本地同步继续运行。

## 实际清理

| 类别 | 操作与结果 |
| --- | --- |
| uv 缓存 | `uv cache prune --offline --no-progress` 移除 346,152 个文件，命令报告 44.1 GiB；未使用 force 或 CI 模式 |
| pip 下载缓存 | 清理约 8.9 GiB 的 HTTP 下载缓存 |
| 项目缓存与上传副本 | 清理 41 个缓存目录和已逐文件确认相同的 409 个上传暂存文件，内容合计约 5.9 MiB |
| 已完成实验档案 | 扫描 32 个档案目录、10,052 份 JSON，把 2,950 份相同内容的副本改为硬链接；按唯一 inode 的分配块核算，节省约 212.2 MiB |
| 空目录 | 删除空的 `tests/tools` 和项目 `.agents` 目录 |

包缓存的报告大小不等同于精确的磁盘释放量，部分缓存可能与环境共享硬链接。项目 `.venv` 保留，Python、NumPy、pytest 可正常导入。

档案去重涉及 EoH、MCTS-AHD 已完成运行的种群快照，以及早期 `traceaad_e2_a`、`traceaad_refine_e1` 中重复的行为 profile。去重前后，全部 10,052 个文件的 SHA-256 一致；没有删去迭代位置，也没有重新选择程序。

## 保留的内容

`tests/snapshots/` 是 Git 跟踪的提示词基准，8 份文件的哈希均未变化，用途已写入测试说明。跨版本源码有 4 组内容完全相同，重复部分约 28 KiB，但评价协议和续跑身份涉及源码路径与指纹，因此保留版本实现。原始搜索 JSONL 和正在同步的 held-out 日志也保留。

## 恢复与验证

硬链接共享写入；编辑这些档案或恢复相关任务前，须先按[原始结果说明](../../experiments_result/README.md#已完成档案的去重)中的命令恢复独立文件。工具在替换文件前保存恢复清单，核验内容，并保留原权限和时间信息供恢复使用。

五个相关测试通过，其中三个专用测试覆盖去重后完整回读迭代历史、恢复后的独立写入、拒绝覆盖变化的档案，以及保护已有恢复清单和符号链接；另外两个验证现有实验产物读取。
