# 必要检查

在仓库根目录运行：

```bash
uv run pytest -q
```

只保留会影响机制、成绩或实验运行的检查：

- `independent_base/`：Base 的选择、提示、共享修复、预算、恢复、八任务接入与脱离仓库独立运行。
- `evotrace_v2/`：单次保留选择、冷却与真实使用、联合剪枝和路径收缩、逐事件历史守恒、多轮经验交接、提交前后恢复与独立运行。
- `evotrace_v1/`：脱离仓库的独立运行、初始化与修复、模型接口与评价超时、统一选择与完整结构容量、跨方向与重复收缩、跨轮评价计数、路径/旁支归属、参考来源、经验读取与恢复。
- `v21_3/`、`v22_2/`、`v24_1/`：保留机制的上下文、分配、经验、预算与恢复。
- `method/`：基线的关键决策与共用实例评价。
- `task/`：当前六任务的数据划分、解的合法性与真实目标值。
- `experiments/`：结果读取与对应、看板、成本、共享资源调度与远端监控。
- `base/`：模型请求与用量记录、接口故障，以及超时进程清理。

模型回复使用离线假数据，不请求真实模型。测试之间不互相导入；少量共用数据放在 `support.py`。

新增测试应对应一个会改变研究结果的错误，或已经遇到的实际运行问题。同一行为只检验一次。不为提示词原句、旧版本字段、每种部署参数组合或普通辅助函数另写测试。
