# 必要检查

在仓库根目录运行：

```bash
uv run pytest -q
```

只保留会影响机制、成绩或实验运行的检查：

- `method/`：个体、提示材料、选择、预算、修复、评价与基线关键决策。
- `task/`：当前六任务的数据划分、解的合法性与真实目标值。
- `experiments/`：实际运行条件、恢复、结果对应、成本和共享资源释放。
- `base/`：模型请求与用量记录、接口故障，以及超时进程清理。
- `independent_base/`：新 Base 的选择、轨迹提示、共享修复、预算、恢复、八任务接入与脱离仓库独立运行。
- `independent_v19_3/`：全局经验进入生成、独立版本与共享修复、双角色HTTP、实际展示计分、反思中断恢复、上下文边界和独立包运行。

模型回复使用离线假数据，不请求真实模型。测试之间不互相导入；少量共用数据放在 `support.py`。

新增测试应对应一个会改变研究结果的错误，或已经遇到的实际运行问题。同一行为只检验一次。不为提示词原句、旧版本字段、每种部署参数组合或普通辅助函数另写测试。
