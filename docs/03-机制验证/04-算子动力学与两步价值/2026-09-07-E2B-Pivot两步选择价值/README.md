# E2-B'：Pivot 两步选择价值随机干预实验

## 1. 实验目标与双步干预协议

本实验通过小规模随机干预，直接检验 Pivot 算子作为两步“垫脚石（stepping stone）”的期权价值假设：
$$Q_2(Pivot \rightarrow Refine) \quad\text{是否系统性高于}\quad Q_2(Refine \rightarrow Refine)$$

- **区分三类轨迹职责**：
  1. **Formation trajectory**：祖先链代码形成事件（作为生成提示词中的上下文）；
  2. **Development experience**：当前节点出生后接受过的开发尝试次数与前沿推进记录（用于选锚与控制器状态）；
  3. **Behavior transition**：单步变异产生的实际行为位移（事后解释量）。
- **固定锚点与成对干预（18 个 Anchor）**：
  - 涵盖 TSP、OBP、VRPTW 三任务；每个任务选取 3 个具备充分开发经验但已停滞的节点（Experienced，历史开发 $\ge 3$ 次且近期无超父）以及 3 个从未被扩展的节点（Fresh），进行同适应度配对；
  - 每个锚点作为一个 block，无条件执行两条路径：
    - **路径 A**：$Refine \rightarrow Refine$ (RR)
    - **路径 B**：$Pivot \rightarrow Refine$ (PR)
  - 两臂在同一锚点上使用相同生成后端与对应阶段采样种子。第一步只要评价有效，无条件获得恰好一次第二步 Refine（第一步生成的代码与摘要进入第二步上下文）。
- **两步净收益定义**：
  $$Q_2 = \max\{f^*, f(c_1), f(c_2)\} - f^*, \qquad \widetilde{Q}_2 = Q_2 / |f^*|$$
- 数据汇总详见 summary.json。

## 2. 核心实验数据

### 2.1 执行完整性与有效率

18 个锚点共 36 条随机干预路径全部执行完成：
- 第一步有效率：RR 为 13/18，PR 为 15/18；
- 第二步有效率：RR 为 11/18，PR 为 14/18；
- PR 在各阶段的有效率均不低于 RR，排除了语法或评测截断导致两步收益缺失的假设。

### 2.2 两步最好收益（$Q_2$）主结果

| 锚点类型 | RR 均值 | PR 均值 | PR − RR 均值差 | 95% anchor bootstrap 区间 | 配对胜负（PR优 / 平 / RR优） |
| :--- | ---: | ---: | ---: | ---: | :---: |
| **Experienced (核心)** | 0.000000 | 0.000201 | **+0.000201** | [0.000000, 0.000602] | 1 / 8 / 0 |
| **Fresh (对照)** | 0.004234 | 0.014098 | +0.009864 | [-0.012702, 0.042295] | 1 / 7 / 1 |

- **门槛判定**：在 9 个 Experienced 锚点中，8 对为零收益平局，仅在 TSP 上出现 1 对微弱正差（+0.000602），未达到至少 2/3 任务为正的预注册门槛，判定为 **未通过**。
- **关键机制事实**：
  $$\boxed{0 \text{ 个 Pivot continuation 提高了第一步已经达到的 } Q_1}$$
  所有路径中，没有出现任何一个“第一步 Pivot 退化、第二步 Refine 兑现超越锚点”的垫脚石案例。

### 2.3 continuation gain 的表面信号拆解

只在两步均有效的锚点上观察第二步差值 $f(c_2) - f(c_1)$：
- Experienced 上 PR 相对 RR 的平均 continuation gain 达 **+0.7014**（Fresh 上达 +1.4229）。
- **信号伪影识别**：OBP 的 3 个 Experienced Pivot 第一步严重跌落至 -3000 到 -2625，第二步 Refine 恢复至 -745 附近。相对 $c_1$ 产生了巨大的正增益，但其依然显著劣于起点锚点 $f^*$。
- **结论**：$f(c_2) - f(c_1)$ 仅反映大模型具备修复严重代码破坏的恢复能力，不能视为有效的 option value。

### 2.4 行为移动与期权价值解耦

对第一步 Pivot 的实际行为移动距离分析：
- Pivot 行为移动距离与 continuation gain 的相关性为 **0.664**；
- 但与最终净收益 $Q_2$ 的相关性仅为 **-0.032**。
- 大行为移动伴随更大的跌落幅度与随后的修复幅度，并未转化为超越锚点的真实收益。

## 3. 机制分析与决策

1. **否定两步垫脚石假说**：实验未能在一步 Refine horizon 内观察到 Pivot 垫脚石假说的兑现；大模型在面对经过 Pivot 剧烈修改的代码时，后续单步 Refine 主要是恢复性修复，而非站在新机理基石上的飞跃。
2. **指标识别原则**：必须采用相对锚点/前沿的 $Q_2$ 净增量作为因果决策基准，坚决避免使用单纯的子代差值 $f(c_2) - f(c_1)$，防止奖励“制造深坑后再爬回起点”的虚假繁荣。
3. **控制器决策**：
   - 不在控制器中引入强制或动态的 Pivot 连续追踪规则（Pivot continuation）；
   - 停止将大行为位移判定为具备潜力的正向探索信号；
   - 保持以质量为核心的算子调度。
