# BehaveSim 全 Archive 群体验证

## 1. 实验目标与无偏抽样协议

本实验验证在**完全脱离历史选父筛选偏差**（不再要求节点曾作为 Refine parent）的条件下，BehaveSim 行为几何规律能否在完整搜索档案（Archive）的时间代表性样本上无偏复现。

- **时间均匀代表性抽样**：
  - 基于 V10.6 的 15 个冻结 run，所有有效 archive nodes 按 `evaluation_id` 排序，进行等间隔均匀采样，覆盖整个搜索全周期。
  - 样本规模：TSP、OBP、VRPTW 各 64 个节点/run（主结论依据）；OP 32 个节点/run；CVRP 12 个节点/run（诊断性单列）。共 708 个样本点，实际成功画像 707 个（覆盖率 99.86%）。
- **度量规范**：采用上一轮校准通过的协议（OBP scale-matched 1000/5000-item 探针，OP 4 随机流）。详细数值汇总见 summary.json。

## 2. 核心实验数据

`随机−kNN` 为正表示行为近邻适应度差更小；`远−近` 为正表示远距离档平均适应度差更大。

- TSP 与 VRPTW 在全部三个独立重复中展现出充裕的几何统计显著性，同时支持粗粒度适应度地形与局部行为近邻结构。
- OBP 在大样本下验证了离散、多峰簇状的行为结构。
- OP 在样本扩大至 32 个节点后，三项统计在三重复中系统性同向成立。
- CVRP 在重复 1 再次出现反向（Spearman 为 -0.208），持续否证了在当前 ACO 协议下的行为几何有效性。

## 3. 机制分析与决策

1. **核心科学认识**：
   $$\boxed{\text{fitness 描述解题质量，BehaveSim 描述算法群体的行为位置；二者相关但不等价}}$$
   在消除选父偏差后，TSP、OBP、VRPTW 的搜索档案具有高度稳健的群体几何结构；但表型相近不能直接外推为大模型的代码可修改性相近。
2. **控制器与系统应用**：
   - 准许将 BehaveSim 作为离线宏观诊断工具（分析群体覆盖度、扩散/收缩动力学、跨区域探索步幅）；
   - 鉴于在线长前缀成对计算开销，不在通用搜索循环中实时维护全局行为几何；持续禁止在 CVRP 上启用行为度量。
