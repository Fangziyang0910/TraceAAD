# BehaveSim 算法群体几何校准

## 1. 实验目标与校准协议

本实验校准 BehaveSim 在长序列与随机过程下的度量稳定性，确立其作为**算法群体宏观搜索几何传感器（population-level search geometry sensor）**的有效边界。

- **职责定位**：描述搜索群体的宏观分布（空间拥挤度、收缩或扩散态势、多峰行为岛分布、跨区域步幅），不承担单节点微观潜力预测。
- **两项核心校准**：
  1. **OBP 探针规模匹配**：对比廉价 compact 探针（256-item）与 scale-matched 探针（1000/5000-item）在相同候选集上的距离与 kNN 重合率；
  2. **ACO 随机流去噪**：为 OP 与 CVRP 引入 4 个固定随机流（每候选 16 条 PSTraj），检验面板相关性与随机流子集一致性。
- **样本与数据**：基于 V10.6 的 15 个冻结 run，共 600 个有效节点样本（TSP 每 run 48 点，OBP/VRPTW 每 run 64 点，OP/CVRP 每 run 12 点）。详细数值汇总见 summary.json。

## 3. 机制分析与决策

1. **有效性与边界确立**：
   - 在 TSP、scale-matched OBP 与 VRPTW 上，稳定确认了群体宏观几何假说（“行为越近，群体统计上适应度越近”）；
   - OP 四随机流有效压低了采样噪声，相关性大幅改善；CVRP 因路径随机性与评价方式无法形成稳定几何，**明确停用 CVRP 上的行为几何**。
2. **控制器与系统决策**：
   - 彻底终止尝试利用行为近邻预测单节点 Refine 成功率；
   - BehaveSim 作为宏观传感器保留，用于离线监控群体覆盖与多样性坍缩。
