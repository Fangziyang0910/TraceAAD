# BehaveSim 相似度与 fitness 的关系

数据来自BehaveSim 语义景观实验：TraceAAD V9.16，5 任务 × 3 重复，每 run 在全部两两候选对上同时有 BehaveSim 行为距离（combined 面板均值）与 run 内标准化的 fitness（z 分数，越大越好）。全部为已有工件的离线观察。

## 核心判断

**BehaveSim 行为距离与 fitness 差同向变化：行为越近的候选对，fitness 越接近。** 全局秩相关在 15/15 个 run 为正；TSP、OBP、VRPTW 三任务的三个重复全部稳定成立；OP、CVRP 方向不稳定，按测不准处理。

## 证据

### 1. 全局：全部候选对的距离与 |z 差| 的 Spearman

| 任务 | rep1 | rep2 | rep3 | 方向 |
| --- | ---: | ---: | ---: | --- |
| TSP | 0.59 | 0.57 | 0.64 | 三重复同向 |
| OBP | 0.60 | 0.66 | 0.52 | 三重复同向 |
| VRPTW | 0.42 | 0.42 | 0.45 | 三重复同向 |
| OP | 0.66 | 0.72 | 0.71 | 三重复同向 |
| CVRP | 0.32 | 0.27 | 0.63 | 三重复同向 |

全部 15 个 run 为正（0.27–0.72）。两个 ACO 任务的相关数值同样为正；它们不稳的是下面的局部口径。

### 2. 梯度：按行为距离分箱的中位 |z 差|

每 run 把全部候选对按 BehaveSim 距离分成十箱，最近箱与最远箱的中位 |z 差|：

| 任务 | 最近箱 | 最远箱 | 中间段 |
| --- | ---: | ---: | --- |
| TSP | 0.01–0.03 | 1.55–2.64 | 单调上升 |
| OBP | 0.00–0.01 | 3.27–4.72 | 陡升；rep1 在距离=1.0 的最远端回落到 0.13 |
| VRPTW | 0.09–0.11 | 0.51–0.60 | 0.73–0.78 处峰值 1.2–1.5 后回落 |
| OP | 0.09–0.30 | 2.2–3.4 | 单调上升（每箱仅 50 对） |
| CVRP | 0.02–0.25 | 0.3–2.5 | rep1 无梯度，rep2/3 上升 |

主形态是单调梯度：行为最近的对 fitness 几乎相同（|z 差| ≤ 0.03），行为最远的对差出 1.5–4.7 个标准差。两个尾部例外：OBP rep1 与 VRPTW 的最远端中位差回落——距离接近上限的对（执行过程完全不相干）里含不少"两边都差"的对，两端平、中间陡。

### 3. 局部：行为近邻的 fitness 差显著小于随机对

ΔL = 随机非邻居对 − kNN 邻居对的平均 |z 差|（k = 5%，正值表示行为近邻更平滑）：

| 任务 | rep1 | rep2 | rep3 | 判断 |
| --- | ---: | ---: | ---: | --- |
| VRPTW | 0.62 | 0.62 | 0.53 | 三重复同向，最大 |
| OBP | 0.47 | 0.47 | 0.60 | 三重复同向 |
| TSP | 0.34 | 0.63 | 0.34 | 三重复同向 |
| CVRP | 0.006 | 0.298 | −0.024 | 方向不一致 |
| OP | −0.19 | 0.23 | 0.28 | 方向不一致 |

ACO 任务每 run 只有 32 个抽样点（约 500 对），且距离矩阵面板稳定性最低（Spearman 0.48–0.63）；负值幅度小（−0.02、−0.19），读作噪声下的不可分辨。

### 4. 到最优：距离-差距同向（funnel）

每个候选到该 run 抽样最优候选的行为距离，与其 z 差 gap 的 Spearman 在 15/15 个 run 为正（0.13–0.89）：离最好的算法行为越近，分数差距越小。TSP 最弱（0.17/0.62/0.13），OP 与 CVRP rep3 最强（0.57–0.89）。

## 关联的机械成分

距离和 fitness 由同一个算法函数的执行决定：行为在 probe 上完全重合的两个候选，在训练集上大概率也执行相似，fitness 接近有部分机械成分。有信息量的是两段：中间距离段的单调梯度（行为部分重叠时 fitness 差距已按距离拉开——probe 与训练实例不同分布，梯度不是恒等式给的），以及到最优的 funnel 关系（好算法附近存在越近越好的坡）。

## 边界

1. 结论限 V9.16 的抽样候选集（构造式 128、ACO 32）；抽样最优与 run 搜索最优不同（14/15 的 run 最优不在抽样内），funnel 用抽样最优。
2. OP/CVRP 的局部口径方向不稳定，任务级结论只对 TSP/OBP/VRPTW 声称。
3. 这是相关性证据：支持"围绕高行为相似度区域组织利用"的地形依据，不构成"沿行为梯度改写可行"的生成证据，后者需要机制实验。

## 与文献结论的对照

63 号论文用四类代码相似度（BLEU/AST/dataflow 等）测"相似度-性能差"相关，TSP 上中等、OBP 上弱或不一致。换成 BehaveSim 行为距离后，OBP 上三重复稳定同向且梯度最陡——代码相似度测不出的部分，执行行为补上了。这与 54 号论文"代码近可以行为远、代码远可以行为近"的构造证据一致：fitness 的局部结构挂在执行行为上，不在代码文本上。
