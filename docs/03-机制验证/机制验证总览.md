# 机制验证总览与导航

机制验证用于隔离具体机制、检验核心假设，回答“搜索中观察到的收益究竟来自哪里，下一次设计决策应如何依据试错反馈进行”。

所有机制验证按四大研究主题归整，严格执行「设计与假设 $\to$ 实验数据与事实 $\to$ 核心结论与决策」的规范结构。

## 规范与组织准则

1. **单文件自包含原则**：每个实验目录由单一规范的 `README.md` 承载完整闭环（目标与协议设计 $\to$ 核心实验数据与图表 $\to$ 机制分析与确定性决策），杜绝散落为多个设计/结果文件及频繁的碎片化跳转引用。
2. **写作准则**：
   - 聚焦第一性原理与决策事实，行文直截了当；
   - 坚决杜绝模棱两可的防御性免责辞令（如“不能表明...”、“只是初步探索...”等）。
3. **数据工件命名标准化**：统一采用标准英文名（`summary.json`、`budget_curves.png`、`interaction.png` 等），杜绝带冗余中文前缀或非标临时名。
