# V9.18-R0 边界机会评分消融

## 1. 实验目标与协议

检验在父代选择机制中引入基于边界机会项（Opportunity Score, $O$）的调整，能否改善锚点路由并提高有限预算下的算法搜索与泛化表现。

- **对照臂**：
  - **A0 (`q-atomic`)**：仅基于质量项 $q$ 进行原子选择（基线）；
  - **A1 (`q+O-atomic`)**：在质量项基础上叠加机会评分项 $q + O$。
- **协议设置**：
  - 模型：Qwen3.6-27B，temperature 1.0，Refine=0.7、Explore=0.3。
  - 5 任务 × 3 独立重复 = 30 个运行，同任务同 seed 共享精确 8 根 bootstrap checkpoint，各自运行至 1000 个 primary slots。
  - 测试集泛化只在搜索结束后对各路 train best 进行独立评估。

## 2. 核心实验数据

### 2.1 过程激活事实

- 在 OBP 上，各重复 $\sigma_q = 0$（初始八根质量完全无离散度），选择分布未变，A1 机械退化为 q-only。
- 在其余任务上，每个 primary 决策中有 3%–28% 的选择被非零机会增量改变，平均绝对分数增量为 0.02–0.16（VRPTW 变动最大，OP 变动最小）。

### 2.2 搜索与泛化对比

配对差为 $(q + O) - (q\text{-only})$。除 OP（收益越大越好）外，其余任务路径/箱数越低越好（正差 = q-only 更优）。

## 3. 机制分析与决策

1. **本实验观察**：V9.18-R0 的 $q+O$ 相对 $q$-only 在 TSP200 三重复同向退步；OP200 两个可比较重复也退步，第三个对照程序溢出。其余任务没有稳定的正向证据。OBP 中 $\sigma_q=0$，两臂选择规则等价；OBP 的结果差异不能归因于 $O$。本实验没有单独验证“预算被分流至次优节点”这条完整因果链。
2. **当时的控制器决策**：不继续采用 V9.18-R0 的这个边界机会公式，也不据此增加联合调度复杂度。该结论不排除其他明确限定成本和发展窗口的机会分配方式；是否有效须观察其实际改变的选择、后续开发与 held-out 收益。
