# BehaveSim 行为距离与算法质量差异

## 想验证什么

如果两段程序在任务上的实际决策相近，BehaveSim 测得的距离是否也更小？进一步看，距离相近的程序，其训练成绩是否往往更接近。这里检验行为距离作为群体观察工具的测量性质。

## 怎样检查

从 V10.6 的五个任务、各三路搜索档案中抽取程序，计算行为距离和两两训练分差，并比较近邻程序与随机程序对的分差。每路入选 12 至 64 个程序，共 15 路；其中一条 OBP 路的 64 个入选程序有 63 个成功画像。这里的“全档案”指从搜索档案取样分析，不表示逐一画像档案中的每个节点。

## 看到了什么

| 任务 | 路数 | 行为距离与训练分差的 Spearman 相关均值 | 随机配对分差减近邻分差的均值 |
| --- | ---: | ---: | ---: |
| TSP | 3 | 0.470 | 0.434 |
| CVRP | 3 | 0.358 | 0.329 |
| OP | 3 | 0.709 | 0.399 |
| OBP | 3 | 0.548 | 0.527 |
| VRPTW | 3 | 0.693 | 0.575 |

除 CVRP 的一条路相关为负（-0.208）外，其余路的距离与分差呈正相关。CVRP 每路只入选 12 个程序，比其余任务少；它的逐路结果分别为 -0.208、0.721 和 0.563，路间差异较大。

## 目前怎么理解

行为距离在 TSP、OP、OBP 和 VRPTW 的这些档案样本中可以描述程序行为与质量的局部关系：行为近邻的训练成绩通常更接近。CVRP 的结果不稳。距离的用途首先是描述程序差异；要研究起点选择，可以另测距离与后续改写收益的关系。
