# BehaveSim 群体距离的探针校准

## 想验证什么

行为距离依赖用于重放程序的探针。若换一组探针或随机种子，程序之间的相对距离就大幅改变，那么用它描述整个算法群体也不可靠。这里检查不同探针设置下的距离排序与近邻是否一致，并再次观察距离和训练分差的关系。

## 怎样检查

在 V10.6 的五任务各三路档案样本上比较探针设置。TSP、VRPTW 使用原有两组探针；ACO 任务检查多随机种子探针；OBP 比较紧凑探针和匹配规模的 1000/5000 件物品探针。校准记录了不同探针产生的成对距离 Spearman 相关及近邻重合率。

## 看到了什么

| 任务 | 路数 | 原探针距离排序相关均值 | 行为距离与训练分差相关均值 | 随机配对分差减近邻分差均值 |
| --- | ---: | ---: | ---: | ---: |
| TSP | 3 | 0.754 | 0.533 | 0.809 |
| CVRP | 3 | 0.368 | 0.390 | 0.205 |
| OP | 3 | 0.693 | 0.711 | 0.477 |
| OBP | 3 | 0.901 | 0.541 | 0.878 |
| VRPTW | 3 | 0.832 | 0.539 | 0.545 |

CVRP 原探针的距离排序相关较低，三路为 0.245、0.195、0.665；改用多随机种子设置后，结果仍有较大路间差异。OP 中可观察到距离与分差的关系，但不同种子分半后的稳定性并不充分。OBP 的匹配规模探针保留了较强关系，两种规模的探针应分别记录测量结果。

## 目前怎么理解

在这些样本中，TSP、OBP、VRPTW 的行为距离较稳定，适合描述程序群体；CVRP 对探针敏感，OP 对随机种子敏感。后续分析使用对应任务的稳定测量设置。探针稳定后，可以更可靠地描述行为差异；继续解释开发价值时，再检查相近行为的程序对同类改动是否有相近响应。
