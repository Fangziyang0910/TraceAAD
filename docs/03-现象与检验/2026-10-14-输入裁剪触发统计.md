# 输入裁剪触发统计（2026-10-14）

V12.1 的裁剪主要集中在 DeepSeek 组。Qwen 组很少触发。移除本地长度规则会改变部分提示材料和动作，不能将此前运行视为无裁剪运行。

## 数据与统计方法

直接读取 server3 的已提交事件，扫描开始于 `2026-10-14T08:17:31Z`。各路使用读取时 `resume.json` 保存的提交边界，最后事件时间与字节位置保存在明细。V12.1 为 `20261014_deepseek_co6`、`20261014_qwen_co6`，各六任务两路。V12.0 为已完成的 `20261013_qwen_co6`，六任务三路。V12.1 是运行中快照。

这些运行仍使用启动时配置：`max_input_tokens=24320`、`root_tokens=8000`，不是本地刚删除长度规则后的实现。原始统计见[逐路快照](../../experiments_result/traceaad_v12_1/context_trimming_audit_20261014.json)。

程序的 `attempt.trims` 或 `attempt.link.trims` 非空，就记为一次受影响程序。同一程序删去多条材料只计一次。分母为全部已提交程序，包含初始化、修复、重复和失败。按任务与按动作的加总均与逐路总数核对。
