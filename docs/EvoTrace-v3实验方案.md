# EvoTrace V3：完整搜索与机制评价方案

本方案用于组织当前代表覆盖版V3的完整搜索比较与机制分析。实验采用独立冻结的源码、配置与数据划分；完成情况及可引用结果以[实验与边界台账](记录/README.md)为准。

1. **同预算完整搜索与单次独立测试。** 在相同的16实例训练集、160实例秒8进程并行时限、`Qwen3.8-27B` 解码参数与 $B=1{,}000$ 次实际评价记账口径下，对比无记忆演化基线（`TraceAAD Base`）、容量耦合树演化（`EvoTrace V1`）、近期窗口留存对照以及外部种群、树搜索与反思方法（每任务种子0、1、2）。各路搜索完成后锁定训练最优可行程序，在预留的50实例测试集（500实例秒）上执行一次性测试，报告逐种子测试目标值、训练收敛曲线、执行失败率以及生成、修复与反思词元总开销。
2. **固定快照的经验表示对照（`include_experiences` 检验）。** 在预先声明的评价横截面抽取已提交树快照（不按后续是否改进筛选）。固定树状态、采样的 `parent_id`、`operator`、`reference_id` 与输入词元上限，对比同一批已简化区域的三种输入处理：（a）隐藏经验（`include_experiences = False`）；（b）提供相同移除区域的原始代码差分与评价结果；（c）提供EvoTrace凝练的 $E_u$ 与 $E_{u\to v}$ 笔记。以快照为配对单位统计子代可行率、相对父代胜率、适应度变化与实测输入词元。
3. **谱系原位锚定对扁平经验列表及完整搜索经验消融。** 在相同快照上固定 $E_u / E_{u\to v}$ 笔记文本与词元上限，对比按路径边与基点原位呈现同保留来源编号的扁平时间序列表，分离结构定位相对纯文本可见性的作用；同时采用相同的代表选择、树简化规则与初始条件运行 `include_experiences = True` 与 `False` 的同预算完整搜索对照。该对照保持反思写入，用于考察经验读取对后续搜索的影响；生成内容变化后，实际树状态会随之分化。
4. **代表可替代性与多轮交接保真度审计。** 通过对比从覆盖代表与被覆盖近邻节点（$d<\delta$）重复生成子代的质量分布直接检验覆盖可替代性假设；并分层随机抽取多轮交接后的 $E_u / E_{u\to v}$ 样本，对照 `attempts.jsonl` 与 `observations` 核查涨跌方向准确性与代码改动忠实度。


机制定义见[V3设计](EvoTrace-v3设计.md)，研究主张见[研究概述](树状种群与反思简化.md)。
