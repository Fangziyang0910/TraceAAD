# 动态压缩设计

完整机制与当前规则见[EvoTrace V2：持续生长的树状种群与动态反思简化](EvoTrace-v2设计.md)。

核心仍是树状种群：一次确定保留算法与必要连接，同时剪枝、收缩路径，并让被移除经历转为树上的经验，继续服务生成。访问统计与经验沿同一分区交接。

11月13日的第一版候选曾包含宽8、长6、提前等待8和移除后积累4个再反思。随后[自洽性审查](记录/2026-11-13-动态压缩自洽性审查.md)确认几何提前规则贡献很小、同轮重复选择与保护语义冲突、异步反思积累尚不值得引入。这些规则已撤回。参数回放原件见[历史回放](../experiments_result/analysis/evotrace_compression_sim_20261113/README.md)，不作为当前实现的搜索收益证据。

工作区实现已更新，在线旧批次继续使用其冻结源码。修改与验证见[实施记录](记录/2026-11-13-动态反思简化实现与验证.md)。
