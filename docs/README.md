# TraceAAD：从算法试验中学到了什么

搜索留下许多程序、分数和修改记录。**记录越多，不等于越会设计下一个算法。**目前最有价值的经验，来自检查代码实际改变了什么，以及变化能否在后续开发中兑现。

- **好结构的发现与精炼是两种不同的能力。** TSP 的强结果来自在选点函数内部求解剩余路径；CVRP 的强结果主要来自持续协调已有的几何与容量规则。只看最好程序的祖先链，无法判断应当增加结构探索还是继续精炼。[五任务形成路径](03-机制探索与验证/2026-09-09-强结果形成路径.md)
- **新方向的大幅变化不等于发展潜力。** 18 个固定锚点的两步干预中，没有出现 Pivot 第一步退步、接一次 Refine 后超越起点的案例。若只看第二步相对第一步的增益，会把从严重退化中恢复误认成突破。[Pivot 两步实验](03-机制探索与验证/2026-09-07-Pivot两步价值.md)
- **程序差异与有用的多样性不是一回事。** 初始化对照中，OBP 独立生成的根代码彼此不同，但 112 对中有 98 对在两组行为探针上零距；扩大根的行为距离也没有带来稳定的短程收益。[初始化对照](03-机制探索与验证/2026-09-25-初始化方式对照.md)
- **一次改进不一定值得继续追。** 自适应延长开发在 CVRP 上表现较好，在其他任务上却有相反或混合结果；单次局部增益不能通用地预测下一段开发是否划算。[调度对照](03-机制探索与验证/2026-08-24-自适应调度.md)
