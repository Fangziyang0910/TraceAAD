# TraceAAD：问题、证据与认识

TraceAAD 优先研究 LLM 怎样利用信息与试验结果改进算法：它作出什么选择、怎样改变计算、收益与失败来自哪里。搜索系统用于观察和检验这些过程，再将形成的认识用于改进算法设计方法。阅读从[当前问题与认识](04-研究认识与构想/研究主线与问题.md)开始。

## 写作

先写证据支持的判断，再解释原因与下一步。用具体对象和动作表达认识，同一概念使用同一术语。适用条件与判断放在一起，重要负面结果直接报告。周报用第一人称，文献笔记分清作者实际做法、实验结果和我们的解释。
