# TraceAAD 研究文档

TraceAAD 研究在有限评价预算下，怎样利用已有算法试验改进下一次设计。

正式版本为 [TraceAAD V10.14](01-主线机制设计/TraceAAD-V10.14-机制设计.md)，最终批次完成五任务各四路搜索及独立选择，结果见[正式实验分析](03-机制探索与验证/2026-09-29-V10.14-正式实验结果与分析.md)。代码和批次文件内部保留 `v1014_3` 标识以便复现；旧的[局部重验构想](01-主线机制设计/TraceAAD-V10.14-轨迹重验原始构想.md)作为历史材料单独存档。V10.14 尚无正式 held-out 结果。

建议先看[研究主线与问题](04-研究认识与构想/研究主线与问题.md)。已有正式实验机制见[V10.13 机制设计](01-主线机制设计/TraceAAD-V10.13-机制设计.md)，其他方法的成绩见[正式版本平均结果](02-实验结果/01-正式版本平均结果.md)。
