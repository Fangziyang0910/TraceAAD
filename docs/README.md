# TraceAAD 研究资料

研究目标是利用搜索轨迹中的反馈经验改善后续决策。[研究目标与问题](04-研究认识与构想/研究主线与问题.md)说明主线与关键未知量。阅读从当前问题出发，按需选择直接材料。

## 从轨迹视角进入

搜索轨迹记录算法搜索怎样展开。先确定关心的是整场过程、程序来源还是探索竞争，再按需读取直接材料。

| 视角 | 研究问题 | 材料入口 |
| --- | --- | --- |
| 搜索时间线 | 尝试、失败、停滞和转向怎样先后发生，过去响应怎样影响后续投入？ | [搜索观测](03-现象与检验/2026-09-07-搜索观测与预算分配.md)、[自适应调度](03-现象与检验/2026-08-24-自适应调度.md)、[完整搜索成本](03-现象与检验/2026-10-10-V10.24完整搜索与开发成本.md) |
| 算法演化路径 | 程序怎样形成，参考如何进入不同路径，失败与未被采用的修改意味着什么？ | [形成与参考材料](01-搜索方法/形成历史与生成上下文.md)、[形成路径案例](03-现象与检验/2026-09-09-强结果形成路径.md)、[后续改写](01-搜索方法/生成后的继续改写.md) |
| 探索与竞争过程 | 哪些程序获得机会，什么时候继续、停止或转向，哪些方向尚未充分尝试？ | [多阶段开发](01-搜索方法/生成后的继续改写.md)、[轨迹与动作响应](03-现象与检验/2026-09-07-轨迹状态与算子响应.md)、[机会分配相关工作](05-相关工作/机会分配与搜索规划.md) |

[搜索轨迹的记录与使用](01-搜索方法/搜索轨迹的记录与使用.md)统一列出跨版本用途、重点检验，以及现有实现“保存→选出视图→影响决定”的对应关系。[相关工作横向视图](05-相关工作/README.md)连接历史、记忆、路径规划和经验学习。

形成路径、局部修改和固定父代对照是可选观察范围。成功路线与失败、停滞路线共同帮助理解搜索；局部改善率和固定预算下最终收益分别解释。
