## 文档维护

长期观点按主题维护，一处表达完整认识；新分析优先补入已有主题。正文先讲观点，再展开分析、推论和下一步，来源集中放在需要复核的位置。单篇论文只在确有独立长篇讨论价值时单列，通常归入主题。实验结果只记录配置、正式版本均值、逐路结果以及辅助与分支版本成绩。

日期用于机制验证记录，文件名同时点明验证主题；版本号用于确有独立机制的定义，长期研究认识使用主题名。版本定义写清研究对象、选择规则和证据边界；实现与运行细节进入实验入口。重要研究进展直接更新当周周报，用自己的话讲清做了什么、发现了什么、遇到什么困难，不另建工作流水。

实验方案、运行中快照和完赛结果分别标明状态；历史阶段提出的“下一步”只代表当时决策。旧实验中的失败与反例保留原始工件和适用条件，不因与现行方案不同而删除。
