# TraceAAD 研究资料

当前代码只保留 V12.1，全部实现位于 `traceaad/v12_1/`。旧版本与决策模型的研究记录仍在本目录。旧代码路径和命令属于历史记录，复现时须使用对应批次源码快照或 Git 历史。当前运行入口见 [V12.1](../experiments/traceaad_v12_1/README.md)。

研究目标：利用算法搜索轨迹中的反馈经验改善后续决策，提高有限预算下发现和改进优质算法的效率。

当前方法读 [V12.1：检查代码并补写缺失计算](01-搜索方法/设计核验-V12.1.md)，程序个体与保存方式见[实现说明](../traceaad/v12_1/README.md)。本文档集采用[文档写作约定](文档写作约定.md)。
