## 文档维护

长期观点按主题维护，一处表达完整认识；新分析优先补入已有主题。正文先讲观点，再展开分析、推论和下一步，来源集中放在需要复核的位置。单篇论文只在确有独立长篇讨论价值时单列，通常归入主题。正式结果保留批次、预算、重复与 held-out 信息，运行中的快照标明时间和 partial。

日期用于实验记录，版本号用于确有独立机制的定义，长期研究认识使用主题名。工作过程追加到当周流水，避免再为同一结论建立多份索引或讨论稿。
