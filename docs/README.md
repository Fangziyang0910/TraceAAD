## 怎样维护

| 文档 | 保存什么 | 何时更新 |
| --- | --- | --- |
| 研究问题 | 目标与关键未知量。 | 研究对象或核心问题发生变化时。 |
| 当前认识 | 可复用的判断、解释与依据。 | 新证据改变理解时。 |
| 日期化记录 | 具体问题、实际观察、认识变化与待解问题。 | 完成有意义的研究工作后。 |

新工作先进入相关记录。它改变了可复用的理解，再更新当前认识。实验结论要能定位批次、源码、条件和原始结果。概念分析与文献启发注明来源。

每项事实尽量只维护一处，用链接连接。操作细节集中在实验目录。文档围绕所回答的问题组织，暂不按方法版本建立目录。

## 写作与排版

中文借鉴 [ASD-STE100](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf) 的清晰表达原则。“80%”表示本项目的写作偏好，不是标准合规评分。

- **先给答案。** 开头说明本页解决什么问题，再提供证据与细节。
- **一句一个主要意思。** 写明谁做什么，用明确的因果连接。复杂关系可以分成几句。
- **术语保持稳定。** 首次使用专业词时说明含义；代码字段、公式和原始提示保持准确。
- **按信息关系排版。** 比较用表格，操作用步骤，因果与循环用简图。每段集中说明一件事。
- **让判断对应依据。** 说明哪些是观察，哪些是解释，哪些仍需检验；只在容易混淆时显式标注。
