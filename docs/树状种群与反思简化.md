# 树状种群与反思简化

**EvoTrace将种群竞争与树结构的发展关系结合，并将反思作为搜索经历的压缩过程。树状种群随搜索生长，通过简化相关路径与旁支凝练算法设计经验，再用这些经验支持后续改进、交叉与探索。**

## 研究问题

自动算法设计（automated algorithm design，AAD）需要在有限评价预算下选择候选、产生变化并利用评价反馈。种群竞争决定接下来开发哪些算法；树结构组织算法之间的派生关系，呈现连续修改与分支探索的过程。随着搜索推进，树中的程序和尝试不断增加，如何维护这棵树，并把相关尝试凝练为后续设计可用的经验，是EvoTrace要解决的问题。

EvoTrace以同一棵树组织候选竞争、种群维护和经验使用。节点是参与竞争的算法个体，主父代边记录派生关系。反思在树简化时压缩相关尝试，经验保留在节点与边上，随树更新继续参与生成。

## 树感知的反思简化

当前V3在每次受评个体入树后，按同一快照执行三步维护：

1. **保留活跃个体。** 保留近期出生、被直接开发或被选作交叉参考的独立可行个体，以及全局最优个体。活跃窗口默认为40次评价。
2. **保留分叉并划分区域。** 补齐活跃个体之间的最近公共祖先（lowest common ancestor，LCA），保留发展分叉。其余节点按原树关系分为连接保留端点的路径区域，以及依附保留祖先的旁支区域；路径上的冷退旁支并入对应路径区域。
3. **成批简化与反思。** 区域内冷退节点达到4个时，统一执行结构简化与经验凝练。路径区域的经验写入重连边，旁支区域的经验写入保留祖先；不足阈值的区域继续留在树中。

反思读取区域内的程序、实测结果及已有经验，凝练尝试过的计算思想和算法改进认识。节点与边上的旧经验在后续简化中继续参与凝练，原始比较来源随之保存。

树结构由此决定**哪些尝试一起整理、经验由哪里承接，以及后续生成从哪里读取**。活跃分支扩展时，种群随之扩张；冷退区域成批简化时，树随之收紧。

## 基于同一棵树继续搜索

全体保留的独立可行个体按质量名次与路径最优可行祖先的子树累计投入全局竞争父代机会：未刷新路径纪录的变体共享该祖先的子树投入而不凭零计数反超或刷票，刷新路径纪录的新个体从零投入即时参选，重度开发的分支随累计投入自然降温。Refine读取当前算法的形成路径和局部尝试；Crossover读取共同祖先之后的两条分支；Explore通览种群中的算法思路与经验。三种算子从同一搜索状态中获得各自所需的设计材料。

这一设计将**树状种群的生长与竞争、反思简化中的经验压缩、面向生成的经验使用**连接起来。具体规则、公式与参数见[V3设计](EvoTrace-v3设计.md)，实现入口见[V3包说明](../evotrace_v3/README.md)。

## 证据与文档

当前反思树简化与谱系冷却预算分配已完成结构回放和不变量检查，并在四任务12路新批次中检验完整搜索表现。论文保存的12路V3实验快照使用此前的质量名额、近期窗口与直接投入规则，不能作为新版完整搜索效果的证据。科学表述与机制判断随新证据修正。
