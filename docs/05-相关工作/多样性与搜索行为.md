# 多样性与搜索行为

相关工作用代码结构、语言类别、执行行为或实例表现描述候选差异。这些表示服务于不同决策：保留质量折衷、维护搜索方向、拒绝重复，或分析程序的求解决策。

## 保留什么样的差异

MEoH 在质量与运行时间之间保留折衷；CDEoH 通过类别代表维护多方向；PartEvo 用语言空间的 niche 分配机会。它们分别回答目标折衷、设计家族与表示空间覆盖的问题。

BehaveSim 用求解轨迹比较实际行为，可识别代码不同但选择相近的程序。行为距离依赖实例和随机种子，不能直接等同于未来改写收益。

## 搜索停滞来自哪里

Mutation Without Variation 移除选择后仍观察生成器的重访模式；Fitness Landscape 和 Code Evolution Graphs 刻画被访问区域与结构演化；Optimizer Trajectory Analysis 关注模型的连续精炼能力。这些视角共同说明，停滞可能来自模型生成偏好、选择过度集中、接口限制或可开发结构不足。

同样的“长期不涨分”因此有不同处理方式。若生成反复回到同一规则，可改变材料或操作；若优秀新结构从未再次被选中，可改变机会分配；若候选持续变长而决策未变，可要求精简并检查无效计算。

## 为什么简单基线重要

Understanding Evolutionary Search 将复杂方法与 (1+1)-EPS、独立采样放到共同环境中。Behaviour Space Analysis 将提示、种群和精英保留组合比较。两者都借助简单对照区分生成、选择和种群维护的作用。

## 三种观察尺度

经验景观记录访问过哪些候选及其质量；形成轨迹记录程序怎样被改写和选择；求解轨迹记录候选在实例上怎样作决策。前者适合发现搜索覆盖和局部吸引，第二种适合理解持续开发，第三种适合判断代码差异是否改变实际行为。

选择行为表示时，应让它服务于具体问题。例如 OBP 关注箱子排序，路径问题关注局部移动和可行性，跨规模比较关注计算规则是否仍适用。运行轨迹的相似性也会受到实例和随机种子的影响，因此固定探针后再比较候选。

MEoH 将解质量与运行时间作为不同目标，保留质量—效率折衷。运行时间指被评价启发式的执行时间，与模型生成耗时和代码长度不同；质量—时间折衷也不同于单目标搜索中的行为覆盖。

## 相关工作与来源

<a id="paper-06"></a>
### MEoH

同时优化质量与运行时间，以 Pareto 支配和 AST 相异度共同决定父代选择及种群保留，输出质量—效率折衷。

来源：论文：MEoH；本地来源：`papers/MEoH/MEoH.tex`；设计对象：面向组合优化的启发式代码。

原文入口：[arXiv:2409.16867](https://arxiv.org/abs/2409.16867)

<a id="paper-09"></a>
### CDEoH

生成与评价后归纳算法类别；生存选择先保每类最好者，再按质量和稀有度补足种群，类别不进入生成提示。

来源：论文：*CDEoH: Category-Driven Automatic Algorithm Design With Large Language Models*；本地来源：`main.tex`；设计对象：启发式/算法代码（Online Bin Packing、TSP）。

原文入口：[arXiv:2603.19284](https://arxiv.org/abs/2603.19284)

<a id="paper-49"></a>
### Mutation Without Variation

移除选择压力，反复执行 LLM 变异，观察程序与结构的重访、自环和周期，分离生成器自身的偏置。

来源：论文：*Mutation Without Variation: Convergence Dynamics in LLM-Driven Program Evolution*；本地来源：`papers/Mutation_Without_Variation_Convergence_Dynamics_in_LLM_Driven_Program_Evolution/paper.pdf`；研究对象：无选择压力的 LLM 程序 mutation chain，而非一套新 AAD 方法。

原文入口：[arXiv:2606.05408](https://arxiv.org/abs/2606.05408)

<a id="paper-54"></a>
### BehaveSim

以中间解序列和 DTW 比较程序求解行为，区分代码形式相似与实际策略相似。

来源：论文：[*Rethinking Code Similarity for Automated Algorithm Design with LLMs*](https://arxiv.org/html/2603.02787) 本地论文：`papers/Rethinking_Code_Similarity_for_Automated_Algorithm_Design/paper.pdf`

原文与实现：[来源 1](https://arxiv.org/html/2603.02787)

<a id="paper-60"></a>
### PartEvo

代码相似度或思想嵌入聚类形成 niche，跨 niche 分配机会，内部精英选择，并加入跨 niche 参考。

来源：论文：*Partition to Evolve: Niching-enhanced Evolution with LLMs for Automated Algorithm Discovery*；本地来源：`papers/PartEvo_Partition_to_Evolve/paper.pdf`；正式发表于 NeurIPS 2025；设计对象：完整 meta-heuristic 算法。

原文入口：[NeurIPS Proceedings](https://proceedings.neurips.cc/paper_files/paper/2025/hash/e389b15166cf98966ba058965a8c17e3-Abstract-Conference.html)

<a id="paper-62"></a>
### Understanding the Importance of Evolutionary Search

统一模型、任务、重复和评价预算，比较复杂搜索与极简 (1+1)-EPS、独立随机生成的实际收益。

来源：论文：*Understanding the Importance of Evolutionary Search in Automated Heuristic Design with LLMs*；本地来源：`main.tex`；研究对象：LLM-EPS 方法相对零样本采样与极简基线的真实贡献，批判性重评估而非新方法。

原文入口：[arXiv:2407.10873](https://arxiv.org/abs/2407.10873)

<a id="paper-63"></a>
### Fitness Landscape of LLM-Assisted Algorithm Search

用已访问算法及父子生成边构造经验景观，分析连通、吸引和搜索集中形态。

来源：论文：*Fitness Landscape of LLM-Assisted Automated Algorithm Search*；本地来源：`manucript.tex`；研究对象：LLM 辅助算法搜索的经验适应度景观，分析而非新方法。

原文入口：[arXiv:2504.19636](https://arxiv.org/abs/2504.19636)

<a id="paper-64"></a>
### Code Evolution Graphs

在形成图中记录 AST 特征、复杂度与性能，比较模型如何改变代码结构及其演化。

来源：论文：*Code Evolution Graphs: Understanding Large Language Model Driven Design of Algorithms*；本地来源：LaTeX 源码目录 `Code_Evolution_Graphs_Understanding_Large_Language_Model_Driven_Design_of_Algorithms/`；研究对象：LLM 进化框架中代码结构与复杂度的演化轨迹，诊断工具而非新方法。

原文入口：[arXiv:2503.16668](https://arxiv.org/abs/2503.16668)

<a id="paper-65"></a>
### What Makes an LLM a Good Optimizer（轨迹分析）

固定进化循环比较多个 LLM，分析局部精炼率、父子距离、分布广度与搜索表现的关系。

来源：论文：*What Makes an LLM a Good Optimizer? A Trajectory Analysis*；本地来源：LaTeX 源码目录 `What_Makes_an_LLM_a_Good_Optimizer_Trajectory_Analysis/`；研究对象：15 个 LLM × 8 任务的进化轨迹，什么变量预测优化成功。

原文入口：[arXiv:2604.19440](https://arxiv.org/abs/2604.19440)

<a id="paper-66"></a>
### Behaviour Space Analysis of LLM-driven Meta-heuristic Discovery

组合探索/精炼提示、种群大小和精英保留，记录 BBOB 上的行为覆盖、收敛与停滞。

来源：论文：*Behaviour Space Analysis of LLM-driven Meta-heuristic Discovery*；本地来源：LaTeX 源码目录 `Behaviour_Space_Analysis_of_LLM_driven_Meta_heuristic_Discovery/`；研究对象：被 LLM 生成的元启发式（而非 LLM 本身）在求解时的行为画像，及其与配置/性能的关系。

原文入口：[arXiv:2507.03605](https://arxiv.org/abs/2507.03605)
