# 多样性与搜索行为

[相关工作目录](README.md) · [方法总览](AAD代表方法与机制.md)

多样性描述候选之间的差异。这里比较差异怎样测量，以及它与程序质量、后续改进和搜索停滞有什么关系。代码、语言描述、执行行为与实例表现记录不同层面的差异。

## 差异表示与候选保留

差异的定义决定哪些程序能够共同保留。`MEoH` 同时考虑算法质量和运行时间，`CDEoH` 保留不同算法类别的代表，`PartEvo` 用代码或思想形成的区域分配机会，分别维护目标折衷、算法类别和表示空间中的方向。

执行轨迹记录程序实际作出的选择。`BehaveSim` 用中间求解过程比较行为，可以识别代码不同但选择相近的程序。行为距离随实例与随机种子变化；OBP 的箱子排序、路径问题的移动与可行性、跨规模的计算规则，各自对应不同的行为特征。

算法运行时间也是候选差异的一部分。`MEoH` 保留质量与执行时间的折衷，单目标搜索则关注相同目标下的不同开发方向。模型生成耗时和代码长度描述另外两类成本。

## 搜索停滞的来源与轨迹证据

停滞可能来自生成偏好、选择集中、接口限制或可改进计算的不足。`Mutation Without Variation` 在移除选择后观察生成器的重访模式；`Fitness Landscape` 与 `Code Evolution Graphs` 分析访问区域和代码演化；`Optimizer Trajectory Analysis` 关注模型持续精炼的能力，分别提供生成与搜索过程的证据。

不同轨迹对应不同层次的行为。访问记录描述试过哪些程序，形成历史描述程序怎样被改写，求解轨迹描述程序在实例上怎样作决策。重复生成相同规则、候选缺少后续机会，以及代码增长但决策相近，因而指向不同的停滞解释。

## 简单基线下的搜索收益

在同一环境中比较简单基线，可以判断复杂搜索是否带来额外收益。`Understanding Evolutionary Search` 比较复杂搜索、$(1+1)$-`EPS` 与独立采样；`Behaviour Space Analysis` 比较提示、种群大小和精英保留的组合。结合实际生成和使用的程序，进一步定位差异来自生成、选择还是继续改写。

本地[初始化对照](../03-现象与检验/2026-09-25-初始化方式对照.md)中，行为距离增加与短程收益没有单调关系。后续问题是参考材料改变了哪些计算、这些程序是否参与改写、保留的差异是否带来新增收益。距离测量用于定位比较样本。

## 论文笔记

<a id="paper-06"></a>

### `MEoH`

`MEoH` 的候选保留面向质量与运行时间的折衷，Pareto 支配和 AST 相异度共同参与父代选择及种群维护。

- 论文：MEoH
- 本地资料：`papers/MEoH/MEoH.tex`
- 研究对象：面向组合优化的启发式代码。

论文链接：[arXiv:2409.16867](https://arxiv.org/abs/2409.16867)

<a id="paper-09"></a>

### `CDEoH`

`CDEoH` 用生成与评价后归纳的算法类别组织候选存留。每类最好者获得保留，其余位置按质量和稀有度补足；类别仅用于生存选择。

- 论文：*CDEoH: Category-Driven Automatic Algorithm Design With Large Language Models*
- 本地资料：`main.tex`
- 研究对象：启发式/算法代码（Online Bin Packing、TSP）。

论文链接：[arXiv:2603.19284](https://arxiv.org/abs/2603.19284)

<a id="paper-49"></a>

### `Mutation Without Variation`

Mutation Without Variation 以移除选择压力的变异链研究生成器偏置，记录反复 LLM 变异中的程序与结构重访、自环和周期。

- 论文：*Mutation Without Variation: Convergence Dynamics in LLM-Driven Program Evolution*
- 本地资料：`papers/Mutation_Without_Variation_Convergence_Dynamics_in_LLM_Driven_Program_Evolution/paper.pdf`
- 研究对象：无选择压力的 LLM 程序 mutation chain 及生成偏置分析。

论文链接：[arXiv:2606.05408](https://arxiv.org/abs/2606.05408)

<a id="paper-54"></a>

### `BehaveSim`

`BehaveSim` 用中间解序列与 DTW 描述程序求解行为，将程序之间的比较落实到实际策略，并呈现代码形式与执行行为之间的差异。

- 论文：[*Rethinking Code Similarity for Automated Algorithm Design with LLMs*](https://arxiv.org/html/2603.02787)
- 本地资料：`papers/Rethinking_Code_Similarity_for_Automated_Algorithm_Design/paper.pdf`

补充链接：[来源 1](https://arxiv.org/html/2603.02787)

<a id="paper-60"></a>

### `PartEvo`

`PartEvo` 以代码相似度或思想嵌入聚类形成 niche，分别组织跨区域机会分配、区域内精英选择与跨区域参考。

- 论文：*Partition to Evolve: Niching-enhanced Evolution with LLMs for Automated Algorithm Discovery*
- 本地资料：`papers/PartEvo_Partition_to_Evolve/paper.pdf`
- 正式发表于 NeurIPS 2025
- 研究对象：完整 meta-heuristic 算法。

论文链接：[NeurIPS Proceedings](https://proceedings.neurips.cc/paper_files/paper/2025/hash/e389b15166cf98966ba058965a8c17e3-Abstract-Conference.html)

<a id="paper-62"></a>

### Understanding the Importance of Evolutionary Search

共同的模型、任务、重复和评价预算，为复杂搜索、极简 $(1+1)$-`EPS` 与独立随机生成提供比较环境，考察各类搜索的实际收益。

- 论文：*Understanding the Importance of Evolutionary Search in Automated Heuristic Design with LLMs*
- 本地资料：`main.tex`
- 研究对象：`LLM-EPS` 方法相对零样本采样与极简基线的真实贡献，属于搜索方法的批判性重评估。

论文链接：[arXiv:2407.10873](https://arxiv.org/abs/2407.10873)

<a id="paper-63"></a>

### Fitness Landscape of LLM-Assisted Algorithm Search

已访问算法与父子生成边共同构成经验适应度景观，该工作据此分析连通、吸引与搜索集中形态。

- 论文：*Fitness Landscape of LLM-Assisted Automated Algorithm Search*
- 本地资料：`manucript.tex`
- 研究对象：LLM 辅助算法搜索的经验适应度景观分析。

论文链接：[arXiv:2504.19636](https://arxiv.org/abs/2504.19636)

<a id="paper-64"></a>

### `Code Evolution Graphs`

形成图记录程序演化中的 AST 特征、复杂度与性能，可用于比较不同模型带来的代码结构变化。

- 论文：*Code Evolution Graphs: Understanding Large Language Model Driven Design of Algorithms*
- 本地资料：LaTeX 源码目录 `Code_Evolution_Graphs_Understanding_Large_Language_Model_Driven_Design_of_Algorithms/`
- 研究对象：LLM 进化框架中代码结构与复杂度的演化轨迹，属于搜索诊断工具。

论文链接：[arXiv:2503.16668](https://arxiv.org/abs/2503.16668)

<a id="paper-65"></a>

### What Makes an LLM a Good Optimizer（轨迹分析）

该工作在固定进化循环中比较多个 LLM 的优化表现，局部精炼率、父子距离和分布广度用于分析搜索表现的差异。

- 论文：*What Makes an LLM a Good Optimizer? A Trajectory Analysis*
- 本地资料：LaTeX 源码目录 `What_Makes_an_LLM_a_Good_Optimizer_Trajectory_Analysis/`
- 研究对象：15 个 LLM × 8 任务的进化轨迹及优化成功的预测因素。

论文链接：[arXiv:2604.19440](https://arxiv.org/abs/2604.19440)

<a id="paper-66"></a>

### Behaviour Space Analysis of LLM-driven Meta-heuristic Discovery

探索与精炼提示、种群大小和精英保留构成不同搜索配置，该工作以 BBOB 上的行为覆盖、收敛和停滞描述配置的效果。

- 论文：*Behaviour Space Analysis of LLM-driven Meta-heuristic Discovery*
- 本地资料：LaTeX 源码目录 `Behaviour_Space_Analysis_of_LLM_driven_Meta_heuristic_Discovery/`
- 研究对象：LLM 生成的元启发式在求解时的行为画像，及其与配置/性能的关系。

论文链接：[arXiv:2507.03605](https://arxiv.org/abs/2507.03605)
