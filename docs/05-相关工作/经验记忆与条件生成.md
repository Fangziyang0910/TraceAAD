# 经验记忆与条件生成

[相关工作目录](README.md) · [方法总览](AAD代表方法与机制.md)

经验记忆为后续生成提供过去试验中的代码、修改与反馈。保存方式决定哪些信息留下来，检索方式决定当前设计读取哪些经验。

## 经验的保存形式与适用条件

反思建议将多次试验压缩为可用于生成的文字。`ReEvo` 从好坏候选的比较中形成建议；`HiFo-Prompt`、`RefineEvo` 和 `CogMCTS` 维护知识、适用条件与正负经验。`MeLA` 与 `MeEvo` 则将总结和代码生成相互配合，让已有试验参与后续设计。

保留代码变化与形成关系，有助于将经验对应到具体修改。`DeltaEvolve` 保存父子之间的语义改动，`PhyloEvolve` 用谱系组织不同路径，`MEMOIR` 同时保存分支内经验和跨分支原则。原始记录提供可回查的条件与细节，文字总结更紧凑，但压缩也可能丢失父代和任务背景。

## 知识来源与经验检索

经验可以来自不断积累的搜索记录，也可以来自外部知识。`Experience-Guided CoEvolution` 与 `Back to the Beginning` 将提示或知识纳入演化；`GeoEvolve` 引入领域知识。`Memento-2` 将记忆检索视为策略动作，`Experience Memory Graph` 通过图匹配提炼纠错经验，关注当前状态与已有经验的对应关系。

要确认经验是否帮助了算法改进，需要检查三个环节：是否检索到相关经验，是否落实为代码变化，以及是否改变执行行为。最终分数反映整体效果；检索记录、代码变化与执行结果有助于定位作用环节和适用条件。

相关方法的具体做法见[算子与上下文综述](LLM-AAD中的算子设计与上下文组织调研.md)。

## 论文笔记

<a id="paper-15"></a>

### `ReEvo`

`ReEvo` 将好坏程序的比较转为短期反思，并跨轮积累长期建议，为交叉与精英变异提供生成指导。

- 论文：ReEvo
- 本地资料：main.tex，含 `sections/` 与 `appendix/`
- 研究对象：以 LLM 生成可执行启发式代码的语言超启发式。

论文链接：[arXiv:2402.01145](https://arxiv.org/abs/2402.01145)

<a id="paper-16"></a>

### `HiFo-Prompt`

`HiFo-Prompt` 的生成指导同时包含 hindsight 与 foresight：前者来自精英代码中的已有经验，后者依据搜索进展表达探索意图，两者通过知识检索与提示参与生成。

- 论文：HiFo-Prompt: Prompting with Hindsight and Foresight for LLM-based AHD
- 本地资料：templateArxiv.tex
- 研究对象：组合优化与 BO 的启发式/策略提示生成。

论文链接：[arXiv:2508.13333](https://arxiv.org/abs/2508.13333)

<a id="paper-17"></a>

### `Experience-Guided Reflective Co-Evolution`

提示与启发式代码共同成为演化对象，代码反馈也用于改进提示。从调参到重写的多档变异表达不同修改强度，档案维护多方向结果。

- 论文：Experience-Guided Reflective Co-Evolution of Prompts and Heuristics
- 本地资料：iclr2026_conference.tex
- 研究对象： AHD 中 prompt 与启发式代码的协同演化。

论文链接：[arXiv:2509.24509](https://arxiv.org/abs/2509.24509)

<a id="paper-18"></a>

### `MeLA`

`MeLA` 将经验总结与程序调试分工。反思模型汇总思考过程、错误和精英代码，为下一轮提供指导；独立调试器处理不可执行候选。

- 论文：MeLA: Metacognitive LLM-Driven Architecture for Automatic Heuristic Design
- 本地资料：main.tex
- 研究对象： LLM 自动生成组合优化启发式。

论文链接：[arXiv:2507.20541](https://arxiv.org/abs/2507.20541)

<a id="paper-19"></a>

### `MeEvo`

`MeEvo` 将推理轨迹作为可继承信息，使经验总结与代码演化交替进行，并将总结用于后续候选设计。

- 论文：MeEvo: Metacognitive Evolution for Automatic Heuristic Design
- 本地资料：main.tex
- 研究对象：可执行启发式程序的进化。

论文链接：[arXiv:2606.14202](https://arxiv.org/abs/2606.14202)

<a id="paper-20"></a>

### `DeltaEvolve`

`DeltaEvolve` 的经验单位是父子 semantic delta，记录修改内容及其结果。分层检索选择少量高质量或不同方向的变化，与父代代码共同构成生成条件。

- 论文：DeltaEvolve: Accelerating Scientific Discovery through Momentum-Driven Evolution
- 本地资料：main.tex，分文件 `3_framework.tex`、`4_methods.tex`、`5_experiments.tex`、`appendix.tex`
- 研究对象：科学代码/候选的迭代进化。

论文链接：[arXiv:2602.02919](https://arxiv.org/abs/2602.02919)

<a id="paper-21"></a>

### `PhyloEvolve`

`PhyloEvolve` 以系统发育树组织候选及亲缘关系，为不同分支保存可继续开发的形成历史。

- 论文：PhyloEvolve: LLM-Powered Evolutionary Code Optimization on a Phylogenetic Tree
- 本地资料：main.tex，含 `4_method.tex`、`5_experiments.tex`
- 研究对象：代码优化的谱系树搜索。

论文链接：[arXiv:2601.14523](https://arxiv.org/abs/2601.14523)

<a id="paper-26"></a>

### `CogMCTS`

`CogMCTS` 将候选比较得到的正负知识用于 `MCTS` 扩展，为后续生成提供知识；选择公式沿用 `MCTS-AHD`。

- 论文：CogMCTS: Cognitive-Guided MCTS for Iterative Heuristic Evolution
- 本地资料：ijcai26.tex
- 研究对象： ACO、GLS 和构造式组合优化启发式。

论文链接：[arXiv:2512.08609](https://arxiv.org/abs/2512.08609)

<a id="paper-27"></a>

### `RefineEvo`

`RefineEvo` 将种群进展与经验检索共同用于动作选择。Planner 决定探索或开发，正负经验库提供适用建议，停滞时可重写算子提示。

- 论文：RefineEvo: Planning-Guided Heuristic Evolution with Bidirectional Experience
- 本地资料：main.tex，分文件 `03_method.tex`、`04_experiment.tex`、`06_appendix.tex`
- 研究对象：组合优化的启发式进化。

论文链接：[arXiv:2607.11358](https://arxiv.org/abs/2607.11358)

<a id="paper-45"></a>

### Back to the Beginning of Heuristic Design

设计原则与假设成为可演化的对象，代码生成及执行为其提供检验。该工作也探索知识群体与代码群体的共同维护。

- 论文：*Back to the Beginning of Heuristic Design: Bridging Code and Knowledge with LLMs*
- 本地资料：`papers/Back_to_the_Beginning_of_Heuristic_Design_Bridging_Code_and_Knowledge_with_LLMs/paper.pdf`
- 研究对象：可解释知识状态及其实例化的启发式代码。

论文链接：[arXiv:2605.06123](https://arxiv.org/abs/2605.06123)

<a id="paper-47"></a>

### `MEMOIR`

`MEMOIR` 同时保存分支内经验与跨分支原则。局部记忆记录修改和故障，分支结束后的总结将算法原则与失败模式写入全局记忆，为后续分支提供起步经验。

- 论文：*Memory-Guided Tree Search with Cross-Branch Knowledge Transfer for LLM Solver Synthesis*
- 本地资料：`papers/Memory_Guided_Tree_Search_with_Cross_Branch_Knowledge_Transfer/paper.pdf`
- 研究对象：完整组合优化 solver。

论文链接：[arXiv:2605.17539](https://arxiv.org/abs/2605.17539)

<a id="paper-59"></a>

### `GeoEvolve`

`GeoEvolve` 将外部地理知识作为程序进化的生成材料。代码分析提出查询，领域检索提供知识，检索结果进入下一轮提示。

- 论文：*GeoEvolve: Automating Geospatial Model Discovery via Multi-Agent Large Language Models*
- 本地资料：`papers/GeoEvolve_Automating_Geospatial_Model_Discovery/paper.pdf`
- 研究对象：Kriging 与 geospatial conformal prediction 算法。

论文链接：[arXiv:2509.21593](https://arxiv.org/abs/2509.21593)

<a id="paper-70"></a>

### `Memento 2`

`Memento 2` 将记忆检索纳入策略动作，把固定 LLM 视为环境的一部分，研究记忆读写对后续行动的作用。

- 论文：*Memento 2: Learning by Stateful Reflective Memory*
- 本地资料：LaTeX 源码目录 `Memento_2_Learning_by_Stateful_Reflective_Memory/`
- 研究对象：冻结参数、靠情景记忆 + 反思持续学习的 LLM 智能体的 RL 理论（纯理论，无新实验）。

论文链接：[arXiv:2512.22716](https://arxiv.org/abs/2512.22716)

<a id="paper-71"></a>

### `Experience Memory Graph`

`Experience Memory Graph` 以动作决策图组织探索与专家轨迹，通过图匹配提炼纠错经验和跨任务共性，再以检索洞见指导执行。

- 论文：*Experience Memory Graph: One-Shot Error Correction for Agents*
- 本地资料：LaTeX 源码目录 `Experience_Memory_Graph_One-Shot_Error_Correction_for_Agents/`
- 研究对象：把 agent 失败恢复从在线反思-重放循环改为离线确定性图计算的记忆结构。

论文链接：[arXiv:2607.13884](https://arxiv.org/abs/2607.13884)
