# 经验记忆与条件生成

相关工作把搜索历史保存为反思文字、完整程序、父子改动、谱系关系或可检索记忆。它们的区别在于保留了哪些条件，以及这些材料怎样进入下一次生成。

算子与上下文的区别见[专题综述](LLM-AAD中的算子设计与上下文组织调研.md)。

## 从反思到可检索经验

ReEvo 将好坏候选比较压缩成语言建议，HiFo-Prompt、RefineEvo 和 CogMCTS 进一步维护知识、适用条件和正负经验。MeLA 与 MeEvo 把总结与代码生成交替安排，试图让下一轮设计吸收已有试验。

语言建议压缩了程序和评价记录，但可能丢失适用的父代与任务条件。检验这类记忆时，需要区分建议是否被检索、是否进入代码，以及是否改变真实算法行为。

## 形成边与分支记忆

DeltaEvolve 保存 semantic delta，PhyloEvolve 用谱系组织不同发展路径，MEMOIR 把分支内经验与跨分支原则分开。它们提供了三种互补的记忆粒度：一次改动、一段发展和跨路径规律。

原始代码和形成关系保留可检查的计算，语言总结能压缩历史，也会丢失细节。

## 记忆也可以成为搜索对象

Experience-Guided CoEvolution 和 Back to the Beginning 将提示或知识纳入演化。Memento-2 从检索策略理解记忆作用，Experience Memory Graph 通过图匹配提炼可复用纠错。GeoEvolve 则引入搜索历史以外的领域知识。

这些方法也分别处理知识供给、相关经验检索和代码实现。仅观察最终分数，很难辨别收益来自哪一个环节。

## 相关工作与来源

<a id="paper-15"></a>
### ReEvo

好坏程序对比形成短期反思，跨轮积累长期建议，再用交叉和精英变异生成代码。

来源：论文：ReEvo；本地来源：main.tex，含 `sections/` 与 `appendix/`；设计对象是以 LLM 生成可执行启发式代码的语言超启发式。

原文入口：[arXiv:2402.01145](https://arxiv.org/abs/2402.01145)

<a id="paper-16"></a>
### HiFo-Prompt

从精英代码提炼 hindsight insight，并根据搜索进展生成 foresight 指导；知识检索和探索意图共同进入提示。

来源：论文：HiFo-Prompt: Prompting with Hindsight and Foresight for LLM-based AHD；本地来源：templateArxiv.tex；设计对象为组合优化与 BO 的启发式/策略提示生成。

原文入口：[arXiv:2508.13333](https://arxiv.org/abs/2508.13333)

<a id="paper-17"></a>
### Experience-Guided Reflective Co-Evolution

代码反馈同时推动提示演化；从调参到重写的多档变异表达不同改动强度，档案保存多方向结果。

来源：论文：Experience-Guided Reflective Co-Evolution of Prompts and Heuristics；本地来源：iclr2026_conference.tex；设计对象是 AHD 中 prompt 与启发式代码的协同演化。

原文入口：[arXiv:2509.24509](https://arxiv.org/abs/2509.24509)

<a id="paper-18"></a>
### MeLA

反思模型汇总思考过程、错误与精英代码，生成下一轮指导；独立调试器处理不可执行候选。

来源：论文：MeLA: Metacognitive LLM-Driven Architecture for Automatic Heuristic Design；本地来源：main.tex；设计对象为 LLM 自动生成组合优化启发式。

原文入口：[arXiv:2507.20541](https://arxiv.org/abs/2507.20541)

<a id="paper-19"></a>
### MeEvo

把推理轨迹作为可继承信息，交替执行代码演化与元认知改进，使经验总结和候选搜索轮流推进。

来源：论文：MeEvo: Metacognitive Evolution for Automatic Heuristic Design；本地来源：main.tex；设计对象为可执行启发式程序的进化。

原文入口：[arXiv:2606.14202](https://arxiv.org/abs/2606.14202)

<a id="paper-20"></a>
### DeltaEvolve

以父子 semantic delta 保存“改了什么、结果怎样”，分层检索少量高质量或不同方向的变化，与父代代码共同生成。

来源：论文：DeltaEvolve: Accelerating Scientific Discovery through Momentum-Driven Evolution；本地来源：main.tex，分文件 `3_framework.tex`、`4_methods.tex`、`5_experiments.tex`、`appendix.tex`；设计对象为科学代码/候选的迭代进化。

原文入口：[arXiv:2602.02919](https://arxiv.org/abs/2602.02919)

<a id="paper-21"></a>
### PhyloEvolve

用系统发育树组织候选及亲缘关系，为不同分支保存可继续开发的历史。

来源：论文：PhyloEvolve: LLM-Powered Evolutionary Code Optimization on a Phylogenetic Tree；本地来源：main.tex，含 `4_method.tex`、`5_experiments.tex`；设计对象是代码优化的谱系树搜索。

原文入口：[arXiv:2601.14523](https://arxiv.org/abs/2601.14523)

<a id="paper-26"></a>
### CogMCTS

在 MCTS 扩展前比较候选、归纳正负知识，再将指导加入生成；选择公式沿用 MCTS-AHD。

来源：论文：CogMCTS: Cognitive-Guided MCTS for Iterative Heuristic Evolution；本地来源：ijcai26.tex；设计对象是 ACO、GLS 和构造式组合优化启发式。

原文入口：[arXiv:2512.08609](https://arxiv.org/abs/2512.08609)

<a id="paper-27"></a>
### RefineEvo

Planner 根据种群进展选择探索或开发，正负经验库检索适用建议，停滞时还可重写算子提示。

来源：论文：RefineEvo: Planning-Guided Heuristic Evolution with Bidirectional Experience；本地来源：main.tex，分文件 `03_method.tex`、`04_experiment.tex`、`06_appendix.tex`；设计对象为组合优化的启发式进化。

原文入口：[arXiv:2607.11358](https://arxiv.org/abs/2607.11358)

<a id="paper-45"></a>
### Back to the Beginning of Heuristic Design

先演化原则或假设，再生成代码检验，并探索知识群体与代码群体共同维护。

来源：论文：*Back to the Beginning of Heuristic Design: Bridging Code and Knowledge with LLMs*；本地来源：`papers/Back_to_the_Beginning_of_Heuristic_Design_Bridging_Code_and_Knowledge_with_LLMs/paper.pdf`；设计对象：可解释知识状态及其实例化的启发式代码。

原文入口：[arXiv:2605.06123](https://arxiv.org/abs/2605.06123)

<a id="paper-47"></a>
### MEMOIR

分支内保存修改与故障，分支结束后提炼算法原则和失败模式到全局记忆，帮助后续分支起步。

来源：论文：*Memory-Guided Tree Search with Cross-Branch Knowledge Transfer for LLM Solver Synthesis*；本地来源：`papers/Memory_Guided_Tree_Search_with_Cross_Branch_Knowledge_Transfer/paper.pdf`；设计对象：完整组合优化 solver。

原文入口：[arXiv:2605.17539](https://arxiv.org/abs/2605.17539)

<a id="paper-59"></a>
### GeoEvolve

代码分析提出领域知识查询，经地理知识检索构造下一轮生成提示，连接领域知识与程序进化。

来源：论文：*GeoEvolve: Automating Geospatial Model Discovery via Multi-Agent Large Language Models*；本地来源：`papers/GeoEvolve_Automating_Geospatial_Model_Discovery/paper.pdf`；设计对象：Kriging 与 geospatial conformal prediction 算法。

原文入口：[arXiv:2509.21593](https://arxiv.org/abs/2509.21593)

<a id="paper-70"></a>
### Memento 2

将检索记忆视为策略动作，把固定 LLM 纳入环境，分析读写记忆如何改善后续行动。

来源：论文：*Memento 2: Learning by Stateful Reflective Memory*；本地来源：LaTeX 源码目录 `Memento_2_Learning_by_Stateful_Reflective_Memory/`；研究对象：冻结参数、靠情景记忆 + 反思持续学习的 LLM 智能体的 RL 理论（纯理论，无新实验）。

原文入口：[arXiv:2512.22716](https://arxiv.org/abs/2512.22716)

<a id="paper-71"></a>
### Experience Memory Graph

将探索与专家轨迹组织为动作决策图，通过图匹配提炼纠错和跨任务共性，再检索洞见指导执行。

来源：论文：*Experience Memory Graph: One-Shot Error Correction for Agents*；本地来源：LaTeX 源码目录 `Experience_Memory_Graph_One-Shot_Error_Correction_for_Agents/`；研究对象：把 agent 失败恢复从在线反思-重放循环改为离线确定性图计算的记忆结构。

原文入口：[arXiv:2607.13884](https://arxiv.org/abs/2607.13884)
