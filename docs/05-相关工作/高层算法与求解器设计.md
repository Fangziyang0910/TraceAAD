# 高层算法与求解器设计

[相关工作目录](README.md) · [方法总览](AAD代表方法与机制.md)

设计对象决定自动算法设计的搜索范围。评分函数、算法组件、启发式集合、问题约简、完整求解器与设计器本身，允许模型修改不同层面的计算，也对应不同的评价和部署成本。

## 互补启发式与实例覆盖

启发式集合利用成员在不同实例上的互补表现。`EoH-S` 优化集合的实例覆盖，`InstSpecHH` 为不同实例选择成员，适合任务分布分化、单一规则难以覆盖的情形。集合在部署时保留多个求解器，并通过成员选择或组合发挥作用；生成阶段的程序融合则将参考计算整合到一个新程序中。

## 问题表示与求解器结构的联合设计

设计范围扩大后，搜索也可以修改原先由人固定的控制流程。`RedAHD` 搜索问题约简与模板，`A2DEPT` 开放完整求解器，`BEAM` 分开搜索算法结构与函数实现，`DGA²D` 用算子图生成算法流程。

分层设计将结构选择与组件实现分开，使模型可以集中处理各层任务。结构变化也可能使已有组件失效，因此，需要利用阶段反馈、组件接口和可复用代码协调不同层次。整体评价反映结构与实现配合后的效果。

## 计算组件与设计过程的复用

复用对象可以从算法组件延伸到设计过程。`Hercules` 与 `AutoSND` 从已有程序中提取组件或结构策略，支持后续搜索；`MoH` 在外层设计优化器，以其产生的下游启发式评价跨任务效用。

问题表示、算法主体、组件、参数和运行控制构成不同层次的设计范围。评价预算、有效候选比例与部署成本，则描述在这些范围内搜索并使用结果所付出的资源。

## 论文笔记

<a id="paper-10"></a>

### `EoH-S`

`EoH-S` 以互补启发式集合为设计对象，用逐实例最优成员的平均表现评价覆盖，并贪心保留互补成员。部署时由成员选择策略决定实例使用的启发式。

- 论文：*EoH-S: Evolution of Heuristic Set using LLMs for Automated Heuristic Design*
- 本地资料：`eohs.tex`
- 研究对象：一组协作/组合使用的启发式集合。

论文链接：[arXiv:2508.03082](https://arxiv.org/abs/2508.03082)

<a id="paper-29"></a>

### `RedAHD`

RedAHD 同时搜索问题约简、实例映射、解映射和模板，因此也能更换基础求解框架。

- 论文：*Reduction-Based End-to-End Automatic Heuristic Design with Large Language Models*
- 本地资料：`papers/RedAHD_Reduction_Based_End_to_End_Automatic_Heuristic_Design_with_Large_Language_Models/main_neurips.tex`
- 研究对象：从问题描述到可执行启发式的端到端 COP 设计。

论文链接：[arXiv:2505.20242](https://arxiv.org/abs/2505.20242)

<a id="paper-30"></a>

### `Hercules`

`Hercules` 用精英计算组件指导候选生成。扩展版本利用性能与置信度预测选择实际评价的候选，以减少搜索时间。

- 论文：*Efficient Heuristics Generation for Solving Combinatorial Optimization Problems Using Large Language Models*
- 本地资料：`papers/Efficient_Heuristics_Generation_for_Solving_Combinatorial_Optimization_Problems_Using_La/sample-sigconf.tex`
- 研究对象：GLS、构造式、ACO 启发信息与 NCO attention 重塑。

论文链接：[arXiv:2505.12627](https://arxiv.org/abs/2505.12627)

<a id="paper-31"></a>

### `MoH`

`MoH` 的外层设计对象是启发式优化器，其评价依据是内层在多个任务上产生的启发式表现，以跨任务效用选择元优化器。

- 论文：*Generalizable Heuristic Generation Through LLMs with Meta Optimization*
- 本地资料：`papers/Generalizable_Heuristic_Generation_Through_LLMs_with_Meta_Optimization/main.tex`
- 研究对象：用于生成与改进启发式的优化器。

论文链接：[arXiv:2505.20881](https://arxiv.org/abs/2505.20881)

<a id="paper-32"></a>

### `InstSpecHH`

`InstSpecHH` 用实例子类对应的启发式库支持在线算法选择。规则在离线阶段生成，近邻迁移扩充候选，部署时由实例特征选择成员。

- 论文：*LLM-Driven Instance-Specific Heuristic Generation and Selection*
- 本地资料：`papers/LLM_Driven_Instance_Specific_Heuristic_Generation_and_Selection/main.tex`（含 `section/framework.tex`、`section/experiments.tex`、`supp_content.tex`）
- 研究对象：按实例生成并选择的启发式库。

论文链接：[arXiv:2506.00490](https://arxiv.org/abs/2506.00490)

<a id="paper-33"></a>

### `A2DEPT`

`A2DEPT` 将完整 solver 纳入搜索，程序树保存形成历史，退火接受与历史节点抽样支持结构探索，通过维护流程处理生成的开放代码。

- 论文：*A2DEPT: Large Language Model–Driven Automated Algorithm Design via Evolutionary Program Trees*
- 本地资料：`papers/A2DEPT_Large_Language_Model_Driven_Automated_Algorithm_Design_via_Evolutionary_Program_T/paper.tex`
- 研究对象：完整可执行 solver 程序。

论文链接：[arXiv:2604.24043](https://arxiv.org/abs/2604.24043)

<a id="paper-34"></a>

### `BEAM`

`BEAM` 将算法结构与函数实现分层设计：外层 `GA` 搜索结构，内层 `MCTS` 完善函数。外部记忆保存可复用函数，并配合参数校准。

- 论文：*BEAM: Bi-level Memory-adaptive Algorithmic Evolution for LLM-Powered Heuristic Design*
- 本地资料：`papers/BEAM_Bi-level_Memory-adaptive_Algorithmic_Evolution/bare_jrnl_new_sample4.tex`，含 `sections/beam_framework.tex`、`sections/benchmark.tex`、`sections/experiments.tex`、`sections/appendix.tex`
- 研究对象：完整求解器（算法结构 + 函数实现）。

论文链接：[arXiv:2604.12898](https://arxiv.org/abs/2604.12898)

<a id="paper-51"></a>

### `DGA²D`

`DGA²D` 用带实现的算子图表示算法，策略采样 pipeline。终端收益分配到实现转移与边，为图结构和策略调整提供依据。

- 论文：*DGA²D: Directed Graph-Guided Automated Algorithm Design*
- 本地资料：`papers/DGA2D_Directed_Graph_Guided_Automated_Algorithm_Design/paper.pdf`
- 研究对象：由功能算子有向 walk 组成的完整算法 pipeline。

论文链接：[arXiv:2608.00700](https://arxiv.org/abs/2608.00700)

<a id="paper-52"></a>

### `AutoSND`

`AutoSND` 用广搜中的执行状态和操作记录提炼结构策略，为后续树搜索提供指导，分别优化质量与速度。

- 论文：*AutoSND: From Execution Evidence to Structural Policies for Automated Network Dismantling Heuristic Discovery*
- 本地资料：`papers/AutoSND_Execution_Evidence_to_Structural_Policies/paper.pdf`
- 研究对象：完整网络拆解程序。

论文链接：[arXiv:2608.03653](https://arxiv.org/abs/2608.03653)
