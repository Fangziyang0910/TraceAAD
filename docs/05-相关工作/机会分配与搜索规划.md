# 机会分配与搜索规划

程序当前质量与继续开发的预期收益是不同量。相关工作分别在节点、程序簇、谱系或运行阶段分配机会；所选单位决定后代信息怎样积累，以及预算在深度与广度之间怎样分配。

## 分配对象决定能够学习什么

QUBE 在程序簇上积累子代表现，MCTS-AHD 用树组织扩展，Clade-AHD 将后代信息共享到分支，BaSE 在运行之间分配深度与广度。REx 的代码修复模型把每个程序视作新出现的臂。选择哪个单位，决定观测能否反复积累，也决定不同程序是否共享信用。

逐节点统计在新节点不断出现的搜索中容易稀疏；簇或谱系共享信用能增加样本，却可能合并发展价值不同的程序。这是上述方法在分配单位上的主要取舍。

## 规划带来的额外信息

PoH 和 PathWise 在一个状态下展开多个建议或实现，比较短期后果后再决定方向。规划的收益来自看到了普通单步搜索尚未看到的结果，也占用相应生成与评价预算。

规划会占用额外生成与评价预算，因此短路径比较的收益应与同预算的连续开发比较；多看几步本身不保证更好的最终程序。

## 深度、广度与接力

BaSE 把预算写成深度与并行子代数的组合，RelayEvolve 则先由廉价模型探索，再将候选群交给强模型精炼。两者都强调搜索的阶段性：早期建立可发展的起点，后期将预算集中到仍能产生进展的方向。

SMCEvolve 从概率分布视角联结选择压力、接受和停止。重加权、重采样与变异共同塑造被保留的程序分布，但各环节对收益的贡献仍需分别识别。

## 选择压力、信用与时间安排

质量排名、尝试次数和后续收益回答不同问题。排名表示当前程序的位置；次数表示直接开发机会；后续收益描述一段开发链的结果。QUBE、Clade-AHD 和固定算子池方法分别把这些信息记在不同单位上。

锦标赛和排名抽样适合作为透明基线。若排名 r=1 为最差、r=N 为最好，有放回 k 元锦标赛的选择概率为 `p_r=(r/N)^k-((r-1)/N)^k`。增大 k 会集中开发，质量 softmax 的温度和 ESS 也调节类似的选择压力。比较时应匹配实际竞争范围，并对同分候选保持对称。

FRRMAB 先在近期窗口累计算子改善，再按算子总奖励排序与衰减，用 UCB 分配机会；MOEA/D-DYTS 用成功事件更新被选算子的 Beta 参数并控制历史权重。固定算子池的重复观测条件与持续新增程序节点的搜索不同，其信用不能直接搬到逐程序选择上。

BaSE 等计算分配工作直接讨论有限调用如何分给广度与深度；轨迹研究则报告搜索过程中局部化的现象。阶段性调度和固定选择压力改变的是不同因素，应在相同预算下分别比较。

## 相关工作与来源

<a id="paper-08"></a>
### QUBE

用簇内历史子代质量估计亲代价值，以访问计数提供 UCB 探索项，同时影响选父与岛重置。

来源：论文：*QUBE: Enhancing Automatic Heuristic Design via Quality-Uncertainty Balanced Evolution*；本地来源：`main.tex`；设计对象：启发式算法代码。

原文入口：[arXiv:2412.20694](https://arxiv.org/abs/2412.20694)

<a id="paper-22"></a>
### MCTS-AHD

UCT 选点、渐进扩展和子树最大值回传配合六类生成动作；树路径也作为生成材料。

来源：论文：MCTS-AHD；本地来源：icml2025.tex；设计对象是 ACO、GLS、构造式框架中的启发式函数。

原文入口：[arXiv:2501.08603](https://arxiv.org/abs/2501.08603)

<a id="paper-23"></a>
### Planning of Heuristics（PoH）

把改进建议视作动作、代码实现视作转移，用规划树比较多条短期改进路径。

来源：论文：Planning of Heuristics: Strategic Planning on Large Language Models with Monte Carlo Tree Search；本地来源：example_paper.tex；设计对象为组合优化启发式规划式搜索。

原文入口：[arXiv:2502.11422](https://arxiv.org/abs/2502.11422)

<a id="paper-24"></a>
### PathWise

多父蕴含图记录设计推导，策略提出父代集和改进指令，world model 生成多份候选，critic 总结动作效果。

来源：论文：PathWise；本地来源：example_paper.tex；设计对象为以改进路径为中心的 LLM 启发式搜索。

原文入口：[arXiv:2601.20539](https://arxiv.org/abs/2601.20539)

<a id="paper-25"></a>
### Clade-AHD

将后代观测聚合到 clade，以温度化 Thompson 抽样分配机会，扩大信用统计的共享范围。

来源：论文：Clade-AHD: Clade-level Selection for MCTS in Automatic Heuristic Design；本地来源：main.tex 与 appendix.tex；设计对象为 MCTS-AHD 的谱系（clade）级选择。

原文入口：[arXiv:2602.00549](https://arxiv.org/abs/2602.00549)

<a id="paper-28"></a>
### BaSE：Compute Allocation in Evolutionary Search

将固定模型调用预算分为深度与广度，并以 bandit 在多条搜索之间分配调用，研究有限预算下的期望收益。

来源：论文：Compute Allocation in Evolutionary Search: From Depth–Breadth to Multi-Armed Bandits（arXiv:2605.29268）。本地来源：main.tex、bandit.tex、bandit_appendix.tex。

原文入口：[arXiv:2605.29268](https://arxiv.org/abs/2605.29268)

<a id="paper-48"></a>
### SMCEvolve：用序贯蒙特卡洛统一程序进化

以 reward-tilted 分布组织重加权、重采样和变异，让接受、选择压力与停止共享一个概率视角；黑盒 LLM 下采用近似实现。

来源：论文：Jiachen Jiang、Huminhao Zhu、Zhihui Zhu，*SMCEvolve: Principled Scientific Discovery via Sequential Monte Carlo Evolution*，arXiv:2605.15308v1，2026-05-14，预印本。 本地来源：paper.pdf。

原文与实现：[来源 1](https://github.com/kongwanbianjinyu/SMCEvolve)

原文入口：[arXiv:2605.15308](https://arxiv.org/abs/2605.15308)

<a id="paper-53"></a>
### RelayEvolve

廉价模型探索多条路线，以 relay bank 的边际收益分配广度与深度，再将候选群交给强模型精炼。

来源：论文：*Relay, Don't Route: Adaptive Population Handoff for Cost-Efficient LLM-Driven Evolution*；本地来源：`papers/Relay_Dont_Route_Adaptive_Population_Handoff/paper.pdf`；设计对象：强弱 LLM 共同驱动的程序进化过程。

原文入口：[arXiv:2608.05651](https://arxiv.org/abs/2608.05651)

<a id="paper-61"></a>
### Code Repair EET（REx）

把每个待修复程序看作新出现的臂，每次拉臂进行一次反例条件修复，研究进度与尝试次数的权衡。

来源：论文：*Code Repair with LLMs Gives an Exploration-Exploitation Tradeoff*；本地来源：`main.tex`；研究对象：LLM 迭代修复代码的策略选择理论（arm-acquiring bandit），而非一套 AAD 系统。

原文入口：[arXiv:2405.17503](https://arxiv.org/abs/2405.17503)


## 延伸阅读

- **MCTS for Execution-Guided Program Repair with LLMs (CodePilot)**：混合框架：MCTS + LLM 做仓库级程序修复，层次化故障定位 + 执行引导的补丁轨迹探索，处理真实 GitHub issue。 [arXiv:2602.00129](https://arxiv.org/abs/2602.00129)

- **On the Hidden Objective Biases of Group-based RL (GRPO)**：理论分析 GRPO 类群组 RL 方法：统一代理形式下揭示结构性缺陷——非均匀奖励加权、早期梯度丢弃、组内依赖导致的隐式目标偏差。对 LLM 后训练有直接警示意义。 [arXiv:2601.05002](https://arxiv.org/abs/2601.05002)

- **READY: Reward Discovery for Meta-Black-Box Optimization**：用 LLM 自动发现 MetaBBO 的奖励函数（考虑有效性与效率），替代人工设计，规避设计偏差与 reward hacking 风险。 [arXiv:2601.21847](https://arxiv.org/abs/2601.21847)

- **RF-Agent: Automated Reward Function Design via Language Agent Tree Search**：语言智能体树搜索设计稠密奖励：比贪心/进化式奖励生成更好地利用历史反馈，搜索更高效，用于低层控制任务。 [arXiv:2602.23876](https://arxiv.org/abs/2602.23876)
