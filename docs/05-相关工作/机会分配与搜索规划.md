# 机会分配与搜索规划

[相关工作目录](README.md) · [方法总览](AAD代表方法与机制.md)

机会分配决定下一次从哪个程序开始，以及不同路径获得多少开发预算。已有方法分别利用当前质量、后代收益和尝试次数组织选择，并在开发深度与探索广度之间分配资源。

## 基于后代收益的机会分配

后代结果可以用于估计继续开发的价值。`QUBE` 在程序簇上积累子代表现，`MCTS-AHD` 用树组织扩展，`Clade-AHD` 在谱系分支中共享后代信息。`REx` 将每个待修复程序视为新出现的臂，`BaSE` 在多条运行之间分配调用，使用的统计对象随搜索组织而变化。

逐程序统计常缺少样本，按簇或来源合并则会混合不同程序的结果。迁移这些方法时，比较它们在同类改动下的响应，以及后续收益保留了哪些起点计算。

## 开发深度与探索广度的预算配置

短期规划用额外尝试比较下一步怎样改写。`PoH` 与 `PathWise` 从同一程序与上下文生成多个建议或实现，以短期结果支持后续选择。这些结果可能帮助选择下一次修改，但额外尝试也消耗生成和评价预算。判断规划是否值得，需要与同预算的连续开发比较。

分阶段搜索将预算分给不同的开发方式。`BaSE` 配置开发深度与并行子代数，`RelayEvolve` 由廉价模型探索，再由强模型精炼。`SMCEvolve` 用重加权、重采样和变异组织候选分布，在同一概率表述中描述选择压力、接受与停止。

## 机会分配的统计依据

当前质量提供选优依据，尝试次数记录已经投入的机会，后代收益描述继续开发的产出。分配规则通过不同权重调节选择的集中程度；阶段调度还决定在搜索的什么时候投入预算。

锦标赛和排名抽样提供了可明确计算的选择压力。设程序总数为 $N$，排名 $r=1$ 为最差、$r=N$ 为最好，有放回的 $k$ 元锦标赛选择排名 $r$ 的概率为

$$
p_r = \left(\frac{r}{N}\right)^k - \left(\frac{r-1}{N}\right)^k.
$$

增大 $k$ 会提高高排名程序获得机会的比例。质量 softmax 的温度和 ESS 也调节选择集中程度。实际竞争范围与同分候选的处理方式，共同决定这些规则形成的抽样分布。

算子池固定时，同一动作可以获得反复观测。`FRRMAB` 在近期窗口累计算子改善，结合奖励排序、衰减与 `UCB` 分配机会；`MOEA/D-DYTS` 用成功事件更新被选算子的 Beta 参数并控制历史权重。选择程序时，新节点持续出现，统计对象随之增加，每个节点的观测可能很少。

## 论文笔记

<a id="paper-08"></a>

### `QUBE`

`QUBE` 用簇内历史子代质量估计亲代价值，访问计数提供 `UCB` 探索项，两类信息共同参与选父与岛重置。

- 论文：*QUBE: Enhancing Automatic Heuristic Design via Quality-Uncertainty Balanced Evolution*
- 本地资料：`main.tex`
- 研究对象：启发式算法代码。

论文链接：[arXiv:2412.20694](https://arxiv.org/abs/2412.20694)

<a id="paper-22"></a>

### `MCTS-AHD`

`MCTS-AHD` 的树同时组织开发机会与生成材料。`UCT` 选点、渐进扩展和子树最大值回传配合六类生成动作，树路径提供候选形成的历史。

- 论文：MCTS-AHD
- 本地资料：icml2025.tex
- 研究对象： ACO、GLS、构造式框架中的启发式函数。

论文链接：[arXiv:2501.08603](https://arxiv.org/abs/2501.08603)

<a id="paper-23"></a>

### Planning of Heuristics（`PoH`）

`PoH` 将改进建议作为规划动作、代码实现作为状态转移，以规划树比较多条短期改进路径。

- 论文：Planning of Heuristics: Strategic Planning on Large Language Models with Monte Carlo Tree Search
- 本地资料：example_paper.tex
- 研究对象：组合优化启发式规划式搜索。

论文链接：[arXiv:2502.11422](https://arxiv.org/abs/2502.11422)

<a id="paper-24"></a>

### `PathWise`

`PathWise` 用多父蕴含图保存设计推导。策略提出父代集和改进指令，world model 负责多候选实现，critic 总结动作效果，分别承担路径选择、生成与反馈。

- 论文：PathWise
- 本地资料：example_paper.tex
- 研究对象：以改进路径为中心的 LLM 启发式搜索。

论文链接：[arXiv:2601.20539](https://arxiv.org/abs/2601.20539)

<a id="paper-25"></a>

### `Clade-AHD`

`Clade-AHD` 将开发价值的统计范围扩展到谱系分支，聚合后代观测，并以温度化 Thompson 抽样分配机会。

- 论文：Clade-AHD: Clade-level Selection for MCTS in Automatic Heuristic Design
- 本地资料：main.tex 与 appendix.tex
- 研究对象： `MCTS-AHD` 的谱系（clade）级选择。

论文链接：[arXiv:2602.00549](https://arxiv.org/abs/2602.00549)

<a id="paper-28"></a>

### `BaSE`：Compute Allocation in Evolutionary Search

`BaSE` 将固定模型调用预算配置为开发深度与探索广度，用 bandit 在多条搜索之间分配调用，研究有限预算下的期望收益。

- 论文：Compute Allocation in Evolutionary Search: From Depth–Breadth to Multi-Armed Bandits（arXiv:2605.29268）
- 本地资料：main.tex、bandit.tex、bandit_appendix.tex。

论文链接：[arXiv:2605.29268](https://arxiv.org/abs/2605.29268)

<a id="paper-48"></a>

### `SMCEvolve`：用序贯蒙特卡洛统一程序进化

`SMCEvolve` 以 reward-tilted 分布描述程序进化，将重加权、重采样和变异纳入统一表述，使接受、选择压力与停止共享概率依据；黑盒 LLM 条件下采用近似实现。

- 论文：Jiachen Jiang、Huminhao Zhu、Zhihui Zhu，*SMCEvolve: Principled Scientific Discovery via Sequential Monte Carlo Evolution*，arXiv:2605.15308v1，2026-05-14，预印本
- 本地资料：paper.pdf。

补充链接：[来源 1](https://github.com/kongwanbianjinyu/SMCEvolve)

论文链接：[arXiv:2605.15308](https://arxiv.org/abs/2605.15308)

<a id="paper-53"></a>

### `RelayEvolve`

`RelayEvolve` 将廉价模型的多路线探索与强模型精炼衔接，以 relay bank 的边际收益配置广度与深度，再移交候选群。

- 论文：*Relay, Don't Route: Adaptive Population Handoff for Cost-Efficient LLM-Driven Evolution*
- 本地资料：`papers/Relay_Dont_Route_Adaptive_Population_Handoff/paper.pdf`
- 研究对象：强弱 LLM 共同驱动的程序进化过程。

论文链接：[arXiv:2608.05651](https://arxiv.org/abs/2608.05651)

<a id="paper-61"></a>

### Code Repair EET（`REx`）

`REx` 将不断出现的待修复程序建模为新增臂，每次拉臂对应一次反例条件修复，研究修复进度与尝试次数的权衡。

- 论文：*Code Repair with LLMs Gives an Exploration-Exploitation Tradeoff*
- 本地资料：`main.tex`
- 研究对象：LLM 迭代修复代码的策略选择理论（arm-acquiring bandit）。

论文链接：[arXiv:2405.17503](https://arxiv.org/abs/2405.17503)
