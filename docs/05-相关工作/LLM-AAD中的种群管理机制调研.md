# 种群保存与父代选择

[相关工作目录](README.md) · [方法总览](AAD代表方法与机制.md)

种群保存决定哪些候选可用于后续搜索，父代选择决定下一次生成从哪里出发。已有方法使用质量、区域、谱系或后代统计作出这些决定，并通过岛屿和跨分支参考交换信息。

## 候选保存与开发机会的组织

| 方法 | 实际分配或保留的对象 | 机制含义 |
| --- | --- | --- |
| `EoH`、`ReEvo` | 按质量或动作类型选择父代，另行决定哪些程序留在种群 | 父代选择分配当前起点，候选存留维护后续可用程序。 |
| `FunSearch` | 多岛内按评价签名分组，再选择程序进入提示 | 岛内信息隔离与周期重置共同影响生成分布。 |
| `MCTS-AHD` | 形成树上的选择、扩展与最大值回传，并使用跨分支精英参考 | 谱系记录形成关系，树上的选择规则决定节点获得的机会。 |
| `MAP-Elites`、`PartEvo` | 在行为或表征划出的区域内保留代表 | 描述器决定区域含义，覆盖率与最好质量分别描述方向维护和搜索产出。 |
| `QUBE`、`Monte Carlo Elites` | 依据后代质量或进入档案的频率估计生成起点价值 | 后代产出提供开发价值的观测，区域共享统计依赖状态相似性。 |
| `ShinkaEvolve` | 质量权重叠加较少繁衍次数的优待 | 繁衍次数记录既有投入，对较少开发的程序提供额外机会。 |

父代选择影响下一轮生成的起点，候选存留影响未来可用的程序。区域划分进一步决定哪些差异得到保留，其作用取决于描述器表达的算法特点。

## 本地试验中的差异与续投表现

本地试验表明，差异如何测量、继续开发是否有收益，都取决于任务。[`BehaveSim` 校准](../03-现象与检验/2026-09-07-BehaveSim群体距离校准.md)中，CVRP 的距离排序随探针变化较大。[机会评分消融](../03-现象与检验/2026-08-25-边界机会评分.md)在 TSP200 退步；OBP 上两种规则等价，为排查成绩差来源提供了线索。[`Pivot` 两步干预](../03-现象与检验/2026-09-07-Pivot两步价值.md)中，退步方向接一次 `Refine` 后均未超过起点。

保存候选、保留差异和继续开发，需要分别评价。谱系与距离描述候选关系，访问次数记录既有投入；继续开发是否值得，则需要比较相同预算下的后续结果。

搜索目标决定收益的计量方式。全局最好值逐次增加的量相加，等于终点相对起点的改善；超过父代的比例和后代平均分描述局部产出，未必与最终最好值同向变化。
