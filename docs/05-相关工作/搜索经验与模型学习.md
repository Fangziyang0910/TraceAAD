# 搜索经验与模型学习

相关工作让搜索经验进入提示、外部数据库、生成模型参数或搜索控制策略。它们可能使用相同的任务、父代和候选记录，却改变不同的决策环节。

## 学习生成、学习控制、学习表示

| 学习对象 | 代表路线 | 改变的决策 |
| --- | --- | --- |
| 代码生成分布 | CALM、EvoTune、Fine-tuning LLM for AAD | 给定状态后提出怎样的程序 |
| 长程动作策略 | AHD-Agent、LinTree | 何时生成、检索、扩展和评价 |
| 性能代理与连续表示 | LLaMEA-SAGE、LHS | 哪些结构值得改、往哪个表示方向移动 |
| 可复用求解器 | Hero、AlgoPilot | 将设计经验转成一次生成或执行能力 |
| 联合学习 | GAE、Self-Developing、GPRT | 生成与搜索相互供给新数据 |

这些学习对象可以协作，但不能混为一类。例如 LHS 保持代码 LLM 冻结，学习的是连续表示和代理；CORAL 主要改变 agent 的推断期记忆与搜索组织。

## 经验应该怎样进入参数

CALM 用父代相对表现和执行反馈训练生成器，EvoTune 让历史数据库同时用于上下文和偏好学习，离线微调则先收集算法样本再更新模型。它们对样本单位与训练信号的选择不同：模仿高质量程序和学习给定父代后的有用修改，并非同一个目标。

同状态候选对天然保留了这个问题。失败也能贡献信息：格式错误教接口，运行错误教约束，退步但可发展的结构教设计取舍。训练目标若只有全局最好程序，容易丢掉这种丰富性。

## 过程反馈与老师

DyACE 从求解过程诊断算法，Teacher-Aware Evolution 用动作分歧提出修改建议。它们让反馈从一个整体分数延伸到程序具体做了什么。AlgoPilot 和 LinTree 则探索过程表示如何进入学习。

形成关系描述改动从哪里来，求解行为描述改动带来了什么。DyACE 与 Teacher-Aware Evolution 增加过程反馈，但它们与直接按最终分数训练生成器的监督信息不同；比较效果时也应区分训练期额外评价与推断期搜索成本。

## 相关工作与来源

<a id="paper-35"></a>
### CALM

启发式种群生成 prompt–response–performance 数据，用 GRPO 更新本地 LLM；语言算子和参数学习共同进化。

来源：论文：*CALM*；本地来源：`papers/CALM/main.tex` 与 `appendix.tex`；设计对象：启发式种群、产生它们的本地 LLM 参数，以及二者的在线共进化。

原文入口：[arXiv:2505.12285](https://arxiv.org/abs/2505.12285)

<a id="paper-36"></a>
### EvoTune

进化数据库同时服务上下文和训练，按同一 prompt 的多个输出构造偏好，通过周期训练改进生成分布。

来源：论文：*Algorithm Discovery With LLMs: Evolutionary Search Meets Reinforcement Learning*；本地来源：`papers/Algorithm_Discovery_With_LLMs_Evolutionary_Search_Meets_Reinforcement_Learning/colm2025_conference.tex`；设计对象：算法程序及生成它们的 LLM 策略。

原文入口：[arXiv:2504.05108](https://arxiv.org/abs/2504.05108)

<a id="paper-37"></a>
### Fine-tuning LLM for AAD

用搜索获得的算法偏好微调代码模型，再接入随机采样、EoH 或 FunSearch，比较候选质量与跨实例表现。

来源：论文：*Fine-tuning LLM for Automated Algorithm Design*；本地来源：`papers/Fine-tuning-LLM-Automated-Algorithm-Design/iclr2026_conference.tex`；设计对象：为 AAD 生成候选程序的 LLM 参数。

<a id="paper-38"></a>
### AHD-Agent

训练能规划、生成、评价和反思的 agent，让参数学习同时触及长程搜索控制。

来源：论文：*AHD-Agent: Agentic Reinforcement Learning for Automatic Heuristic Design*；本地来源：`papers/AHD_Agent_Agentic_Reinforcement_Learning_for_Automatic_Heuristic_Design/neurips_2026.tex`，含 `Sections/Methodology.tex`、`Sections/Experiment.tex` 与 Appendix；设计对象：启发式设计过程中的 agent policy 与生成代码。

原文入口：[arXiv:2605.08756](https://arxiv.org/abs/2605.08756)

<a id="paper-40"></a>
### CORAL

让 agent 自主选择检索、生成、测试和记忆更新，多个 agent 共享持久记忆；主要改变推断期搜索组织。

来源：论文：*CORAL: Towards Autonomous Multi-Agent Evolution for Open-Ended Discovery*；本地来源：`papers/CORAL_Towards_Autonomous_Multi_Agent_Evolution_for_Open_Ended_Discovery/colm2026_conference.tex`，含 `sections/method.tex`、`sections/experiments.tex`、`sections/appendix.tex`；设计对象：开放式发现任务中的搜索过程、共享记忆与多个自主 agent。

原文入口：[arXiv:2604.01658](https://arxiv.org/abs/2604.01658)

<a id="paper-41"></a>
### Beyond Inference-Time Search

Hero 通过 GRPO 和课程反馈学习生成可跨实例复用的 standalone solver，关注训练后一次生成的使用价值。

来源：论文：*Beyond Inference-Time Search: RL Synthesizes Reusable Solvers*；本地来源：`papers/Beyond_Inference-Time_Search_RL_Synthesizes_Reusable_Solvers/template.tex`；设计对象：可复用的完整 solver 代码及其 GRPO 训练策略（Hero）。

原文入口：[arXiv:2605.18374](https://arxiv.org/abs/2605.18374)

<a id="paper-42"></a>
### Self-Developing

搜索模型合并算法，以合并后模型成绩构造偏好，DPO 更新算法生成器后继续发现。

来源：论文：*Can Large Language Models Invent Algorithms to Improve Themselves?*；本地来源：`papers/Can_Large_Language_Models_Invent_Algorithms_to_Improve_Themselves/paper.pdf`；正式发表于 NAACL 2025 Long Paper；设计对象：可执行的模型合并算法与生成这些算法的 algorithm factory。

原文入口：[ACL Anthology](https://aclanthology.org/2025.naacl-long.519/)

<a id="paper-43"></a>
### AlgoPilot

从随机程序的执行轨迹训练轨迹模型，再通过环境奖励学习操作序列，最后还原为代码。

来源：论文：*AlgoPilot: Fully Autonomous Program Synthesis Without Human-Written Programs*；本地来源：`papers/AlgoPilot_Fully_Autonomous_Program_Synthesis_Without_Human_Written_Programs/paper.pdf`；设计对象：由 Compare/Swap 轨迹恢复出的排序程序。

原文入口：[arXiv:2501.06423](https://arxiv.org/abs/2501.06423)

<a id="paper-44"></a>
### LLaMEA-SAGE

从 AST/控制流特征训练性能 surrogate，再将 SHAP 分析转换为变异指导；学习对象是代理模型。

来源：论文：*LLaMEA-SAGE: Guiding Automated Algorithm Design with Structural Feedback from Explainable AI*；本地来源：`papers/LLaMEA_SAGE_Guiding_Automated_Algorithm_Design_with_Structural_Feedback/paper.pdf`；设计对象：完整黑盒优化算法代码。

原文入口：[arXiv:2601.21511](https://arxiv.org/abs/2601.21511)

<a id="paper-46"></a>
### Latent Heuristic Search

冻结代码编码器与生成 LLM，训练连续表示、soft-prompt 映射和性能代理，在潜空间优化后解码真评。

来源：论文：*Latent Heuristic Search: Continuous Optimization for Automated Algorithm Design*；本地来源：`papers/Latent_Heuristic_Search_Continuous_Optimization_for_Automated_Algorithm_Design/paper.pdf`；设计对象：由 latent soft prompt 解码的启发式程序。

原文入口：[arXiv:2605.17137](https://arxiv.org/abs/2605.17137)

<a id="paper-50"></a>
### GAE

GNN 性能代理、SAC 编辑控制器和 PPO 代码生成器共同学习；父代由精英档案均匀采样。

来源：论文：*GAE: Graph-Augmented Evolution for Scientific Discovery via Reinforcement Optimization*；本地来源：`papers/GAE_Graph_Augmented_Evolution_for_Scientific_Discovery/paper.pdf`；设计对象：非线性振子符号方程程序。

原文入口：[arXiv:2607.10127](https://arxiv.org/abs/2607.10127)

<a id="paper-56"></a>
### DyACE

从求解过程提取轨迹特征，agent 诊断后在滚动时域内改写启发式，使算法和解种群共同演化。

来源：论文：*DyACE: Dynamic Algorithm Coevolution*；本地来源：`papers/DyACE_Dynamic_Algorithm_Coevolution/paper.pdf`；设计对象：随求解阶段在线变化的组合优化启发式控制逻辑。

原文入口：[arXiv:2603.13344](https://arxiv.org/abs/2603.13344)

<a id="paper-57"></a>
### Teacher-Aware Evolution

比较候选在自身访问状态上的动作与 teacher 偏好，形成结构修改、参数校准、机制融合建议。

来源：论文：*Teacher-Aware Evolution of Heuristic Programs from Learned Optimization Policies*；本地来源：`papers/Teacher_Aware_Evolution_of_Heuristic_Programs/paper.pdf`；设计对象：部署时不依赖教师的静态启发式程序。

原文入口：[arXiv:2605.10634](https://arxiv.org/abs/2605.10634)

<a id="paper-67"></a>
### LinTree

用父指针显式表达搜索树轨迹，再训练搜索策略，检验拓扑表示如何影响历史利用。

来源：论文：*LinTree: Improving LLM Reasoning with Explicitly Structured Search Histories*；本地来源：LaTeX 源码目录 `LinTree_Improving_LLM_Reasoning_with_Explicitly_Structured_Search_Histories/`；研究对象：把 LLM 推理轨迹视为线性化搜索树、以显式树拓扑作为上下文的搜索策略学习（Qwen3-0.6B，SFT+GRPO）。

原文入口：[arXiv:2605.31492](https://arxiv.org/abs/2605.31492)

<a id="paper-69"></a>
### GP with RL-Trained Transformer（GPRT）

序列模型周期性生成调度启发式补充 GP 种群，并从程序及其表现更新模型，交替进行学习与进化。

来源：论文：*Genetic Programming with a Reinforcement Learning Trained Transformer for Dynamic Scheduling in Real-World Environments*；本地来源：LaTeX 源码目录 `GP_with_RL_Trained_Transformer_for_Dynamic_Scheduling/`；设计对象：集装箱码头动态卡车调度的 GP 启发式（LGP 波兰式 token 序列）与生成它们的序列模型。

原文入口：[arXiv:2504.07779](https://arxiv.org/abs/2504.07779)


## 延伸阅读

- **LLMs as End-to-end Combinatorial Optimization Solvers**：训练 LLM 直接端到端输出 COP 解，省去代码生成或调用求解器的中间步骤。 [arXiv:2509.16865](https://arxiv.org/abs/2509.16865)

- **Thompson Sampling via Fine-Tuning of LLMs (ToSFiT)**：用 LLM 直接参数化"候选产生最大奖励"的概率，绕开采集函数最大化；微调实现大规模离散空间的 Thompson 采样式贝叶斯优化。 [arXiv:2510.13328](https://arxiv.org/abs/2510.13328)

- **ReMiT: RL-Guided Mid-Training for Iterative LLM Evolution**：提出"中途训练"双向流水线：RL 调优的模型反过来强化基座模型，形成自增强飞轮，让后训练洞见回馈预训练基础。 [arXiv:2602.03075](https://arxiv.org/abs/2602.03075)

- **E-SPL: Evolutionary System Prompt Learning for RL in LLMs**：同时改进模型上下文与权重：每次 RL 迭代并行采样多个 system prompt 的轨迹，联合进化提示与更新权重，实现智能体自主持续改进。 [arXiv:2602.14697](https://arxiv.org/abs/2602.14697)

- **Helix: Evolutionary RL for Open-Ended Scientific Problem Solving**：分层进化强化学习：同时演化任务解与探索策略，克服纯学习方法与手工流水线在开放科学问题上的探索效率与泛化缺陷。 [arXiv:2603.07642](https://arxiv.org/abs/2603.07642)

- **Discovering RL Interfaces with LLMs**：用 LLM 从原始模拟器状态综合完整的 RL 任务接口（观测映射 + 奖励函数），超越"只自动设计奖励"的现有工作。 [arXiv:2605.03408](https://arxiv.org/abs/2605.03408)
