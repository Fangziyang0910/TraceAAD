# 搜索经验与模型学习

[相关工作目录](README.md) · [方法总览](AAD代表方法与机制.md)

模型学习将算法试验转化为生成、预测或搜索控制的训练数据。学习对象决定要更新哪项能力，训练信号决定使用哪些反馈。相关的外部记忆与过程诊断工作，也有助于比较不同的经验利用方式。

## 生成模型、搜索策略与程序表示

搜索经验可以作用于生成模型、动作策略、性能代理或可复用求解器。这些对象分别对应候选生成、动作选择、程序表示和训练后的直接求解能力。

| 学习对象 | 代表方法 | 对应能力 |
| --- | --- | --- |
| 代码生成模型 | `CALM`、`EvoTune`、`Fine-tuning LLM for AAD` | 给定状态后生成候选程序 |
| 搜索动作策略 | `AHD-Agent`、`LinTree` | 选择生成、检索、扩展和评价动作 |
| 性能代理与连续表示 | `LLaMEA-SAGE`、`LHS` | 预测程序表现并搜索表示空间 |
| 可复用求解器 | `Hero`、`AlgoPilot` | 直接生成或执行算法 |
| 联合学习 | `GAE`、`Self-Developing`、`GPRT` | 从生成与搜索结果持续学习 |

学习方式取决于实际更新的对象。`LHS` 保持代码生成 LLM 冻结，学习连续表示和性能代理；`CORAL` 通过推断期记忆与搜索组织使用经验。参数更新与上下文记忆因此对应不同的经验利用方式。

## 候选质量与修改条件的训练信号

高质量程序提供可模仿的计算，父代相对表现则提供修改是否有效的反馈。`CALM` 使用父代相对表现与执行反馈，`EvoTune` 同时用历史数据库构造上下文和偏好数据，离线微调先收集算法样本再更新模型，因此使用的样本单位与训练目标不同。

同状态下的候选比较保留了修改条件。格式错误涉及接口，运行错误涉及约束，退步但仍可能发展的程序涉及设计取舍，这些记录提供不同类型的学习信息。仅由全局最好程序构成的数据，则主要保留成功结果。

## 执行反馈与过程监督

执行过程将整体成绩展开为具体决策。`DyACE` 从求解过程诊断算法，`Teacher-Aware Evolution` 根据动作分歧提出修改建议；`AlgoPilot` 与 `LinTree` 研究过程表示如何进入学习。形成关系记录修改来源，执行行为记录算法实际作出的选择。两者可提供不同的监督信息。

训练期额外评价、推断期搜索和新任务上的表现，需要分别报告，以评价经验复用的成本与效果。方法的使用价值取决于训练得到的能力如何用于后续任务。

## 论文笔记

<a id="paper-35"></a>

### `CALM`

`CALM` 将启发式种群的试验用于生成模型训练。prompt–response–performance 数据支持 `GRPO` 更新本地 LLM，语言算子与参数学习共同参与进化。

- 论文：*CALM*
- 本地资料：`papers/CALM/main.tex` 与 `appendix.tex`
- 研究对象：启发式种群、产生它们的本地 LLM 参数，以及二者的在线共进化。

论文链接：[arXiv:2505.12285](https://arxiv.org/abs/2505.12285)

<a id="paper-36"></a>

### `EvoTune`

`EvoTune` 将进化数据库同时用于上下文构造与模型训练。同一 prompt 的多个输出形成偏好数据，周期训练据此更新生成分布。

- 论文：*Algorithm Discovery With LLMs: Evolutionary Search Meets Reinforcement Learning*
- 本地资料：`papers/Algorithm_Discovery_With_LLMs_Evolutionary_Search_Meets_Reinforcement_Learning/colm2025_conference.tex`
- 研究对象：算法程序及生成它们的 LLM 策略。

论文链接：[arXiv:2504.05108](https://arxiv.org/abs/2504.05108)

<a id="paper-37"></a>

### `Fine-tuning LLM for AAD`

算法偏好微调用于学习代码生成能力，其产出的模型可接入随机采样、`EoH` 或 `FunSearch`，以候选质量与跨实例表现评价复用效果。

- 论文：*Fine-tuning LLM for Automated Algorithm Design*
- 本地资料：`papers/Fine-tuning-LLM-Automated-Algorithm-Design/iclr2026_conference.tex`
- 研究对象：为 AAD 生成候选程序的 LLM 参数。

<a id="paper-38"></a>

### `AHD-Agent`

`AHD-Agent` 将规划、生成、评价和反思纳入 agent 训练，使参数学习同时作用于候选生成与长程搜索控制。

- 论文：*AHD-Agent: Agentic Reinforcement Learning for Automatic Heuristic Design*
- 本地资料：`papers/AHD_Agent_Agentic_Reinforcement_Learning_for_Automatic_Heuristic_Design/neurips_2026.tex`，含 `Sections/Methodology.tex`、`Sections/Experiment.tex` 与 Appendix
- 研究对象：启发式设计过程中的 agent policy 与生成代码。

论文链接：[arXiv:2605.08756](https://arxiv.org/abs/2605.08756)

<a id="paper-40"></a>

### `CORAL`

`CORAL` 通过推断期的自主动作与持久记忆组织搜索。agent 选择检索、生成、测试和记忆更新，多个 agent 共享已有经验。

- 论文：*CORAL: Towards Autonomous Multi-Agent Evolution for Open-Ended Discovery*
- 本地资料：`papers/CORAL_Towards_Autonomous_Multi_Agent_Evolution_for_Open_Ended_Discovery/colm2026_conference.tex`，含 `sections/method.tex`、`sections/experiments.tex`、`sections/appendix.tex`
- 研究对象：开放式发现任务中的搜索过程、共享记忆与多个自主 agent。

论文链接：[arXiv:2604.01658](https://arxiv.org/abs/2604.01658)

<a id="paper-41"></a>

### Beyond Inference-Time Search（`Hero`）

`Hero` 通过 `GRPO` 和课程反馈学习生成可跨实例复用的 standalone solver，关注训练后一次生成的使用价值。

- 论文：*Beyond Inference-Time Search: RL Synthesizes Reusable Solvers*
- 本地资料：`papers/Beyond_Inference-Time_Search_RL_Synthesizes_Reusable_Solvers/template.tex`
- 研究对象：可复用的完整 solver 代码及其 `GRPO` 训练策略（`Hero`）。

论文链接：[arXiv:2605.18374](https://arxiv.org/abs/2605.18374)

<a id="paper-42"></a>

### `Self-Developing`

`Self-Developing` 用模型合并算法的执行成绩训练算法生成器。合并后模型的表现构成偏好数据，`DPO` 更新与后续算法发现相互衔接。

- 论文：*Can Large Language Models Invent Algorithms to Improve Themselves?*
- 本地资料：`papers/Can_Large_Language_Models_Invent_Algorithms_to_Improve_Themselves/paper.pdf`
- 正式发表于 NAACL 2025 Long Paper
- 研究对象：可执行的模型合并算法与生成这些算法的 algorithm factory。

论文链接：[ACL Anthology](https://aclanthology.org/2025.naacl-long.519/)

<a id="paper-43"></a>

### `AlgoPilot`

`AlgoPilot` 以执行轨迹作为程序学习的表示。随机程序的轨迹用于训练轨迹模型，环境奖励支持操作序列学习，学得序列再还原为代码。

- 论文：*AlgoPilot: Fully Autonomous Program Synthesis Without Human-Written Programs*
- 本地资料：`papers/AlgoPilot_Fully_Autonomous_Program_Synthesis_Without_Human_Written_Programs/paper.pdf`
- 研究对象：由 Compare/Swap 轨迹恢复出的排序程序。

论文链接：[arXiv:2501.06423](https://arxiv.org/abs/2501.06423)

<a id="paper-44"></a>

### `LLaMEA-SAGE`

`LLaMEA-SAGE` 学习由 AST 与控制流特征预测性能的代理模型，并用 `SHAP` 将结构分析转为变异指导。

- 论文：*LLaMEA-SAGE: Guiding Automated Algorithm Design with Structural Feedback from Explainable AI*
- 本地资料：`papers/LLaMEA_SAGE_Guiding_Automated_Algorithm_Design_with_Structural_Feedback/paper.pdf`
- 研究对象：完整黑盒优化算法代码。

论文链接：[arXiv:2601.21511](https://arxiv.org/abs/2601.21511)

<a id="paper-46"></a>

### `Latent Heuristic Search`

`Latent Heuristic Search` 学习连续表示、soft-prompt 映射和性能代理，保持代码编码器与生成 LLM 冻结。候选在潜空间中优化，解码为程序后接受实际评价。

- 论文：*Latent Heuristic Search: Continuous Optimization for Automated Algorithm Design*
- 本地资料：`papers/Latent_Heuristic_Search_Continuous_Optimization_for_Automated_Algorithm_Design/paper.pdf`
- 研究对象：由 latent soft prompt 解码的启发式程序。

论文链接：[arXiv:2605.17137](https://arxiv.org/abs/2605.17137)

<a id="paper-50"></a>

### `GAE`

`GAE` 联合学习 `GNN` 性能代理、`SAC` 编辑控制器和 `PPO` 代码生成器，父代从精英档案中均匀采样。

- 论文：*GAE: Graph-Augmented Evolution for Scientific Discovery via Reinforcement Optimization*
- 本地资料：`papers/GAE_Graph_Augmented_Evolution_for_Scientific_Discovery/paper.pdf`
- 研究对象：非线性振子符号方程程序。

论文链接：[arXiv:2607.10127](https://arxiv.org/abs/2607.10127)

<a id="paper-56"></a>

### `DyACE`

`DyACE` 将求解过程作为算法调整的反馈，轨迹特征支持 agent 诊断与滚动时域内的启发式改写，使算法和解种群共同演化。

- 论文：*DyACE: Dynamic Algorithm Coevolution*
- 本地资料：`papers/DyACE_Dynamic_Algorithm_Coevolution/paper.pdf`
- 研究对象：随求解阶段在线变化的组合优化启发式控制逻辑。

论文链接：[arXiv:2603.13344](https://arxiv.org/abs/2603.13344)

<a id="paper-57"></a>

### `Teacher-Aware Evolution`

`Teacher-Aware Evolution` 用候选在自身访问状态上的动作与 teacher 偏好之间的差异，提供结构修改、参数校准和机制融合建议。

- 论文：*Teacher-Aware Evolution of Heuristic Programs from Learned Optimization Policies*
- 本地资料：`papers/Teacher_Aware_Evolution_of_Heuristic_Programs/paper.pdf`
- 研究对象：部署时不依赖教师的静态启发式程序。

论文链接：[arXiv:2605.10634](https://arxiv.org/abs/2605.10634)

<a id="paper-67"></a>

### `LinTree`

`LinTree` 将父指针表示的搜索树轨迹用于策略训练，研究显式拓扑信息与历史利用之间的关系。

- 论文：*LinTree: Improving LLM Reasoning with Explicitly Structured Search Histories*
- 本地资料：LaTeX 源码目录 `LinTree_Improving_LLM_Reasoning_with_Explicitly_Structured_Search_Histories/`
- 研究对象：把 LLM 推理轨迹视为线性化搜索树、以显式树拓扑作为上下文的搜索策略学习（Qwen3-0.6B，SFT+`GRPO`）。

论文链接：[arXiv:2605.31492](https://arxiv.org/abs/2605.31492)

<a id="paper-69"></a>

### GP with RL-Trained Transformer（`GPRT`）

`GPRT` 将序列模型学习与 `GP` 进化交替组织。模型周期性生成调度启发式补充种群，程序及其表现又为模型更新提供反馈。

- 论文：*Genetic Programming with a Reinforcement Learning Trained Transformer for Dynamic Scheduling in Real-World Environments*
- 本地资料：LaTeX 源码目录 `GP_with_RL_Trained_Transformer_for_Dynamic_Scheduling/`
- 研究对象：集装箱码头动态卡车调度的 `GP` 启发式（LGP 波兰式 token 序列）与生成它们的序列模型。

论文链接：[arXiv:2504.07779](https://arxiv.org/abs/2504.07779)
