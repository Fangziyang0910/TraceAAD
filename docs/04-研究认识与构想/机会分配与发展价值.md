# 机会分配与发展价值

当前质量说明一个程序已经做到了什么，不能直接说明继续投入后还能得到什么。TraceAAD 的父代选择以质量为主，保留一部分均匀机会；这给高分程序提供持续开发起点，也让新方向偶尔有机会被检验。研究问题是：什么时候值得把后续评价留给一个尚未兑现的新结构？

## 已有观察怎样改变判断

[V9.17 自适应调度对照](../03-机制探索与验证/2026-08-24-自适应调度.md)中，追加开发在 CVRP 上与较好的终局表现相伴，在其他任务上并不稳定。这提示发展机会需要结合任务和近期开发响应，但一次局部改善并不足以保证下一次仍有收益。[Pivot 两步干预](../03-机制探索与验证/2026-09-07-Pivot两步价值.md)也没有观察到“先退步、再用一次 Refine 超越起点”的垫脚石收益；不能把从严重跌落中恢复误记为新方向的价值。

因此我暂不主张无条件延长新结构的开发。更具体的可能性是：某些结构变化确实需要多步协调，但判断它们要看相对起点或前沿的净收益，以及是否真的得到过足够的发展机会。代码或行为距离能帮助发现差异，却不能独自预测未来收益。

## 想检验的三个决策

**竞争范围。** 高质量节点集中开发与保留更多路线之间有预算取舍。可以固定生成模型和上下文，分别改变父代竞争池范围，观察每路前沿、重复间波动及 held-out，而不把较大的程序差异直接当成收益。

**新方向的试用。** 对同一批新候选随机给予或不给予固定的短开发窗口；两组保持相同总评价预算，未续投的机会交给常规开发。比较相对原始锚点的最好净增量，并记录无效生成和后续评价的实际成本。若试用只增加恢复性改写而不改善终局，就应降低续投优先级。

**近期响应的信用。** 父代、算子和参考程序承载不同选择。先区分当前质量、直接开发次数及后续净收益，再决定是否把响应用于某一项选择。新程序不断出现，逐节点估计潜力可能过于稀疏；在相似形成状态或相同动作之间共享统计量需要独立检验。

这条线若成立，贡献不只是一个新的权重公式，而是说明有限预算应在什么状态下从现有高分程序转向尚未兑现的方向。相关方法的分配单位与规划机制见[机会分配与搜索规划](../05-相关工作/机会分配与搜索规划.md)，多样性表示的区别见[多样性与搜索行为](../05-相关工作/多样性与搜索行为.md)。
