# TraceAAD 版本演化：BehaveSim 行为距离变化

## 核心判断

BehaveSim v3 可以比较不同版本访问到的执行行为分布，但不能把这些分布命名为算法思想簇，也不能从版本之间的相关变化推出某个机制的因果效果。版本比较的对象是固定 probe 上的 PSTraj 行为，质量结论仍以正式 held-out 结果为准。

版本比较合并展示 57 个已完成 run：独立的 V9.16 campaign 有 15 个 run，另一个版本 campaign 有 42 个 run（TSP、OP、OBP、CVRP 比较 V9.7、V9.14、V9.17；VRPTW 比较 V9.14、V9.17）。每个设置 3 次重复。每个任务内按共同成功样本数做平衡，TSP/VRPTW 为 128，OP/CVRP 为 32，OBP 为 126。V9.7 没有 VRPTW 工件，因此该格为缺失。

## 版本变化的认识

1. 没有一个版本在五个任务上同时表现为“更远、更少重访、更多突破”。行为距离的变化是任务相关的：V9.16 相对 V9.7 在 TSP 的 `d` 上升，在 OP 的重访下降，在 OBP 的无突破重访上升，在 CVRP 的重访下降；这些方向不能压缩成单一的“多样性变好”结论。
2. OBP 的 V9.16 抽样行为最符合停滞诊断：无突破精确重访高于 V9.14 和 V9.17，抽样突破率最低。这个事实支持进一步检查其调度节律，不证明版本机制造成了停滞。
3. OP 的 V9.16 与 V9.17 都有很少的无突破精确重访；V9.17 的抽样突破较高。它说明这两个版本的抽样序列更少重现相同执行行为，不能直接说明突破质量更高。
4. CVRP 各版本的抽样突破率都高于多数构造任务，精确重访逐步降低；同时面板相关性从 V9.14 的 0.400 到 V9.17 的 0.615，探针敏感性仍然明显。不能把一个版本的距离画像当作任务固有几何。
5. VRPTW 中 V9.16、V9.17 的无突破精确重访低于 V9.14，最长抽样无突破段也较短；这与过程更少重复相容，但不区分“有效探索”与“无效发散”。

版本搜索期 best 仅作为工件审计字段，不能替代测试集质量。正式训练集和 held-out 数字见主实验结果；本页不把搜索期 fitness 改写成方法性能结论。

## 因果边界与后续实验

版本之间同时改变了多个实现和搜索协议。当前结果是版本级观察，不能归因于某一个调度、上下文或算子机制。若要检验“行为诊断能否改善探索与利用”，应在同一版本内固定其它因素，只加入行为状态，并预先规定：

- 低距离且无突破时如何延长或终止当前方向；
- 高距离且无突破时如何限制无效发散；
- 高距离且有突破时如何给予有限的后续 Refine；
- 线上质量、有效率、行为重访、算子分布和 held-out 的共同评价。

交叉同样需要匹配实验：在相同父代质量、生成提示和预算下比较近行为对、远行为对与随机配对。行为距离只能作为配对条件，不能作为融合成功的证明。
