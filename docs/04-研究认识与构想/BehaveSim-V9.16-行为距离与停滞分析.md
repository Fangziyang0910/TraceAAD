# TraceAAD V9.16：BehaveSim 行为距离与停滞诊断

## 核心判断

BehaveSim v3 可以为 TraceAAD 增加一个有用的过程观测：候选程序在固定问题探针上，如何逐步形成解，以及它与先前候选的执行行为相距多远。它不能把候选自动划成语义算法思想簇，也不能单独决定下一次预算给谁。

在 v3 的五个任务中，V9.16 最清楚的停滞信号出现在 Online Bin Packing：抽样序列中约 27.7% 的转移是“精确行为重访且没有质量突破”，抽样突破约 4.8%。TSP 的无突破精确重访约 18.6%，并出现平均 57.3 个候选的最长无突破段。OP 与 CVRP 的精确重访均约 1.1%，抽样突破分别约 17.2% 和 26.9%；在这两个任务上没有看到同样强的行为重访停滞。VRPTW 的精确重访约 5.8%，抽样突破约 10.2%。这些数字描述抽样候选序列，不是完整搜索的逐评价曲线。

## 分析协议

- 对 V9.16 的五个任务各分析 3 个已完成搜索 run，共 15 个 run；画像不调用 LLM，不启动新搜索，也不计入正式搜索预算。
- 每个任务使用面板 A、B 两组固定探针，每组 4 个实例。TSP、VRPTW 按正式构造 evaluator 记录逐步部分路线；OBP 预创建全部空箱并记录逐步箱号选择；OP-ACO、CVRP-ACO 执行正式 evaluator 的 prior 处理、蚂蚁采样、信息素更新和 incumbent 路线。
- 构造式轨迹均匀保留 12 个状态，ACO 轨迹保留 5 个状态；单步编辑距离除以当前两份部分解的较长长度，轨迹距离按 DTW 除以较短轨迹长度；两个面板的距离矩阵取均值。
- TSP、VRPTW 每个 run 画像 128 个候选，OP、CVRP 画像 32 个候选，OBP 在共同成功集合上比较 126 个候选。候选按搜索顺序确定性抽样；另行画像搜索期 best，不把它混入多样性分布。
- `panel rho` 是两个面板距离矩阵上三角元素的 Spearman 相关。它用于报告探针稳定性，不是“簇边界”或有效性阈值。

实现、探针和抽样规则见实验协议，原始 v3 工件见 `experiments/_logs/behavesim_v3/`。

## 停滞诊断

行为距离和质量突破要联合读取。四种状态提供了比单一新颖度更清楚的诊断：

| 行为状态 | 过程含义 |
| --- | --- |
| 低距离、无突破 | 反复生成相近执行行为，是当前最直接的停滞信号 |
| 低距离、有突破 | 有效利用，重复行为仍可能带来改进 |
| 高距离、有突破 | 有质量兑现的探索 |
| 高距离、无突破 | 行为发生变化但没有兑现，可能是无效发散 |

V9.16 的 OBP 同时呈现较高的无突破精确重访和较低的突破率，适合用作“需要重新开放探索或更换发展方向”的候选过程信号。TSP 也存在低距离无突破段，但其面板相关性较低，在线使用前应增加探针或采用更稳健的历史窗口。OP、CVRP 的新颖度较高且突破较常见，不能因为没有精确重访就判定它们已经收敛；需要继续观察高距离无突破事件。VRPTW 的无突破段存在，但当前证据不足以区分区域停滞和无效探索。

## Explore 与 Refine

V9.16 每个 run 抽取最多 32 条构造式、16 条 ACO 的父子边，并在两个面板上配对。五个任务中，Explore 的中位父子行为距离在三个重复里都高于 Refine：

| 任务 | Explore 中位距离均值 | Refine 中位距离均值 | Explore 正向 fitness 边占比 | Refine 正向 fitness 边占比 |
| --- | ---: | ---: | ---: | ---: |
| TSP | 0.712 | 0.453 | 3.1% | 15.6% |
| OP | 0.664 | 0.557 | 2.1% | 12.5% |
| OBP | 0.339 | 0.155 | 0.0% | 15.6% |
| CVRP | 0.830 | 0.749 | 2.1% | 43.8% |
| VRPTW | 0.740 | 0.525 | 4.2% | 13.5% |

这支持“Explore 诱导更大的执行行为改变、Refine 更接近局部改写”的过程描述。边样本是离线抽样，且父子行为距离与质量差异没有匹配单因素实验，因此不能推出 Explore 的因果收益或把距离远解释成创新成功。

## 对在线机制的边界

当前结果可以支持一个离线诊断器：在共同探针上记录候选到历史的最近行为距离，并与即时质量突破、失败和超时一起形成状态。它还不能直接替换 V9.16 的节点评分或算子概率。原因是：

1. 行为距离依赖探针、轨迹采样和随机流，面板相关性在任务间为 0.484–0.964；
2. 相近行为既可能是有效利用，也可能是停滞；远行为既可能是有效探索，也可能是无效发散；
3. 当前没有行为距离进入在线搜索的匹配消融，联合版本结果也不能归因于该信号。

因此下一步若要把它用于调度，应先固定节点、生成协议和正式预算，比较只加入行为诊断的版本与原版本，并报告质量、有效率、行为重访和 held-out 结果。
