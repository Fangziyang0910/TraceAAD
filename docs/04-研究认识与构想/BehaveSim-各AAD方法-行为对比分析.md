# 各 AAD 方法：BehaveSim 行为距离与过程信号

## 核心判断

BehaveSim v3 能说明不同 AAD 方法在固定 probe 上访问了不同的执行行为分布。它不能据此识别方法的语义算法思想，也不能把某种行为集中度归因于 PathWise、ReEvo、EoH、MCTS-AHD、CALM 或 TraceAAD 的单个机制。

外部方法战役包含 5 个方法、5 个任务、3 次重复，共 75 个已完成 run；TraceAAD V9.16 作为同协议参照。非 CALM 方法在同任务内按共同成功画像数比较：TSP/VRPTW 为 128，OP/CVRP 为 32，OBP 为 126。CALM 工件只保存最终 archive，画像数随重复变化，时间行为指标为 `n/a`，不进入完整搜索候选的时间轴比较。

行为距离和下面的质量突破都沿候选记录顺序计算；它们不是完整 1000 次评价曲线。搜索期 best 只来自训练集搜索工件，正式测试质量见主实验结果。

## 方法比较的边界

本分析能够回答“已记录候选在共同 probe 上的执行行为是否重访或分散”。它不能回答“哪一种算法思想更好”“为什么某方法得到某个 held-out 结果”或“两个远行为父代是否适合交叉”。候选的 `idea` 和 lineage 只作为搜索档案，不足以把距离邻域命名成语义 family；CALM 的最终 archive 也不能和完整时间轴等价。

要检验行为距离能否改善探索与利用，应在一个固定版本中做匹配的一因子实验：原调度、加入低距离无突破诊断、加入高距离无突破抑制，分别保持生成协议和真实预算不变，并报告有效率、质量曲线、行为重访、算子分布和 held-out 结果。交叉实验使用近行为、远行为和随机父代三组，行为距离只作为配对条件。

## 工件

汇总文件为 `experiments/_logs/behavesim_v3/aggregate.json`，外部方法入口为`run_all_baselines_behavesim.py`，协议见 BehaveSim 行为度量校正。

`*` CALM 为 `final_archive_only`：其行为距离指标只描述最终 archive，时间行为列保持 `n/a`，不作为完整搜索时间轴的等价样本。
