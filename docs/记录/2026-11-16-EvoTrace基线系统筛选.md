# EvoTrace 对比基线名单

日期：2026-11-16

主实验固定对比 **5 个外部基线**（均具备作者公开官方源码、发表于 ICML / NeurIPS 2024–2026，且已在本地完成移植），另设 **内部参照**（`TraceAAD Base` 与 EvoTrace 内部消融）单列，不计入外部基线数。

## 一、外部基线（5 个）

### 1. 基础范式锚点（建立领域公共参照系）

1. **EoH**（[ICML 2024](https://proceedings.mlr.press/v235/liu24bs.html) · 官方源码 `FeiLiu36/EoH`，[`baselines/eoh/`](../../baselines/eoh/)）
   - **机制**：自然语言 `thought` 与代码协同演化，扁平种群配合多生成算子，无历史树与经验池。
   - **入选原因**：LLM4AD 领域最通用的基础种群演化基准，作为所有结构与记忆增强方法的公共起点。

2. **ReEvo**（[NeurIPS 2024](https://papers.nips.cc/paper/2024/hash/4ced59d480e07d290b6f29fc8798f195-Abstract-Conference.html) · 官方源码 `ai4co/reevo`，[`baselines/reevo/`](../../baselines/reevo/)）
   - **机制**：成对优劣比较的短期反思与跨代累积的单段长期反思共同指导交叉与变异。
   - **入选原因**：语言反思演化的奠基基线，用于对照“普通代际种群 + 全局扁平长短期反思文本”的基准水平。

3. **MCTS-AHD**（[ICML 2025](https://proceedings.mlr.press/v267/zheng25o.html) · 官方源码 `zz1358m/MCTS-AHD-master`，[`baselines/mcts_ahd/`](../../baselines/mcts_ahd/)）
   - **机制**：保留完整生成派生树，按 UCT 分配扩展机会，并结合根到叶路径上下文生成启发式。
   - **入选原因**：历史树搜索的代表基线，用于对照“保留整棵演化树 + 树统计调度（不解耦代表集、不做树简化与经验凝练）”的效果。

### 2. 前沿直接对手（检验核心竞争路线）

4. **RefineEvo**（[ICML 2026](https://proceedings.mlr.press/v306/wu26ap.html) · 官方源码 `samwu-learn/RefineEvo`，[`baselines/refineevo/`](../../baselines/refineevo/)）
   - **机制**：维护成功与失败正负双向经验池，按语义向量相似度检索经验，并由规划器动态选择与改写演化算子。
   - **入选原因**：全局经验池路线的最新顶会代表，直接对照“脱离树拓扑、靠成败分池与语义检索复用经验”是否足以替代 EvoTrace 的树节点/边原位锚定。

5. **PathWise**（[ICML 2026](https://proceedings.mlr.press/v306/gungordu26a.html) · 官方源码 `oguzhangungordu/PathWise`，[`baselines/pathwise/`](../../baselines/pathwise/)）
   - **机制**：外层维护竞争种群，内层展开推导蕴含图并结合 Policy、World Model 与 Critic 反思进行多步推演。
   - **入选原因**：结构化图搜索与反思耦合的最新顶会代表，直接对照“外层种群 + 内层推导图的套叠双重结构”与 EvoTrace“单棵派生树内解耦代表集竞争与反思树简化”的设计取舍。

## 二、内部参照（单列）

- **TraceAAD Base**（[`traceaad_base/`](../../traceaad_base/)）：同任务接口与同算子框架下的无树、无经验 Boltzmann 采样基线，提供内部起点参照。
- **EvoTrace 内部受控消融**（[`evotrace_v3/`](../../evotrace_v3/)）：在同一实现内隔离单一机制贡献，包括隐藏节点/边经验（`include_experiences=False`）、原始代码差分对比凝练经验、同经验文本下原位锚定对比扁平列表、以及去除 AST 结构覆盖（`cover_distance=0`）。
