# 基于演化轨迹的评分机制：第一版设计

北京时间2026-11-03。本文给出第一版完整设计，以及每个关键决策的原因、理论依据和现有证据。证据全部来自历史日志分析；没有修改在线代码，也没有启动新实验。脚本与输出见[分析目录](../../experiments_result/analysis/trajectory_value_mechanism_20261103/)。

## 结论

预算分配分两步：先按固定比例抽取算子 \(o\)，再按价值 \(V_o(p)\) 的比例抽取节点 \(p\)。价值估计"从 \(p\) 出发做一次 \(o\)，子代超过当前全局最好"的概率：

\[
V_o(p)=\underbrace{b_o(g_p)}_{\text{基础概率}}\times\underbrace{\frac{n_0}{n_0+k_o(p)+\lambda\,k_{\bar o}(p)}}_{\text{消耗因子}}\quad[\times\ \text{精炼诊断的似然比}]
\]

| 组成 | 读取的轨迹字段 | 含义 |
| --- | --- | --- |
| \(g_p\)：\(p\) 与当前最好的相对差距 | 节点适应度 | 离目标还有多远 |
| \(b_o(g)\)：基础概率 | 本次搜索中全部带算子标记的父子结果 | 用算子 \(o\) 从这个差距出发，一次超过最好的概率 |
| \(k_o(p),k_{\bar o}(p)\)：\(p\) 上同类、异类算子的无效尝试数 | 子代的算子、适应度、代码 | \(p\) 的潜力已被检验到什么程度 |
| 似然比（仅精炼） | 代码、design、analysis、祖先路径上的修改说明 | 是否存在可定位、影响输出的实现缺陷 |

精炼与拓展的区别来自两处：\(b_o\) 随差距变化的方式不同，诊断项只服务精炼。

## 1 目标量：一次尝试超过当前最好的概率

**决策。** 价值的预测对象是"子代超过当前全局最好"（下称突破），不是"子代优于父代"，也不是子代的平均质量。

**原因。** 搜索的最终产出是最好程序。优于父代只说明局部可修，不说明值得投入。等预算接续 pilot 直接显示了两者的分离：16条接续中12条改善了起点，0条超过全局最好（[接续记录](2026-11-03-轨迹行为信号与等预算接续.md)）。

**理论。** 这是贝叶斯优化中的改进概率（probability of improvement, Kushner 1964），即以当前最好为阈值的超越概率。期望改进（EI, Jones 等 1998）还要乘以超越幅度。第一版不乘幅度，因为现有数据还看不出幅度能按状态预测。

**视界取一步。** 价值只看下一次尝试，原因有两个。第一，价值从祖先流向后代：一次成功产生的子代自己进入候选，下一步从它出发是另一次决策，多步路径由一步决策串成。第二，一步结果立即可得，不受后续策略影响。代价是：刚接入新思想、需要多轮精炼才兑现的设计会被低估。第3节的数据显示，拓展的基础概率几乎不随差距下降，消耗因子又会压低反复失败的高分节点，这两点部分抵消了低估。视界仍是最关键的未知量（第8节）。

## 2 基础概率 \(b_o(g)\)：按算子与差距，跨节点共享估计

**决策。** \(b_o(g)\) 按差距分四档：\(p\) 就是当前最好；差距 \(<1\%\)；\(1\%\sim5\%\)；\(\ge5\%\)。每档用本次搜索中该算子的全部尝试估计突破率，以历史数据作 Beta 先验，在线更新。

**原因与理论。** 单个节点的轨迹很短，无法单独估计突破率。跨节点共享估计属于经验贝叶斯（empirical Bayes）：同类单元共享一个总体分布，少量的单元观测向总体收缩。这与 LinUCB 混合模型共享参数、缓解单臂样本不足的做法相同。

**为什么不用父代增益分布推算。** 我先试了一个更"理论化"的做法：用父子增益的指数尾估计跨过差距的概率。它在两端都错了。V19.1 精炼中，\(p\) 就是当前最好时，预测0.44，实测0.093；差距超过4倍平均增益时，预测0.001，实测0.004（V19为0.043）。原因是：近最好处的节点更难改进，而远处节点偶尔通过大幅重写直接突破。因此 \(b_o\) 直接以突破为标签估计，不从增益推算。

**证据：突破率随差距的变化（%）。** 统计对象是各版本自身策略选中的全部有效父子对，修复中间版本折叠到最近的有效父代。

| 版本 | 精炼：=0 / <1% / 1–5% / ≥5% | 拓展：=0 / <1% / 1–5% / ≥5% |
| --- | --- | --- |
| V15 | 4.3 / 2.5 / 1.3 / 1.0 | 2.9 / 2.0 / 1.3 / 1.8 |
| V17 | 6.4 / 2.6 / 2.5 / 1.0 | 4.6 / 2.2 / 1.4 / 1.6 |
| V18.1 | 2.5 / 1.4 / 1.0 / 0.7 | 3.3 / 1.6 / 1.3 / 1.8 |
| Base | 6.8 / 2.3 / 0.7 / 0.6 | 4.9 / 1.8 / 0.8 / 2.2 |
| V19.1 | 9.4 / 1.4 / 0.6 / 0.3 | 9.1 / 1.5 / 0.8 / 0.6 |

两个规律在五个版本中都存在。第一，差距为零的节点突破率最高。第二，精炼的突破率随差距单调下降；拓展在差距超过1%后基本持平，四个版本中 ≥5% 档不低于 1–5% 档。因此，同一套比例抽样下，精炼会集中在最好附近，拓展会分散到更远的节点。这正是"不同算子需要不同价值"的数据基础，而且不需要额外规则。

## 3 消耗因子：\(p\) 上的无效尝试越多，下一次越难

**决策。** 只计无效尝试，即子代没有优于 \(p\)，包括变差、同分和生成失败，三类权重都为1。规范化后代码与 \(p\) 相同的子代权重为0，因为它就是已知结果。成功不计：成功的子代自己进入候选，\(p\) 的突破价值不因子代成功而上升。

**理论。** 设节点 \(p\) 对算子 \(o\) 有未知的成功率 \(\theta_p\)，各节点的 \(\theta\) 服从 Beta 分布。连续观察到 \(k\) 次失败后，下一次成功的预测概率是

\[
P(\text{成功}\mid k\text{ 次失败})=\frac{\alpha}{\alpha+\beta+k}=\bar\theta\cdot\frac{n_0}{n_0+k},\qquad n_0=\alpha+\beta .
\]

这就是消耗因子的来源。营销学的流失模型（shifted Beta-geometric, Fader & Hardie 2007）用同一结构解释"留存越久的客户越不容易流失"：个体本身不一定在变化，而是总体有异质性，失败让我们知道这个个体的 \(\theta\) 偏低。对搜索来说，两种解释（潜力被用尽，或潜力本来就低）都意味着下一次价值下降，机制不需要区分它们。

**证据一：Beta 预测与实测吻合。** 下表是精炼子代优于父代的比例，按此前同一父代上的无效精炼次数 \(k\) 分组。括号内是用 \(k=1\) 拟合 \(n_0\) 后对 \(k=2,3\) 的预测。

| 版本 | k=0 | k=1 | k=2 | k=3 | k≥4 | 拟合 \(n_0\) |
| --- | --- | --- | --- | --- | --- | --- |
| V15 | .27 | .17 | .11（.12） | .09（.10） | .05 | 1.7 |
| V17 | .28 | .19 | .17 | .16 | .08 | 2.1 |
| V18.1 | .31 | .14 | .09（.09） | .07（.07） | .04 | 0.8 |
| Base | .30 | .18 | .12（.13） | .13（.10） | .04 | 1.5 |
| V19.1 | .47 | .30 | .21（.22） | .14（.18，n=28） | – | 1.8 |

拓展有相同的趋势，例如 V18.1 为 .35/.20/.14/.10/.07，Base 为 .22/.15/.08/.05/.04。\(n_0\) 在0.8–2.1之间，第一版取历史估计值，再在线更新。

**证据二：控制差距后，失败仍然降低突破率。** 只看 \(p\) 是当前最好的尝试，按 \(k=0/1/\ge2\) 分组的突破率（%）如下。精炼：Base 9.5/5.4/3.0，V17 8.5/6.3/4.3，V15 8.3/3.1/1.6，V18.1 4.4/1.0/1.2。拓展：Base 6.3/5.9/2.7，V17 7.1/5.0/2.6，V15 5.5/2.2/1.5，V18.1 4.7/3.2/2.2。到 \(k\ge2\) 时，突破率下降为原来的1/2到1/5。

**异类失败也算，权重 \(\lambda\)。** 原先我设想消耗只针对同一算子：精炼饱和的节点精炼价值低，但拓展价值不受影响。数据不支持这一点。在同类失败为0的尝试中，一次异类失败使优于父代的比例从 .31 降到 .19（V15 精炼），从 .39 降到 .21（V18.1 拓展），从 .24 降到 .13（Base 拓展）。它的降幅与一次同类失败接近，换算成 \(\lambda\) 约为0.7–1。因此消耗主要是节点层面的：一个节点在任一算子下反复失败，都说明它的潜力偏低。第一版取 \(\lambda=0.8\)，在线估计。

**为什么不区分失败类型，也不用行为探针剔除。** 我原先担心：同分或决策未变的尝试没有真正检验 \(p\)，不应计入消耗。数据不支持区分。只看此前恰好有一次失败的父代，下一次精炼优于父代的比例如下（无失败 / 前一次变差 / 前一次同分 / 前一次生成失败）：V15 为 .28/.17/.12/.15，V17 为 .28/.18/.14/.22，V18.1 为 .32/.12/.10/.16，Base 为 .31/.20/.17/.19，V19.1 为 .44/.27/.26/.26。同分失败带来的下降不小于变差失败。分类型计数也几乎不提高预测；只有 V18.1 精炼的突破 AUC 从 .619 升到 .679。我的解释是：生成器在 \(p\) 上只能写出不改变决策的改动，这本身就说明 \(p\) 上缺少它能找到的有效改法。另一侧的探针也表明，这类改动的语句都执行了，只是没有改变决策（历史 TSP 抽样中，AST 不同而两条完整路线相同的情况在 V16、V17、V18.1、V19.1、Base 中都出现过）。短探针还会高估"输出相同"，例如 V14 中六个状态全同的有6/8对，完整路线相同的只有1/8对。所以第一版只剔除规范化后代码相同的子代。

**为什么成功不计。** 子代成功确实说明 \(p\) 容易改进：此前有成功、无失败时，下一次优于 \(p\) 的比例约为无尝试时的1.5–2倍（V15 精炼 .55 对 .28，V19.1 精炼 .66 对 .44，五个版本都如此）。但下一次突破全局最好的比例没有提高：V15 为 .039 对 .035，V17 为 .028 对 .034，Base 为 .020 对 .024，V19.1 都是 .005。加入成功数与最大增益后，"优于父代"的 AUC 在全部版本提高 .01–.04，突破的 AUC 则时升时降。原因是改进已经由成功的子代吸收，门槛随之抬高；从 \(p\) 再做一次，多半只能重复子代的水平。这与"价值从祖先流向后代"一致。另一侧发现，近期最大增益能预测 \(p\) 所在分支在后续30次内突破；这个标签包含了成功子代自己的后续，所以并不矛盾。

脚本与输出：`mech4.py`、`out_typed_success.txt`。

**证据三：失败计数在差距之外提供预测信息。** 用逻辑回归预测突破，按运行做6折交叉验证，AUC 如下（差距 → +同类失败 → +异类失败）。

| 版本 | 精炼 | 拓展 |
| --- | --- | --- |
| V15 | .609 → .667 → .702 | .508 → .601 → .609 |
| V17 | .607 → .635 → .656 | .568 → .625 → .634 |
| V18.1 | .553 → .613 → .619 | .521 → .556 → .580 |
| Base | .747 → .747 → .748 | .633 → .648 → .647 |
| V19.1 | .626 → .624 → .615 | .540 → .537 → .606 |

四个旧版本中，失败计数都有增益；Base 的精炼没有增益；V19.1 的突破样本很少（精炼37个、拓展67个）。这些增益不大，但方向一致，足以让失败计数进入第一版。

## 4 精炼诊断：独立调用，按似然比进入价值

**决策。** 节点第一次被抽中精炼时，先做一次独立的 LLM 诊断，不与反思合并。输入是 \(p\) 的代码、design、analysis，以及祖先路径上的修改说明和适应度变化；如果 \(p\) 来自修复，再加修复前后的版本。如果 \(p\) 比祖先路径上最好的那个祖先差，再加入那个祖先的代码，让诊断指出 \(p\) 相对它删掉或改坏了什么。输出是：是否存在可定位、会影响输出的实现缺陷；有的话给出位置，并用一句话说明它怎样影响输出。诊断结果作为材料交给这次精炼，同时进入之后的价值计算。

**进入价值的方式。** 诊断改变的是 \(V_R\) 的几率（odds）：\(\text{odds}'=\text{odds}\times \mathrm{LR}\)。LR 在线估计：比较"有诊断缺陷"与"无缺陷"的节点，它们的精炼子代优于父代的几率之比，并加平滑、向1收缩。如果诊断没有区分力，LR 趋于1，这一项自动失效。依据缺陷的精炼一旦失败，这条诊断就算用掉，LR 回到1。

**原因与理论。** 诊断是不确定的证据。按贝叶斯更新，它应以似然比改变先验几率，权重由它过去的区分力决定，而不是由人工设定的加分决定。这样它的决策权受数据约束，判断错误的代价也有上限。这里假设诊断对"优于父代"的几率效应可以平移到突破。之所以用优于父代来校准，是因为突破太少，无法在线校准。

**证据。** 目前只有案例，没有统计。这些案例说明：同样的适应度，背后的代码状况可能完全不同，而读代码能看出这种差别。
- CVRP P189→P193：精炼把 `beta` 从4改为6，适应度相同。可行边的指数因子恒为1，不可行边被掩码置零，所以 `beta` 在合法输入域内不起作用。这次失败说明这个参数无效，不说明精炼空间已经用尽。
- 图着色 P169：design 写的是模拟退火，但入口路径上冲突数已为0，退火从未执行。
- JSSP P316：接受移动时无条件覆盖历史最好的输出，造成可定位的输出错误。
- JSSP P77→P84：修复删掉了剩余工作量信息，分数退步；补回这部分信息后成为新最好。
- V15 TSP P93→P94→P100：P94 把完整的贪心补全换成两项最短边近似，分数退步；P100 恢复后回到 P93 的水平。
- V17 TSP P230→P231→P235：P231 把完整路线模拟换成距离惩罚，退到12.52；P235 恢复模拟，同时保留 P231 的候选限制，达到6.19，低于 P230 的6.26，并留在最终最优链上。

后两例来自另一侧对最优链低排名节点的代码核对。它们说明：最优链上出生排名低的节点，常常是"删掉好结构、再恢复"的弯路，而不是提出了有益新思想的踏脚石。对这类节点，相对好祖先的差异就是可定位的精炼机会。P235 还说明，恢复时保留新结构的有用部分，可以超过原来的祖先。

案例来源：[轨迹字段与代码潜力](2026-11-02-轨迹字段与代码潜力.md)、[历史线索](2026-11-03-轨迹价值历史线索.md)。祖先路径主要通过这一项进入价值：哪次修改删除了什么、哪些机制从未执行，都要读路径和代码才能知道。

**成本。** 每个被精炼的节点最多诊断一次。

## 5 抽样：按价值比例抽取节点

**决策。** \(P(p\mid o)\propto V_o(p)\)。不用 argmax，也不加 UCB 式的探索奖励。

**原因与理论。** 突破概率只有百分之几，估计噪声大，argmax 会把预算押在估计误差上。按概率比例抽样就是概率匹配（probability matching），它与 Thompson 抽样同源，可以在不另设探索项的情况下保持覆盖。机制也不给新个体保留尝试次数：新节点 \(k=0\)，消耗因子为1，它的价值仍由差距和算子决定。

## 6 融合对象：按互补性选择

先按拓展价值选出节点 \(p\)，再选择融合对象 \(r\)：\(P(r\mid p)\propto b_E(g_r)\times(1-\cos(e_p,e_r))\)。其中 \(e\) 是 design 文本嵌入，第二项表示两个设计相差越大越可能互补。这一项还没有证据，只有设计理由：融合是否成功取决于一对算法，不属于单个节点（见 [method.md](../method.md)）。

## 7 没有进入第一版的轨迹信号

| 信号 | 证据 | 决定 |
| --- | --- | --- |
| 最近一步的适应度变化，按算子解读（如"融合后小幅下降是好信号"） | V19.1 中按算子与变化幅度分组，后代刷新全局最好的比例都在2.6%–8.4%，小幅下降组最低 | 不直接使用；差距项已包含当前水平 |
| 设计年龄（新思想接入后经过的精炼步数） | Base、V17、V15 中精炼的平均增益随年龄明显下降（如 Base .097→.012），但改进率不变，突破率的变化在各版本不一致 | 暂不纳入；作为第一个候选残差特征 |
| 趋势、波动、AST、文本相似度等丰富静态特征 | 批量预测增益小且不稳定：我的模型 AUC +0.014（精炼）/+0.024（拓展）；另一侧的 AP 没有增益 | 预留残差接口：把 \(b_o(g)\) 扩成 \(b_o(g,\phi)\) |
| 出生排名、祖先路径趋势 | 另一侧在23个批次中预测后续30次内的分支突破：加入出生组后，14/23批次 AP 提高；加入路径组后，10/23批次提高 | 不设固定加分 |
| 低起点节点作为踏脚石 | 校正后，最优链上出生在后60%的节点比例多为1%–12%，只有 V19、V19.1 为25%–31%；代码核对显示其中常有"删掉再恢复"的弯路 | 不设专门奖励；弯路节点由诊断项通过与好祖先的对比处理 |

残差特征的准入标准：在按运行留出的验证中，它在 \(b_o(g)\) 与失败计数之外提高突破预测，且方向在多个版本中一致。

## 9 关键未知量与下一步

1. **视界。** 一步突破可能低估需要多轮精炼的新设计。目前的证据让这个担心变小了：最优链上的低排名节点多为弯路，不是需要长期打磨的新设计；另一侧的30次分支标签下，当前水平与已有尝试也是主要信号，与一步标签一致。下一步仍要直接比较两种标签对节点的排序。
2. **在线估计是否稳定。** 在一次搜索的前期，\(b_o\) 的四档样本很少，需要确认历史先验的强度。
3. **诊断的区分力。** 先在历史节点上离线运行诊断，用它们的真实精炼结果估计 LR，再决定是否进入完整搜索。
4. **最终检验。** 在固定协议下运行完整搜索，与当前机制比较最终结果。短对照只用来检查各项算得是否正确，不用来裁决机制。

## 对 method.md 叙述的影响

有两处叙述与数据不一致，需要修改。
- "融合的第一版实现往往会损失一些性能"：V19.1 中融合子代当步改进的比例为57%，在三种算子中最高。
- "饱和的节点转向拓展"：异类失败同样降低改进率，所以饱和节点的拓展价值也会下降。按算子区分价值的依据应改为：两种算子的突破概率随差距变化的方式不同，所以精炼集中在最好附近，拓展分散到更远的节点。
