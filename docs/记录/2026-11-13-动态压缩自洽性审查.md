# 动态压缩自洽性审查

结论：统一剪枝、路径收缩和经验交接的核心合理。上一版候选仍有冗余规则、选择语义与模拟不一致、经验归属示例错误，不能直接作为定稿。最小修订是删除宽长提前折叠分支，固定一次维护中的质量保护集合，并暂时沿用每个实际移除区域一次反思。

本轮检查对象为采用宽8、长6、空闲8及移除后积累4次再反思的早期候选、[冻结回放](../../experiments_result/analysis/evotrace_compression_sim_20261113/README.md)、`sim.py`、`audit.py`及当前V2的选择、分区、采样、经验读取代码。没有修改方法实现或在线实验。

## 哪些部分成立

算法作为下一次修改起点的价值，与其经历作为参考的价值可以分别保留。先确定保留算法，再恢复必要分叉，最后将被删部分分成路径与旁支，这个顺序合理。它支持同次处理宽分叉和长路径，不需要为两种结构操作分别规定保留配额。

直接开发次数与承接历史必须分开。压缩不能清空真实投入，也不能把后代历史全部变成承接算法自身的开发次数。模型负责凝练经验；保留决定、统计与真实来源由程序给出。这些区别有实际用途，应当保留。

## 具体问题与处理

| 检查项 | 发现 | 影响与最小处理 |
| --- | --- | --- |
| 宽8、长6、空闲8 | 在全部36路中只提前折叠10个版本；同源码也不意味着相同谱系上下文 | 三个阈值加同方向、同区域条件几乎不改变结果。删除整个提前折叠分支，保留统一的结构剪枝和收缩 |
| 前50%质量保护 | `sim.py`在同一维护中最多重算6轮；删掉较差节点后再次缩小保护集合 | 将一次维护的候选、排名和保留集合固定下来，只选一次。结构闭包不再反过来触发本轮重选 |
| 规模约50–80 | 来自有限历史事件流，不是规则保证。必要分叉与前半保护可以相互支撑 | 改为工作尺度观察；不声称冷却40能保证大小或缓慢增长。前50%是暂留启发式，需要与采样共同检验 |
| 移除后攒4个反思 | 引入待处理材料、跨节点迁移、原始卡片读取及恢复语义；末尾仍有大量未反思版本 | 暂时撤回异步积累。按最终计划合并同一承接位置的移除区域，每区一次反思；若成本过高，再单独优化调用时机 |
| 旁支归属 | 文档例子把被删B、C的新旁支送到A→D边；模拟与V2实际送到最近保留祖先A | 固定原始拓扑和最终保留集合，唯一分区。修正文档，不混用两种经验归属 |
| 访问聚合的用途 | 最近使用时间与累计次数含义不同；旧文把聚合次数也称为冷度依据 | 冷度只用真实最近使用时刻；累计投入用于经验和方向发展记录。没有消费方的历史时间缓存不新增 |
| “压缩不参与选择” | 折叠节点会取消它的父代与参考资格，且改变全树中位数与采样权重 | 撤回严格分工说法。分配决定本次开发对象；压缩决定后续可开发集合，两者相互作用 |
| 反思提示 | 主旨合理，但输入已给统计时，重复写多段统计解释增加负担 | 保留实际计算、结果、旧经验和解释边界，用简短统一提示；不新增审判模型或关键词删句 |
| 288次回放的证据 | 实际是36路历史事件流复用8组规则，且删除父代后仍注入原历史后代 | 用于检验结构、规则冗余与使用冲突；不是288次独立搜索，也不能证明新策略收益 |

## 三个可执行反例

脚本为[consistency_review.py](../../experiments_result/analysis/evotrace_compression_sim_20261113/consistency_review.py)，原始结果为[consistency_review.json](../../experiments_result/analysis/evotrace_compression_sim_20261113/consistency_review.json)。反例暂时关闭AST近似过滤，隔离排名与结构本身的作用。

**质量保护在一次维护中被推翻。** 虚拟根下有8个不同算法，全部空闲超过40次，成绩依次为1至8。第一次选择保留1至4；旧模拟接着在这4个里重算排名，保留1至2，再只剩1。保护集合由同一次删除不断变动，与“本轮保护前半候选”的通常含义不一致。真实36路的纯冷却40回放中，909个节点在本轮开头受保护、却在同轮后续迭代被删，因此不是仅存在于构造例子中的差异。

**全冷不保证缩小。** 构造255个算法节点的完整二叉树，128个叶节点的成绩都好于127个内部节点，所有节点都已空闲1000次。前半质量保护留下全部叶节点，LCA闭包恢复全部内部节点，最后仍为255个节点。可以构造更大的同类树。必要分叉本身没有错；问题是不能从这个选择与闭包的组合推出规模稳定。

**旁支的实际归属与例子不同。** A→B→C→D，另有B→X，仅保留A、D。模拟将B、C计入A→D的路径材料，将X计入A的旁支材料；上一版例子把X也送到了边上。新移除节点应按维护前的真实拓扑唯一分区。已有经验随原承载节点或边所属的区域迁移，保留实际来源；先前已经汇总的记录不重新计为新事件。

## 最小修订方案

每次新版本评价结束，使用同一个维护前快照执行以下步骤：

1. 保留最近40次评价内出生或实际用作父代、参考的可行版本。模型接口故障不推进评价时钟，正常修复重评推进；失败版本保存错误后退出可用集合。
2. 计算一次质量与差异保护集合。暂沿用前50%的秩门槛、AST近似阈值0.08和同分0.20，冠军必留。代表必须成绩更好或相等；结构锚点不参与排斥代表。这些阈值是既有启发式，不是本轮证明的最优值。
3. 合并上述保留集合，补齐必要LCA。给定这些保留算法，一次闭包已能决定全部必要分叉和连接，无需重做质量选择。
4. 在原始拓扑上，将其余节点唯一分成路径中间版本与无保留后代的旁支。前者形成重连边经验，后者进入最近保留祖先的选择经验。没有实际移除就不反思。
5. 同一最终承接位置的材料合并后做一次反思，连同统计与结构一起提交。反思失败沿用已有确定性回退，不增加新持久队列。

宽分叉、长路径仍会在同次更新中被简化。这里宽、长描述的是需要简化的结构；最近使用与质量差异提供保留理由。不再为宽、长另加一组几乎不起作用的提前淘汰阈值。这个版本也不承诺折叠所有正在被频繁使用的长链；若实际运行中它成为明显成本，再针对该事实新增规则。

仅修正“同轮重复选择”为一次选择，在同样36路冻结输入上补做回放。以下只验证结构，不包含新的反思调用政策和模型输出：

| 来源 | 单次选择后平均节点 | 峰值 | 创纪录主父代冲突 |
| --- | ---: | ---: | ---: |
| V1 | 60.4 | 78 | 0/203 |
| V2 | 79.9 | 103 | 11/70 |
| Base | 78.5 | 103 | 13/107 |

规模与旧回放接近，支持删除同轮重复选择，不支持声称40是最优窗口。下一次评价后，排名仍可能变化；固定一次维护的集合解决本轮级联，不提供跨多轮的终身保护。

## 统计与经验的最小要求

- `children_count`继续表示当前版本的直接子代生成次数；`last_used`表示当前版本最近一次真实使用或出生时的评价时钟。
- 被折叠历史按原始来源分别累计实际评价、失败以及父代/参考使用。使用次数与评价次数保持不同单位；是否展示某项统计由具体生成用途决定。
- 每一种统计分别满足事件唯一归属和总量守恒。父代与参考使用可以分别属于不同承接位置，不能要求同一个交叉事件的所有角色都强行落到一个位置。
- 方向统计是按原始方向的另一种汇总视图，不能再与节点/边持有的历史统计相加。既有日志保留真实父代、算子及交叉参考；压缩后的单条边不冒充一次真实生成操作。
- 冷度只需要当前版本的最近真实使用时刻；整块区域是否冷，可从显式存活节点的时刻求最大值。被折叠历史的旧时间不刷新当前版本，累计访问数不参与冷却公式。
- 模拟现有断言只核对计数总和，不能证明事件没有“一个重复、另一个丢失”。正式实现应按原始事件标识核对去重和迁移，包括多轮压缩、交叉引用与恢复。

精简后的反思提示候选：

```text
Write a concise research note connecting the implemented computations,
their observed outcomes, and useful earlier experience. Use the actual
parent relationships and supplied development history. Distinguish
observations from possible explanations, and leave future design decisions
open. Return one JSON object with an "experience" string, around 120 words
or less when the evidence is sparse.
```

单次初稿与充分开发的差别用实际材料表达，不能凭冷、宽、长标签推断。这个精简提示与旧提示一样，仍需实际模型调用才能判断质量；不能用变短代替验证。

## 当前判断

我撤回“上一版参数已经收敛成一套合理完整的联合机制”的表述。现在可支持的是：冷度与质量保护提供一个可执行保留规则，LCA闭包将其统一实现为剪枝和路径收缩；额外几何阈值没有显示足够作用，反思积累队列尚未证明值得。

仍会改变下一步决策的核心问题是：在真实采样闭环中，全树相对排名与冷却是否让新方向过早失去修改机会，或让大量结构锚点长期留下。最小修订先固定其余条件作短程续跑，观察算法质量、方向实际开发、经验使用与模型成本。本轮不引入额外探索配额、容量控制器或新的综合评分来掩盖这一未知量。
