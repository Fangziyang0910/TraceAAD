# Base 父代选择：以直接子代质量分配预算

日期：2026-10-30，北京时间。正式规则已写入 [Base 父代选择](../TraceAAD-Base.md#6-父代与生成操作的选择)。本轮核对论文、源码与公式，没有运行模型或搜索实验。

**决定：父代自身质量提供初始估计，直接子代在全库中的质量提供产出证据，模型调用数提供成本。是否超过父代或交叉参考不参与收益计算。**

## 1. 规则与含义

每次选择前，按全部有效候选的成绩升序排名，排除 0 号根，同分取平均名次。定义当前质量 \(q_t(x)=1/r_t(x)\)。令 \(\mathcal V_p\) 为以 \(p\) 为主父代的全部最终有效直接子代，\(C_p\) 为这些开发尝试的实际模型调用总数，包含失败与修复。选择权重为：

\[
w_p(t)=\frac{3q_t(p)+\sum_{y\in\mathcal V_p}q_t(y)}{3+C_p},
\qquad P_t(p)=\frac{w_p(t)}{\sum_jw_j(t)}.
\]

未尝试时 \(w_p=q_t(p)\)；有直接证据后，逐步用单位调用产生的子代质量修正初始估计。常数 3 沿用原有平滑强度。父代与历史子代的质量均按当前名次重算，避免一直奖励已经落后的旧排名。

每次尝试至多贡献一个最终子代。有效子代均贡献其质量，最终无有效产出记零；修复增加调用成本，不额外增加一份产出。交叉结果与成本只归主父代，参考身份保留，但不以参考成绩设置奖励门槛。统计使用全部直接尝试，不受提示中的 8／3／2 窗口限制，不沿祖先链回传。

这里估计的是产出质量，既不计局部改善次数，也不要求刷新个人或全局纪录。用户明确纠正了我此前保留“超过输入才奖励”的做法：**高质量子代可以略差于优秀父代，低质量子代也可以远好于很差的父代；父子改善不能代替产物质量。** [独立核对](2026-10-30-父代选择定案独立核对.md)中的改善门槛属于已放弃的候选，最终采用本式。

## 2. 依据与取舍

[ShinkaEvolve 方法](https://arxiv.org/html/2509.19349v1)给出幂律排名选择；[源码](/home/fang/code/LLM4AD/reference_code/ShinkaEvolve/shinka/database/parents.py:11)支持指数 1，即倒数排名。其默认策略另为 weighted，不能将这一出处说成倒数排名已被证明最优。Base 原用的 EoH 权重 \(1/(N+r)\) 在全库中最多产生不足两倍的质量差异，而 EoH 还配有精英种群筛选；这一迁移条件在此前设计中被忽略。

[QUBE 方法与消融](https://arxiv.org/html/2412.20694v4)更直接支持观察父代生成的子代质量：OR3 装箱消融中，自身质量、子代平均质量、再加 UCB 探索项的平均 excess ratio 分别为 3.07%、2.98%、2.89%。它采用 cluster 与绝对成绩，没有采用父子改善奖励。Base 借鉴子代质量这一统计对象；倒数排名、平滑和调用成本的组合是本次设计，尚未获得该消融的验证。可定位[方法](/home/fang/code/LLM4AD/papers/QUBE_Enhancing_Automatic_Heuristic_Design_via_Quality_Uncertainty_Balanced_Evolution/main.tex:273)及[消融](/home/fang/code/LLM4AD/papers/QUBE_Enhancing_Automatic_Heuristic_Design_via_Quality_Uncertainty_Balanced_Evolution/main.tex:391)。

自身质量只作为初始估计，避免很差的父代即使稳定产出优秀子代，仍被自身低排名永久压低。使用质量而非纪录次数，也避免奖励“连续刷新很弱的个人纪录”超过“持续产生优秀算法”。

此处保留全部有效程序并按比例随机选择，不设固定 ESS、精英截断或强制试遍每个新程序。平均名次会降低同分个体各自的质量权重，但不保证重复方向的总选择概率不增长；既定的不去重设计没有提供辨别相同源码与不同同分算法的依据。

## 3. Clade-AHD 的贝叶斯信念是否更适合

**参考了，但必须区分产出价值、估计不确定性与实际选择对象。** [Clade-AHD 在线 v2](https://arxiv.org/html/2602.00549v2#S4)用归一化绝对成绩作为分数证据，更新 Beta 信念；后代证据按祖先距离衰减聚合，再用汤普森采样（Thompson sampling）逐层选择分支。它也不以超过父代定义奖励。

忽略聚合与退火时，基本更新是：

\[
\alpha\leftarrow\alpha+u,\qquad
\beta\leftarrow\beta+1-u,\qquad
\hat\theta\sim\operatorname{Beta}(\alpha,\beta),\quad u\in[0,1].
\]

信念同时记录均值与不确定性。同样的均值可以来自少量或大量证据；汤普森采样利用这种差别，让尚不确定的分支有机会因较高抽样值而被选择。只按平滑均值分配没有这一能力；不能把 Base 的随机选择称为汤普森采样。

这一思想值得保留，但有两个迁移条件：

- **决策对象**：Clade-AHD 选择继续探索的子树，再向下寻找展开位置。Base 直接选择下一次提供代码的父代。优秀远代能支持继续开发这一分支，却不直接证明重新修改祖先原代码有相同价值；因此 Base 先用直接子代证据。
- **候选规模与先验**：Base 的候选不断增加，若统一使用宽先验，探索强度会随未试候选数量增大。假设一个已充分观测的候选固定取值 0.8，另有 20 个未试候选独立服从 Beta(1,1)，至少一个未试候选胜出的概率为 \(1-0.8^{20}=98.85\%\)。这个算例说明先验与候选数量会共同决定分配，不是 Clade-AHD 的实测行为，也不说明贝叶斯选择本身无效。

本轮还核对了在线 v2 新增说明：§IV-A 明确将连续质量的分数更新视为减少额外伯努利抽样噪声的建模选择；它不是对相关、变化中的程序产出的校准概率保证。表 VI 支持五个组件在其整套方法内的作用，表 VII 补充 UCT 参数比较，但均未隔离“同样证据和搜索空间下，信念抽样相对平滑均值”的收益。本地实现另有重叠证据聚合问题，详见[源码核对](2026-10-30-轨迹预算分配文献核对.md)；这个实现问题不构成否定贝叶斯思想的理由。

**Base 的选择：先采用上面的平滑质量权重，不另建 Beta 信念。** 它直接回答当前父代的产出质量与成本，也避免在持续扩大的候选库中额外设置信念先验、聚合与探索控制。若检验不确定性建模，最有区分力的对照是固定直接子代质量、成本、提示和候选范围，只改变选择规则；不能同时换成整谱系统计再把效果全部归给贝叶斯信念。

## 4. 公式核对与证据边界

以下均为静态算例，不是搜索实验：

| 条件 | 规则的结果 |
| --- | --- |
| 父代 10 分，子代 11 分、全库第 2 | 子代贡献 \(1/2\)，虽未超过父代仍计入 |
| 父代 100 分，子代 99 分、全库第 90 | 子代贡献 \(1/90\)，局部改善不额外加分 |
| 未尝试父代 | 权重为自身倒数排名，全部有效候选都有正权重 |
| 固定父代第 10、子代第 2 | 直接产出权重 0.20；修复后产出权重 0.16 |
| 固定父代第 10、一次调用无有效产出 | 权重从 0.10 降至 0.075 |

独立核对中的 100 候选算例也保留成立：两个父代均为第 99.5 名，成本均为 10；A 的十个子代名次为 2～11，B 为 89～98，本式给 A 约 14.94 倍于 B 的权重。相同父代质量与成本下，子代质量逐一更好不会得到更低权重。

这是一套有明确统计含义的 Base 默认规则。它估计平均产出质量，未建模罕见突破的尾部概率；当前名次重算反映竞争地位变化，不等于遗忘旧的生成表现。其最终搜索效果仍须在固定生成机制与评价预算下验证，不能由这些算例宣称最优。
