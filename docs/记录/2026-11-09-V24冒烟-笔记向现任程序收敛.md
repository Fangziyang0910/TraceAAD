# V24 冒烟：设计笔记向现任程序收敛

## 结论

V24 的反思机制运行正常，但笔记写成了"现任程序最好，偏离都会退步"，生成随后把笔记引作定论。我先把它归因于提示中要求评价优劣的四处表述，并改写了提示；冻结窗口回放否定了这个解释：改写后优劣判断不减，笔记在两种提示下都跟随当时的现任程序，现任程序变化后随之转向。

当前认识是：向现任程序收敛是按结果归纳的阶段性反思的性质。它是否有害，取决于笔记是否阻止 Refine 和 Crossover 发展新思想，以及突破后笔记是否及时转向，只能由完整搜索判断。新提示保留，V24 正式批次对照 V21。

## 观察

**反思按设计运行。** 第15、25次尝试后各反思一次，最后一窗因预算结束跳过。每次输入4.2K–4.9K tokens，没有请求错误。笔记只进入 Refine 和 Crossover。

**笔记写成了现任程序加一组失败的偏离。** 最好程序在第7次尝试出现：最近邻加 $1/N$ 回程权重，6.8202。之后的偏离都更差。第二版笔记的五条是：

1. $1/N$ 回程系数"outperforms" 固定权重和指数、对数衰减。
2. 最小距离惩罚项常为零，避免使用。
3. 平均距离信号有用，但加入后退步。
4. 复杂多项启发式（孤立、遗憾、空间一致性）"tend to regress"。
5. 一步前瞻不如动态回程贪心。

`analysis` 写的是 "the simple inverse-count pressure is optimal""consistently underperform"。第5条只来自一次 Explore（第14次，相对父代 7.38→8.21）。

**生成把笔记当作定论。** 笔记出现后，生成说明写 "restore the proven simple two-term heuristic""remove this third term entirely, relying solely on the proven two-term computation""remove the minimum distance penalty term which was noted to regress"。第16–35次的17个 Refine/Crossover 中，8个回到 6.8202。但笔记出现前的7个 Refine/Crossover 中也有4个是 6.8202：新增的项常常不改变候选排序，这是机制2文档中已有的同分现象。所以冒烟能说明生成把笔记引作定论，不能说明笔记增加了回退。

**笔记也沉淀了一条好的实现教训。** 第2条指出最小距离项因对角线为零而恒为零。这与机制2文档中的实测一致，是可迁移的认识。

**被笔记否定的方向，正是 V21 在 TSP 上的成功方向。** V21 三路的最好程序（5.70–5.73）都构造完整路线做模拟：多次随机化构造、蒙特卡洛加 2-opt。三路分别在第14、9、34次评价时由 Explore 跳出贪心水平（6.26 或 6.64），之后主要靠 Refine 继续改进。这只是 V21 的事实，不说明 V24 冒烟中的停滞由笔记造成：冒烟只有36次评价，Explore 也不读笔记。

## 已有对策为什么没起作用

| 设计中的对策 | 实际情况 |
| --- | --- |
| 反思不读现任程序的代码 | 我给每张卡片加了 `Search best before this attempt`。现任成绩进入每张卡片，每次尝试都被读成"输给现任"。 |
| "初次实现不等于思想差" | 只是一句措辞。11月2日的回放已表明措辞几乎无效，提问方式才是杠杆。 |
| "计算思想比常数取值更有用" | 现任程序与其他程序的区别正是一个常数公式（$1/N$），第1条笔记仍落在常数上。 |
| Explore 不读笔记 | 保护了 Explore 的生成，但 Explore 子代要靠 Refine 和 Crossover 继续发展，而它们读笔记。笔记说"前瞻不如贪心"，开发前瞻子代的理由就被削弱。 |
| 原位修订、按用处淘汰 | 这些规则稳定了笔记，但稳定的是已有判断。第二版保留了第一版的全部否定，又补入指数、对数衰减和空间一致性两项。这与 V19 两级反思的固化相同。 |

与这些措辞相对，提示中有四处在要求评价：

1. 读者目的："tell which ideas are worth using"。这句话本身就是要模型给思想排序。
2. 笔记要素："what happened when the idea was tried"。
3. `analysis` 的问题："what these attempts show"。11月2日的回放中，这种问法引出42%的否定措辞。
4. 卡片上的搜索最好成绩。

四处评价信号对一句措辞，结果就是排序。

## 初判：笔记的内容定义（已被回放修正）

一批10次尝试中，多数是对较好父代的修改；Base 分配下 Refine 约占42%，刷新率只有几个百分点。新思想的初次实现通常不如调好的现任程序。所以按结果归纳的笔记，必然收敛为"现任程序加一组失败的偏离"。这不是模型的问题，而是笔记的内容定义：只要笔记回答"哪个更好"，局部、早期的结果就会给出这个答案，并且由于被否定的方向不再被尝试，答案不会再被修正。

全局经验的作用是长程记忆和思想迁移。迁移需要的是**怎样把一个思想实现好**：它计算什么，在代码中实际起了什么作用，是什么限制了它。"哪个思想更适合当前程序"应由读者自己的程序和局部轨迹判断，那是机制2的职责。

## 改进方案（已实施，回放见下）

每项改动对应上面的一个原因。

| 改动 | 对应原因 |
| --- | --- |
| **读者目的改为"把思想实现好"。** 读者是要在自己程序上实现思想的设计者；哪种做法适合他的程序，由他的程序和结果决定，笔记不做这个判断。 | 读者目的要求排序 |
| **笔记改为两个字段：`idea`（它计算什么）和 `lesson`（它在这里的代码中实际怎样起作用、受什么限制、怎样实现得更好）。** 生成端渲染为 `- {idea}: {lesson}`。结构中没有放置比较结论的位置。 | 笔记要素要求结果陈述 |
| **`analysis` 改问：** 这批尝试中的思想，各自的实现受什么限制或得到什么帮助，可以怎样实现得更好。 | 提问方式；有回放证据 |
| **去掉每张卡片的搜索最好成绩，只在刷新最好的卡片上写 `This attempt set a new search best.`** 突破是值得长期记住的少数正面事实；其余卡片只与自己的父代比较。 | 现任成绩进入每张卡片 |
| **生成端段首说明笔记的性质：** 笔记描述思想怎样表现、怎样实现，不判断哪种做法最适合当前程序。 | 生成把笔记当作定论；这句如实描述新笔记，单独作用预计很小 |

没有采用的做法：限制否定笔记的数量、过滤 "optimal" 一类词、强制保留探索思想。它们只处理症状，不改变笔记回答的问题。

## 检验

1. **反思回放。** 冻结冒烟的两个窗口，以及 V21 TSP 第1路的两个窗口（Explore 刚跳出贪心时、运行中段），新旧提示各采样3次。读笔记：是否还有思想之间的优劣判断，前瞻或模拟类思想被记为实现教训还是被否定。回放只检查模型怎样读提示，不判断机制效果。
2. **TSP 冒烟。** 检查生成说明是否仍把笔记引作定论。
3. **正式批次。** 六任务×三种子，每路1000次评价，对照 V21 `20261105c_v21_co6`。

## 关键未知量

不排序以后，笔记能否仍把真正有效的思想传到别处。改进方案通过刷新最好的标记保留突破事实，但"这个思想在别处带来了突破"本身也是一种排序信号。它会不会在后期把笔记重新拉向现任程序，要看正式批次中各版笔记的变化。

## 回放：改写提示没有改变笔记的性质

我按上面的方案改了提示，并在冻结窗口上做了反思回放：冒烟的两个窗口，V21 TSP 第1路的前两个窗口（第14次评价时 Explore 以完整路线贪心模拟跳到 6.262），以及第300–309次尝试的中段窗口。新旧提示各采样3次，前两个窗口按顺序接续笔记，共30次反思请求，全部解析成功。脚本、提示与回复在 server4 `/home/fzy/code/LLM4AD/TraceAAD_runs/20261109b_traceaad_v24/experiments_result/replay/`。

结果否定了我的改进假设。按 "outperform、superior、optimal、inferior、regress、consistently、confirm" 等词计数，新提示每条笔记约1.3个优劣判断，旧提示约1.2个；`analysis` 两者都写 "confirms … outperforms"。`idea`/`lesson` 结构让笔记多了一些机制解释，例如"两步前瞻依赖最近邻假设，这个假设常不成立"，但 `lesson` 字段照样写成比较结论。

更重要的是笔记跟随的对象。两种提示下，笔记都把当时最好的程序写成最好的做法：冒烟窗口中是 $1/N$ 贪心，V21 窗口中是完整路线模拟（6.26），中段是带转角惩罚的模拟。现任程序变了，笔记随之改为支持新的现任程序。新提示的6份 V21 早期笔记中，只有1份把模拟写成"不如轻量启发式"。

我据此修正认识：向现任程序收敛是按结果归纳阶段性反思的性质，不是提示措辞造成的；提问方式对单次反思的作用（11月2日的42%到27%）没有延续到批量归纳。它是否有害，取决于两件事：笔记是否阻止 Refine 和 Crossover 发展新出现的思想，以及突破之后笔记是否及时转向。V24 中 Explore 不读笔记，新思想仍会被提出；回放显示突破之后笔记会转向。这两点只能由完整搜索判断。

新提示保留：它去掉了我加的每卡搜索最好成绩，结构更利于记录实现教训，优劣判断不多于旧提示。下一步启动 V24 正式批次，对照 V21。
