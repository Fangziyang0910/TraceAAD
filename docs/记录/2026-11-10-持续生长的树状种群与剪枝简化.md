# 持续生长的树状种群与剪枝简化

日期：2026年11月10日（北京时间）。研究构想。

## 核心思想

我希望将树的发展关系与种群的演化更新融合起来，维护一个持续生长的树状种群。节点保存算法个体，连接保留个体之间的演化发展关系。这套结构同时承载当前参与搜索的算法，以及可供后续设计利用的演化经历。

**核心是树的剪枝与简化算法，以及它与持续生长的配合。** 搜索扩展一批候选并评价，再对树剪枝和简化，使其在结构约束内保留多样的算法个体及其发展关系，随后继续生长。种群的更新由树上的操作完成，演化轨迹随种群一起维护。

## 生长、剪枝与简化

基本循环是：

> 从当前树扩展一批候选 → 评价新个体 → 剪枝与简化 → 从更新后的树继续扩展。

树的具体形状随搜索变化，整体由结构约束控制。可设计的约束包括树的深度范围、分支数量范围和总节点数上限。约束的组合与取值，以及每批扩展的规模，共同决定树的生长和整理节奏。

剪枝与简化承担两类操作：

- **剪枝**：移除节点或分支，更新继续参与搜索的个体集合。
- **简化**：省略中间节点、缩短路径，并重新连接保留的代表节点。例如，将A→B→C→D压缩为A→D，保留两个阶段及其发展关系。

种群淘汰由此体现为树上的剪枝与简化。每轮更新既调整当前种群，也组织后续搜索可利用的演化经历。

## 多样性与辅助比较

剪枝与简化的目标是在受约束的结构中保留不同计算方式的个体，以及有用的发展关系。个体成绩反映当前性能，代码树结构比较、嵌入相似度等可辅助识别相近实现、重复变化与不同设计方向，为剪枝、路径压缩和代表节点保留提供依据。

结构约束控制规模与形状，个体比较支持多样性维护。两者结合，使树状种群能够在持续更新中保留不同方向及其发展经历。

## 演化轨迹与三个机制

简化后的轨迹由代表节点及其发展关系构成。连接可以跨越中间步骤，展示算法从一个阶段发展到另一个阶段的过程。历史视图以代表节点的设计描述（Design）为主要内容，模型利用这些经历作出当前设计决定；当前待修改算法提供完整代码。

同一棵树可以提供局部、两个分支和全局视野，支持三个自动算法设计（Automated Algorithm Design，AAD）机制：

| 机制 | 基于树状种群的作用 |
| --- | --- |
| 机制1：价值评估与预算分配 | 根据当前树及已有发展经历，决定下一批扩展的位置与机会。 |
| 机制2：轨迹上下文与算子 | Refine利用局部形成与修改经历决定改什么；Crossover利用两个个体的发展分支决定借什么、怎样融合；Explore利用全局分支及其发展经历决定探索什么方向。 |
| 机制3：反思与经验学习 | 从跨阶段、跨分支的经历中提炼和更新设计经验，供后续生成利用。 |

树的更新同时改变可继续发展的个体、生成时可读取的经历，以及不同方向获得机会的方式。三个机制由此共享一套持续更新的搜索结构。

## 思路来源与结构特点

PathWise启发了我对路径与候选组织方式的思考。它将内层推导图与外层种群结合，在图中记录生成关系，再选择个体进入下一轮；来源摘要随个体保留，当前图由新种群重新建立。我希望跨轮维护一棵经过剪枝与路径简化的代表个体树，使保留的发展拓扑持续参与搜索。[PathWise，§3.1、§3.5](https://arxiv.org/html/2601.20539v3#S3)。

PhyloEvolve是更接近这一整体思路的工作。它维护持续生长的算法演化森林，选择树和节点扩展，对节点、分支及整棵树剪枝，并利用轨迹指导生成。Clade-AHD也通过冻结低潜力子树调整扩展机会。它们为树状搜索、种群更新和轨迹利用提供了直接先例。[PhyloEvolve，§4.3—4.5](https://arxiv.org/html/2601.14523v1#S4)、[Clade-AHD](https://arxiv.org/abs/2602.00549)。

更广泛的进化计算还提供了路径简化的基础操作：Phylotrack所依托的Empirical库可以清理绝灭旁支，删除无存活成员且只有一个子节点的中间节点，并将其后代接回父节点。[Phylotrack](https://arxiv.org/abs/2405.09389)、[路径收缩实现](https://github.com/devosoft/Empirical/blob/56d1679efa31bb27e013e7910afdd7b94b1587cc/include/emp/Evolve/Systematics.hpp#L1472)。

我希望在这些基础上研究面向AAD的剪枝与简化算法：每轮扩展后，将分支剪枝、路径收缩与代表节点重连纳入同一更新过程，在结构约束内维护多样个体和发展关系；更新后的树同时提供局部、两个分支与全局视野，支持后续选择、生成和经验学习。完整比较及可借鉴操作见[相关工作调研](2026-11-11-树状种群与剪枝简化的相关工作调研.md)。

## 两层贡献定位

1. **面向AAD的树状种群及其剪枝与简化算法。** 将算法个体与演化发展关系共同组织起来，通过批量扩展、分支剪枝、路径收缩与代表节点重连，在结构约束内维护具有多样性的种群。
2. **基于该结构的三个AAD机制。** 围绕共享的树状种群，设计轨迹价值评估与预算分配、轨迹引导的上下文与算子、轨迹反思与经验学习，将保留的演化经历用于后续算法设计。

第一层研究如何组织和更新算法个体及其演化关系，第二层研究如何利用这一结构指导搜索与生成。

## 下一步设计重点

将一轮“扩展—评价—剪枝与简化”具体化：确定结构约束，定义节点和分支的剪枝操作、路径压缩与重连操作，再选择辅助比较方法，使更新后的树保留多样个体和可用于后续设计的发展关系。
