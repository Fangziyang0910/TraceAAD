## 公共边界

公共框架提供本项目的任务契约、数据、评价器、模型与采样配置、资源调度、预算上限和记录。官方任务的输入类型、数据规模、评价公式不作为移植目标。具体历史批次仍以自身保存的源码和配置为准。

公共框架不再替方法解释模型回复。已删除 `baselines/shared/sampling.py`，各方法自行决定提取、接受、拒绝和重试。`core/code.py` 的 `function_from_source` 只表示方法已经接受的 Python 源码，不截尾修复、不补入口、不替换参数。未被方法编辑的源码原样保存；方法修改函数后再更新表示。

模型采样统一由 `experiments/infra/base.py` 决定。已取消 CALM 的任务温度、ReEvo 和 PathWise 的初始化升温、MCTS 的描述对齐温度 0，以及 DeltaEvolve 单独指定的温度和 top_p。FunSearch 数据库内部的 softmax 温度属于搜索机制，继续保留。

最终选择按用户进一步确认执行：**搜索结束，直接固定训练成绩最好的有效程序，再做独立测试。** 同分取记录编号较小者。公共记录器不再重评前 5 个程序，不再重新选赢家。`selection_evaluations=0`，测试结果不参与选择。已有实验结果没有回填或覆盖。

## 已修正的内部行为

| 方法 | 已落实的修改 |
| --- | --- |
| FunSearch | 移入官方函数体截取代码；只将生成函数体放回模板，不接收整份模块。恢复官方版本元数据行为，保留祖先调用检查。给模型发送原代码前缀，不再额外追加本地生成指令。chat 返回完整函数时，仅在模型接口边界取其函数体。 |
| EoH | 移入当前官方提示构造和回复提取；缺代码/描述最多请求 4 次，重复代码最多再生成 2 次。保留当前逐个更新、四算子规则。默认种群 5、父代 2；父代按官方 rank 权重抽取。成绩按官方舍入到 5 位小数，种群按目标值去重。 |
| ReEvo | 原样复制 9 份 common 提示，移入官方代码提取和父代码过滤。每次变异重新带入固定 external knowledge。交叉全部失败时仍更新该代、长期反思并对 elite 变异。elite 是否补入选择池按个体记录判断。 |
| MCTS-AHD | 移入官方算子与描述对齐提示，恢复其通过最后一个 return 提取代码的方式。重复代码先重采一次；生成异常在方法内重试。成绩舍入到 5 位；e1 先抽引用数再截断。扩展评价超时立即返回，移除额外初始化次数上限；UCT 保留源码原公式。入口实际设置所记录的随机种子。 |
| CALM | 只接受唯一 Python 函数；数值细化也走该规则。取消完整 solve 额外放宽 helper 的提示。injection/simplification 检测恢复官方字符串，保留源码的实际分类行为。继续保留官方已有的数值细化、实例表现去重、reward gate 和局部修改要求；继续关闭 GRPO。 |
| PathWise | 移入官方初始化、world-model、policy 解析与父代码清理。缺描述/推导理由不再填默认值，按官方检查 placeholder。保护当前图中的唯一最优节点，按官方筛选 policy state。先生成 rollout 批次，再评价候选；同 action 格式重试使用源码中的最后一份消息。无 entailment 时重评当前种群再选最好；单节点图仍可尝试 inner step。取消额外全局 imports。 |
| ShinkaEvolve | 直接移入官方 full/diff 补丁引擎及依赖，只改包导入路径；full/cross 保留可变区外的代码。灵感采样按岛内查询、LIMIT、排除和随机补齐的顺序执行。embedding 取前 10000 字符，异常返回空向量；novelty 空回复/异常按源码放行。不同父程序之间不再携带上一次补丁错误。恢复当前官方默认系统提示。可选迁移排除初始和无效程序，并在同轮去重。 |

源代码自身的行为也保留。例如 FunSearch 的生成版本元数据与 header 存在一位偏移；CALM 两个检测字符串与其生成提示不完全匹配；MCTS 的 UCT 原式没有零分母防护。这些没有被当成本地“优化”继续修改。

## 仍不能确认等价的部分

DeltaEvolve 没有公开作者实现。父代池与权重、描述子投影与网格、历史窗口和年龄、保留与迁移、严格补丁接收边界等，仍是本地明确选择。它们可能影响性能，不能据“实现了 delta 思路”认定与作者一致。细节继续见 [DeltaEvolve 实现说明](../../baselines/deltaevolve/README.md)。

Shinka 当前比较只走已确定的单模型入口。本地可选多模型调度仍是简化实现，不能通过增加多个 endpoint 就称为官方 AsymmetricUCB；本次没有开启它。
