# 八个任务的初始参考代码

初始参考代码直接放在各任务的 `template_program` 中，沿用原函数签名与输入输出约定。每个起点仅提供一个最简单的合法实现，供初始化时阅读和修改。经机制审查，Base 公共提示只展示从模板提取的接口骨架，完整参考代码只作为初始化的 0 号样例展示一次；演化与修复不重复展示初始实现。

## 各任务采用的起点

| 任务 | 初始规则 | 函数体的关键代码 |
| --- | --- | --- |
| [TSP](../../benchmarks/tsp_construct/template.py) | 选择最近候选；输入候选已按距离排序 | `return int(unvisited_nodes[0])` |
| [CVRP-ACO](../../benchmarks/cvrp_aco/template.py) | 距离倒数作为边先验 | `return 1.0 / distance_matrix` |
| [OP-ACO](../../benchmarks/op_aco/template.py) | 目的节点奖励除以距离 | `return prize[np.newaxis, :] / distance` |
| [在线装箱](../../benchmarks/online_bin_packing/template.py) | Best Fit：优先选择放入后剩余空间最小的可行箱子 | `return item - bins.astype(float)` |
| [VRPTW](../../benchmarks/vrptw_construct/template.py) | 选择第一个可行客户 | `return int(unvisited_nodes[0])` |
| [FSSP-GLS](../../benchmarks/fssp_gls/template.py) | 返回原加工时间和当前序列中的第一个作业 | `return processing_times.copy(), current_sequence[:1].copy()` |
| [图着色](../../benchmarks/graph_colouring/template.py) | 每个顶点使用一种独立颜色 | `return np.arange(len(adjacency), dtype=np.int64)` |
| [JSSP](../../benchmarks/jssp_construct/template.py) | 按作业顺序串行执行全部工序 | 开始时间为此前所有工序时长之和 |

JSSP 的完整函数体为：

```python
durations = processing_times.ravel()
return (np.cumsum(durations, dtype=float) - durations).reshape(processing_times.shape)
```

串行安排满足作业内工序顺序与机器互斥；图着色的独立颜色满足所有边约束。FSSP 的起点不改变加工时间，固定框架仍执行原有构造与局部搜索。VRPTW 的候选按编号排列，这个起点表示选择第一个可行客户，不能称为最近邻。

## 相关方法的源码依据

我核对了作者源码：

- ReEvo 的 [CVRP 种子](https://github.com/ai4co/reevo/blob/6dce18257da5e11db2d138e417a2fffc5c72d05f/prompts/cvrp_aco/seed_func.txt)直接返回 `1 / distance_matrix`；[OP 种子](https://github.com/ai4co/reevo/blob/6dce18257da5e11db2d138e417a2fffc5c72d05f/prompts/op_aco/seed_func.txt)直接返回 `prize[np.newaxis, :] / distance`。这两项已符合极简要求，保持原实现。
- FunSearch 的[装箱 notebook](https://github.com/google-deepmind/funsearch/blob/cc53f274237d7ab05c19df939edbc1f9616a7c19/bin_packing/bin_packing.ipynb)在标有 `@funsearch.evolve` 的起始 `priority` 中返回 `-(bins - item)`，即 Best Fit。当前任务要求浮点输出，故显式转换 `bins` 的类型。
- ReEvo 的 [TSP 种子](https://github.com/ai4co/reevo/blob/6dce18257da5e11db2d138e417a2fffc5c72d05f/prompts/tsp_constructive/seed_func.txt)包含多项加权评分，[装箱种子](https://github.com/ai4co/reevo/blob/6dce18257da5e11db2d138e417a2fffc5c72d05f/prompts/bpp_online/seed_func.txt)使用较复杂的已发现规则；因此“所有相关方法都使用极简起点”并不准确。本次按用户要求选择更简单的合法实现，其余任务不宣称直接复现某篇论文的种子。

## 起点与数据参考的关系

图着色与 JSSP 以前复用模板里的 DSATUR、Giffler–Thompson/MWKR 计算数据参考成绩。更换模板后，这两个原算法分别保存在 [graph_colouring/reference.py](../../benchmarks/graph_colouring/reference.py) 和 [jssp_construct/reference.py](../../benchmarks/jssp_construct/reference.py)，由数据生成器调用；生成提示读取新的极简模板。

这是初始代码的修改，既有实验按其保存的源码和设置解释。评价仍使用解的真实目标值。

## 验证

八个初始程序均通过小规模实例的实际任务求解器检查，获得有限成绩；任务与实验入口相关的 55 项检查通过。八个函数签名与修改前一致。图着色与 JSSP 的训练、测试共 132 个实例，其输入校验值、参考成绩和元数据与修改前逐项一致。全套离线测试 **581 项通过**。本轮未调用生成模型。
