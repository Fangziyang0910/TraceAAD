# 轨迹价值分配：决策对象与 AAD 先例

日期：2026-11-05（北京时间）。本次是文献核对和机制讨论，没有运行实验或修改在线机制。

## 问题与认识修正

我要解决的是：在有限预算下，根据个体及其演化轨迹，决定下一份预算交给哪个父代，以及怎样修改。目标是预算结束时找到的最好有效算法。现有机制的实验条件与新问题不等价，本次没有用它们证明新机制有效。

我最初建议联合选择父代与精炼／探索，并给探索预留一次精炼。用户先允许这两个方向，随后指出自己探索过它们，尤其觉得预留预算与原来的理念冲突，要求核对 AAD 先例。我据此暂停把固定短程开发作为默认方案。

这次需要分清三个问题：价值是否依赖算子；父代与算子是否联合决定；选中一次探索后是否承诺继续投入。前两个问题不推出第三个。为了获得等预算、容易比较的标签而固定后续步骤，是一种测量设计；它不自动成为在线搜索应遵循的决策规则。

## 原始文献实际做了什么

### DGS：明确联合选择算子与父代

[Wang et al., How to Guide LLM Generation: Dual-Surrogate Guided Search for Automated Heuristic Design, 2026](https://arxiv.org/html/2607.13911v1)。定位：Preliminaries；Uncertainty-Aware Action Selection，式 (18)–(19)；Algorithm 1；Effect of Joint Operator-Parent Selection。

作者把一个生成动作写成 `x=(operator, parent set)`。先从有效档案中取成绩最好的 top-K 父代池，再列出可行的算子—父代组合。转移代理预测动作产生的子代潜在表示分布，效用代理预测这些表示的表现，采集函数据此选择下一次生成动作。生成、评价、加入档案后，再进入下一轮。

这是联合动作选择的直接先例，不是先按固定比例抽算子。它的核心选择循环没有把每次探索与一次后续精炼绑定。它预测的是新子代的效用，不是完整后代分支的长期最优价值。

文中 TSP 的受控对比保持提示算子、搜索预算和 top-K 父代池构建相同，比较规则选择、只用算子或父代的代理、联合动作代理。该局部比较为联合建模提供证据，不能据此认定所有 AAD 场景都应联合选择。

### A₂DEPT：父代选择与节点内算子选择分层进行

[Chen et al., A₂DEPT: Large Language Model–Driven Automated Algorithm Design via Evolutionary Program Trees, 2026](https://arxiv.org/html/2604.24043v1)。定位：§3.3、§3.4.2，式 (5)–(6)；Appendix B Algorithm 1。

先用模拟退火式前沿选择和历史树的 Boltzmann 补充构造父代集合。对于其中的每个节点，依据该节点的算子权重，用 softmax 选择微调或宏观修改；交叉按另一个条件触发。算子权重由父子性能变化更新，子代继承更新后的权重。

这是“父代确定后，条件化该父代选择算子”的自适应机制。它没有用一个统一价值对全部父代—算子组合取最大值。依赖修复用于让程序可执行，不能计作对新思想进行性能精炼的保证预算。

### MEMOIR：有短程开发分支，但有上限和提前停止

[Memory-Guided Tree Search with Cross-Branch Knowledge Transfer for LLM Solver Synthesis, 2026](https://arxiv.org/html/2605.17539v1)。定位：§3.2、§3.2.2、§4.1.4；Appendix B Algorithm 1，第 2–14 行。

每条分支先提出一个新算法设计，随后在该分支内连续修复或改善。总执行预算为 B，分支深度上限为 n，初始提案占深度 1。论文实验使用 B=16、n=5。

伪代码仅在至少剩余两次执行时开启新分支；但每次后续开发前检查 `ImprovementExpected(local memory)`，若预期不再改善或预算耗尽就结束该分支。正文同样说明允许提前停止。因此，它是集中开发一个分支的先例，但不是保证把 n 次预算全部花完，也不是无条件保证每个提案都获得一次精炼。

它与全档案逐步竞争预算还有差别：分支尚未终止时，后续选择主要在当前分支内部进行。其主要消融检验记忆组件，并没有单独证明这种分支预算安排优于全局逐步重分配。

### LLaMEA-HPO：明确给新算法嵌套调参预算

[van Stein, Vermetten and Bäck, In-the-loop Hyper-Parameter Optimization for LLM-Based Automated Design of Heuristics, 2024](https://arxiv.org/html/2410.16309v1)。定位：§3.2–3.3、Algorithm 1、§5.1–5.3。

LLM 生成算法结构及参数空间，随后 SMAC 在给定评价预算内调参，再用调优后的算法表现反馈给结构搜索。作者明确把结构搜索与数值调参分工。它是“先生成，再投入局部优化预算”的直接先例。

但这里的局部开发是固定结构的参数优化，不能直接等同于 LLM 继续改写任意程序。论文也区分 LLM 请求和算法评价成本：省请求不等于在所有任务的等评价预算下都更好。

### 两个容易误读的相关例子

- [RefineEvo, 2026](https://arxiv.org/html/2607.11358v1)，§3.2、Algorithm 1、Appendix E.2：Planner 根据种群状态选择算子；`operator refinement` 改写的是算子提示。它不能作为“给探索子代预留精炼预算”的证据。
- [HSEvo, 2024/AAAI 2025](https://arxiv.org/html/2412.14995v1)，§4 Harmony Search：提取优秀个体的参数和范围，用 Harmony Search 调优，标记后放回种群。它支持嵌套参数优化的可行性，不等于给每个探索子代分配后续 LLM 修改次数。

## 数学上，价值前瞻与预算承诺可以分开

令 q=-fitness，m(S) 是状态 S 中已观测到的最好质量。S 包含当前候选、轨迹记录和模型后验。u=(p,a) 表示本次使用父代 p 和算子 a。先假设每次执行消耗一单位预算，令

\[
r(S,u,S')=m(S')-m(S)\ge 0.
\]

则任一路径的增量满足

\[
\sum_{t=0}^{B-1}r_t=m(S_B)-m(S_0).
\]

因此，优化预算结束时的最好结果，可以精确写成这个状态变化过程的累计记录增益。它仍不是普通的平稳 bandit：动作会产生新的程序、更新轨迹及后验，并改变以后可选的动作。

完整的有限时域价值满足

\[
Q_b(S,u)=\mathbb E\left[r(S,u,S')+\max_{u'\in\mathcal A(S')}Q_{b-1}(S',u')\mid S,u\right],
\qquad Q_0=0.
\]

这是一条决策目标，不是已经得到的估计器。它允许这次探索暂时不改善 m，但因创造更好的后续动作而有价值。下一次仍根据真实的新状态决定是否精炼这个新个体，也可以回到旧父代或改用其他算子。成本不等时，剩余预算应减去实际成本；没有收益的失败也消耗预算。

对比两步的情况，令 W(S',u') 是第二步的期望记录增益。自由决策和固定精炼分别为

\[
Q_{\mathrm{free}}(S,u)=\mathbb E[r+\max_{u'\in\mathcal A(S')}W(S',u')],
\]

\[
Q_{\mathrm{commit}}(S,u)=\mathbb E[r+W(S',u'_{\mathrm{fixed}})].
\]

在同样的信息、执行成本和可行动作下，只要固定后续动作也在自由策略的可选集合中，就有

\[
Q_{\mathrm{free}}(S,u)\ge Q_{\mathrm{commit}}(S,u).
\]

这个关系说明：固定继续投入并不是长期价值估计的数学要求。有限样本下，承诺策略可能因简化学习、稳定反馈或减少切换成本而有实际优势；是否值得，应由这些具体收益解释。这里没有证据要求我们先加入该约束。

同样，联合比较也不必实现成一个大模块。若有统一的 Q，先计算每个父代最好的动作，再选父代，与直接对 `(p,a)` 取最大值等价：`max_p max_a Q(p,a) = max_(p,a) Q(p,a)`。关键是两级选择使用什么价值，而不是代码上先执行哪个循环。A₂DEPT 的父代规则与节点内算子规则不同，所以不因此等价于 DGS。

## 本轮保留的设计方向

我撤回把“探索后固定精炼”作为默认方案。后续机制应先围绕以下对象继续设计：对同一父代分别预测精炼和探索的条件收益；利用轨迹进行跨个体共享；每次只执行当前选中的一步，取得新反馈后重新分配预算。

联合动作选择是否采用统一分数，仍取决于能否把两种算子的价值放在相同时间尺度上。DGS 提供联合选择的先例，但其单步子代效用不直接解决延迟收益问题。多步前瞻可以只发生在估值中，不必表现为预留真实预算。

估计器尚未定稿。当前真正未解决的是：用少量轨迹怎样估计新个体带来的后续机会，以及怎样避免把“还没有被开发”当成“没有开发价值”。固定两步采样可以作为受控测量手段，不能默认为在线执行流程。另一个必须保留的区别是：两步内的期望改善仍会漏掉更晚出现的机会；即使参数已经完全知道，汤普森采样也不能补回目标中省略的继续价值。WWH 和机制规格等用户确认后再更新。

## 核对范围与方法来源



以上 AAD 判断来自本次阅读的原文方法、公式和伪代码，不来自各论文摘要中的性能宣称，也不来自当前 V20/V21 结果。这里只核对上述相关工作，未作穷尽检索。

跨领域参考：[Nishihara et al., No Regret Bound for Extreme Bandits, AISTATS 2016](https://proceedings.mlr.press/v51/nishihara16.html) 说明最好样本目标与平均收益目标的区别；[Jiang et al., Nonmyopic Bayesian Optimization, 2020](https://arxiv.org/abs/2006.15779) 给出多步前瞻的 Bellman 表述；[Sutton, Precup and Singh, 1999](https://people.cs.umass.edu/~barto/courses/cs687/Sutton-Precup-Singh-AIJ99.pdf) 提供将多步开发定义成 option 的形式。它们支持数学表达，不证明具体 AAD 机制有效。

本次使用 scientific-brainstorming 技能辅助分开候选方案、假设与证据。方法来源为 [Kassis, Agarwal, He, Patel and Brueckner, Scientific Agent Skills, 2026](https://arxiv.org/abs/2609.00065)，已核对当前记录；该来源不是价值模型有效性的证据。
