# EvoTrace 三代融合设计构想：动态树生长、分块反思淘汰与统一分差竞争

日期：2026-11-17（北京时间）

状态：设计构想与机制审阅稿（不影响正在 server4 运行的 `20261117_181830_evotrace_v3_clean_co4` 批次与现行源码）。

**核心目标：** 遵循第一性原理与奥卡姆剃刀，将 **V1 的统一竞技场竞争与分差聚焦分配**、**V2 的自由生长与动态冷却保留**、**V3 的挂根拓扑与分块纯事实反思/精简轨迹上下文** 合一，使树状种群既具备自由生长与跨鞍点踏脚石能力，又保持前排深挖锐度与低开销结构化记忆。

### 论文顶层立意与摘要定稿（金字塔结构）

> 大语言模型驱动的自动算法设计结合语义生成与演化搜索，在持续探索中自动发现高性能算法。在这一过程中，优秀算法往往经由多步修改、思想融合与反复试错逐步演进，演化历程所揭示的有效改法与受阻方向正是指导大模型后续设计的重要依据。然而，现有演化搜索在通过优胜劣汰更替种群时，主要保留当前胜出的算法个体，而未能将演进过程与试错认识随筛选系统沉淀，使后续生成难以在既有探索基础上持续深入。本文提出**树状种群（Tree-Structured Population）**，以一棵动态维护的演化树组织候选算法，使种群的竞争淘汰不再丢弃历史，而是直接转化为对演化脉络的结构压缩与经验凝练：竞争确定保留骨架，被淘汰的中间路径与失势分支则通过路径收缩与子树剪枝，分别凝练为保留边与节点上的设计经验。依托这一结构，评价预算可结合候选质量与树上开发状态进行分配以兼顾探索与利用，生成算子则沿演化脉络调用历史过程与经验来指导新算法设计。在多项组合优化自动算法设计基准上的实验表明，该方法在相同评价预算下持续优于现有代表性基线。

### 关键演化链事实（踏脚石效应）

回放 V1 在 CVRP 上冲至 `7.8387` 的夺冠谱系可见：
`(196: 8.2795) → (201: 8.7014) → (243: 8.2648)` 以及 `(448: 8.0102) → (467: 8.0279) → (468: 7.9977) → (478: 7.9279) → (913: 7.8387)`。

## 2. 第一性原理与历史证伪约束

### 2.1 种群竞争与树发展的正交分工

1. **种群竞争（横向：统一竞技场的资源聚焦与优胜劣汰）：** 所有现役可行个体在同一尺度下直接竞争留存与评价预算。留存需连续权衡“当前质量”与“相对已选集的边际结构差异”；预算需对**真实适应度分差**敏感，并随节点自身直接开发次数递减。
2. **树发展（纵向：异步自由生长、踏脚石窗口与分块经验凝练）：** 树自由生长，不设人工世代重置墙；新分支与中间踏脚石在现役活跃期内留在树上接受检验；只有当局部路径或旁支**既未进入代表集、又已退出活跃期（冷却成熟）**且累积满一个简化块时，才在局部执行路径收缩（写边经验）或子树剪枝（写点经验）。

### 2.2 必须遵守的已核实边界（防重复踩坑）

1. **不做按谱系/路线的分层或分组预算平摊**（不用 `route_max`、不设按根谱系硬配额分配算力），避免压低 TSP 等连续改进任务前排个体的深挖份额（见[实验与边界台账](README.md)第 4 条）。
2. **代表选择与 LCA 结构补全解耦：** 先选代表集，再补齐最近公共祖先骨架，结构锚点不挤占代表名额、不参与距离排斥阻挡更优实现（修掉 V1 历史耦合缺陷）。
3. **不恢复 `direction_id` 路线账本、代码 diff 与单节点碎片反思：** 保持 `Explore` 挂虚拟根 `0`、区域满阈值 `region_size` 成批凝练及 V3 纯事实反思与轨迹上下文。

## 3. 三代融合机制草案（V1 竞争分配 + V2 动态保留 + V3 分块反思上下文）

### 3.1 演化树表示与挂接（沿用 V3）

- 节点保存 `code`、`design`（约 60 词）、`fitness` / `failure`、`experience`（节点经验）与直接开发评价计数 $n_v$（`direct_evaluations`）。
- 边保存 `parent_id`、`operator`、`reference_id`、`contracted` 与 `experience`（边经验）；虚拟根 `0` 保存 `root_experience`。
- `Init` 与 `Explore` 挂接于虚拟根 `0`（开启新分支，不计入任何节点的 $n_v$）；`Refine` 与 `Crossover` 挂接于主父代 $p$，其实际消耗的程序评价次数累加至 $n_p$。

### 3.2 动态保留核 $\mathcal{S} = Q \cup A$ 与分块异步简化（V1 选代表 + V2 活跃层 + V3 分块简化）

初始化集齐 `initial_size = 5` 个可行个体后，每次受评实现入树时，在当前树 $T$ 上计算：

1. **质量—差异代表集 $Q$（至多 $K = 24$ 个，负责长期生态位与质量标尺）：**
   - 先由 `distinct_individuals(T)` 对标准化源码与适应度均相同的可行节点仅保留最早编号节点，记去重可行集为 $V_{\text{dist}}$，按 `(fitness, id)` 升序排列。
   - 若 $|V_{\text{dist}}| \le K$，则 $Q = V_{\text{dist}}$；否则先将全局最优个体放入 $Q$，随后在剩余候选中贪心迭代选入使下式最大的个体，直至 $|Q| = K$：
     $$U(i \mid Q) = q(i) \cdot \Bigl((1 - \alpha) + \alpha \cdot \min_{r \in Q} \operatorname{code\_distance}(i, r)\Bigr),$$
     其中 $\alpha \in (0, 1)$（如 V1 默认 `0.35`），$q(i) \in [0, 1]$ 为候选在当前可行排序中的质量分（待评审项见第 4 节）。去掉硬 `0.15` 阶跃门槛与多重克隆硬阈值：高质微调可入选，同家族第 $k$ 个表亲因 $\min_{r \in Q} d(i, r)$ 缩小而边际得分自动递减，异质结构获得留存溢价。
2. **近期活跃窗口 $A$（窗口大小 $W$，负责踏脚石与新幼苗的现役发育期）：**
   - 近期新入树（或最近 $W$ 次评价内出生/被开发，如 $W = 20$）的可行节点集合 $A$ 暂留在树。无需专门设置“新方向保护名额”，新 `Explore` 初稿与轻微退步踏脚石（如 `8.01 → 8.02`）在冷却退出 $A$ 之前天然留在现役池中。
3. **LCA 骨架与局部满块简化（`region_size = m`，默认 `4`）：**
   - 令主动保留核 $\mathcal{S} = Q \cup A$，补齐最近公共祖先分叉集 $F = \operatorname{LCA}_T(\mathcal{S}) \setminus (\mathcal{S} \cup \{0\})$，保留骨架为 $\mathcal{H} = \{0\} \cup \mathcal{S} \cup F$。
   - 其余节点 $V(T) \setminus \mathcal{H}$ 为**既未入选代表集 $Q$、又已冷却退出活跃窗口 $A$、且非连接骨架**的待淘汰节点，唯一划分为路径收缩区（`PathContraction`）与子树剪枝区（`SubtreePruning`）。
   - **仅当某局部区域的待移除节点数 $\ge m$ 时**，对该区域执行拓扑简化并调用一次 V3 纯事实反思；未满 $m$ 的冷却尾端暂留树上但不进入现役抽样池。由于 $|Q| \le K$、$|A|$ 有界，树总节点数在任意长预算下严格有界。

### 3.3 统一分差敏感预算分配（V1 直接竞争 + V2 代表标尺锚定，无 `route_max`）

每步先按固定先验 `0.45 / 0.30 / 0.25` 抽取算子 `Refine / Explore / Crossover`：

- **`Explore`：** `parent_id = 0`；直接在代表集 $Q$ 上选取最优者及最大最小 AST 距离代表（至多 `6` 个）展示于 `[Existing Approaches]`。
- **`Refine` 与 `Crossover`：**
  - **现役抽样池：** $P = Q \cup A$（包含长期代表与近期活跃节点；排除仅作拓扑连接的历史冷分叉点 $F$ 与已退出 $A$ 等待凑满 $m$ 剪枝的冷却节点）。
  - **代表集锚定标尺：** 在代表集 $Q$ 上计算适应度中位数 $m_Q$ 与中位数绝对偏差 $s_Q = \operatorname{MAD}(Q)$（当 $s_Q \le 10^{-9}$ 时回退至非零绝对偏差中位数与 $10^{-6}$ 下限），避免 $A$ 中大量弱探索初稿抬高中位数导致上半区权重平顶饱和。
  - **统一父代概率（不做路线分组）：**
    $$w(v) = \sigma\!\left(\lambda \frac{m_Q - f(v)}{s_Q}\right) \cdot \frac{1}{1 + n_v}, \qquad p(v) = \frac{w(v)}{\sum_{u \in P} w(u)} \quad (v \in P).$$
    头部好解获得高锐度深挖；$A$ 中接近或优于 $m_Q$ 的踏脚石与新分支因 $n_v = 0$ 自然获得验证机会；远差于 $m_Q$ 的劣质初稿即使仍在 $A$ 中，其 $\sigma(\cdot) \approx 0$，不浪费算力，待退出 $A$ 后成批剪入经验。
  - **`Crossover` 参考代表：** 在 $Q \setminus \{p\}$ 上按质量项乘以 $\operatorname{code\_distance}(p, r)$ 软抽样（或取前排异质代表）。

### 3.4 事实反思与轨迹上下文（完整沿用 V3 定型版）

- 反思仅在局部区域满 $m = 4$ 简化时触发，使用 V3 统一无 diff 纯事实反思模板（约 120 词，写明具体计算与实测结果，根区域附存活最优基准锚点）。
- 生成上下文保持 V3 设计语言：源码仅给被修改主父代与交叉参考，演化轨迹与兄弟尝试以约 60 词 `design`、结果及点/边经验呈现，`root_experience` 仅提供给 `Explore`。

## 4. 待独立评审与压力测试的关键问题

请独立评审重点从第一性原理、数学边界与真实树快照分布角度检验以下问题：

1. **代表集 $Q$ 中质量项 $q(i)$ 的定义域与抗噪性：**
   - 在动态树中，$V_{\text{dist}}$ 的规模与尾部垃圾比例随近期窗口与未满块缓冲波动。若沿用线性秩质量 $q(i) = 1 - \operatorname{rank}(i)/(|V_{\text{dist}}|-1)$，当树上暂存较多劣质节点时，排名第 25–30 位的平庸节点其 $q(i)$ 会被分母被动抬高。$q(i)$ 应采用何种无标度或分差/排名形式最稳健且参数最少？是否仍需 `quality_floor`？
2. **近期活跃窗口 $A$ 的极简刻画：**
   - 对比两种定义：① **纯出生窗口**（最近 $W$ 个入树可行节点，零额外状态字段）；② **出生或直接开发刷新窗口**（距最近出生或作为主父代被 `Refine/Crossover` 开发的评价步数 $< W$）。两者在跨鞍点多步踏脚石（`A → B → C`）和树规模上界上各有什么实质差异？$W$ 与 $K, m$ 的合理比例关系是什么？
3. **分差采样标尺 $(m_Q, s_Q)$ 与新范式初稿的真实存活抽样率：**
   - 当搜索中后期 $Q$ 内前排适应度收敛较紧（$s_Q$ 变小）时，$\lambda = 10$ 下刚进入 $A$、分数略逊于 $m_Q$（例如差 $1.5 \sim 2.5\, s_Q$）的跨范式 `Explore` 初稿，其实际被抽中至少 1 次 `Refine` 的概率是多少？是否存在 $s_Q$ 过紧导致 $A$ 变成“只暂留、不抽样”的盲区？
4. **奥卡姆剃刀与耦合自洽性审查：**
   - 上述 $Q \cup A$ + 分块简化（`region_size = m`）在单步更新下是否仍保持代表集不变性与幂等性？当节点刚从 $A$ 滑出变为冷却节点时，与 `PathContraction / SubtreePruning`、经验归属及 `direct_evaluations` 记账之间是否存在隐蔽的边界漏洞或可进一步删减的冗余概念？

## 5. 独立评审记录

### 5.1 Astra Max（`gpt-6-astra`, `reasoningEffort=max`，基于 48 个真实历史树快照反事实重算）

- **总体结论：** 支持 $Q \cup A$ 动态树保留 + V3 区域划分与事实反思框架，但指出原草案公式有三处关键数学缺陷需修正，并给出更简的单一质量函数规格。
- **因果归因校准：**
  1. V3 相对 V1 的约 $2\times$ 墙钟提速除输入词元缩短（`11.2k → 1.9k`）外，还受评价器并行度差异影响（V1/V2 为 1 worker、CVRP 单次评价 `37.53s`，V3 Clean 为 8 workers、单次评价 `5.47s`；模型单次调用为 `32.50s → 29.86s`），论文表述不得将提速全归因于轻量上下文。
  2. V2 的 `route_max` 在单路线权重主导时影响抵消，并非 V2 与 V1 差距的唯一来源；FSSP 前 300 评 `Refine` 改善率 V1（`23.0%`）与 V3 Clean（`23.4%`）持平。
  3. V1 CVRP `#448 (8.0102) → #467 (8.0279)` 的 AST 距离实测仅 `0.0367`，确证在 V3 现行规则下被完全阻断父代资格。
- **四项核心修正（奥卡姆剃刀化简）：**
  1. **用单一固定标尺质量函数取代排名质量（修复非幂等性漏洞）：** 实测线性秩质量或排名函数在删除落选节点后会改变幸存者相对排名，导致 V1 CVRP rep3（300 评）上 $Q$ 发生漂移（`#194 → #278`）并引发二次连环删除，破坏单轮简化幂等性。改为在去重可行集前 $K$ 优集合 $B_t = \operatorname{best}_{\min(K, |D_t|)}(D_t)$ 上冻结计算 $(\mu_t, s_t) = \operatorname{median/MAD}(B_t)$，统一定义 $q_t(i) = \sigma((\mu_t - f_i)/s_t)$ 同时用于选 $Q$ 与算父代概率 $p_t(i) \propto q_t(i)/(1+n_i)$。在 **48 个真实快照上实测代表集漂移为 0、二次删除为 0**。
  2. **去掉 $\lambda = 10$（令 $\lambda = 1$）：** 在真实 300 评快照上，$s_Q$ 收敛后仅约 `0.025`（CVRP/TSP），$\lambda = 10$ 使劣于中位数 $1.5\, s_Q$ 的新草稿在 20 步内获至少 1 次 `Refine` 的概率跌至 `0.00005%`，且将真实踏脚石 `#467` 的单步父代概率从 V1 的 `8.28%` 压至 `0.45%`；改为 $\lambda = 1$（无额外超参）后，`#467` 恢复至 `6.84%`（20 步暴露率 `46.5%`），$+1.5\, s_Q$ 新草稿恢复至 `18%–29%`。
  3. **纯出生评价时钟窗口且令 $W = K = 24$：** 定义 $A_t = \{i \in D_t : 0 \le t - b_i < W\}$（按实际评价时钟 $t$ 而非节点编号计龄，且在 $D_t$ 去重集上取以避免同分克隆刷免费席位）。既支持 `A → B → C` 接力推进，又给出严格树节点上界 $|T| \le (4m-2)(K+W)-m = 668$（需保持同骨架锚点下待剪旁支合并语义）。
  4. **反思异常回退补强：** 当反思调用异常且无旧经验可拼接时，应生成含本次移除节点 `design` 与分数的确定性短摘要，避免首次区域简化在极端故障下丢失全部事实。

### 5.2 Opus XHigh（`claude-opus-5-5`, `effort=xhigh`，基于 V1 12 路 1000 评与 V3 Clean 12 路全程逐步开环回放）

- **总体结论：** 支持 `P = Q ∪ A`（将 `A` 作为剪枝宽限与踏脚石现役窗口）+ V3 分块纯事实反思方向，但实测证明原草案的 `σ(10z)/MAD` 抽样与线性秩 `q×d` 代表选择均事与愿违，建议进一步削减至极简排名衰减规格。
