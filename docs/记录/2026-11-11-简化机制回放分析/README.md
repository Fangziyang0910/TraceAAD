# 简化机制回放分析

2026-11-11（北京时间）。问题是当前的简化机制是否合理：[topology.py](../../../evotrace_v1/topology.py) 决定保留哪些节点，[reflection.py](../../../evotrace_v1/reflection.py) 把移除区域凝练为经验。

我的判断是骨架合理，两处失衡。骨架指“先选保留节点，再求分叉闭包，再把移除节点切成路径收缩区与旁支整理区”。失衡一是拓扑规则很多，但保留集合基本只由“质量×代码距离”与方向配额决定，而方向配额的依据最弱。失衡二是约96%的移除节点走旁支整理，负载集中在少数父节点的选择经验上，这部分实现最薄。

## 条件

- 代码：`topology.py` SHA256 前16位 `9ebf43b6d0b830f8`，`reflection.py` `aa2c5b5e969f9bc1`，默认 `TopologyConfig()`。
- 日志：`experiments_result/traceaad_base_boltzmann_20261109` 中 TSP、CVRP、FSSP、OP 各3路的 `native/attempts.jsonl`。
- 方法：[replay_stats.py](replay_stats.py) 按日志顺序接入节点，节点数达到64时调用 `plan_consolidation` 并应用。后代的日志父代若已被移除，改挂到最近的保留祖先。只读日志，不调用模型，不评价程序。
- 这是 Base 的搜索轨迹。EvoTrace 自己搜索时，父代只能来自保留节点，树形会不同。以下数字说明规则在这类树上的行为，不说明搜索效果。

## 观察

12路共334轮重构，每轮保留31.4个节点。前沿24.1，分叉锚点6.7（可与前沿重合），里程碑1.4。

**保留集合由两条规则决定。** 在同一棵重构前的树上，去掉单条规则后与默认保留集合的 Jaccard：

| 去掉的规则 | Jaccard 均值 | 保留集合完全相同的轮数 |
| --- | ---: | ---: |
| 方向配额（`max_directions`、`max_per_direction`） | 0.580 | 0 / 334 |
| 克隆过滤 | 0.956 | 228 / 334 |
| 里程碑 | 0.977 | 253 / 334 |
| 方向归并 | 0.980 | 269 / 334 |
| 质量下限 | 0.980 | 257 / 334 |
| 深度上限 | 0.984 | 254 / 334 |
| 新方向保护 | 0.995 | 312 / 334 |

**方向在边上有意义，在分组上很弱。** Explore 边的父子代码距离中位数为0.42—0.52，Refine 边为0.21—0.33。同方向节点对的平均距离为0.39—0.52，跨方向为0.46—0.55，只差0.03—0.07。前64个可行节点已分成21—24个方向，默认上限是7。补齐阶段的次级前沿不受方向配额约束。

**移除节点几乎都是旁支。** 每轮路径收缩移除1.37个节点，旁支整理移除31.21个节点。旁支节点中：

- 16.5%超出每个父节点6个样本的上限，没有展示给模型。单个父节点单轮最多移除36个。
- 6.4%超出每轮8次调用的上限，走确定性摘要。
- 7.9%的真实父代不是承接它的保留节点，其结果按承接节点的适应度标注。
- 一路运行中，吸收最多的1个父节点占全部旁支的22.7%，前5个占68.6%。

**保留的节点是产出改进的父代。** 首轮重构后，Base 有63.6%的尝试选了已被规则移除的父代；刷新全局最优的69步中，这一比例是30.4%。全局最优每轮必然保留，因为代码强制把它放入前沿，管理文档中的“3/3保留率”不携带信息。

## 认识

1. 里程碑、深度上限、方向归并、质量下限和新方向保护，各自只改变不到2.5%的保留集合。去掉它们，规则的行为基本不变。
2. 方向配额是作用最大的规则，它用派生来源代替计算差异来分配容量。机制文档自己的原则是“亲缘距离不能代替计算差异”。贪心准则里的最小代码距离已经在直接度量差异。Explore 边作为路径收缩的边界仍有依据。
3. 变异经验在这类树上很少产生，大多数边保持单步修改、经验为空。选择经验承担主要工作，而且集中在少数父节点上：一个父节点在一路运行中要把一两百次尝试并入一段固定长度的文本。它的形式应当是按修改类型汇总的累计记录，而不是若干条尝试的列表。
4. 选择经验里的“Surviving”一半重复了树上已有的节点信息，子节点变化后会过时。经验只需保存树上已经没有的内容。
5. “每次已评价的尝试都归属于某条经验”目前在计数上成立，在内容上不成立：上述三类合计占旁支节点的两到三成，它们没有经过模型整理，或被标注到了别的父代上。
