# 轨迹评分机制 V2：分解的层次贝叶斯模型与汤普森采样

北京时间2026-11-03。本文取代[第一版设计](2026-11-03-轨迹评分机制设计.md)中的评分公式与抽样规则，并吸收[元评审](2026-11-03-轨迹评分机制元评审.md)的意见。第一版的问题在于：它把几个不同的量手工拼进了一个乘积。V2 改为一个统一的概率模型，多种轨迹信号由后验分布联合决定，再用汤普森采样做决策。本文只是设计，还没有离线拟合，也没有修改在线代码。

## 结论

预算分配仍然分两步：先按固定比例抽取算子 \(o\)，再在候选节点中选择 \(p\)。选择节点分三层：

1. **目标量**：用概率链式法则把"一次尝试突破当前全局最好"的概率 \(P(B)\) 拆成三个因子，每个因子用最合适的数据去学。
2. **置信模型**：每个因子是一个贝叶斯广义线性模型。轨迹特征的权重在节点之间共享；另有一个节点随机效应，表示节点自身的潜力。先验从历史批次学得，搜索中在线更新后验。
3. **决策**：汤普森采样。从后验中抽一组参数，算出每个候选的 \(P(B)\)，选最大的那个。

## 1 问题的结构

| 结构事实 | 对机制的要求 | 借鉴的理论 |
| --- | --- | --- |
| 候选不断新增；同一节点反复失败后，继续投入的价值下降 | 新节点要有机会被试；反复失败的节点要自然退出；不为新个体保留尝试次数 | 无限臂老虎机（Berry 等 1997；Wang、Audibert、Munos 2008），衰减臂老虎机（Levine 等 2017） |
| 轨迹相似的节点，潜力也相似 | 一个节点上的结果，也要影响对相似节点的判断 | 上下文老虎机与 GLM 老虎机（Li 等 2017；Kveton 等 2020），GP 老虎机（Chowdhury & Gopalan 2017） |
| 目标是突破当前最好；这个事件很少，只有百分之几 | 数据多的事件要正当地利用，不能拿来冒充目标事件 | 概率链式法则分解；层次模型跨批次借力 |
| 估计不确定，而且一次搜索的预算有限 | 决策时把不确定性也算进去，不能只看均值 | 汤普森采样（Thompson 1933；Russo & Van Roy 2014） |

## 2 目标量：分解的突破概率

**定义。** 一次投入指一次完整的开发尝试，包含其中的修复。\(V\) 表示尝试交付了有效程序，\(I\) 表示子代优于 \(p\)，\(B\) 表示子代优于当前全局最好。因为 \(B\subseteq I\subseteq V\)，所以下式精确成立：

\[
P(B\mid p,o)=P(V\mid p,o)\cdot P(I\mid V,p,o)\cdot P(B\mid I,p,o).
\]

**为什么要分解。** 三个因子回答三个不同的问题，各自的数据量也不同。

| 因子 | 问题 | 主要信号 | 数据量 |
| --- | --- | --- | --- |
| \(P(V)\) | 从 \(p\) 出发，能否交付有效程序 | 代码复杂度、此前的生成失败、算子 | 多 |
| \(P(I\mid V)\) | 能否改进 \(p\) | 节点潜力（随机效应）、已有尝试的结果、近期尝试、算子 | 多，约20%–50%的有效子代为正例 |
| \(P(B\mid I)\) | 改进能否越过当前最好 | 与当前最好的差距、算子 | 少 |

第一版的问题由此消失：每个事件只用于对应的因子，失败消耗与成功信号作用在 \(P(I)\) 上，生成失败的代价由 \(P(V)\) 计入，不再被丢掉。全局最好移动时，只有 \(P(B\mid I)\) 中的差距会变，模型其余部分不受影响。

## 3 置信模型：带节点随机效应的贝叶斯广义线性模型

**形式。** 以 \(P(I\mid V)\) 为例：

\[
\operatorname{logit}P(I\mid V,p,o)=w_o^\top\phi(\tau(p))+u_p,\qquad u_p\sim\mathcal N(0,\sigma^2).
\]

- \(\phi(\tau(p))\)：从 \(p\) 的轨迹计算出的特征。
- \(w_o\)：按算子区分的权重，在所有节点之间共享。
- \(u_p\)：节点随机效应，所有算子共用。

\(P(V)\) 的形式相同。\(P(B\mid I)\) 的正例太少，只保留差距、算子和少量特征，不设随机效应。

**特征 \(\phi\)：多种来源，由后验决定组合方式。**

| 来源字段 | 特征 |
| --- | --- |
| 节点适应度 | 与当前最好的差距（分档与连续值）、当前排名 |
| 子代（已有尝试） | 同类、异类算子的尝试数；此前优于 \(p\) 的次数；近期尝试中变差、同分、复制、生成失败的计数和最大增益 |
| 祖先路径 | 出生排名、路径趋势与范围、最近一步增益；是否比路径上最好的祖先差 |
| 代码与 design | 代码规模和 AST 结构统计；代码和 design 的嵌入（降维后进入） |
| 诊断（独立调用） | 状态：未诊断、有缺陷、未检出缺陷 |
| 搜索阶段 | 预算进度 |

每个特征的权重先验均值为0，方差从历史数据学得。出生排名、路径趋势这类跨版本不稳定的信号，学到的权重会自然趋近于0，不需要人工决定"用"还是"不用"。

**为什么设节点随机效应。** \(u_p\) 表示"这个节点本身好不好改"，特征解释不了的那部分。它的子代每失败一次，\(u_p\) 的后验就往下移一点，消耗由此自然产生，不需要 \(n_0/(n_0+k)\) 这类手工式子。最简单的情形下（只有截距，Beta 先验），它退化为第一版的 Beta-Bernoulli 预测。第一版观察到，改进率随失败次数下降的方式与 Beta 预测吻合（V15、V18.1、Base、V19.1 的 \(k=2,3\) 预测值与实测值相差不超过0.03）。这个证据用的是"优于父代"标签，正好对应 \(P(I)\) 这个因子，现在用在了对的地方。

**成功也更新 \(u_p\)，不需要特别规则。** 子代成功说明 \(p\) 容易改进，\(u_p\) 上升。五个版本中，此前有成功、无失败的节点，下一次优于父代的比例约为无尝试节点的1.5–2倍。成功的子代自己也成为候选，它的差距更小，通常比 \(p\) 更有希望突破。\(p\) 与它的子代之间的取舍，由模型对两者的 \(P(B)\) 估计决定，不靠"成功不计"这样的人为规则。

**随机效应为什么跨算子共用。** 历史数据中，异类算子的一次失败使改进率下降的幅度，与同类失败接近（换算成权重约为0.7–1）。所以节点潜力主要是节点层面的。算子之间的差别由 \(w_o\) 表达。

**先验与在线更新。** 超参数（\(w\) 的先验均值与协方差、\(\sigma^2\)）按批次从历史数据中用经验贝叶斯估计。搜索开始时用这个先验；每完成一次尝试，就用 Laplace 近似更新后验。参数只有几十维，每次更新的计算量可以忽略。

**相似节点之间的证据共享。** 共享的 \(w\) 已经让特征相近的节点共享证据。如果后续发现这还不够，可以把线性项换成轨迹核上的高斯过程分类，核由差距、尝试结果和代码嵌入构成。第一版先不这样做。

## 4 决策：汤普森采样

每次选择时：

1. 按固定比例抽出算子 \(o\)。
2. 从三个因子的后验中各抽一组参数 \(\tilde\theta\)，包括每个候选的 \(\tilde u_p\)。
3. 对每个候选计算 \(\tilde P(B\mid p,o)=\tilde P(V)\,\tilde P(I\mid V)\,\tilde P(B\mid I)\)。
4. 选 \(\tilde P(B)\) 最大的候选。

**为什么用汤普森采样。** 这样每个节点被选中的概率，就是它在当前证据下是最优候选的后验概率。不确定性大的节点（新节点，或少见的轨迹类型）更容易在某次抽样中胜出，所以会被探索；证据充分、均值又低的节点会自然退出。这正是无限臂情形所需要的行为，而且不需要额外的探索奖励或保留尝试次数。GLM 与 GP 老虎机上的汤普森采样都有遗憾上界（Agrawal & Goyal 2013；Kveton 等 2020；Chowdhury & Gopalan 2017）。我们的问题不完全满足这些定理的假设，所以这些结果只作为方法依据，不作为性能保证。

**和第一版的区别。** 第一版按均值的比例抽样：即使估计已经很准，也会持续把预算分给明显较差的节点；同时它又不感知不确定性。汤普森采样在这两点上都更合理。

## 5 诊断与融合对象

**诊断。** 诊断仍是独立的 LLM 调用，不与反思合并。输入是 \(p\) 的代码、design、analysis、祖先路径上的修改；如果 \(p\) 比路径上最好的祖先差，再加入那个祖先的代码。诊断有两个用途，需要分开检验：

- **作为精炼材料**：这是一种干预，要用"同一起点、同一预算、有无诊断"的配对生成来检验。
- **作为特征**：诊断状态进入 \(\phi\)，它对 \(P(I)\) 的效应由后验学得。效应的估计是相对"未检出缺陷"组的 log-OR，用法在数学上是对的。

V2 的第一步只把诊断当作精炼材料；它是否进入特征，等预测关联检验之后再决定。

**融合对象。** 保留现有的参考选择方式。用 design 距离表示互补性仍只是假设，在验证核心评分时不同时改动这一处。

## 6 元评审意见的处理

| 元评审指出的问题 | V2 的处理 |
| --- | --- |
| 目标、样本、公式用的是不同事件 | 用链式法则分解，每个事件对应一个因子 |
| 只用有效子代，丢掉了生成失败的代价 | 由 \(P(V)\) 计入 |
| 基础概率已含失败历史，再乘折扣是重复计入 | 基准、计数与随机效应在同一模型中联合拟合 |
| 忽略成功，不是标准后验；"信用流向"不是统计理由 | 成功同样更新 \(u_p\) 与特征，它的作用由数据决定 |
| 诊断把几率比当成似然比 | 诊断状态作为特征，系数就是 log-OR；第一步只作为材料 |
| 比例抽样不是汤普森采样 | 改用真正的汤普森采样 |
| 复制权重为0没有检验 | 复制作为近期尝试中的一个计数特征，权重由数据决定 |
| 单步 PI 只是短视的替代目标 | 承认这一点；多步扩展见第8节 |
| 融合距离只是假设 | 不进入 V2 |
| 历史转述超出证据 | 本文只引用经过核对的统计；"低排名节点多为弯路"不再作为结论 |

## 7 现有证据与它支持的结构

| 结构选择 | 证据 | 条件 |
| --- | --- | --- |
| \(P(B\mid I)\) 以差距为主，且按算子区分 | 突破率随差距的变化方式因算子而不同：精炼单调下降，拓展在差距超过1%后基本持平；五个版本一致 | 第一版第2节；有效子代口径，需按完整尝试口径重算 |
| 节点随机效应 | 改进率随失败次数的下降与 Beta 预测吻合 | 第一版第3节；"优于父代"标签 |
| 随机效应跨算子共用 | 一次异类失败的影响与一次同类失败接近 | 第一版第3节 |
| 成功进入 \(P(I)\) | 此前有成功时，下一次优于父代的比例约为1.5–2倍；加入成功信号后，"优于父代"的 AUC 在五个版本中都提高 .01–.04 | `mech4.py` |
| 近期尝试作为特征 | 在23个批次中，加入近期尝试组后，22个批次对后续30次内分支突破的预测 AP 提高 | [历史报告](../../experiments_result/analysis/historical_trajectory_signals_20261103/README.md)第4节 |
| 出生排名、路径趋势只作为先验均值为0的特征 | 加入这两组后，AP 分别在14/23、10/23个批次中提高，方向不稳定 | 同上 |

前三行使用 V15、V17、V18.1（qwen3.8-27b-awq，温度0.7，预算1000次生成回复）、Base 与 V19.1（Qwen3.8-27B，温度1.0，预算1000次评价）的六任务数据。所有统计都基于各版本自身策略选中的尝试。

## 8 风险与扩展

- **突破事件稀少。** \(P(B\mid I)\) 主要依靠历史先验，在线更新只做小幅修正。所以这一项的特征要少。
- **历史数据有选择偏差。** 先验来自旧策略选中的尝试，没被选中的节点没有结果。汤普森采样自身的探索会在新搜索中逐步补上覆盖，但先验中的偏差不会自动消失。
- **短视。** 当前目标是一步突破概率（PI），不计突破幅度，也不计延迟收益。可以借鉴两种扩展：一是知识梯度或 freeze-thaw 贝叶斯优化，按"这一步对最终最好结果的期望贡献"估值；二是同时预测突破幅度，改用 EI。
- **成本。** 不同节点的一次尝试，消耗的评价次数可能不同（修复次数不同）。可以把目标改为 \(P(B)/E[\text{评价次数}]\)，这对应预算约束下的老虎机。
- **非平稳。** 提示中的经验和全局最好会随搜索变化。差距特征承担了阈值的移动，预算进度特征承担阶段差异。如果仍不够，可以对旧观测做指数遗忘。

## 9 检验计划

1. **构建一步数据集。** 用另一侧冻结的 `decisions.jsonl.gz`（23个批次、230502次决策、生成前特征）与 `pairs.jsonl.gz`（一步父子结果）合并，得到每次尝试的 \(V,I,B\) 三个标签。没有有效子代的尝试记 \(V=0\)。
2. **离线拟合与比较。** 按批次、按 seed 留出，比较三种模型：(a) 直接预测 \(B\) 的逻辑回归；(b) 分解模型，无随机效应；(c) 分解模型，有随机效应。指标是对数损失、AUC 和校准曲线。重点看两点：分解是否改善了 \(P(B)\) 的校准；随机效应能否取代手工计数项。
3. **回放检查。** 在历史状态上运行汤普森采样，检查它选出的节点分布是否合理：新节点有多少机会，反复失败的节点是否退出。这一步只检查行为，不判断机制好坏。
4. **完整搜索。** 在固定协议下与现有机制比较最终结果。机制好不好由这一步裁决。
