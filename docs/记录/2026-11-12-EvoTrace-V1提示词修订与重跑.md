我将本轮修正收束为一条原则：**反思读取完整受评代码与结果，凝练计算事实；生成算子使用这些事实决定下一次改动。** 节点结构、统一选择、LCA补全、预算分配与初始化机制沿用原实现。四个对应模块与旧冻结源码逐字节一致。

## 修正

1. 分叉整理逐个读取被移除节点，保留内部错误、完整旧节点经验和旧边经验。取消“入口节点＋最优后代”的预摘要及240字符截断。
2. 反思用完整受评代码与结果逐项配对。移除生成时的设计自述，避免把含糊描述当作实际计算。路径两端仍有净差分；生成上下文中的差分保留全部改动行。
3. 提示词按任务、证据、整理动作和输出格式组织。经验采用“具体计算：观测结果”，同类参数尝试合并为分数区间。移除禁用词清单、空失败统计、存活分支复述等旁支内容。
4. 初始化与修复统一为 `analysis → code → design`。候选代码移除注释与过程自述；任务接口说明保留。Refine失败子代同时给出计算改动和异常。
5. 每次反思记录完整输入、原始响应、最终经验、错误与用量，失败调用也计入辅助成本。

机制说明已同步至[反思简化设计](../反思简化设计.md)、[方法文档](../树状种群与反思简化.md)和[模块说明](../../evotrace_v1/README.md)。
