# EvoTrace V4：机制信息边界与反思基准修正及12路重跑

记录时间：2026-11-12 09:57（北京时间）。

## 问题与证据（来自 V3 批次 9,492 次评价审计）

对 `20261111_235642_evotrace_v1_v3_co4`（9,351 次生成/修复请求、263 轮拓扑重构、4,981 次区域反思）的逐环节审计表明，V3 已将初始化/修复顺序冲突、“无运行错误”套话和内部错误漏传降至 0，但在长程运行中暴露出四处核心失真：

1. **`Explore` 上下文混入局部利用答案，导致探索算子退化为模仿**：`_directions_overview_block` 向 `Explore` 展示了每个方向的 `best retained fitness`、`Best retained design` 公式以及方向内部全部微调节点的旁支账本与内部阶段边（后期提示词膨胀至 25k–45k 字符）。2,692 次 `Explore` 中有 1,122 次（41.7%）在 `analysis` 中直接模仿已有高分方向；有效 `Explore` 子代与全库最近 AST 距离 `< 0.12` 的近克隆率达 37.8%–46.9%（`Base-Boltzmann` 为 2.5%–27.3%，`V24.1` 为 1.4%–23.5%）。模仿产生的同分改写版本在 `op_rep1`（22/32 同分）与 `tsp_rep2`（19/32 同分）占满保留容量，并在 11/263 轮触发 `MAD = 0`。
2. **分叉整理（`Selection Reflection`）缺少父节点代码与相对差分锚点**：`build_selection_prompt` 仅提供父节点编号与分数，却逐个粘贴被删子节点的完整代码。875 次单分支淘汰反思中有 273 次（31.2%）将被删子节点继承自父代、并未改动的基线计算一并标上退步分数写入 `[Eliminated]`，使后续 `Refine` 收到与当前父代代码自相矛盾的信号。
3. **多轮累加的截断与回退细节**：3,799 次选择反思中有 266 次（7.0%）在 900 字符上限处断在半个词中间；仅有的 2 次反思 JSON 解析回退均由 `reflection_max_tokens = 1024` 输出截断引起，且确定性回退重复拼接了 `[Eliminated]` 前缀。
4. **生成上下文的悬空引用与控制字符污染**：跨方向收缩边或参考节点已淘汰的交叉边产生了 3,478 次 `Explore with reference Algorithm X` 或悬空参考号；47.0% 的反思经验含有对下游无定义的临时 `#ID`；超过 6 步的路径截掉了初始起点算法；约 1.1% 的候选 `design` 因单反斜杠 LaTeX（`\beta`、`\frac`）被 JSON 解析为控制字符进入后续提示词。

## 根源级精简修正（`tree_population_multiscale_v4`）

遵循奥卡姆剃刀原则，直接修正输入结构与信息边界，不堆叠防御性禁令：

1. **校准 `Explore` 的全树级视野与种群同分去重**：
   - `_directions_overview_block` 按 AST 结构距离（`>= 0.12`）去重筛选异构方向，每个方向只展示起点核心机制（`Core mechanism`）、累计评价次数、收缩入口过渡与去重淘汰账本，彻底移除 `best retained fitness`、`Best retained design` 与内部微调边；`EXPLORE_INSTRUCTION` 明确要求引入异构主计算而非重加权已有公式。
   - `TopologyConfig` 增加 `same_fitness_clone_distance = 0.20`（常规跨分数门槛仍为 `0.08`），防止同分等价改写挤占 32 个槽位；`parent_probabilities` 在 `MAD == 0` 时平滑回退至非零绝对偏差中位数。
2. **为分叉整理补齐保留父节点基准代码与相对真实父代差分**：
   - `build_selection_prompt` 在顶部提供一次保留承接父节点的标准化基准代码，每个被删尝试展示相对其真实父代的 `compact_diff`（初始根下展示完整代码）。既消除了把父代未改动代码误记为淘汰的根源，又将重度分叉反思输入从 61.8k 字符压缩至 30.2k 字符。
   - 明确先承接旧账本各方向最优分与报错、再并入新改动（`<= 125` 词）。
3. **分句边界收束与容量校准**：
   - `reflection_max_tokens` 上调至 `1536`，经验上限设为 `960` 字符并由 `_truncate_at_clause` 在 `; ` / `. ` 分句边界收尾；修复确定性回退的重复前缀并保留新增淘汰项。
4. **清理悬空引用、临时编号与未转义控制字符**：
   - `_operator_label` 仅在 `edge.operator == "Crossover"` 且参考节点仍在树上时渲染 `with reference Algorithm X`；反思输入不暴露内部 `#ID` 且输出自动剥离残留 `#ID`；`_render_subpath`（`max_path_steps = 10`）始终锚定路径首节点；`clean_prompt_text` 自动还原 `\x08`/`\x0c` 等未转义 LaTeX 反斜杠字符。
