# EvoTrace 的对比方法与任务选择

> 2026-11-14 修订建议。前一版建议十种外部方法和七个任务，范围过大；下面的建议取代前一版，不改变已经运行的批次。

## 论文实际怎么比较

这里数的是每张表中除作者方法外的 LLM 自动算法设计方法，不把人工规则、神经求解器或同一方法的消融算进去。

- [PartEvo，NeurIPS 2025，表1](https://proceedings.neurips.cc/paper_files/paper/2025/file/e389b15166cf98966ba058965a8c17e3-Paper-Conference.pdf)：FunSearch、EoH、ReEvo 共三种；另列 GA、PSO、DE 等人工算法。主实验有四组基准。
- [MCTS-AHD，ICML 2025，表1和表2](https://arxiv.org/html/2501.08603)：TSP/KP 构造任务比较 FunSearch、EoH；ACO 任务比较 EoH、ReEvo。在线装箱表则有四种同类对照。不同任务的对照数量并不相同。
- [PathWise，ICML 2026，表1和表2](https://arxiv.org/html/2601.20539)：TSP 构造表列五种同类方法，KP 部分有方法不适用；ACO 表列 EoH、ReEvo、HSEvo、MCTS-AHD 四种。
- [RefineEvo，ICML 2026，表1和表3](https://arxiv.org/html/2607.11358)：TSP/KP 表列七种同类方法，CVRP/VRPTW 的构造启发式表列 PartEvo 和 OpenEvolve 两种。

这些例子说明，论文通常围绕任务和方法选择对照，不存在需要列出十种方法的统一标准。具体数量也有变化：不能说每篇论文都只比较两三种。

## 建议主表：四种外部方法

| 方法 | 选择理由 |
| --- | --- |
| [EoH](https://proceedings.mlr.press/v235/liu24bs.html) | 经典的算法思想与代码共同演化的种群方法。 |
| [MCTS-AHD](https://proceedings.mlr.press/v267/zheng25o.html) | 用树组织候选并分配搜索，是树结构方面直接且已发表的对照。 |
| [PathWise](https://proceedings.mlr.press/v306/gungordu26a.html) | 用派生图、规划和反思利用历史，与本研究关注的经历复用接近。 |
| [RefineEvo](https://proceedings.mlr.press/v306/wu26ap.html) | 用规划和正负经验池指导演化，是经验积累方面的近期对照。 |

加 EvoTrace 自己，主表为五个方法。四个外部方法都有项目内入口，正式使用前核对各自实现和运行条件。不强制加入 PhyloEvolve；它仍应在相关工作中准确讨论。DeltaEvolve 也研究历史表示，但本地是论文复现版，作者仓库查阅时尚未发布代码；本次不将它列为必须运行的主对照。

## 建议主任务：四项

| 任务 | 搜索生成什么 | 为什么选择 |
| --- | --- | --- |
| TSP | 路线构造规则 | 经典任务，连接已有 AAD 工作。 |
| CVRP | 蚁群算法的启发式矩阵 | 有容量约束，使用固定搜索框架。 |
| FSSP | 引导式局部搜索的扰动与作业选择 | 不同于路径问题的调度场景。 |
| 图着色 | 完整求解程序 | 图结构问题，也检验从局部启发式到完整程序的不同接口。 |

这四项覆盖路径、调度、图问题，以及构造规则、ACO 启发式、GLS 扰动、完整求解器四种接口。与最初四任务中的 OP 相比，图着色在任务结构和接口上提供了更大的区别；OP、JSSP 原有实验继续按既定条件运行，已有结果可按条件用于补充。无需为凑数量接入在线装箱。

## 实验安排

每个方法、任务先做三次独立搜索；每路以 1000 次实际程序评价估算，五方法、四任务约 6 万次程序评价。搜索用训练集选择最终程序，测试集独立。完整结果报告各路表现与模型调用成本；不同评价次数、采样和时限的旧批次不能直接合并。

机制分析优先做一个问题：在其他搜索设置相同的情况下，是否向生成模型提供压缩经验，会怎样影响后续搜索。可先选两个任务做固定状态对照与完整搜索对照。具体变体按最终确定的 V3 实现设计；TraceAAD Base 与 V3 有多处差异，二者整体比较不能充当单一因素消融。

本次调整只改变研究建议，没有启动实验或修改运行中的任务。实验设计参考 [Scientific Agent Skills](https://doi.org/10.48550/arXiv.2609.00065) 的独立重复原则。
