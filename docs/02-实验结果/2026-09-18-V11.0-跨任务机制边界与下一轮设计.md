# V11.0 的跨任务机制边界与下一轮设计

## 核心判断

V11.0 证明了全档案参考上下文在 CVRP-ACO 上具有稳定收益，同时显示同一套全局调度和参考组织不能覆盖五类任务。V11.0 五重复结果将研究焦点从“是否使用历史”推进到“任务和算法状态需要哪类历史证据”。

V11.0 的两个系统变化是：

1. 用全档案质量百分位与有限探索加分分配父代；
2. 让 Pivot/Fuse 共享最多 8 个参考节点的 Idea 与实测适应度。

CVRP held-out 三个规模的五重复均值相对 V10.11 generic 改善约 3.70%–4.46%，说明路径外精英经验可以推动多信号机制组合。TSP、OP、VRPTW 和 OBP 没有获得同方向收益，表明参考证据的有效性取决于任务收益形成结构。

## 五任务证据

| 任务 | 结果信号 | 机制解释 |
|---|---|---|
| TSP | 短形成轨迹支持优势谱系持续发展 | 形成关系帮助模型围绕残余路径估计、2-opt 和候选池继续协调 |
| VRPTW | 短形成轨迹在多预算点保持优势 | savings、等待、slack、容量和返仓规则需要连续协调 |
| CVRP-ACO | 全档案参考在训练与 held-out 均形成稳定优势 | 跨分支精英算法族传播了距离、节约、极角、容量衰减和车场锚定等互补信号 |
| OP-ACO | 全代码上下文的收益随规模分化 | 组合和参数校准依赖当前规模，单一历史形态无法覆盖全部状态 |
| OBP | 参考思想进入代码并改变 `argmax` 排序 | `residual-myopic` 诊断被实现为可复用孔洞机制，形成真实决策边界变化 |

这组结果支持任务条件化的上下文组织：短轨迹适合维持协调结构，精英档案适合传播互补机制，行为与排序证据适合需要边界改变的任务。

## V11.0 的选择行为

V11 的调度分数为

$$S(x)=q(x)+0.1\sqrt{\frac{\log(1+T)}{1+n(x)}}.$$

由于每轮直接选择最高分代码，实际开发集中在高质量代码：正常候选中 `q ≥ 0.95` 的代码承担约 99.7%–100% 的开发，`q < 0.75` 的代码几乎没有开发机会。V11 的 best 节点深度约 50–72，明显高于 V10.11 的约 9–34。

这一行为在 CVRP 上体现为精英传播，在其他任务上则压缩了替代路线的开发机会。探索加分因此改变了开发位置的排序，却没有形成独立的低质量新路线机会。

同时，倒数排名参考让约 40%–43% 的参考来自前 32 名之外的长尾节点，而 V10.11 的 rank-softmax 参考约为 2%。V11 形成了“父代选择很窄、参考信息很宽”的结构：CVRP 能从高质量算法族的 Idea 传播中获益，其他任务更需要形成关系、代码机制或行为证据。

## 机制边界

V10.11 四组对照给出的是任务相关的上下文事实，而不是一个已经验证的全局控制器：

- 短轨迹在 TSP 和 VRPTW 上支持持续协调；
- 精英档案在 CVRP 上支持跨分支机制传播；
- OP 需要按规模观察完整代码与形成历史的作用；
- OBP 的关键是思想是否改变实际排序；
- 所有对照从头到尾使用固定上下文，尚未检验动态切换策略。

因此，V11 的下一步应拆分父代调度与参考池组织，分别测量它们对开发分布、代码行为和 held-out 结果的影响。

## 下一轮实验设计

### 调度变量

保持 V10.11 generic 的提示、四算子、解析、修复和预算不变，比较：

| 条件 | 父代选择 |
|---|---|
| A0 | V10.11 质量抽样 |
| A1 | V11 质量百分位加探索分数，但从分布抽样 |
| A2 | A1 加入低质量新代码的最低开发机会 |

核心指标是跨谱系开发率、候选持续开发率、训练曲线和三规模 held-out 结果。

### 参考池变量

不改变父代调度，比较：

| 条件 | 参考信息 |
|---|---|
| B0 | V10.11 的 rank-softmax 精英参考 |
| B1 | top-16 参考并加入少量机制多样性卡 |
| B2 | 参考 Idea 加入短代码机制摘要 |

核心指标是参考机制进入代码的比例、实际排序变化、父代改进率和执行成本。B1 主要检验精英传播与长尾噪声的平衡，B2 主要检验可执行机制信息对 OBP 等边界任务的作用。

### 任务条件化方向

调度与参考池消融确定作用来源后，再按任务采用最小策略：

| 任务 | 起始策略 |
|---|---|
| TSP | 短形成轨迹，Pivot 使用少量替代卡 |
| CVRP | 精英档案与少量互补卡 |
| OP | 形成链与 top-16 档案的受控组合 |
| OBP | 行为摘要和排序变化证据 |
| VRPTW | 短形成轨迹，并记录执行成本 |

## 论文可用的结论

V11.0 的价值不在于提供一个全任务统一的自适应器，而在于证明：**历史上下文必须匹配收益形成结构；当参考证据进入代码并改变实际决策时，路径外经验能够转化为搜索收益。** 这一结论直接规定了下一轮研究的自变量，也为 TraceAAD 的任务条件化经验组织提供了实证基础。
