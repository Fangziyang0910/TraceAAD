# 已完成搜索批次的 held-out 补测

按 V10.14、V10.15 初版、V10.13、V9.21 遗漏、V11.0 复测补档、B/C 已完成运行的顺序，在 server3 逐批补测。清单固定为 100 路、362 项。V11.0 CVRP 第 3 路已有文档汇总分数，但本地缺原始测试文件，本次复测补齐原始数据，不将其计为此前从未测试。测试使用各次搜索已经选定的程序。
