# 已完成搜索批次的 held-out 补测

V10.14-3 与 V10.15 初版使用原独立选择冻结程序，沿用 V10.15-5/-6 的数据、730241 评价种子、4 个 ACO worker、时限和单线程设置，逐项核对协议哈希。V10.14-3 仅兼容旧选择记录的字段名。较旧版本按原共享评价入口的 pick_best_sample 导出训练最佳程序，保留历史基础 ACO 种子与 CVRP50/100/200 规模，不将它们与新版种子口径混合。

资源预算为 48 个逻辑 CPU、最多 24 个并发测试，绑定 CPU 0–47；低 CPU 空闲或内存不足时减少新任务并发。每批同步原始结果、命令、运行日志与资源采样，并逐文件验证 SHA-256。正式超时与运行失败保留。
