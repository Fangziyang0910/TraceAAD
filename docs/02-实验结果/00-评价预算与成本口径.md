# TraceAAD 评价预算与成本口径

TraceAAD 按评价器调用次数使用搜索预算。调用前计一次，随后无论候选得到分数、运行失败、超时、返回非法结果或评价器抛出异常，都不撤销这次计数。模型输出未解析成程序时没有调用评价器，因此不计评价预算。

## 计数规则

| 情况 | 评价预算 |
| --- | --- |
| 获得合法分数 | 1 |
| 代码错误、运行错误、超时、非法结果或非有限分数 | 1 |
| 评价器调用抛出异常 | 1 |
| 重复程序再次评价 | 1 |
| 解析失败，未调用评价器 | 0 |

这一定义直接对应“模型生成的程序获得多少次真实评价机会”。实现使用单一 `budget_used` 计数，不区分预约、回执、故障免责或人工核定。

## 其他成本

评价预算不包含模型成本。报告实验时同时给出：

1. 评价器调用数；
2. 得到合法分数的程序数；
3. 模型调用数及可用的输入、输出 token；
4. held-out 评价次数。

相同评价预算不代表相同模型成本或运行时间。解析率、有效程序数和单次最好值可以解释运行过程，但不能替代重复实验与 held-out 结果。

## 实现

当前实现见 [traceaad.py](../../traceaad/v10_13/traceaad.py)，行为测试见 [test_traceaad_v1013.py](../../tests/method/test_traceaad_v1013.py)。旧批次如果采用不同计数方式，按其原始结果和历史机制说明解释，不把旧运行状态迁移成当前口径。

各基线的内部预算单位并不完全相同。跨方法比较前，应先把本地实现换算为评价器调用、合法程序和模型调用三个独立数量，再决定可比预算。
