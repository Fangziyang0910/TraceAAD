# TraceAAD V9.10 实验结果与机制失效诊断

过程诊断由 `analyze_v910_failure.py` 从终局 checkpoint 重放。

## 1. 核心判断

V9.10 试图在“锚点 × 算子”空间维护折扣 Thompson 联合后验以学习多代延迟信用（$H_C=3$），遭遇了全面的实证失败（四任务全线下滑，CVRP 退化 +7.9% 至 +11.8%）。其根本理论失效在于：**非平稳动作空间膨胀与信息右删失（Informative Right-Censoring）彻底摧毁了贝叶斯后验闭环**。

1. **非平稳动作空间膨胀（Action Explosion）**：在 1000 次评价中，有效锚点数线性增长至 ~1000 个（对应 ~2000 个联合臂），而约 50% 的锚点在整个搜索中从未获得二次访问。新臂的不断涌入导致先验质量严重稀释已有历史证据；
2. **多代延迟结算诱发严重信息右删失（Informative Censoring）**：在搜索终局，**36%–53% 的动作仍处于未决（Pending）状态**，其中超过 80% 的动作年龄超过 100 次评价。后验看到的“已结算成功”仅为被后续搜索选择性访问的幸存样本；
3. **后验退化为近均匀扩散（Diffusive Allocation）**：由于有效观测严重删失，Thompson 联合后验熵指数高达 92%–94%（Top-20 臂仅占 2% 质量，与完全均匀随机几乎一致），算法完全丧失了对高潜力血脉进行深精炼的算力聚焦能力。
4. **不可替代的科学结论**：**信用必须在有限响应时间内可观测；在非平稳代码搜索空间中，任何依赖多代后代结构才能结清的延迟信用机制必死，即时原子反馈不可替代。**

## 2. 结果事实

正式比较使用 Qwen3.6-27B、每次 1000 次真实 evaluator 调用和三次独立搜索。结果方向遵循任务指标：TSP/CVRP/OBP 越低越好，OP 越高越好。均值差使用同一结果页中的三重复均值。

### 2.1 与 V9.7 的均值差

| 任务与设置 | V9.10 相对 V9.7 的变化 | 解释 |
| --- | ---: | --- |
| TSP50/100/200 | `+2.82% / +2.30% / +2.73%` | 三个规模均变差 |
| OP50/100/200 | `-2.15% / -3.19% / -9.21%` | 均值均变差；OP200 为 `n=2` |
| OBP capacity=100 | `+1.36% / +1.34% / +1.35%` | 三个规模均变差 |
| OBP capacity=500 | `-0.33% / +0.12% / +0.11%` | 近似持平，方向不一致 |
| CVRP50/100/200 | `+7.95% / +11.18% / +11.80%` | 三个规模均变差 |

TSP 的 run-level 对照中，TSP50 和 TSP200 的三个重复均比 V9.7 差；TSP100 有两个重复变差、一个重复改善。因此 TSP 的负结果不是单个重复造成的。OP 的 run-level 方向不完全一致，不能写成三重复同向退化；但均值、尤其 OP100 和 OP200，已经不支持 V9.10 的净收益。OBP capacity=500 的变化小于 1%，应按近似中性而非改善报告。CVRP 三个规模的均值均明显高于 V9.7，也高于 V9.9，说明负结果不是由 OP200 的单程序失效或单一任务造成。

### 2.2 与 V9.9 的关系

V9.10 相对 V9.9 的 TSP 变化为 `+3.06% / +1.88% / +3.34%`；OP 变化为 `-2.28% / -4.53% / -12.95%`，OBP capacity=100 变化为 `+0.19% / +0.69% / +0.74%`，capacity=500 为 `-0.57% / -0.03% / +0.06%`，CVRP 变化为 `+4.00% / +4.41% / +4.99%`。因此 V9.10 不是在 V9.9 之上形成稳定升级，且四任务中至少三个任务出现一致或近似一致退化。OP200 的失效样本使其不适合直接进入与完整三重复方法相同的综合排名。

## 3. 过程激活诊断

诊断脚本从每个终局 checkpoint 的 `forest` 重建锚点、动作、父子关系和折扣后验，不依赖已被精简的 `events.jsonl`。

### 3.1 `H_C=3` 没有形成可结算的观察窗口

终局 checkpoint 中，pending 比例为：

| 任务 | pending / actions | pending 年龄超过 100 响应的比例 |
| --- | ---: | ---: |
| TSP | `0.362–0.368` | `0.836–0.859` |
| OP | `0.356–0.384` | `0.833–0.852` |
| OBP | `0.526–0.545` | `0.857–0.873` |

这些 pending 动作中没有一个达到三代深度；大量动作的 child 从未获得足够的后代结构。当前结算条件要求：child 及其后代中出现超过起始锚点的程序，或者观察到 `H_C` 代深度。若锚点不再被访问，深度永远增长不到三代，动作就不会进入后验。这里的右删失不是普通的末端少量未完成动作：在多数运行中，超过 80% 的 pending 动作已经年龄超过 100 个响应。

因此 `pending` 同时混合了三种状态：

1. 动作确实没有改进，但尚未达到深度窗口；
2. child 有潜在后续价值，但没有得到再次分配；
3. 运行结束时的末端右删失。

V9.10 把三种状态都排除在后验之外。后验看到的已结算动作不是全部提议的代表性样本，而是被后续搜索选择性观察后的样本，存在明显的 informative censoring。

### 3.2 联合分配近似均匀，意图先验也没有真正学习

终局重放得到以下范围：

| 诊断量 | TSP | OP | OBP |
| --- | ---: | ---: | ---: |
| 有效锚点数 / 评价数 | `0.946–0.959` | `0.980–0.985` | `0.994–1.000` |
| 从未再次被选择的锚点 | `0.471–0.494` | `0.474–0.491` | `0.487–0.501` |
| 有效锚点数占比（熵指数） | `0.932–0.936` | `0.927–0.931` | `0.923–0.930` |
| top-20 联合臂质量 | `0.0201–0.0210` | `0.0201–0.0202` | `0.0202` |
| Refine 边际质量 | `0.698–0.701` | `0.690–0.697` | `0.696–0.704` |

若分配真正集中到少数近期高产锚点，top-20 质量应明显高于 `20 / n_arms` 的均匀基线，熵指数应明显低于 1。实际 top-20 约为 `2%`，有效锚点质量仍约为总锚点数的 `92%–94%`，Refine 质量仍接近先验 `0.7`。这说明后验没有形成可观的路线集中，也没有使算子份额脱离初始先验。

这里的关键不是“Thompson 没有随机性”，而是臂空间增长速度和证据到达速度不匹配：约 1000 次评价产生约 1000 个锚点和约 2000 个联合臂，而每个臂平均没有足够的后续动作来形成稳定后验。所有新臂保留非零概率在设计上避免了硬淘汰，但在这个规模下也使冷启动质量不断稀释已有证据。

### 3.3 已结算成功率不能作为机制有效证据

TSP 已结算动作中成功数约为 `541–566`，OP 约为 `542–585`，OBP 约为 `349–364`。这些数字不能直接解释为联合臂成功率，因为进入 `settled` 的动作取决于 child 是否被继续发展以及是否达到深度窗口。尤其是大量失败或未观察动作停留在 pending，已结算集合本身是选择性样本。

因此不能用“已结算成功率较高”证明分配器学到了高价值锚点，也不能用“后验均值范围较宽”证明它识别了真实差异。必须先解决结算可观测性，再评价后验是否能预测未来收益。

## 4. 为什么 V9.10 没有超过 V9 / V9.7

### 4.1 生成侧没有被证明变差，但分配侧失去有效反馈

V9.10 保留了 V9.9 的 parent path 和 Refine/Explore 生成契约，现有单步实验也支持父代改进来时路对固定锚点有价值。更直接的解释是：V9.10 将每次新 child 都转成新的联合臂，却没有为这些臂提供足够的重复观察；有限预算被扩散到大量没有完成信用结算的状态。

V9.7 的优势至少来自已被单步证据支持的 parent-path 生成条件，并且其搜索选择仍能在实际运行中形成较深的有效改进路径。V9.10 在分配侧引入的反馈闭环没有形成，反而增加了新的冷启动臂和延迟状态。

### 4.2 可识别性条件

首要问题是一个更基础的可识别性条件：一次动作能否在有限响应时间内得到明确的结果。如果动作长期 pending，任何后验形式都无法从它获得及时反馈。

## 5. 阶段判断与后续方向

在四任务 1000-eval 与统一外部基线协议下，V9.7 是同场表现最佳的 TraceAAD 版本；V9.10 在至少三个任务上退化，未形成稳定升级。

自适应分配并未在有限预算下自动带来改进。后续探索以 V9.7 的有效生成条件为基座，设计最小且可观测的预算分配机制。
