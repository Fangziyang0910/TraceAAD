# TraceAAD V1–V9.6 机制诊断与理论解构

本报告对 TraceAAD 早期演化（V1–V9.6）过程中的关键机制尝试、实验事实与退化机理进行系统诊断，并从**算法簇几何（Algorithm Cluster Geometry）**、**离散提议核（Discrete Transition Kernel）**与**计算分配理论（Compute Allocation Dynamics）**的统一视角重构理论认识。

---

## 1. 早期控制器与基线建立（V1–V4）：因果链断裂与代理指标失真

### 1.1 V1–V2：控制层过度叠加与因果混淆（Causal Obfuscation）
* **机制尝试**：V2 引入了岛模型、五类算子、六分量状态价值（直接质量、历史发展、新颖性、复杂度惩罚等）、算子 Bandit、三层记忆与 Pareto 生存淘汰。
* **事实与退化机理**：
  * 多层控制器同时介入生成提议 $P(x_{t+1}\mid x_t, h_t, o_t)$ 与计算分配 $\mu(a_t\mid \mathcal{H}_t)$，导致各组件对搜索质量的边际贡献无法解耦归因；
  * 在基础代码提议核尚未稳定时，过度复杂的元启发式调度只是在为低质量提议进行无效的重分配；V2 在四任务上的表现全面落后于大幅删减控制层后的 V3。
* **沉淀认识**：建立最短因果链；任何新增机制必须具备可独立识别的边际收益。

### 1.2 V3：回归极简轨迹表示
V3 剥除了岛模型、课程、Elo 评级、复杂度惩罚与 Pareto 生存，仅保留单父派生图、四类语义算子与确定性最优选择。虽然系统显著精简，但锚点价值评估仍受到多项启发式代理指标的干扰。

### 1.3 V4：四任务基线与程序复杂度（LOC）的实证实相
V4 首次将算法改进过程形式化为状态历史 $s_t = (x_t, p_t, h_t, b_t)$，确立了自然语言 Idea + 可执行代码生成的标准骨架。
* **程序膨胀现象**：在 CVRP 任务上，TraceAAD 生成程序的非空有效代码行数（LOC）达到 MCTS-AHD 的 1.6–4.4 倍，引发了“程序膨胀是否导致测试集过拟合”的质疑。
* **去中心化相关分析**：对 119 个独立运行进行严格的按方法去中心化（Within-method Centered）分析：

| 分析层次 | 样本数 $n$ | $r(\mathrm{LOC}, \mathrm{gap})$ | $p$ 值 |
| :--- | ---: | ---: | ---: |
| 方法间级别（全部 11 方法） | 11 | 0.48 | 0.14 |
| 方法间级别（预先选定的 5 个基线） | 5 | 0.98 | 0.004 |
| 运行级别（原始池化数据） | 119 | 0.20 | 0.03 |
| **运行级别（按方法去中心化）** | **119** | **0.05** | **0.60** |

* **理论结论**：原始相关性完全源自不同方法之间的基线性能差异，而非“代码行数越长越过拟合”。在同一算法范式内部，LOC 增长是机制逐步复杂化与特化的自然表征。**LOC 仅作为诊断量，严禁作为适应度惩罚项、在线信用或硬拒绝规则**。

## 2. 进化机制与状态保留（V5–V7）：离散代码接口与固定种群的局限

### 2.1 V5：结构化 Action 与全局反思的失败机理
* **结构化 Action 失败**：强制模型输出严格的 JSON/DSL 语法动作，极大压缩了大语言模型的自然代码生成概率空间，诱发大面积语法解析崩溃；
* **自由文本全局反思（Global Reflection）失效**：脱离具体代码上下文的自由文本反思缺乏离散反馈接地点，在 1000 次搜索预算中无一次产生合法且有效的程序改进。
* **结论**：彻底放弃结构化动作与宏观反思，确立“自然语言 Idea 阐述 + 完整可执行代码生成”的通用提示契约。

### 2.2 V6–V7：代码去重与固定种群生存淘汰的局限
* **机制演化**：V6 删除了成熟度、路线信用与人工差异门槛；V7 引入精确代码哈希去重（相同代码复用 fitness），有效解决了重复程序浪费预算的问题。
* **固定种群（Population-based Survival）的理论缺陷**：
  * 经典进化计算的固定种群机制强制在每轮迭代淘汰低分个体，将“即时适应度高低”与“未来可发展性（Development Potential）”强行绑定；
  * 程序进化是非单调的（Non-monotonic），常需经历短期退步（Regress）、重构与修复；固定种群过早淘汰退步个体，导致大量有潜力的非平庸路线被永久截断。

## 3. 完整树搜索与纯树基准（V8–V9）：状态全保留与分配拓扑困境

### 3.1 V8 / V8.2：完整单父树的建立
V8 彻底放弃固定种群，采用带虚拟根的**单父程序树**持久保存所有已评价的有效程序。所有状态永久可回访，祖先链天然记录唯一的生成历史。V8.2 将初始根收敛至 10 个，并将生成统一为单次 `Idea + Code`。

### 3.2 V8.3：最大值回传引发根锁定（Root Lock）的理论根源
V8.3 引入复合回报、宽度下限与深度上限，试图通过子树最大值回传 $G(n) = \max(y(n), \max_c G(c))$ 引导分配。
* **实验事实**：导致严重的“根锁定（Root Lock）”与兄弟节点爆炸，预算在前 10% 迅速被锁死在早期偶然出现高分的单一拓扑分支中。
* **深层理论根源**：
  1. **血缘拓扑（Provenance）与算法簇（Cluster）的错位**：树分支仅是代码生成的历史派生路径（生成事实），并非平稳的赌博机臂。同一分支后代可能迅速陷入局部饱和，也可能在单步变异后发生语义漂移；
  2. **历史功劳归因（Ancestral Attribution）与边际延续价值（Marginal Continuation Value）的混淆**：子树最大值 $G(n)$ 的向上传播，本质是在用“过去的最高历史荣誉”充当“当前重新回访该节点的边际产出期望 $\mathbb{E}[\Delta y\mid n, t]$”。祖先节点曾孕育高分仅证明其是成功路径上的可行跳板，不代表当前在其上继续扩展仍有高产出。

### 3.3 V9：简约纯树基线
V9 剥除深度限制与复合信用回传，基于全树中秩百分位（$Z$-rank）进行下潜（$S_{\text{down}}$）与原地扩展（$S_{\text{new}}$）的直接 UCB 竞争，确立了纯树搜索的强劲基线。

## 4. 锚点分配与决策粒度演化（V9.1–V9.4）：从局部内卷到原子决策闭环

### 4.1 V9.1：路线推进率的理论失效（19,191 次事件重建）
V9.1 试图以“路线自身历史最好质量被刷新”的频率（路线推进率）计算 Wilson 上界来分配信用。
* **19,191 次事件重建事实**：路线推进率达到 18.5%，但全局推进转化率仅 2.6%；**88.9% 的预算被错配给当时全树排名 10 以外的平庸锚点**；修正后又有 70.3% 预算过度集中在第 1 锚点。
* **理论失效机理**：路线推进率衡量的是相对于该路线起点的相对增量 $\Delta y_{\text{local}}$，而非相对于全局前沿的绝对产出。这导致分配器严重偏爱在极低起点附近频繁取得微小进步的平庸路线（**低水平内卷**）。

### 4.2 V9.2：经验生产力均值 $Q(a)$ 的缺陷
V9.2 将锚点确立为选择与信用单位，计算经验均值 $Q(a) = \frac{q(a) + \sum z_i}{1 + n(a)}$。该公式将当前算法固有质量与子代采样结果强行混合，对子代样本量极度敏感，未能提供稳定的前瞻分配信号。

### 4.3 V9.3：固定三步 Rollout 的理论缺陷
V9.3 将一次全局选择绑定为连续三步生成，试图用三步最佳结果结算信用。
* **理论缺陷**：**混淆了历史多步事实与未来预算承诺**。轨迹提供多步演化历史，并不意味着单次决策应提前承诺多步未来预算。固定步长绑定破坏了异步调度的即时纠错弹性。

### 4.4 V9.4：原子决策粒度的确立
V9.4 正式确立了标准**原子决策循环（Atomic Decision Cycle）**：
$$
\text{选择单一锚点 } a \longrightarrow \text{生成单次 Idea + Code} \longrightarrow \text{执行一次真实评价} \longrightarrow \text{立即更新状态并重新决策}.
$$
该原子循环彻底消除了多步绑定与树递归下潜的滞后性，成为后续所有版本的核心执行契约。

## 5. 上下文解构与非单调改进事实（V9.5–V9.6）

### 5.1 V9.5 质量-机会分配与非单调形成事实
* **分配形态诊断**：$S(a) = q(a) + s / \sqrt{n(a)+1}$ 在不同任务上干预率极度分化（TSP/CVRP 上达 85%–95%，OP 上仅 2%–14%，OBP 上为 0%），且干预强度与最终性能无单调关系。
* **非单调形成路径证据**：TSP/CVRP 最终最好程序的演化谱系中分别包含了 **43–51 步与 135 步短期退步（Regress）**。这从实证上证明了优秀算法常常是在非单调探索中形成的，确立了“必须保留可执行退步状态但不可给退步预设正信用”的原则。

### 5.2 V9.6 历史表示解构
V9.6 将历史上下文严格解耦为：
1. **父代形成过程（Formation Lineage）**：从根到当前锚点的父链改进事件；
2. **局部尝试事实（Direct Attempts）**：当前锚点已产生的子代分支记录。

## 6. 固定锚点受控生成识别实验（三轮，共 1,512 次生成）

为彻底厘清各历史成分对大模型单步生成的真实因果贡献，开展了三轮严格受控的固定锚点单步生成识别实验（无缺失、无重复、无格式错误）。

### 6.1 实验设计
* **第三轮主实验**：固定任务、代码、输出契约和采样温度，覆盖 4 个任务、72 个代表性锚点、3 个上下文比较臂，每臂独立重复 3 次，共 648 次严格受控生成。
* **比较臂设计**：
  1. `code_only`：仅提供当前算法完整代码与适应度；
  2. `+来时路`（Parent Path）：当前代码 + 父链上至多 8 条改进事件（Idea、结果分类、适应度变化量）；
  3. `+来时路+子代尝试`：在臂 2 基础上，追加当前锚点已尝试过的所有直接子分支历史。

### 6.2 实验结果与统计事实

| 比较维度 | 现象与统计事实 |
| :--- | :--- |
| **父代来时路主效应（臂 2 vs 臂 1）** | 四个任务的配对条件增量 $\Delta q$ 置信区间**全部严格脱离 0 且为正**；72 个锚点中 **58 个方向更好、14 个更差**。 |
| **子代试错增量（臂 3 vs 臂 2）** | 追加局部试错历史后，四个任务的置信区间**全部跨 0**（**35 好 / 34 差 / 3 平**）；在 TSP 和 CVRP 上点估计甚至偏负。 |
| **修改幅度收缩（Surgical Edits）** | 父代来时路使中位修改比例大幅收缩，最差十分位极端改写率显著下降（TSP 16% $\to$ 6%，CVRP 23% $\to$ 4%，OP 16% $\to$ 8%）；该收缩与生成质量提升严格同向发生。 |

### 6.3 深层理论机理与标准生成契约

基于上述严密证据，得出以下理论结论：

1. **父代来时路的正向流形对齐（Causal Manifold Alignment）**：
   父代改进来时路向模型揭示了当前算法核心机制与不变量（Invariants）的因果演化轨迹，使自回归模型的提议先验集中在有效改进的流形邻域内，抑制了盲目重写。
2. **离散程序空间的 Attention Bias 与负反馈失效**：
   离散代码空间缺乏连续梯度的反向指示作用。局部失败代码包含具体的语法、变量绑定与缺陷控制流；将这些失败尝试塞入上下文，反而在自回归模型中引入了强烈的**局部注意力偏置（Attention Bias）**，诱导模型在错误实现的细微变体上做无意义打转。
3. **标准生成提示结构收敛**：
   固定锚点实验确立了后续所有版本的标准 Prompt 规范：
   ```text
   Task Specification
   
   Current Algorithm (Code & Fitness)
   
   Recent Parent-Path Improvements (Up to 8 events)
     Idea: ...
     Result: outcome (Fitness: parent -> child)
   
   Instruction (Refine or Explore)
   ```
   **核心契约**：父代改进来时路是得到受控实验直接支持的唯一标准历史成分；子代试错仅作为树中记录的事实，永久移出默认生成提示词。
