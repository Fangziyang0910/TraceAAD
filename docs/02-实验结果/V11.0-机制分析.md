# V11.0 机制分析

本页解释 V11.0 历史批次；文中的“下一轮”是该批次结束时提出的对照建议，不是现行机制定义。当前问题见[研究主线与问题](../04-研究认识与构想/研究主线与问题.md)。

V11.0 的突出特征是父代高度集中、参考材料广泛分散。它在 CVRP 上获得收益，在其他任务上没有形成一致改善。这个结果把研究问题推进到机会分配与上下文的匹配：持续开发哪些程序，以及为这些程序提供什么材料。

## 两项联合变化

父代由质量 softmax 抽样改为对唯一 AST code 计算质量百分位和探索加分，每次取最高分：

`S(x)=q(x)+0.1*sqrt(log(1+T)/(1+n(x)))`。

Pivot/Fuse 同时改为共享最多 8 个 Idea+fitness 参考，按倒数排名无放回抽样。Refine/Tune 保留短形成轨迹，四算子仍各 25%。机制细节见[V11.0 定义](../01-主线版本/TraceAAD-V11.0-机制设计.md)。

## 实际开发高度集中

约 99.7%–100% 的正常开发选择落在 `q≥0.95` 的代码，`q<0.75` 几乎没有机会。best 深度约 50–72，V10.11 约为 9–34；Pivot 的父代改进率由约 9%–16% 降至约 1.5%–3.2%。

探索加分主要在头部相近候选之间改变排序。新 AST 持续出现，使直接开发次数很难形成共享统计；四算子又共用最高分父代，替代方向得到的独立机会很少。下一步可以固定上下文，比较质量抽样、高分集中和明确的最低探索配额。

## 参考很宽，计算信息较少

约 40%–43% 的参考来自排名前 32 之外，V10.11 的 rank-softmax 参考约为 2%。Idea+fitness 能提示一种思路及其整体成绩，具体计算、形成顺序和适用父代却较少出现。

CVRP 的高质量算法族包含距离、节约、极角、容量和车场信号，适合跨分支组合；TSP/VRPTW 中多个规则需要持续协调；OBP 的关键在于实际排序变化；OP 则需要考虑规模。这样的任务差异提示，应让参考代码或局部计算承担更多作用。

## 结果与解释

正式训练和 held-out 数据统一保留在[V11.0 结果](各版本实验记录/V11.0-实验结果.md)。该结果表现为 CVRP 改善，TSP、OP、VRPTW 回落，OBP 接近不变；重复数、缺失项和统计范围以该结果页为准。

两项机制联合变化，使本轮结果更适合提出匹配假设：高质量父代的深度开发与互补机制传播在 CVRP 中可能相互支持，其他任务需要不同材料和更多替代路线机会。它们各自的增量留给下一轮分开比较。

## 下一轮选择

先固定提示、四算子、解析和修复，比较父代分配，观察前沿曲线、路线开发与重复间方差。再固定分配，比较 rank-softmax 精英参考、top-16 加少量不同机制参考，以及 Idea 加具体代码。随后才讨论按任务或状态动态选材料。

程序层面追踪参考计算是否进入候选、改变了哪些决策，以及候选是否超过父代并继续发展。相关任务分析见[任务收益与上下文设计](../04-研究认识与构想/任务收益与上下文设计.md)，对照基础见[V10.11 分析](2026-09-17-V10.11-三组对照分析.md)。原始轨迹位于 `experiments/traceaad_v11_0/results/`。
