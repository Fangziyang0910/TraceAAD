# 实验配置

## 搜索与统计

| 项目 | 配置 |
| --- | --- |
| 任务 | TSP Construct、CVRP-ACO、OP-ACO、Online Bin Packing、VRPTW Construct |
| 生成模型 | 早期及基线使用 Qwen3.6-27B；V10 及后续使用 Qwen3.8-27B |
| 搜索预算 | 每路 1000 个预算单位；早期配置按评价次数计，完整代码生成配置按候选尝试计（包含失败和重复）；具体口径见各实验入口 |
| 重复运行 | 独立运行；各配置的路数见逐路结果表 |
| 训练结果 | 每路搜索所得最优程序在训练集上的目标值 |
| 测试结果 | 各路选定程序在未参与搜索的测试实例上的目标值；使用独立选择集的配置先在选择集选优，再测试 |
| 平均结果 | 对有有效结果的路次取算术平均 |

## 任务与数据

| 任务 | 训练集 | 测试集 | 目标 |
| --- | --- | --- | --- |
| TSP Construct | TSP50，16 个实例 | TSP50/100/200，各 16 个实例 | 路径长度，越低越好 |
| CVRP-ACO | CVRP50，10 个实例 | CVRP50/100/200，各 64 个实例 | 路径长度，越低越好 |
| OP-ACO | OP50，5 个实例 | OP50/100/200，各 64 个实例 | 负收集奖励，越低越好 |
| Online Bin Packing | 1k/5k × 容量 100/500，各 1 个实例 | 1k/5k/10k × 容量 100/500，各 5 个实例 | 使用箱数，越低越好 |
| VRPTW Construct | VRPTW50，16 个实例 | VRPTW50/100/200，各 16 个实例 | 总距离，越低越好 |

TSP、VRPTW 和装箱的训练实例使用 seed 2024，测试实例使用 seed 2025。CVRP、OP 的训练实例使用 seed 1234；ACO 分别采用 30 蚁 × 100 迭代、20 蚁 × 50 迭代。
