# 主实验配置说明

本文对应下列 V9 系列历史比较；新正式实验设置见实验导航。

## 比较口径

- 预算：1000 次成功计入搜索的候选评估。
- 模型：Qwen3.6-27B；`temperature=1.0`，`max_tokens=16384`，单次请求 timeout 600 秒，关闭 thinking。
- 重复：每种方法 3 次独立运行。
- 训练集上优化；测试集为未参与搜索的不同规模新实例。搜索 best 与测试结果分开报告。

主表方法：五个对比方法（EoH、ReEvo、MCTS-AHD、PathWise、CALM），加上 TraceAAD V9、V9.16、V9.17。其余版本见TraceAAD 历史版本结果。

## 对照方法

| 方法 | 角色 | 搜索配置 |
|------|------|----------|
| EoH | 种群演化 | 20 代；E1/E2 各 5 个父代；OBP 种群 20，其余 10；算子 `e1/e2/m1/m2`；初始化 `2 × population` |
| ReEvo | 反思与反馈 | `max_sample_nums=1000`，`pop_size=10`，`init_pop_size=30`，`mutation_rate=0.5`，初始化温度 `+0.3` |
| MCTS-AHD | 树搜索对照 | 4 个 evaluator |
| PathWise | 路径式搜索 | 4 个 evaluator |
| CALM (w/o GRPO) | 固定权重的搜索框架 | 主表不包含带 GRPO 微调的完整 CALM |

所有方法在同一 LLM、1000 eval、数据划分和评价器下重新运行。

## 任务

| Task | 问题族 | 嵌入 |
|------|--------|------|
| `tsp_construct` | 路由 | 构造 |
| `cvrp_aco` | 路由 | ACO |
| `op_aco` | 路由 | ACO |
| `online_bin_packing` | 装箱 | 构造评分 |
| `vrptw_construct` | 路由 | 构造 |

### `tsp_construct`

平均 tour length，越低越好；搜索 score 为其相反数。评估 timeout 20 秒。

- 训练：TSP50，16 个实例，`seed=2024`。
- 测试：TSP100、TSP200 各 16 个实例，`seed=2025`；另列独立采样的 TSP50（16 个，`seed=2025`）。

### `cvrp_aco`

平均最优路径长度，越低越好；搜索 score 为其相反数。评估 timeout 120 秒。ACO：30 ants，100 iterations，`aco_seed=1234`。

- 训练：CVRP50，10 个实例，车辆容量 50，`seed=1234`。
- 测试：`test_100`、`test_200` 各 64 个实例，`seed=1234`；另列独立采样的 `test_50`（64 个，`seed=1234`）。

### `op_aco`

平均 collected prize，越高越好。评估 timeout 60 秒。ACO：20 ants，50 iterations，`aco_seed=1234`。路程预算 OP50/100/200 的 `maxlen=3/4/5`。Prize 相对 depot 距离离散化后归一化；depot 为实例第 0 点。

- 训练：OP50，5 个实例，`seed=1234`。
- 测试：OP100、OP200 各 64 个实例，`seed=4567`；另列独立采样的 OP50（64 个，`seed=4567`）。

### `online_bin_packing`

平均使用箱数，越低越好。评估 timeout 30 秒。物品尺寸 Weibull(3,45)，裁剪上限 100。同一 item 规模下 `capacity=100/500` 共享 item 序列。测试序列与训练不同且固定。

采用多容量搜索协议：训练纳入 `1k/5k × C=100/500`，10k 为未见规模。

- 训练：4 个固定实例，`1k/5k × capacity=100/500` 各 1 个，`seed=2024`。
- 测试：`n_items=10000`，`capacity=100/500`，每个组合 5 个实例，`seed=2025`；另列 `n_items=1000/5000` 的对应组合。

### `vrptw_construct`

平均总距离，越低越好；搜索 score 为 objective 的相反数。演化组件 `select_next_node`；启发式中途返回 None 且未完成构造判为无效解。搜索 timeout 30 秒；测试每个「最终程序 × 测试规模」最多 120 秒。

- 训练：16 个生成实例 × 50 节点，`seed=2024`。
- 测试：100 与 200 节点各 16 个生成实例，`seed=2025`；另列 16 个 × 50 节点（`seed=2025`）。
