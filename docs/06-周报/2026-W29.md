# TraceAAD 周报｜2026-W29（7月13日—7月19日）

## 本周概况

这周重点是把 TraceAAD 从 TSP、CVRP 扩展为多任务实验，并弄清搜索中哪些机制值得保留。我开始把“算法如何形成”“从哪里继续改进”和“何时参考其他算法”作为后续研究的三个具体问题。

## 主要进展

我完成了 V2 在 TSP、CVRP、OP 和在线装箱上的搜索与测试，也补做了装箱和背包构造等任务的重复实验。各任务的测试入口已统一，生成模型的调用接口也收敛为同一协议。方法上重审了算子选择，并开始观察程序复杂度与运行成本，删除了职责不清的机制。

## 目前的发现与下一步

多任务结果让“一个任务上能运行”与“机制确实有效”之间的差别更清楚。现在还没有足够证据把某个算子或历史信息固定为默认方案。下一步会用更明确的轨迹表示和对照实验，检查生成内容与搜索选择分别起了什么作用。
