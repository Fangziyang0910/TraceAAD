# TraceAAD 周报｜2026-W28（7月6日—7月12日）

## 本周概况

这周我把 TraceAAD 的第一个版本跑了起来。研究刚开始，首要任务是确认模型生成程序、执行评价和保存改进过程能连成一个真实可运行的实验，而不只是停留在方法设想。

## 主要进展

我完成了首轮真实 LLM 实验，并在 TSP Construct 上对照了三种方法。为了让后续比较有意义，我重新核对了 MCTS-AHD 的原始机制、TSP 的预算计算方式和 PathWise 的实验入口，也检查了 TraceAAD 保存的轨迹与评价记录。周末又接入 CVRP-ACO，开始把流程从单一任务扩展到不同的算法设计对象。

## 目前的发现与下一步

目前可以确认的是实验链路已经跑通，TSP 的比较口径也得到校准；这些还不足以判断轨迹是否带来了稳定收益。下周我会继续扩充任务和重复实验，再看方法在不同任务上是否呈现一致的行为。
