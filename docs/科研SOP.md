# TraceAAD 科研方法论与 SOP

本指南将**经典计算机科学科研思维**与 EvoTrace V1–V5.2 的真实教训融合为一套可执行的研究循环：**先想清本质，再用极简设计承载核心假说，用最低成本的关键实验做强推理证伪。**

---

## 一、五步科研循环

### 1. 立问与守魂（Heilmeier 之问 × 核心守卫线）

动笔改版或立新实验前，先用 3 句话写清：
1. **真问题**：当前要解决哪一个已被日志或理论证实的瓶颈？（而非“直觉觉得可以更优雅”）
2. **核心守卫线**：本工作的核心假说（论文灵魂，本轮不动摇）是什么？本次只准备拧动哪 **1 个** 外围杠杆，以及它如何独立消融验证？
3. **成功与证伪判据**：如果这个解释成立，哪个具体过程指标必须变好；**看到什么结果就承认该假设被推翻**？

> **防目标漂移原则**：若连续修补已经把核心假说拆散成零碎补丁，立即停手，退回最近一个**健康且完整承载核心假说**的底座重新做单变量推导。

---

### 2. 极简推导（第一性原理 × 奥卡姆剃刀）

设计算法、树规则或提示词时：
- **从底层约束出发**：显式考虑 3 个硬物理约束——① 评价器只给极稀疏的标量目标值；② 本地小模型（如 27B）的注意力与上下文消化上限；③ [实验协议](../experiments/PROTOCOL.md) 的公平边界（零任务先验、零规模/预算泄露、零暗含算法范式提示词）。
- **奥卡姆剃刀剪枝**：每个模块、超参、提示区块都必须对应一个明确失败模式；无法说明“删掉它会坏在哪”的组件直接删去。
- **保真减噪**：展示给模型的源码仅去注释与文档字符串、保留原写法（避免 `ast.unparse` 类格式重排引入跨模型语法陷阱）；优先给紧凑代码 diff 而非冗长全量复述。

---

### 3. 强推理与低成本证伪（Platt Strong Inference × 波普尔证伪）

把实验当作**排除错误解释的精密仪器**，而不是昂贵的盲目调参器。面对任何新想法或争议，先列出 2–3 个互斥假说，再按成本从低到高选择能“一锤定音”的关键实验：

| 想回答的科研问题 | 最低成本关键实验 | 过关标准 |
| --- | --- | --- |
| 选择权重、树简化、去重、代码格式是否健康？ | **离线快照重放**（零 LLM 成本，本地 5 分钟） | 核验冠军抽中率、各排名区间预算分布、树规模上界/幂等性、AST 等价性与跨模型语法安全 |
| 提示词、反思格式、上下文组织是否有净因果收益？ | **同父代配对微对照**（15–30 个干净真实父代 × 3 次重复，约 1 小时，参考 [V5.1 同父代对照](记录/2026-11-21-V5.1三组同父代对照实验结果.md)） | 控制混杂块并按代码修改幅度分层后，仍呈现统计与定性双胜 |
| 整体方法在长程搜索上能否赢过基线？ | **12 路冻结正式长跑**（4 任务 × 3 种子 × 1000 评） | 冻结配置跑至预定检查点或终点；不因早期 50–150 评分数波动拍脑袋停跑重开 |
| 核心机制是否真的起了作用、且不依赖特定大模型？ | **健康底座同口径自消融 + 跨模型抽验** | **凡赢过基线的健康版本，首要补跑其自身同口径自消融**（如关闭经验展示），并在本地小模型（27B）与更强模型（如 DeepSeek）上核验正增益 |

---

### 4. 机制解剖（超越均值榜单的因果归因）

均值榜单只能告诉你“输了还是赢了”，不能告诉你“为什么”。在正式运行的早期检查点（约 100–150 评，专查沉默故障）与满预算收尾时，用真实轨迹回答 5 个机制问题（参考 [V5.1 全量体检](记录/2026-11-21-V5.1全量深度体检与机制剖析.md) 与 [机制作用的证据](记录/2026-11-19-机制作用的证据.md)）：

1. **预算流向**：冠军有没有被饿死？各排名档位的破纪录投入产出比（ROI）是否单调合理？
2. **结构多样性**：树规模是否有界？同分行为克隆占了多少槽？新探索方向能否活过第一次繁殖？
3. **信息利用率**：反思输入有多少是有效对比（而非彻底写崩的垃圾）？写出的经验**实际被读率**是多少？有无基准串台（亲生父代 vs 存活祖先）或硬字数下限逼出的废话？
4. **因果归因**：把真实破纪录样本拆解到具体生效区块，严格区分反思经验、近期退步对比块与源码本身的贡献。
5. **同口径与代价**：核对模型、量化/端点（AWQ / FP8 / GGUF）、单评 prompt/completion token、反思频次、墙钟耗时与失败率。

任何经数学构造或真实数据证伪的边界，立即记入 [实验与边界台账](记录/README.md)。

---

### 5. 分层排障与金字塔汇报

- **三层排障顺序**：遇到掉点或消融打平，先依次排除 **① 工程与格式暗伤**（语法陷阱、修复行号错位、端点/量化漂移）→ **② 外围机制失配**（上下文过肥噎死小模型、选择权重平顶饱和、触发漏斗倒挂、高比例零阅读）→ 最后才在**健康底座**上裁决 **③ 核心假说本身的局限**。
- **金字塔输出**：先给一句最可信的核心判断，再用 2–3 条相互独立的逻辑支柱支撑，底层附可复现的数据、节点编号或代码依据；易混淆时显式标明**事实 / 推断 / 假说**。

## 二、附录：V1–V5.2 真实得失速查（为什么坚持上述原则）

| 踩过的真实坑 | 后果 | 对应的思维防线 |
| --- | --- | --- |
| 只给改坏的 V4/V5 跑无反思消融，从未给打赢全场的 V1/V3 跑消融 | 误判“27B 扛不住完整轨迹反思”，一路把路径/根部/交叉经验砍光 | 强推理（健康底座优先自消融）+ 分层排障 |
| V3→V4、V4→V5 一次同时大改上下文、反思、拓扑与选择器 | 掉点后无法定位主因，V4 两天连开 14 批短跑猜谜 | 单变量推进 + 先微对照再长跑 |
| 沿用 $\lambda=10$ 中位数 Sigmoid 与“最差叶触发反思”而未先验分布 | 69.5% 步数饿死冠军、ROI 倒挂 16.6 倍、60% 喂垃圾、74% 笔记 0 读 | 离线快照重放 + 机制解剖 |
| 塞入长篇 `analysis` 与 5 份完整源码、禁写参数值逼写抽象空话 | 上下文胖 2.3 倍噎死 27B，DeepSeek 凭大胃口硬扛，掩盖真实根因 | 第一性原理（小模型注意力约束）+ 跨模型抽验 |
| `ast.unparse` 重排产生双括号 `min((...))` | 27B 无事，DeepSeek Eco 在 TSP 上 15% 评价直接语法报错 | 保真减噪（留原文）+ 跨模型验证 |
| V1/V2 含 Explore 范式暗示词且 90% 走 AWQ，与纯 FP8 版本混比 | 高分带公平与口径争议，不能直接下干净结论 | 认识论诚实（同口径 + 公平边界） |
| 不断在残血版上打补丁做减法 | V5.1→V5.2 逐步偏离“淘汰即积累轨迹经验”的统一初心 | 核心守卫线 + 防漂移回退 |
