# 论文库索引

本汇总覆盖 `papers/` 目录归档的 **130 个论文条目**，按研究主题分类提供检索索引。

标注口径：日期为 arXiv 首次发布（无 arXiv 版时标注来源）；"发表于"仅标注确认的正式发表（会议/期刊），源码模板不等于已录用，不写入正式发表。
### 1. 统计集合范围与分工说明
本仓库内不同文献统计集合对应不同的研究层级与覆盖范围，各自独立演进，不作强制数字对齐：
- **130 篇论文归档（`papers/` 目录与本表）**：本地收集的文献档案总库（包含 PDF / LaTeX 源码工程），覆盖综述、进化搜索、规划、轨迹记忆、模型微调与能力分析。
- **71 篇精读笔记（`docs/05-文献与基线/单篇阅读/`）**：聚焦于 AAD 核心主线（代码变异、进化算子、轨迹反馈、不确定性）经过第一性原理核查与机制拆解的深度笔记，负责事实核验、消融审计与理论归因。
- **10 种训练方法族（`docs/05-文献与基线/专题调研/自动算法设计与模型训练方法.md`）**：严格限定为“涉及显式模型参数学习（生成模型、动作策略、表示或 surrogate 优化）”的研究谱系，排除纯上下文提示演化与内层被设计算法的独立训练。

表中摘要压缩论文自述的问题、方法和主要结果，不表示本仓库已独立验证其主张。机制证据强度、消融充分性和可迁移边界以逐篇阅读笔记为准。
### 2. 字段标注口径与出版状态边界
- **日期**：以 arXiv 首次发布或正式出版日期为准（无公开版本时标注源码归档时间）。
- **发表于**：严格区分“正式同行评审录用”与“预印本 / 投稿记录 / 样式模板源码”：
  - **正式发表（会议/期刊）**：仅用于确认在正刊或官方会议 Proceedings 见刊的论文（如 Nature 625、ICML 2024、NeurIPS 2024/2025、ICLR 2024/2026、NAACL 2025 等）。
  - **Workshop 录用**：标明具体 Workshop（如 GECCO 2026 Workshop、ICML 2026 Workshop），不混同为主会正刊。
  - **投稿记录 / 源码**：OpenReview 匿名投稿记录、源码归档中包含会议 LaTeX 样式文件（例如 `neurips_2025.sty [preprint]`、`iclr2026_conference.sty`），**绝不能作为正式录用凭证**，统一标为“投稿记录 / 投稿源码”或“arXiv 预印本”（典型纠错：CALM 曾因源码包内含 NeurIPS 2025 preprint 样式被误标，实为 ICLR 2026 录用）。
  - **预印本**：统一标为“arXiv 预印本”。
- **摘要性质**：表中摘要均为**论文作者自述观点与主要声称结果的紧凑压缩**，供快速检索与了解研究脉络；**不承担对机制有效性、因果归因与实验充分性的独立背书**。机制证据强度、消融对照完备性与跨模型可迁移边界以逐篇阅读笔记及各专题调研为准。
