# What Makes an LLM a Good Optimizer（轨迹分析）

- 论文：*What Makes an LLM a Good Optimizer? A Trajectory Analysis*；本地来源：LaTeX 源码目录 `What_Makes_an_LLM_a_Good_Optimizer_Trajectory_Analysis/`；研究对象：15 个 LLM × 8 任务的进化轨迹，什么变量预测优化成功。

## 1. 核心问题与方法

在完全相同的进化循环（AlphaEvolve 式轻量：精英切片 q=0.2、fitness 加权父代采样、去重、池截断）、选择规则与评价函数下，比较 15 个 LLM（OpenAI/Gemini/Gemma/Llama×4/DeepSeek-V3/Mistral×4）× 8 任务（TSP-30/60、SAMSum/ASSET 提示优化、Oscillator-1/2 方程发现、OBP OR3/Weibull 启发式设计）；30 代 × 每代 10 子代 × 2 次重复，共 72,000+ 次调用，温度 0.7。分析量：零样本 best-of-N、突破率（超越 best-so-far 事件频率）、新颖性（语义移动）、语义空间熵（$H_{spatial}$ 候选分布广度、$H_{fitness}$ 高分解集中度）、局部精炼率 LRR（子代严格优于其提示父代的频率）、父代-子代语义距离 PCD；统计用固定任务效应 + 模型聚类的 OLS、世代级混合效应模型（约 3,209 观测）与干预实验（模型混合）。

## 2. 论文宣称的机制贡献（逐项）

- 零样本能力只解释部分方差：仅零样本 $R^2\approx0.103$；突破率单独 $R^2\approx0.198$（约两倍）；合并 0.246，且加入突破率后零样本系数下降——零样本的预测力部分经由"能否持续产生改进"中介。
- 新颖性不预测性能：平均与初始新颖性系数接近 0 且不显著；新颖性×局部化交互项在同期与滞后设定都显著为负（−0.090***/−0.051***，$\Delta AIC=51$）——**新颖性只在搜索足够局部化时才转化为突破**。
- 大步修改的危害由精炼可靠性中介：PCD 单独 −0.329**，加入 LRR 后变为 −0.024 不显著；LRR 系数 +0.528***；$R^2$ 从 0.204 升至 0.367。

## 3. 实验究竟支持了什么

|主张|论文证据|证据等级|判断|
|---|---|---|---|
|LRR（可重复局部精炼率）是最强预测子|算子级回归 + 模型混合干预实验|直接支持|注入弱精炼模型的子代使 TSP-60 与 bin packing 性能随比例单调劣化且精炼率同步下降（因果证据）；提示优化任务上效应较弱。|
|新颖性是条件性资产|新颖性主效应不显著；交互项结构性显著（滞后设定中主效应消失而交互保留）|直接支持|无条件多样性最大化被否定；"新颖性→突破"以搜索已局部化为前提。|
|强优化器渐进局部化|$H_{spatial}$ 随代数单调下降（如 Gemini-1.5-Pro）；弱优化器持续漂移、高熵波动|部分支持|局部化与突破存在部分机械耦合（选择压力本身造成局部化），作者以滞后 + 交互项缓解但未完全排除。|
|成功轨迹=频繁小步改进|突破率解释方差约零样本两倍；成功模式为高频小突破而非"罕见大突破+长平台"|直接支持|与经典元启发式叙事相反的关键经验事实。|

## 4. 机制的底层逻辑（阅读分析，不是作者已证明结论）

LLM 算子因生成先验天然偏利用（定向变异），瓶颈通常在"可靠的小步改进能力"而非探索不足；漂移大常是失败信号。这组证据的含义：把 LRR 类指标（严格父代改进率）作为在线观测量来分配预算，比把新颖性作为目标更符合证据；跨模型混合子代等价于调节精炼率。优化能力是（模型+prompt+解码）系统的性质：温度改变绝对水平但"精炼率-性能"关系稳定。

## 5. 对 LLM4AD / TraceAAD 可学习之处

- 可学习点：把 LRR、突破率、语义熵（局部化程度）纳入运行诊断面板。前提：父子边与语义距离可在线计算。风险：局部化的机械耦合。最小验证：按 LRR 分桶报告后续突破率，检验其前瞻性。
- 可学习点：探索的引入时机应读取局部化状态（熵），而非固定日程。最小验证：熵触发的探索注入 vs 固定间隔注入同预算对照。
