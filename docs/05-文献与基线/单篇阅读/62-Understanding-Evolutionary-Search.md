# Understanding the Importance of Evolutionary Search

- 论文：*Understanding the Importance of Evolutionary Search in Automated Heuristic Design with LLMs*；本地来源：`main.tex`；研究对象：LLM-EPS 方法相对零样本采样与极简基线的真实贡献，批判性重评估而非新方法。

## 1. 核心问题与方法

统一基准回答两问：LLM 固有能力（不加搜索机制）是否足以完成 AHD；现有 LLM-EPS（FunSearch、EoH、ReEvo）相对极简基线取得多少真实进展。设置：4 个 EPS 方法（含自建 (1+1)-EPS）× 4 个 AHD 问题（Admissible Set A(15,10)、OBP-OR、OBP-Weibull、TSP100）× 最多 9 个 LLM × 5 次重复，统一 10,000 次评价预算（EoH/ReEvo 种群 100，FunSearch 10 岛 × 每 prompt 4 样本）。基线 (1+1)-EPS：只把"当前最优启发式"做 one-shot 提示生成一个变体，更优则替换，零超参、零 prompt 工程；RandSample 为独立反复采样不查重。

## 2. 论文宣称的机制贡献（逐项）

- 搜索循环（保留—变异—选择）是必要组件：最小 (1+1) 循环用 500 次查询即可在多数 LLM×任务组合上超过独立采样 10,000 次的结果；EPS 方法约 2,000 次预算接近或超过独立采样 10,000 次。
- 约束 2,000 次评价后 EPS 增益明显放缓（TSP 上尤甚）。
- 没有单一方法跨任务一致占优（正式版结论；早期稿"无方法统计显著超过 (1+1)-EPS"在正式版被弱化）。

## 3. 实验究竟支持了什么

|主张|论文证据|证据等级|判断|
|---|---|---|---|
|独立采样不足以完成 AHD|RandSample 给到 100,000 查询仍与最优已知有显著差距；最好个体几乎不随预算改善|直接支持|纯探索无累积与筛除，一个数量级的预算折算不成性能。|
|模型容量与 AHD 表现不挂钩|独立采样 top-1 差距：DeepSeek-6.7B 4.24%、StarCoder 4.21%、GPT-3.5 4.31%、GPT-4 4.44%、Claude 3 Opus 4.63%，无单调关系；UniXcoder 9.15% 显著最差|直接支持|HumanEval/MMLU/参数量不作预测子；代码特化不显著优于通用模型。|
|无方法跨任务一致占优|约 800 次运行的方法级对比；EoH 在 TSP 全程领先；(1+1) 除 OBP-Weibull 外有竞争力|部分支持|大量非传递性格子（TSP×GPT-3.5 上 RandSample 0.33×10⁻² 级好于 (1+1) 3.97 与 FunSearch 4.16，EoH 达 0.33）；方法级对比无法归因单个组件。|
|搜索增益是任务属性|OBP-OR 上各方法与 RandSample 差距很小（EPS 几乎无优势）|直接支持|好解密度与簇稀有度决定搜索必要性——探索-利用收益的任务边界证据。|

唯一的组件消融是 EoH 设置（模板初始化+种群 100 vs 默认采样初始化+种群 20）：Admissible Set 差异明显（默认更好 6.85 vs 7.89），OBP 与 TSP 差异可忽略。**没有精英 prompt、岛屿、重采样的逐项组件消融**。

## 4. 机制的底层逻辑（阅读分析，不是作者已证明结论）

搜索的必要性来自累积与筛除（保留—变异—选择的最小闭环），而非复杂种群结构；纯采样（纯探索）与贪心单链（纯利用）之间，后者的性价比高一个数量级。复杂组件（岛屿、CoT 多算子、反思）在统一设置下没有被证明有跨任务可归因的增益——存疑而非证伪。评价预算口径上，本仓库 1,000 次评价正处于该文测得的增益最大区间（<2,000），分配机制的价值在有限预算下更大。

## 5. 对 LLM4AD / TraceAAD 可学习之处

- 可学习点：新增控制器必须与 (1+1) 型强简单基线同预算对照。前提：基线实现公平。风险：复杂框架赢了弱基线被误读为机制有效。最小验证：每任务报告 (1+1)、随机父代、完整方法三线。
- 可学习点：把"任务×模型"格间的增益不均匀作为研究对象而非噪声。最小验证：报告每格的 EPS−RandSample 差值分布，与好解密度指标关联。
