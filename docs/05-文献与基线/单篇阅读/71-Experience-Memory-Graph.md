# Experience Memory Graph

- 论文：*Experience Memory Graph: One-Shot Error Correction for Agents*；本地来源：LaTeX 源码目录 `Experience_Memory_Graph_One-Shot_Error_Correction_for_Agents/`；研究对象：把 agent 失败恢复从在线反思-重放循环改为离线确定性图计算的记忆结构。

## 1. 核心问题与方法

训练侧把每条探索轨迹与专家轨迹（ETO 数据集提供）转为有向**动作决策图** $G=(V,E,q,r)$：节点 = 归一化动作元组（type, object, receptacle），边 = 归一化观测文本（动作前置条件）；同动作节点复用（多入边捕捉"同一动作在不同观测下出现"）、无效动作并行挂接在同一有效决策点，虚拟 INIT 节点携带初始观测；内容相同则标签相同，图匹配退化为标签相等比较。记忆图：节点 $\nu_i=(q_i, embed_i, I_i^{intra}, G_i, G_i^\*, r_i)$，边 $\epsilon_{ij}=(s_{ij}, I_{ij}^{cross})$，$s_{ij}=\cos(embed_i,embed_j)$，$s_{ij}\ge\tau$ 且 top-$k$ 近邻才连。**一次纠错**：Fused Gromov-Wasserstein 无监督图匹配（软匹配后线性指派离散化）——匹配的相同部分 = 公共子图（正确工作流），差异部分 = 最短图编辑路径（在哪个观测下应删除/添加/替换哪个动作），这是确定性的纠错计划；LLM 只负责把结构总结为自然语言洞见。相似任务专家图之间图匹配取公共子图得跨任务边洞见。测试时按 top-$K$ 节点 + 其 top-$T$ 邻边检索洞见进 prompt，单次执行无循环。

## 2. 论文宣称的机制贡献（逐项）

- 失败与参考的确定性结构 diff（公共子图 + 编辑路径）替代自由文本反思。
- 图记忆使一次纠错长期生效、跨任务迁移（边洞见）。
- 测试时无反思循环，推理时间显著低于迭代式基线。

## 4. 机制的底层逻辑与向 AAD 迁移的本质缺口

EMG 把“这次怎么改”从概率生成问题（LLM 自由文本反思）转化为确定性结构对齐问题（图编辑路径）：图 diff 的每一步均绑定到具体的前置观测条件，从而实现单步纠错生效与跨任务模式迁移。

**不能将 EMG 直接当作 TraceAAD 的理论证明或实现模板（二者在状态、动作与前提假设上存在根本鸿沟，严禁使用“同构”略过）**：
1. **专家参照 vs 缺乏保证的 Best-so-far**：EMG 能够通过图匹配提取“确定性纠错路径”，核心前提是存在**具备全局正确性保证的专家轨迹（ETO 数据集）**；而在自动算法设计中，**完全没有外部专家参照轨迹**。TraceAAD 的 best-so-far 只是一次启发式搜索中偶然采出的当前最高分代码，**绝不具备同等正确性保证**；
2. **消灭替代探索方向的致命风险**：best-so-far 自身极可能带有未被发现的算法缺陷或低效局部结构。若像 EMG 一样将所有探索轨迹强制向 best-so-far 靠拢并施加结构纠偏，**极有可能扼杀具有突破潜力的异质替代路线，导致种群过早收缩陷入局部极值**；
3. **具身动作词典 vs 自由代码语义**：具身环境动作由封闭规范的离散三元组构成，图节点相等性易于判定；而算法代码的语法与控制流高度灵活，无法做机械的离散图匹配。

## 5. 对 LLM4AD / TraceAAD 可学习之处

- **结构化表示的启发**：在向 LLM 提示历史修改或失败原因时，以**结构化的代码 diff / 具体算子变异意图**呈现，通常优于自由发散的文本反思；但这属于表示层面的工程借鉴，绝非理论证明。
- **保护替代路线的多样性**：明确“向最好个体学习”与“保留异质新方向”的矛盾；TraceAAD 中不能把 best-so-far 奉为专家标准答案，必须通过独立的 Pivot 或创新算子分支维持搜索开拓面。
