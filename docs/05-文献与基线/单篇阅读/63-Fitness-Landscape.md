# Fitness Landscape of LLM-Assisted Algorithm Search

- 论文：*Fitness Landscape of LLM-Assisted Automated Algorithm Search*；本地来源：`manucript.tex`；研究对象：LLM 辅助算法搜索的经验适应度景观，分析而非新方法。

## 1. 核心问题与方法

以图方法刻画 LLM 辅助算法搜索（LAS）的景观：节点 = 搜索过程中产生的去重候选算法（节点大小 = 被生成次数），边 = 父子生成关系（无向、权重 = 转移次数）——邻域结构直接由生成算子定义，属**经验景观**（只含被访问过的算法），借鉴 STN/吸引子网络。设置：EoH 框架（E1/E2/M1/M2 四算子）、种群 20、2,000 次评价；6 任务 × 6 LLM，LLM4AD 平台。

## 2. 论文宣称的机制贡献（逐项）

- 景观刻画：多峰、无漏斗结构、低连通——搜索不自然汇聚向单一最优区域，而在碎片化空间分散推进。
- 任务决定好解密度：启发式设计任务约 80% 的算法落在最低 20% fitness 区间；符号回归（细菌生长）98% 的算法远离最优；Mountain Car 双峰。
- 模型与种群规模是探索-利用旋钮：稠密图利于局部精炼易困局部最优，稀疏图利于全局探索牺牲精炼；小种群（2、5）聚焦局部利用，大种群（10、50）暴露多个未探索峰。

## 3. 实验究竟支持了什么

|主张|论文证据|证据等级|判断|
|---|---|---|---|
|无漏斗、多峰、低连通|6 任务 × 6 LLM 的图度量（密度、聚类系数、平均度）|直接支持|对被采样到的经验景观成立；度熵、聚类系数量级极小（10⁻³），解释须谨慎。|
|模型诱导不同生成几何|TSP 上 GLM-3-Turbo 图最密（密度 0.00223、聚类 0.02282）=局部密集；DeepSeek-Chat 最稀疏（0.00069、平均度 2.15）=全局定向；Qwen-Turbo 平均度最高 4.76|直接支持|同一任务、同框架下模型选择即改变邻域结构；"异构 LLM 组合"是方向性主张，无直接系统实验。|
|代码相似度与性能差相关|TSP 上 AST/dataflow match 与性能差相关性最高，相似度越高性能差越小；OBP 上趋势弱或不一致|部分支持|四指标（BLEU/加权 BLEU/AST/dataflow）彼此强正相关；作者自认现有相似度不足以刻画算法等价性。|
|EoH 算子的探索/利用标签在测量上成立|E1 产生最宽方差、最高中位性能差、最低 dataflow match；M1/M2 保持高 dataflow match、性能分布更紧|直接支持|不同算子提供不同探索度，支持按算子分意图组织的必要性。|

## 4. 机制的底层逻辑（阅读分析，不是作者已证明结论）

碎片化（无漏斗 + 低连通）意味着从当前最优继续生成不一定能沿连通路径走向全局最优——这是 Mutation Without Variation 的"吸引盆"在完整搜索里的宏观对应。好解密度是任务属性（80% 密集 vs 98% 稀疏），探索-利用的最优配比应是任务可读出量；以文本距离做多样性保持（去重、niching）在 OBP 上有失效风险。

## 5. 对 LLM4AD / TraceAAD 可学习之处

- 可学习点：把经验景观度量（连通性、簇结构）作为运行中诊断量。前提：父子边与去重记录完整。风险：只反映已访问区域。最小验证：对同一 run 的不同阶段构图，看连通性变化是否预测停滞。
- 可学习点：任务分组报告"好解密度"（落入低 fitness 区间的候选占比）。最小验证：与该任务上 EPS−纯采样增益关联，检验簇稀有度主张。
