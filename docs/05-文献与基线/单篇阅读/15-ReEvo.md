# ReEvo

- 论文：ReEvo；本地来源：main.tex，含 `sections/` 与 `appendix/`；设计对象是以 LLM 生成可执行启发式代码的语言超启发式。

## 1. 核心问题与方法

ReEvo 关注在昂贵评价下怎样提高启发式搜索的样本效率。每轮从已成功执行的程序中选父代，LLM 先比较候选与分数形成短期反思，再把跨轮可复用的建议汇入长期反思；随后用交叉和精英变异生成代码并评价、保留精英。反思是生成邻域的语言条件，不是对程序参数求梯度。

## 2. 论文宣称的机制贡献（逐项）

1. 用短期相对比较与长期知识累积提供“verbal gradient”。
2. 在反思条件下结合交叉、变异，使代码进化比直接采样更有效。
3. 反思改变 LLM 所诱导的 fitness landscape，使邻域更平滑。

## 4. 机制的底层逻辑

这是阅读分析：反思把“两个程序的相对优劣”压缩成可复用的设计语言，再作为下一次采样的条件，因而改变候选生成分布；长期反思减少每轮只追随局部父代的遗忘。其风险是文本建议的归因未必正确，且交叉、变异、提示共同改变分布，不能把最终分数单独归给反思。

## 5. 对 LLM4AD / TraceAAD 可学习之处

|可学习点|成立前提|主要风险|最小验证方式|
|---|---|---|---|
|把相邻改进的理由保留为短轨迹注释|父子关系及评价差可信|反思事后合理化|固定父子与模型，比较有/无轨迹提示的下一代增益。|
|把跨轮规律与单次评论分层|能区分可复用规律和实例噪声|长期池变成陈词滥调|只记录命中后带来改进的规则，并做小预算检索消融。|
