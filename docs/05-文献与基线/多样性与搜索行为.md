# 多样性与搜索行为

多样性有价值，是因为不同候选可能通向不同的后续收益。代码差异、思想类别、执行行为和实例表现分别观察不同侧面；选择哪一种表示，应服务于实际的搜索决策。

## 保留什么样的差异

MEoH 在质量与运行时间之间保留折衷；CDEoH 通过类别代表维护多方向；PartEvo 用语言空间的 niche 分配机会。它们分别回答目标折衷、设计家族与表示空间覆盖的问题。

BehaveSim 用求解轨迹比较实际行为，可帮助识别形式不同但选择相近的程序。作为研究启发，它促使我们观察最终决策，而不只比较代码外观。TraceAAD 当前可以先检查具体排序、采样或构造动作，按研究需要再选择更复杂的行为表示。

## 搜索停滞来自哪里

Mutation Without Variation 移除选择后仍观察生成器的重访模式；Fitness Landscape 和 Code Evolution Graphs 刻画被访问区域与结构演化；Optimizer Trajectory Analysis 关注模型的连续精炼能力。这些视角共同说明，停滞可能来自模型生成偏好、选择过度集中、接口限制或可开发结构不足。

同样的“长期不涨分”因此有不同处理方式。若生成反复回到同一规则，可改变材料或操作；若优秀新结构从未再次被选中，可改变机会分配；若候选持续变长而决策未变，可要求精简并检查无效计算。

## 为什么简单基线重要

Understanding Evolutionary Search 将复杂方法与 (1+1)-EPS、独立采样放到共同环境中。Behaviour Space Analysis 将提示、种群和精英保留组合比较。它们让我们直接看到复杂结构增加的是什么：更好的起点、更多方向，还是更可靠的局部精炼。

## 对 TraceAAD 的推论

多样性机制应当说明它把机会给了谁，以及这些机会如何继续发展。可优先比较全档案质量抽样、有限竞争池和少量新方向机会，再观察不同程序族的延续。若行为分析只是重复解释最终分数，就让它留在诊断层；若它能识别被忽略的可开发结构，再考虑进入选择。

## 三种观察尺度

经验景观记录访问过哪些候选及其质量；形成轨迹记录程序怎样被改写和选择；求解轨迹记录候选在实例上怎样作决策。前者适合发现搜索覆盖和局部吸引，第二种适合理解持续开发，第三种适合判断代码差异是否改变实际行为。

选择行为表示时，应让它服务于具体问题。例如 OBP 关注箱子排序，路径问题关注局部移动和可行性，跨规模比较关注计算规则是否仍适用。运行轨迹的相似性也会受到实例和随机种子的影响，因此固定探针后再比较候选。

MEoH 将解质量与运行时间作为不同目标，保留质量—效率折衷。运行时间指被评价启发式的执行时间，与模型生成耗时和代码长度不同。对 TraceAAD，有价值的推论是高效程序可能提供另一类可开发骨架；是否需要增加时间目标，可以通过固定评价预算下的搜索质量与总耗时一起判断。

## 相关工作与来源

<a id="paper-06"></a>
### MEoH

同时优化质量与运行时间，以 Pareto 支配和 AST 相异度共同决定父代选择及种群保留，输出质量—效率折衷。

来源：论文：MEoH；本地来源：`papers/MEoH/MEoH.tex`；设计对象：面向组合优化的启发式代码。

原文入口：[arXiv:2409.16867](https://arxiv.org/abs/2409.16867)

<a id="paper-09"></a>
### CDEoH

生成与评价后归纳算法类别；生存选择先保每类最好者，再按质量和稀有度补足种群，类别不进入生成提示。

来源：论文：*CDEoH: Category-Driven Automatic Algorithm Design With Large Language Models*；本地来源：`main.tex`；设计对象：启发式/算法代码（Online Bin Packing、TSP）。

原文入口：[arXiv:2603.19284](https://arxiv.org/abs/2603.19284)

<a id="paper-49"></a>
### Mutation Without Variation

移除选择压力，反复执行 LLM 变异，观察程序与结构的重访、自环和周期，分离生成器自身的偏置。

来源：论文：*Mutation Without Variation: Convergence Dynamics in LLM-Driven Program Evolution*；本地来源：`papers/Mutation_Without_Variation_Convergence_Dynamics_in_LLM_Driven_Program_Evolution/paper.pdf`；研究对象：无选择压力的 LLM 程序 mutation chain，而非一套新 AAD 方法。

原文入口：[arXiv:2606.05408](https://arxiv.org/abs/2606.05408)

<a id="paper-54"></a>
### BehaveSim

以中间解序列和 DTW 比较程序求解行为，区分代码形式相似与实际策略相似。

来源：论文：[*Rethinking Code Similarity for Automated Algorithm Design with LLMs*](https://arxiv.org/html/2603.02787) 本地论文：`papers/Rethinking_Code_Similarity_for_Automated_Algorithm_Design/paper.pdf`

原文与实现：[来源 1](https://arxiv.org/html/2603.02787)

<a id="paper-60"></a>
### PartEvo

代码相似度或思想嵌入聚类形成 niche，跨 niche 分配机会，内部精英选择，并加入跨 niche 参考。

来源：论文：*Partition to Evolve: Niching-enhanced Evolution with LLMs for Automated Algorithm Discovery*；本地来源：`papers/PartEvo_Partition_to_Evolve/paper.pdf`；正式发表于 NeurIPS 2025；设计对象：完整 meta-heuristic 算法。

原文入口：[NeurIPS Proceedings](https://proceedings.neurips.cc/paper_files/paper/2025/hash/e389b15166cf98966ba058965a8c17e3-Abstract-Conference.html)

<a id="paper-62"></a>
### Understanding the Importance of Evolutionary Search

统一模型、任务、重复和评价预算，比较复杂搜索与极简 (1+1)-EPS、独立随机生成的实际收益。

来源：论文：*Understanding the Importance of Evolutionary Search in Automated Heuristic Design with LLMs*；本地来源：`main.tex`；研究对象：LLM-EPS 方法相对零样本采样与极简基线的真实贡献，批判性重评估而非新方法。

原文入口：[arXiv:2407.10873](https://arxiv.org/abs/2407.10873)

<a id="paper-63"></a>
### Fitness Landscape of LLM-Assisted Algorithm Search

用已访问算法及父子生成边构造经验景观，分析连通、吸引和搜索集中形态。

来源：论文：*Fitness Landscape of LLM-Assisted Automated Algorithm Search*；本地来源：`manucript.tex`；研究对象：LLM 辅助算法搜索的经验适应度景观，分析而非新方法。

原文入口：[arXiv:2504.19636](https://arxiv.org/abs/2504.19636)

<a id="paper-64"></a>
### Code Evolution Graphs

在形成图中记录 AST 特征、复杂度与性能，比较模型如何改变代码结构及其演化。

来源：论文：*Code Evolution Graphs: Understanding Large Language Model Driven Design of Algorithms*；本地来源：LaTeX 源码目录 `Code_Evolution_Graphs_Understanding_Large_Language_Model_Driven_Design_of_Algorithms/`；研究对象：LLM 进化框架中代码结构与复杂度的演化轨迹，诊断工具而非新方法。

原文入口：[arXiv:2503.16668](https://arxiv.org/abs/2503.16668)

<a id="paper-65"></a>
### What Makes an LLM a Good Optimizer（轨迹分析）

固定进化循环比较多个 LLM，分析局部精炼率、父子距离、分布广度与搜索表现的关系。

来源：论文：*What Makes an LLM a Good Optimizer? A Trajectory Analysis*；本地来源：LaTeX 源码目录 `What_Makes_an_LLM_a_Good_Optimizer_Trajectory_Analysis/`；研究对象：15 个 LLM × 8 任务的进化轨迹，什么变量预测优化成功。

原文入口：[arXiv:2604.19440](https://arxiv.org/abs/2604.19440)

<a id="paper-66"></a>
### Behaviour Space Analysis of LLM-driven Meta-heuristic Discovery

组合探索/精炼提示、种群大小和精英保留，记录 BBOB 上的行为覆盖、收敛与停滞。

来源：论文：*Behaviour Space Analysis of LLM-driven Meta-heuristic Discovery*；本地来源：LaTeX 源码目录 `Behaviour_Space_Analysis_of_LLM_driven_Meta_heuristic_Discovery/`；研究对象：被 LLM 生成的元启发式（而非 LLM 本身）在求解时的行为画像，及其与配置/性能的关系。

原文入口：[arXiv:2507.03605](https://arxiv.org/abs/2507.03605)


## 延伸阅读

- **Transformers Learn In-Context by Gradient Descent**：构造性证明单层线性自注意力层等价于对回归损失做一步梯度下降，实证显示训练后的 Transformer 展现出与 GD 一致的 ICL 行为。ICL 机制奠基性工作。 [arXiv:2212.07677](https://arxiv.org/abs/2212.07677)

- **Why Can GPT Learn In-Context? Implicit Gradient Descent as Meta-Optimizers**：把 LLM 解释为元优化器、ICL 视为隐式微调：理论上证明注意力是梯度下降的对偶形式，实证上 ICL 表现与显式微调一致。 [arXiv:2212.10559](https://arxiv.org/abs/2212.10559)

- **Large Language Models Are Latent Variable Models**：把预训练 LLM 视为隐变量模型：预训练隐式编码隐变量生成过程，解释 few-shot 演示敏感性的来源，并据此指导演示选择。 [arXiv:2301.11916](https://arxiv.org/abs/2301.11916)

- **Large Language Models as Optimizers (OPRO)**：提出 OPRO：把优化任务描述为自然语言，LLM 从含历史解与评分的提示中迭代生成新解。提示优化上 SOTA，LLM 作为优化器的开山工作。 [arXiv:2309.03409](https://arxiv.org/abs/2309.03409)

- **Uncovering Mesa-Optimization Algorithms in Transformers**：在合成序列预测任务上分析 Transformer：最小化下一 token 损失会产生内部学习算法（mesa-optimization），即使无显式训练也表现出 ICL 能力。 [arXiv:2309.05858](https://arxiv.org/abs/2309.05858)

- **Large Language Models as Evolutionary Optimizers**：首个把 LLM 作为组合优化进化算子（EvoLLM）的系统研究：无需领域知识、人工设计与模型训练，在 CO 任务上超越部分经典 EA。 [arXiv:2310.19046](https://arxiv.org/abs/2310.19046)

- **When Large Language Models Meet Evolutionary Algorithms**：从微观层面建立 LLM 与 EA 的概念对应（token/个体表示、位置编码/适应度塑形等），分析结合后的增强潜力与挑战。 [arXiv:2401.10510](https://arxiv.org/abs/2401.10510)

- **LLMs for the Automated Analysis of Optimization Algorithms**：把 LLM 集成进 STNWeb（搜索轨迹网络可视化工具），自动解读优化算法行为，展示 LLM 在算法分析侧的应用。 [arXiv:2402.08472](https://arxiv.org/abs/2402.08472)

- **Ten Words Only Still Help: Proxy-Guided Efficient Re-Sampling (AIGT 检测)**：黑盒 AI 文本检测：少量代理词引导高效重采样，缩小与白盒方法的差距。与 AAD 弱相关（黑盒 LLM 行为研究），列此备查。 [arXiv:2402.09199](https://arxiv.org/abs/2402.09199)

- **Large Language Models as Evolution Strategies**：证明未经黑盒优化训练的大 Transformer 在原理上可实现进化优化算法（ES 变体）：区分语言化任务规范与真实数值优化能力，输出解向量迭代分布。 [arXiv:2402.18381](https://arxiv.org/abs/2402.18381)

- **Bias Amplification in Language Model Evolution: An Iterated Learning Perspective**：用迭代学习视角分析 LLM 多轮自改进（自我训练、多智能体交互）中的偏差放大：迭代过程系统性放大初始偏差，与人类文化演化中的 iterated learning 结论平行。 [arXiv:2404.04286](https://arxiv.org/abs/2404.04286)

- **Exploring the True Potential: Black-box Optimization Capability of LLMs**：全面评测 LLM 在黑盒优化中的真实能力：LLM 主要贡献初始解多样性，但对反馈利用不充分，单独作为搜索器仍有限。 [arXiv:2404.06290](https://arxiv.org/abs/2404.06290)

- **Revisiting OPRO: The Limitations of Small-Scale LLMs as Optimizers**：复现 OPRO 于小模型（LLaMa-2、Mistral 7B）：优化能力有限、受初始提示与随机性影响大，且不能一致超越精心设计的搜索基线。对方法结论的可迁移性提出警告。 [arXiv:2405.10276](https://arxiv.org/abs/2405.10276)

- **LLMs as Surrogate Models in Evolutionary Algorithms**：初步研究 LLM 作为替代模型（surrogate）预测候选性能，替代传统 ML 回归器，探索预训练知识在昂贵优化中的价值。 [arXiv:2406.10675](https://arxiv.org/abs/2406.10675)

- **Deep Insights into Automated Optimization with LLMs and Evolutionary Algorithms**：深入分析 LLM+EA 自动优化框架：LLM 作为动态智能体生成/精炼/解读策略，EA 负责搜索空间探索；分析组件行为与失败模式。 [arXiv:2410.20848](https://arxiv.org/abs/2410.20848)

- **Evolutionary Thoughts: Integration of LLMs and Evolutionary Algorithms**：分析 LLM 推理（易幻觉、易卡在局部错误解）与 EA 搜索（探索能力强、盲搜索）的互补性，提出在思想空间（thought-level）而非仅代码空间整合二者。 [arXiv:2505.05756](https://arxiv.org/abs/2505.05756)

- **RAFP: Identifying LLM Lineages via Rare-Region Fingerprints**：黑盒 LLM 溯源：微调主要更新高密度常用语言行为，而低概率稀有区域保留指纹，据此识别模型血统。与 AAD 弱相关（LLM 内部机制），列此备查。 [arXiv:2505.12682](https://arxiv.org/abs/2505.12682)

- **LLMs as Computable Approximations to Solomonoff Induction**：建立 LLM 与算法信息论的首个形式联系：训练过程计算近似 Solomonoff 归纳，为涌现现象提供统一数学视角。 [arXiv:2505.15784](https://arxiv.org/abs/2505.15784)

- **Transformers in the Dark: Navigating Unknown Search Spaces via Bandit Feedback**：研究无需外部搜索组件、仅靠 bandit 反馈引导 LLM 在未知树状搜索空间导航的能力，评估 LLM 自身作为搜索器的局限与条件。 [arXiv:2603.24780](https://arxiv.org/abs/2603.24780)

- **Relation Reasoning with LLMs in Expensive Optimization (R2SAEA)**：把关系推理（排序偏好）作为 LLM 替代模型的监督信号：RL 训练的关系式 LLM 替代模型减少昂贵评估与重训练开销。 [arXiv:2605.02933](https://arxiv.org/abs/2605.02933)

- **Estimating Black-box LLM Uncertainty with Distribution-Aligned Distillation**：用分布对齐对抗蒸馏估计黑盒 LLM 的不确定性，无需多次采样或内部参数，实时捕捉推理过程中的隐式信息。 [arXiv:2605.05777](https://arxiv.org/abs/2605.05777)

- **Hyper-ES: Effective Evolution Strategies for LLM Reasoning via Descent Direction Merging**：子空间进化策略：全参数 ES 在高维空间中多数扰动近正交于有用方向而低效；在低维子空间合并下降方向，用 ES 做资源受限的 LLM 推理优化。 [arXiv:2608.05541](https://arxiv.org/abs/2608.05541)
