# TraceAAD V10.14 正式机制

正式结果对应批次 `20260928_v1014`，实现模块为 `traceaad.v10_14`。五任务各四路，每路最多 1,000 次候选尝试。

| 环节 | 正式规则 |
| --- | --- |
| 初始化 | 默认八次提案，前四次独立生成，后四次可参考已有有效根；不为凑足八个有效根免费重试。每个有效且源码唯一的根最多获得一次 Refine bootstrap。 |
| 候选交付 | 模型提交完整 Python 代码，Idea 可选；失败、重复和无效程序均消耗候选预算。 |
| 动作 | Refine、Tune、Pivot、Transfer 从可用动作中等概率抽取。Pivot 不读取父程序或参考；Transfer 需要不同语法组的参考。 |
| 历史 | 当前程序、最近直接尝试及有限形成事件进入请求；额外历史上限为 4,000 token、6 个事件、深度 6。 |
| 选择 | 搜索后冻结最多五个语法不同的候选，由独立选择集选最终程序。选择集不参与搜索。 |

所有有效候选保留。父代竞争在 AST 语法组上共享使用次数，同组各程序的源码、分数和形成来源仍分别保存。正式选父得分为

\[
S(a)=Q_{\mathrm{midrank}}(a)+\frac{1}{\sqrt{n_a+1}},
\]

其中分位项是任务内质量，`n_a` 是该语法组的开发次数；同分优先较少使用、较早记录的候选。行为探针只做诊断，不参与父代准入或预算分配。在线轨迹重验和固定多步开发票均未启用。

[正式结果](../03-机制探索与验证/2026-09-29-V10.14-正式实验结果与分析.md)是这套联合配置的表现，无法分解为某个单独规则的收益；选择集成绩也不是 held-out。复现参数见[运行说明](../../experiments/traceaad_v10_14/README.md)。
