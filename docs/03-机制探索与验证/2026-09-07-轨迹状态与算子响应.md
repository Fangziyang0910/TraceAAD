# 行为轨迹状态与 Refine/Pivot 响应（E2-A）

## 1. 实验目标与轨迹状态定义

本实验检验当算法形成路径处于停滞特征时，切换 Pivot 算子相对继续 Refine 是否具备更高的一步预算价值。

- **科学问题**：当当前节点表现为低行为移动、行为重访且近期无适应度兑现（停滞状态）时，Pivot 相对 Refine 的一步前沿收益是否显著增加？
- **数据与隔离**：基于 V10.6 15 路未见 prospective suffix（E1 cutoff 之后已完成事件），包含 424 个具有完整非根轨迹状态的 Refine/Pivot 动作。
- **Action 前的轨迹状态构造**：
  1. $D_{move}$：当前节点与形成父节点之间的 BehaveSim 行为距离；
  2. $D_{revisit}$：当前节点到 action 前已有 Archive（排除自身及形成父节点）的最小行为距离；
  3. $G_{recent}$：沿祖先链最近最多 3 条形成边的相对适应度收益和。
  - **停滞状态定义**：以 E1 prefix 中位数对照，满足上述 3 项中至少 2 项判定为停滞状态（stagnant）。
- **因果估计器**：分层 Hájek inverse propensity weighting (IPW)，限定于 $0.05 \le e_P \le 0.95$ 的重叠样本（overlap population）。
- 数据汇总见[原始结果](../../experiments/traceaad_e2_a/report/summary.json)。

## 3. 机制分析与决策

1. **未通过交互门槛**：当前以祖先形成历史定义的停滞状态，未能在一步操作上显现出提高 Pivot 的前沿增益。
2. **机制认知深化**：
   - 原特征主要反映的是祖先的**形成路径（Formation History）**，并未反映该节点自身出生后接受过多少次**实际开发（Development Experience）**；
   - 理论上 Pivot 允许以一步的暂时退化换取机理突破，强行要求一步前沿改善作为准入门槛过紧。
3. **决策结论**：
   - 不修改在线算子分配概率；
   - 终止 Q_kernel 选父分支；
   - 针对 Pivot 的两步“垫脚石”期权价值假设，设计独立的固定锚点随机干预实验（E2-B）进行检验。
