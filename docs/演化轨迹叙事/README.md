## 设计与研究认识


树状种群之前，EvoTrace围绕同一演化过程组织三个机制。它们的叙事、设计与实现作为旧版资料保留，其中的认识是当前叙事的来源。

1. **轨迹节点价值评估与预算分配。** 先按Base的质量偏好分配机会，再用近期、起点质量相近的真实轨迹结果修正分配；交叉参考用轨迹嵌入选择形成经历差异最大的个体。见[机制1](机制设计/机制1-轨迹节点价值评估与预算分配.md)。
2. **轨迹引导的上下文与算子。** Refine通过当前算法的形成路径和同起点尝试决定改什么，Crossover通过参考的形成与历史接入决定借什么，Explore通过既有方向及其后续发展决定探索什么。见[机制2](机制设计/机制2-轨迹引导的上下文与算子.md)。
3. **轨迹反思与经验学习。** 从不同节点的改进经历中提炼带计算条件的设计经验，并随新轨迹修订。见[机制3](机制设计/机制3-轨迹反思与经验学习.md)。

方法叙述见[Method](method.md)与[论文引言旧稿](paper.md)。保留的实现为V21.3（Base＋机制2）、V22.2（V21.3＋机制1）、V23.2（Base＋机制1）和V24.1（V21.3＋机制3）。

三个机制留下的主要认识：

- 同起点的已有尝试改变生成。消融中去掉它们后，子代好于父代的比例从27.5%降到16.7%；去掉祖先链没有变化（[W45](../记录/2026-W45.md)）。
- 按次数触发的全局笔记逐渐跟随当时成绩最好的程序（[W46](../记录/2026-W46.md)）。
- Base与三个机制的效果比较，以及由此修正的认识，见[三机制效果审计](../记录/2026-11-10-Base与三个轨迹机制的效果和认识修正.md)。
- 轨迹的信息增量与作用位置的讨论见[价值边界](../记录/2026-11-10-演化轨迹的价值边界.md)与[作用位置](../记录/2026-11-10-演化轨迹的信息增量与三个机制的作用位置.md)。
