V10.13 只有一个正式机制，定义见[机制设计](TraceAAD-V10.13-机制设计.md)与[机制清单](../04-研究认识与构想/2026-09-24-V10.13机制清单.md)。本页保留正式机制确定前的接口实验事实，不把这些实验当作独立版本。

## 输出接口实验

早期实验允许模型返回动作 JSON、请求局部试验或参考实现，再通过第二次调用完成候选。固定快照包含 2471 个候选事件：1726 个有效、638 个解析失败、107 个评价失败。解析失败占 25.82%；进入评价的候选中失败占 5.84%。主要问题是外层协议会拒绝一部分可执行程序。

对这些响应做离线重放时，1726 个原有效程序的代码全部保持一致，另有 323 次原解析失败变得可解析，315 次仍失败。新增可解析程序没有重新评价，因此这项实验只支持简化代码提取，不能说明算法质量提高。

正式接口取消额外读取回合。Refine 和 Tune 直接获得已有局部试验摘要，Pivot 只看当前程序，Fuse 使用一份完整参考。模型默认输出单个 Python 代码块和可选的一句 Idea；小修改可以使用绑定当前父代的精确 edit。
