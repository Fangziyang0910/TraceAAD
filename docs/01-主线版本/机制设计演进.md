# 机制设计演进：TraceAAD 各代演化脉络

本页梳理 TraceAAD 各代版本的设计意图与演进脉络。各版本的跑榜指标与对比数据统一收录于 [02-实验结果](../02-实验结果/主实验结果汇总.md)。

---

## 近期主线

- **V11.0**：[机制设计](TraceAAD-V11.0-机制设计.md)（2026-09-17 设计定稿，实现待启动）。全档案"质量百分位＋有限探索加分"调度彻底替代 ESS（按唯一代码分配）；Pivot/Fuse 改为共享的最多 8 个参考节点 Idea＋适应度上下文（$1/r$ 抽样、无 donor 代码）；Refine/Tune、单亲树与任务契约完全保留；新增断点恢复契约（评价结果复用、每候选单次提交）。继承基线为 V10.11 generic 配置。
- **V10.10**：[机制设计](TraceAAD-V10.10-机制设计.md)。基于 V10.9 移除新结构试用与直接子代试错上下文，引入一次有界修复；解决 Fuse 超限后整边裁剪 capfix；sequential informed initialization。运行代码见 [experiments/traceaad_v10_10](../../experiments/traceaad_v10_10/README.md)。
- **V10.9**：[机制设计](TraceAAD-V10.9-机制设计.md)。思想形成借鉴与精炼，评估失败分类排查。运行代码见 [experiments/traceaad_v10_9](../../experiments/traceaad_v10_9/README.md)。
- **V10.8**：[机制设计](TraceAAD-V10.8-机制设计.md)。显式近期形成轨迹，父代机会分配。运行代码见 [experiments/traceaad_v10_8](../../experiments/traceaad_v10_8/README.md)。
- **V10.7 / V10.7R**：[机制设计](TraceAAD-V10.7-机制设计.md) 与 [V10.7R 机制设计](TraceAAD-V10.7R-机制设计.md)。分层采样与试错经验沉淀。
- **V10.6**：[机制设计](TraceAAD-V10.6-机制设计.md)。代码优先生成与摘要对齐，父代先行分配。
