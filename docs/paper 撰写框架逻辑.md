顶会顶刊论文的 Introduction 通常可组织为 5–6 个段落，遵循“研究背景 → 现有进展 → 核心问题 → 关键洞察 → 提出方法 → 贡献与结果”的论证逻辑。

1. 研究背景（Background）： 介绍研究任务、重要性及核心挑战，说明为什么值得研究。
2. 研究现状（Prior Approaches）： 概述现有方法的主要思路与进展，建立研究背景。
3. 现有局限（Limitations）： 指出尚未解决的关键问题，分析问题产生的原因及其影响。
4. 核心洞察（Key Insight）： 提出对问题的新理解，并由此引出解决问题的关键思路。
5. 方法概述（Our Approach）： 介绍所提方法的核心机制，说明各部分如何回应上述问题。
6. 贡献与结果（Contributions）： 总结主要贡献，并用关键实验结果支持方法的有效性。

关键原则： Introduction 不是背景、问题和方法的简单罗列，而是一条逐步推进的论证链，使读者自然理解为什么需要提出本文的方法。
