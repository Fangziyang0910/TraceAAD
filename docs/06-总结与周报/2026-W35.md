# TraceAAD 周报｜2026-W35（8月24日—8月30日）

## 本周概况

这周完成了 V9.17 的自适应调度对照。它比单看版本排名更有帮助，因为两组从相近的起点出发，比较的是新方向得到后续开发机会的方式。

## 主要进展

Adaptive 与 FixedCycle 在五任务各三路，共 30 路搜索和测试全部完成。CVRP 的三个测试规模、三次重复均是 Adaptive 更好；TSP200、VRPTW100/200 也显示同向优势，其他规模和 OP 则没有这么一致。这说明连续开发的收益随任务变化，不能把一个任务上的结果直接推广到全部任务。配对设置与详细结果见[自适应调度消融](../03-机制探索与验证/2026-08-24-自适应调度.md)。

我还完成了五个对照方法的重复运行，并检查原批次与重跑批次之间的波动；75 个测试设置中，重跑更好和更差分别为 39、36 个，没有统一方向。另一条探索是用算法行为而非代码表面差异描述搜索区域：在 TSP、装箱、VRPTW 上，行为相近的程序表现也更接近；CVRP、OP 的关系不够稳定。V9.18 的机会项对照已经启动，V9.19 开始尝试把行为信息纳入搜索，但本周没有足够终局结果支持采用它。

## 目前的发现与下一步

正的阶段性收益不一定意味着值得持续加预算；新的机会分配仍要看最终算法和未见实例。下周会继续检验机会项与行为信息是否真能改善完整搜索，同时保留不使用它们的简单版本作为对照。
