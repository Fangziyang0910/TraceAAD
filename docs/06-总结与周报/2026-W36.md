# TraceAAD 周报｜2026-W36（8月31日—9月6日）

## 本周概况

这周我从早期的方向与机会调节转向 V10 系列，重点看父代选择、算子生成和后续开发怎样衔接。虽然部分任务有改进，还没有找到跨任务稳定领先的方案。

## 主要进展

我统一了五任务后续实验的生成模型与采样设置，完成 V10、V10.1 的实现，并启动每任务三次重复的正式搜索。训练过程分析显示：选过很多不同父节点，预算仍可能集中在少数算法方向；统计的 4054 个 Pivot 新方向中，只有约 3.6% 出生后得到过继续开发的预算。单看节点选择的分散程度，无法知道新方向是否真有发展机会。

CVRP 的一次重复在评价 815 次时因程序膨胀导致生成上下文超限，但截至中断时得到的最优程序在独立测试上反而有竞争力。这件事提示我，复杂程序可能有效，问题是如何让生成过程有选择地替换旧机制，而不是不断叠加。我把选择性修改作为下一版的重点，没有用代码行数设一个简单的硬上限。

## 目前的发现与下一步

当前质量能给搜索可靠的起点，却不能单独预测一个新方向未来是否值得开发。下一步会比较更简洁的提示、算子动作和分配规则，观察它们对完整搜索而非单次改写的影响。相关机制演进见[开发机会与生成上下文](../01-主线机制设计/V10-V11-机会分配与生成上下文.md)。
