# TraceAAD 周报｜2026-W39（9月21日—9月27日）

这周我完成了 V10.12 和 V11.1 的搜索与独立测试，重新检查“短形成历史加跨分支参考”能否稳定改善算法。结果没有支持一个统一升级：V11.1 在 CVRP 的部分规模和在线装箱上改善，TSP 三个规模却都比 V10.11 默认组差；V10.12 的退步较小，但没有通过原定的 TSP/VRPTW 门槛。[结果表](../02-实验结果/01-正式版本平均结果.md)

V10.11 几组训练终点也呈现任务差异：短轨迹在 TSP、VRPTW 较好，档案参考在 CVRP、装箱较好，全代码轨迹在 OP 较好。这让我不再把“提供更多历史”当作普遍有效的机制。更值得检查的是，参考内容是否进入了实际计算，以及模型是否保留了已经有效的结构。已有接口试验还发现，有些可解析程序会因外围说明被拒收；这会损失搜索机会，却不能解释为算法方向本身无效。

我也重新区分了模型对修改的描述和代码真正改变的决策。形成历史中曾有效的部件，放进当前程序未必仍起作用；轨迹重验可以帮助诊断，但当时还没有证据说明把它加入在线搜索会提升结果。早期 V10.14 探索沿用了这一构想，后续正式版本的判断以[下一周结果](2026-W40.md)为准。
