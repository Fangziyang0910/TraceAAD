# TraceAAD 周报｜2026-W41（10月5日—10月11日）

上周主要推进了三项工作。

## 1. 确定主实验任务

我选定了 TSP、CVRP、FSSP、图着色、JSSP 和 OP 六个组合优化任务，并明确了任务接口、数据划分和评价条件。TSP、CVRP、FSSP、OP 在固定框架内进化关键函数，图着色和 JSSP 进化完整求解器，作为后续方法比较的实验基础。[任务设计](../04-研究认识与构想/2026-10-07-六个组合优化任务的设计.md)

## 2. 梳理 TraceAAD 的贡献与机制

我重新思考了搜索轨迹能提供什么额外经验，以及这些经验应当影响哪个具体决策。现有系统保存的信息比实际用于生成和选择的信息更丰富；记录本身不等于有效利用。当前重点是收缩机制范围，明确要解决的问题，具体机制仍在收敛。[研究主线](../04-研究认识与构想/研究主线与问题.md)

## 3. 切换模型并开展实验

我将主实验模型从本地模型切换为 DeepSeek-V4.1-Flash，关闭原生思考，并启动了六任务基线实验，每路预算为 1,000 次候选。我也核对并修复了基线的任务接口、提示和反馈适配，为后续比较建立对照。[基线实现](../03-现象与检验/2026-10-11-七种基线官方实现忠实性审查.md)
