# TraceAAD 周报｜2026-W38（9月14日—9月20日）

这周我比较了当前程序的短形成历史与其他分支的参考程序。V10.11 三次重复的训练终点显示，TSP 和 VRPTW 的短形成过程较好，CVRP 和装箱的跨分支参考较好；OP 没有清楚的单一选择。这使我不再假定一种历史材料适合所有任务。[结果](../02-实验结果/03-辅助与分支版本结果.md)

V11.0 同时改变选父规则和参考内容，CVRP 的三个测试规模相对 V10.11 默认组改善，TSP、OP、VRPTW 回落。过程复盘还发现，集中开发高分程序会影响新分支的后续机会，而只有 Idea 与分数的参考未必把别的算法计算带进代码。完整版本的结果无法分开这两个因素；它提示我需要看材料是否落实为实际修改，以及新结构是否得到发展，而非只数参考卡片或超父次数。[正式成绩](../02-实验结果/01-正式版本平均结果.md)
