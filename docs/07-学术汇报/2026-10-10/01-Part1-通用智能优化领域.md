## 第 2 页　通用智能优化：任何问题，都能正确建模、高效求解

目标：任何一个问题，系统都能正确建模、高效求解，并满足以下性质。

| 范围 | 性质 | 含义 |
|---|---|---|
| 对每一个问题 | 正确 | 建模忠实于问题，求解的正是需要求解的问题 |
| | 高效 | 整个求解过程在有限的计算资源与时间内完成 |
| | 高质量 | 所得的解与最优解的差距很小 |
| 对全部问题 | 通用 | 问题类型不受限制，覆盖路径、调度、装箱以及新出现的问题 |
| | 泛化 | 对未见过的问题、规模与分布，表现不退化 |
| 实现方式 | 智能（自适应） | 系统自适应地调整建模与求解方式，同时达成以上各项 |

三个词的对应：通用对应“对全部问题”，优化对应“对每一个问题”，智能对应“自适应”。

图 2：六项性质示意（建模与问题一致、过程在资源上限内、解接近最优、问题类型不限、未见规模不退化）。

## 第 3 页　通用智能优化难在三层：原理有边界，性质要权衡，研究较分散

1. **固有局限：没有任何固定算法，适用于所有问题。**
   - 原理：无免费午餐定理（Wolpert 与 Macready，1997）指出，在全部问题上取平均，任意两个算法表现相同。通用只能依靠按问题调整。
   - 现状：理论进展与大语言模型能力，限定当前所能。
2. **实现局限：各项性质相互牵制，难以同时最优。** 单个问题上做到高效不难，每个问题都专业很难。五项性质构成一个多目标问题。
3. **研究现状：现有研究各解决一段，彼此难以串联。** 多数工作针对某类问题的某个环节，很少考虑整体。各环节目前由专家逐题串联。

结论：通用智能优化是一个整体问题，而现有研究只解决了其中的一段。

## 第 4 页　通用智能优化包含四个研究方向，覆盖从问题理解到求解的全过程

四宫格，不排顺序，不列代表工作。两端是自然语言问题与解与分数。

| 研究方向 | 作用于 | 说明 |
|---|---|---|
| 问题建模 | 问题表述 | 把自然语言描述的问题，转为数学模型：确定变量、目标与约束。 |
| 算法选择 | 算法的选用 | 面对一个问题，从已有算法中选出合适的一个。不同的问题，适合不同的算法。 |
| 算法配置 | 算法的参数 | 确定所选算法的参数取值。同一个算法，参数不同，表现也不同。 |
| 算法设计 | 算法的计算逻辑 | 改变算法内部的计算逻辑，生成新的算法程序。关注算法本身怎样做，而不是选用或调参。 |

结论：四个方向作用于求解的不同环节，各自解决不同的问题。

动画：四个方向依次出现；算法选择中候选依次被选中，算法配置中参数来回调整，算法设计中曲线随改写与评价上升，问题建模中目标与约束交替突出。

### 第 5 页　问题建模：把自然语言问题转为可求解的数学模型

- 定义：问题建模确定问题的变量、目标与约束。它把自然语言描述的问题转为数学模型，再写成求解器可运行的代码。
- 研究内容：理解（识别变量、目标与约束）、表述（写出与原问题一致的模型）、验证（检验模型是否忠实于原问题）。
- 动画：一个线性规划例题。文本中的变量、目标、约束依次高亮，并出现在数学模型中；模型写成代码并求解；执行结果回到模型做检验与修正。
- 代表工作：NL4Opt（NeurIPS 2022 竞赛）、Chain-of-Experts（ICLR 2024）、OptiMUS（ICML 2024）、ORLM（Operations Research 2025）、TriVAL（我们的工作，arXiv 2026）。
- 现状：大语言模型使端到端建模成为可能。方法从提示与多智能体流程，发展到微调专用模型；基准扩展到工业场景。
- 局限：基准质量参差，评测方法缺乏统一标准，各项结果难以直接比较；模型与原问题的等价性难以自动验证，错误的模型会得到对错误问题最优的解；提示方法受限于底层模型的能力，复杂工业问题上的准确率仍然较低。

### 第 6 页　算法选择：为每个实例选出表现最好的已有算法

- 定义：算法选择从一组候选算法中，为每个问题实例选出一个算法。它依据实例的特征，预测各算法的表现，再做选择。
- 研究内容：特征（刻画实例之间的差异）、预测（由特征预测各算法的表现）、决策（选出一个，或分时运行多个）。
- 动画：两个实例依次进入：实例 → 特征 → 各算法预测运行时间 → 选中算法。两个实例选出不同算法。
- 代表工作：Rice（1976）、SATzilla（JAIR 2008）、AutoFolio（JAIR 2015）、ASlib（AIJ 2016）、InstSpecHH（arXiv 2025）。
- 现状：方法与公共基准已经成熟，在 SAT 等组合搜索问题上提升显著。近年开始用大语言模型提取特征或做选择。
- 局限：上界是逐实例最优的虚拟最优求解器，现有选择器只弥补部分差距；特征需人工设计且计算成本高，成本过高会抵消选择的收益；假设训练实例代表待求解实例，换到新领域需要重新收集数据。依据：Kotthoff 综述（AI Magazine 2014）及后续研究。

### 第 7 页　算法配置：为算法找到表现最好的参数取值

- 定义：算法配置为一个带参数的算法，确定参数取值。它在一组问题实例上运行算法，评价各个配置，并搜索表现最好的一个。
- 研究内容：搜索（选出下一个要试的配置）、评价（用尽量少的运行判断优劣）、泛化（使配置在新实例上依然有效）。
- 动画：竞赛淘汰（irace 式）。候选配置在实例上逐列评价，明显较差者被淘汰，最优配置得出，再围绕优者采样新配置。
- 代表工作：ParamILS（JAIR 2009）、irace（ORP 2016）、SMAC（LION 2011）、SMAC3（JMLR 2022）、动态配置（ECAI 2020）。
- 现状：配置器已成为调参的常用工具。方法覆盖局部搜索、竞赛淘汰与模型代理，并扩展到运行中调整参数。
- 局限：每次评价都要运行目标算法，评价成本高，限制了可搜索的配置数量；存在过度调优，配置在训练实例上表现好，在新实例上表现下降；配置空间限于目标算法已有的参数，不涉及算法本身的计算逻辑。依据：Schede 等综述（JAIR 2022）；Eggensperger 等（JAIR 2019）。最后一条是我们的归纳，文献未单独作为挑战讨论。

### 第 8 页　算法设计：自动生成并改进求解问题的算法

- 定义：算法设计让系统生成新的算法程序，并依据评价结果持续改进。设计对象从关键的启发式函数，延伸到完整的求解器。
- 研究内容：生成（产生有用的新候选程序）、评价（为候选打分并给出反馈）、搜索（保留候选，并选择改进对象）。
- 动画：种群中选出起点程序 → 大语言模型写出新程序（思想加代码）→ 评价器打分 → 加入种群 → 最优分数上升。
- 代表工作：FunSearch（Nature 2023）、EoH（ICML 2024）、ReEvo（NeurIPS 2024）、MCTS-AHD（ICML 2025）、AlphaEvolve（DeepMind 2025）。
- 现状：大语言模型使程序成为可搜索的对象，方法源自超启发式。已在组合优化启发式与数学构造上取得结果。
- 局限：只适用于能自动、快速评分的目标，评分昂贵或无法自动评分的任务难以应用；每个候选都需要评价与模型调用，成本高，上下文长度限制了可用信息；多数方法只设计单个启发式组件，而非完整算法，多样性与收敛需要权衡。依据：Liu 等综述（arXiv 2410.14716）。
