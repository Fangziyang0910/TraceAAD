# 搜索轨迹的记录与使用

搜索轨迹包括全局生成时间线、程序形成关系、跨程序参考、评价与后续响应。形成路径只是其中一个视图，成功路径只是其中一个样本。当前规则见[V12.1](设计核验-V12.1.md)，研究问题见[研究主线](../04-研究认识与构想/研究主线与问题.md)。

## 当前保存与使用的信息

| 信息 | 保存位置与关系 | 谁使用、改变什么 |
| --- | --- | --- |
| 程序个体 | `Program` 保存分析、设计、源码、来源、评价与代码检查结果 | 搜索器围绕个体组织后续生成、参考和最终选择 |
| 形成关系 | `parent_id` 记录修改起点，`reference_id` 记录额外参考，`repair_of` 记录修复来源 | 提示构建器重建形成路径与代码差异；单父路径不包含所有跨程序信息 |
| 直接子代及结果 | 按父个体收集 Refine、Explore、Crossover 子代；修复关联到被修个体 | 生成器读取局部改动经验；选择器统计子代数和改善次数 |
| 最好成绩刷新 | 从有效个体按生成顺序选出刷新最好成绩的版本 | Explore 读取有限的全局进展，不等于读取全部分支与失败 |
| 同一计算的已有实现 | `link` 记录检索、模型匹配和展示结果 | 实现请求参考同一主要计算的已评价程序 |
| 设计实现与原有计算检查 | 个体的 `verdict` 保存判断、缺失内容及调用编号 | 决定是否补写、从哪个版本补写、是否参与设计匹配，以及后续如何描述程序 |
| 探索与补写过程 | `exploration` 关联提案与补写版本，探索关闭事件汇总结果 | 按检查、成绩、补写次数及预算结束本次探索 |
| 原始调用、解析失败与运行进度 | 调用日志、错误日志和恢复点 | 回查实际输入输出与成本；解析失败不创建程序个体 |

保存的记录、选入提示的材料与参与数值计算的信息要分别核对。模型生成的分析虽然保存在个体中，但不会全部进入后续提示。源码是否相同不决定个体身份。

实现见[程序个体说明](../../traceaad/v12_1/README.md)，文件格式见[搜索结果格式](../../experiments/infra/SEARCH_FORMAT.md)。
