# 机制 1：以 Base 为基准的轨迹经验分配

**先按 Base 的质量偏好分配机会，再用近期、起点质量相近的真实轨迹结果修正分配。没有可比经验的动作，保持 Base 权重。**

本版直接学习当时实际产生的冠军改善。不再把父代改善幅度平移到另一个质量水平。实现位于 [traceaad_v22_1/selection.py](../../traceaad_v22_1/selection.py) 与 [traceaad_v22_1/runtime.py](../../traceaad_v22_1/runtime.py)，由 V22.1（V21 加机制 1）与 V23.1（Base 加机制 1）共用。

---

## 1. 固定动作集合

选择池保留所有有效、fitness 有限、AST 源码不重复的版本，包括退步版本。同源码保留最早的有效代表。

每个主父代 $p$ 有精炼 R、探索 E，以及存在其他 family 时的融合 C。C 的参考固定取不同 family 中最好节点，同分取最小 ID：

$$
\mathrm{ref}(p)=
\arg\min_{\substack{q\in\mathcal P\\
\mathrm{family}(q)\ne\mathrm{family}(p)}}
\bigl(f(q),\mathrm{ID}(q)\bigr).
$$

每个父代最多一个 C 动作。局部动作组为 $g=(\mathrm{parent\_id},\mathrm{operator},\mathrm{reference\_id})$。总可行动作数不超过 $3|\mathcal P|$。

family 规则固定：

| 来源 | family |
|---|---|
| Init | 自立 |
| R | 继承主父代 |
| E、C | 自立 |

每轮按当前池重新确定 C 参考。动作选定后参考固定到该 attempt。提示生成与结果统计使用同一个参考。动作顺序固定为 `(parent_id, operator_order, reference_id)`，算子顺序为 R、E、C。

---

## 2. 反馈统一使用真实冠军改善

对历史 attempt $i$，保存动作开始时的冠军 $f_i^*$。完整 attempt 的反馈为：

$$
\boxed{
Y_i=
\begin{cases}
\max(f_i^*-f(c_i),0),
&\text{最终结果有效、有限且相对 attempt 开始前的池不重复},\\
0,&\text{其他情况}.
\end{cases}
}
$$

首评视图使用同一定义，只把 $f(c_i)$ 换成第一次实际评价的 fitness，并要求首评当时可用。评价成本为真实调用次数 $c_i$。完整视图取实际 1 或 2 次评价。首评视图固定取 1。

因此，改善父代但未超过当时冠军记 0。大幅退步、持平、无效、重复也记 0。真正突破按实际幅度记收益。repair 后突破只记一次，成本包含全部实际评价。例如冠军为 100 时，120→110 记 0，100→99 记 1，105→95 记 5。120→110 的子代仍入池并进入轨迹。它的排名上升后由 Base 权重自动获得更多机会。

零评价 attempt 保存为生成失败记录。不进入收益率估计。它仍更新 Base 的 `model_calls` 统计，并受连续无评价停止规则约束。本版不使用 `max(1,e)` 代替真实评价成本。

---

## 3. 先确定哪些历史可以借用

### 3.1 同算子、近期、已评价

对当前动作 $g$，只使用同一待执行算子、至少发生过一次真实评价、且位于最近 $H$ 次 evaluation 范围内的历史 attempt：

$$
H=\min(B,256),
$$

其中 $B$ 是总评价预算。默认预算 1000 时使用最近 256 次评价范围。历史分为两个互不重叠的集合。本地记录 $L$ 与当前 $g$ 完全相同。共享记录 $S$ 为同算子的其他动作组。R 的结果不直接作为 E 的收益样本。

### 3.2 用真实质量状态匹配

当前动作的质量状态为：

$$
x_g=
\begin{cases}
\bigl(f(p),f_t^*\bigr),&R/E,\\
\bigl(f(p),f(\mathrm{ref}),f_t^*\bigr),&C.
\end{cases}
$$

历史 $x_i$ 使用当时记录的父代、参考和冠军成绩。距离为最大坐标差 $d_i(g)=\|x_i-x_g\|_\infty$。过去的冠军 200 与今天的冠军 100 不会因当时都排名第一而被视为相同起点。

共享池按 $(d_i,\mathrm{attempt\_id})$ 稳定排序，取最近的 32 条。不足则全部使用。

### 3.3 匹配半径与质量权重

对选出的共享记录，取其输入状态之间所有严格为正的两两距离的中位数，定义匹配半径：

$$
h_g=2\times\operatorname{median}\bigl\{\|x_i-x_j\|_\infty>0\bigr\}.
$$

共享池为空时，用最近的至多 32 条本地记录计算 $h_g$。没有正距离时 $h_g=0$。没有任何历史时视为无匹配经验。

共享记录的质量权重为线性紧支撑核：

$$
k_{Q,i}=
\begin{cases}
\max(1-d_i/h_g,0),&h_g>0,\\
\mathbf1[d_i=0],&h_g=0.
\end{cases}
$$

所有共享历史都离当前状态很远时，允许一条也借不到。此时该动作回到 Base 分配。

本地记录不做质量核衰减，$k_{Q,i}=1$。本地记录与候选同父代、同参考，是最强的可比关系。若仍按含 $f^*$ 的距离衰减，一次大幅突破会因冠军跳变把自己的成功记录排除在外。阶段陈旧由评价窗口与近期权重处理。

## 4. 轨迹只做温和的相似度修正

本版取消离散轨迹分组，保留连续纵量。对非根节点：

$$
\delta_p=f(\mathrm{parent})-f(p),\qquad
M(p)=0.5\,\operatorname{sign}(\delta_p)+0.5\,M(\mathrm{parent}),
$$

$$
T(p)=\min\bigl(f(p),T(\mathrm{parent}),T(\mathrm{reference})\bigr).
$$

无参考时省略参考项。根节点 $\delta=0,\ M=0,\ T=f$。同时保存出生操作 `Init/R/E/C`。

用当前匹配半径把出生变化与回撤深度压到可比尺度：$s_h(z)=z/(h+|z|)$。当 $h=0$ 时规定 $s_0(z)=\operatorname{sign}(z)$，且 $s_0(0)=0$。记 $u_p=s_{h_g}(\delta_p)$，$v_p=s_{h_g}(f(p)-T(p))$。当前与历史节点都用同一个当前 $h_g$ 计算。

轨迹距离与权重为：

$$
D_{\mathrm{tr},i}
=
\frac{
\mathbf1[\text{出生操作不同}]
+\frac{|u_p-u_i|}{2}
+\frac{|M(p)-M_i|}{2}
+|v_p-v_i|
}{4},
\qquad
k_{\mathrm{tr},i}=\frac{1}{1+D_{\mathrm{tr},i}}\in[0.5,1].
$$

质量同样接近的历史，最多因轨迹相似度产生两倍权重差。本版不预设正动量适合 R 或回撤适合 E。本地记录与候选同父代，轨迹距离恒为 0。

近期权重为 $k_{T,i}=\max(1-(E_t-E_i)/H,0)$。其中 $E_i$ 是历史动作开始时已消耗的评价数。最终样本权重为：

$$
\boxed{w_i=k_{Q,i}\,k_{\mathrm{tr},i}\,k_{T,i}}
$$

## 5. 一个共享估计，加一个本地修正

分别对 $S$ 与 $L$ 计算 $n_A=\sum_{i\in A}w_i$，$Y_A=\sum_{i\in A}w_iY_i$，$C_A=\sum_{i\in A}w_ic_i$。$n_A$ 是匹配权重之和，不是记录条数。

共享经验最多以 16 条等效尝试参与：$a_S=\min(1,16/n_S)$，$n_S=0$ 时 $a_S=0$。经验收益率为加权收益总量除以加权评价成本：

$$
\boxed{
V_g=\frac{Y_L+a_SY_S}{C_L+a_SC_S}
}
$$

分母为 0 时 $V_g=0$，表示没有收益率估计。共享证据充分时，本地有效权重为 2 的反馈在预测均值中的权重约为 $2/(16+2)=11.1\%$。少量本地反馈不会立即压过共享经验。

经验使用强度与共享上限用同一口径。记有效证据 $\tilde n_g=n_L+\min(n_S,16)$，则：

$$
\boxed{
\eta_g=\frac{\tilde n_g}{16+\tilde n_g}
}
$$

匹配记录越少、越不相似、越陈旧，$\eta_g$ 越小。纯共享动作的 $\eta_g$ 不超过 $0.5$。$\eta_g$ 是收缩系数，不是成功概率。

---

## 6. 用经验修正 Base 的联合概率

先在当前可行动作集上算 Base 概率 $\beta_g$：

$$
\beta_g
\propto
\operatorname{rank}(p)^{-1.5}
\frac{3}{3+\mathrm{model\_calls\_spent}(p)}
\,b_o,
\qquad \sum_g\beta_g=1.
$$

并列 fitness 用平均排名。算子权重 $b_o$ 读 Config，默认为 $b_R=0.45,\ b_E=0.30,\ b_C=0.25$。无合法 C 参考时移除 C 后重新归一化。R/E 此时为 60% / 40%。

只重新分配有经验支持的部分。记 $m=\sum_g\beta_g\eta_g$，$Z=\sum_g\beta_g\eta_gV_g$，$\bar V=Z/m$。若 $Z>0$，最终概率与未封顶乘子 $V_g/\bar V$ 的封顶形式成正比：

$$
\boxed{
P(g)\propto
\beta_g\Bigl[(1-\eta_g)+\eta_g\min\bigl(V_g/\bar V,\,4\bigr)\Bigr]
}
$$

最后统一归一化。若 $Z=0$，直接用 $P(g)=\beta_g$。未封顶时该式等价于 $\beta_g(1-\eta_g)+m\cdot\beta_g\eta_gV_g/Z$ 且自动归一化。封顶触发时，未分配量由归一化按比例返还。

含义分三档。无匹配经验时 $\eta_g=0$，保留 Base 机会。有充分失败经验时，在其他动作有正收益证据的前提下让出一部分概率。有充分正收益经验时获得更多概率，但单动作乘子最多 4 倍。窗口内只有一次突破时，未封顶乘子可能极大。封顶防止单事件搬走全部可重分配预算。未封顶乘子写入选择日志，用于事后复查。

本版不再用全局 $4/(N+4)$ 统一衰减 Base。即使已搜索 800 次评价，刚进入新质量区域、缺少可比历史的节点也不会因全局数据多而失去正常机会。E、C 与退步节点没有专属配额。它们保留 Base 机会，后续由实际反馈调整。

## 7. 执行与记录口径

剩余评价不少于 2 时用完整 attempt 视图。成本取实际 1 或 2 次。剩余评价等于 1 时用首评视图。成本固定为 1。无评价 attempt 不进收益率估计。

首评按 attempt 内第一次实际 `_evaluate` 识别。格式修复可能发生在首评之前，不能用 `repair_used` 识别。评价后 repair 的第二次结果不进首评视图。首评的可用性与 AST 去重在首评结束时相对 attempt 开始前的池冻结为 `first_result`。恢复时直接读取，避免子代入池后被误判为重复。

每条非 Init 训练记录保存在 `attempt.record["selection"]`，字段包括：

```text
parent_id, operator, reference_id, action_group
parent_fitness, reference_fitness
champion_before_attempt, evaluations_used_before_attempt
parent_origin, parent_birth_change, parent_momentum, parent_ancestor_best
first_result, final_result
champion_gain, first_champion_gain
evaluations, model_calls
```

所选动作另存 `matching_radius`、`shared_weight`、`local_weight`、`value`、`eta`、`base_probability`、`selection_probability`、`mean_value`、`multiplier`、`uncapped_multiplier`、`window_breakthroughs`、`remaining_evaluations` 与 `valuation_view`。

| 接口 | 行为 |
|---|---|
| `select` | 构造固定动作集，算概率，返回父代、操作、参考与选择记录 |
| `evolution_prompt` | 使用已选定的实际参考 |
| `finish` | 记录一次完整 attempt；有效不同源码子代入池，包括退步子代 |
| `restore` | 按 attempt 顺序重放同一更新，每个 `attempt_id` 只处理一次 |

恢复前核对方法、完整 Config、任务与 `selection_settings`。重放时逐条核对决策时父代状态、冠军与已用评价数，并重算冠军收益。不一致时拒绝。旧版 $f_0/s_0$ 检查点与上一版父代改善检查点都不能直接续跑到本选择器。

## 8. 固定参数与实现

| 设置 | 默认值 |
|---|---:|
| 评价历史窗口 | $\min(B,256)$ |
| 共享近邻数量 | 32 |
| 匹配半径 | 正的历史两两距离中位数 × 2 |
| 质量核 | 线性紧支撑核；本地记录权重 1 |
| 轨迹权重范围 | $[0.5,1]$ |
| EMA 历史权重 | 0.5 |
| 共享等效尝试上限 | 16 |
| 经验强度收缩常数 | 16 |
| 单动作乘子上限 | 4 |
| 父代排名指数 | 1.5 |
| Base 调用衰减常数 | 3 |
| R/E/C 初始权重 | 读 Config，默认 0.45 / 0.30 / 0.25 |

实现在窗口内做精确近邻检索。距离并列按 `attempt_id` 稳定排序。按算子预计算历史两两距离，匹配半径按所选集合缓存。随机流沿用 `seed + attempt_id`。

本版没有固定收益尺度 $s_0$。$h_g$ 只是当前局部样本的匹配半径，不做初始化冻结，也不触发历史重放。fitness 作正比例缩放和平移时，距离与 $h_g$ 同比变化，收益率同比缩放，最终分配概率不变。

**本机制的职责是：在当前质量与搜索阶段可比的前提下，用形成路径与同起点反馈修正父代—操作组合的预算。** 它保留退步版本及其正常竞争机会，只学习已经兑现的冠军改善。轨迹不直接获得奖励，尚未发生的多步收益不提前记账。
