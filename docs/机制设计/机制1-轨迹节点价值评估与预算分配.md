# 轨迹节点价值评估与预算分配

每次演化尝试都要决定两件事：做什么修改，从哪个节点出发。本机制的核心主张是：**节点分数应当等于一个可观测事件的概率。** 这样，搜索才能用自己的结果修正分数，预算才能随证据移动。

## 1 问题：改进稀疏

搜索要在固定评价预算内找到训练成绩最好的程序。所有任务都最小化 fitness \(f\)。设 \(f^*\) 为当前最好成绩。子代 \(c\) 满足 \(f(c)<f^*\) 时，这次尝试称为**突破**。

突破很稀疏。在 90 路已有搜索记录的 80132 次尝试中，突破只有 1306 次，占 1.6%，每路约 15 次。即使精炼当前最好的程序，一步突破率也只有 4.5%。

稀疏带来两个后果。第一，一个节点自己的几次结果几乎分辨不出它的潜力。第二，模型直接学习突破时，一路搜索只有约 15 个正例。预算分配因此需要一个更稠密的信号，而且这个信号要与突破有确定的关系。

## 2 现有方法的不足及其共同根源

现有方法给节点一个分数或抽样规则，再据此分配下一次生成。下表是各方法实际使用的规则。

| 方法 | 节点选择规则 | 算子与节点的关系 |
| --- | --- | --- |
| EoH [1] | 按适应度排名抽样，\(p_i\propto 1/(r_i+N)\)。 | 每代每种提示策略各调用 \(N\) 次，选择规则相同。 |
| ReEvo [2] | 交叉：从可执行个体中随机取亲本对，避开目标值相同的配对。变异：固定作用于当前最好。 | 算子决定规则，没有节点分数。 |
| MCTS-AHD [6] | \(\mathrm{UCT}(c)=\frac{Q(c)-q_{\min}}{q_{\max}-q_{\min}}+\lambda\sqrt{\ln(N(n_c)+1)/N(c)}\)。\(Q\) 回传子节点的最大值，\(\lambda\) 随评价进度线性衰减。 | 先选叶节点，再按固定配额展开：m1、m2 各 \(k\) 个，e2、s1 各 1 个。 |
| A2DEPT [5] | 按模拟退火接受新子代；父代不足时，从全树按 \(\exp((S(n_i)-S_{\max})/T_t)\) 补足。 | 先选节点，再按节点权重 \(\omega\) 抽 m1 或 m2。\(\omega\) 累加相对成绩变化。 |
| [Base](../TraceAAD-Base.md) | 权重为 \(r^{-1.5}\cdot 3/(3+C)\)。\(r\) 是去重源码的成绩排名，\(C\) 是从该节点出发已用的模型调用数，不分成败。 | 父代与算子独立抽取。 |

这些论文的实验证明了什么，需要与作者的解释分开。A2DEPT 的消融显示，均匀随机选父代或去掉 Boltzmann 补充都会使结果变差。MCTS-AHD 显示，树结构的最终 gap 优于种群基线。EoH 与 ReEvo 的消融针对提示策略、反思和算子，选择规则不是检验对象；EoH 的作者也明确说明任何选择方法都可用。

作者进一步解释说，这些规则能发展“暂时落后”的启发式 [6]，能恢复“结构上有前途”的分支 [5]。这个解释超出了实验。两篇论文比较的是最终成绩，没有报告分数能否预测从该节点出发的下一次改进。A2DEPT 的 Boltzmann 权重只含成绩和温度，公式中没有结构信息。

这些规则的不足有同一个根源：**分数没有对应的事件。** UCT 值或抽样权重高，并不声明某件事会以某个频率发生，所以没有结果能说它错了。这个根源带来三个不足。

- **分数无法校准。** 搜索无法把分数与实际频率比较。分数偏高时，后续结果也纠正不了它。
- **探索强度依赖手工常数。** \(N\)、\(\lambda_0\)、\(T_t\) 与 Base 的 1.5、3 都决定预算的集中程度，但它们不由预测误差修正。MCTS-AHD 的敏感性实验也显示，TSP 与 KP 偏好不同的 \(\lambda_0\)。
- **分数不区分算子。** 一个事件必须写明对节点做什么。没有事件时，同一分数就要服务所有算子。EoH、MCTS-AHD 与 Base 选节点时都不考虑本次算子。A2DEPT 学习节点上的算子权重，这最接近按算子区分价值；但它先选节点再选算子，权重也是增益的累加，不是概率。

贝叶斯形式本身不解决这个问题。Clade-AHD [11] 用 Beta 后验和汤普森采样选节点，算法把归一化成绩记为胜负。但后验由全部后代按深度衰减累加，再按预算进度放大参数。抽到的值描述子树的整体表现，不是从该节点出发的下一次尝试的事件概率。

## 3 思路：分解突破概率

分数应当等于**这次尝试突破当前最好**的概率。这个事件太稀疏，不能直接学习。我们用节点的轨迹定义一个更稠密的中间事件，再分解突破概率。

节点 \(p\) 的**轨迹参照** \(T(p)\) 是 \(p\) 自身与沿 `parent_id` 最近 8 个祖先中最好的训练成绩，不含 0 号样例。子代满足 \(f(c)<T(p)\) 时，这次尝试称为**超过参照**。

因为 \(T(p)\ge f^*\)，突破一定也超过参照。设 \(o\) 为本次尝试使用的价值，链式法则给出：

\[
P\big(f(c)<f^*\mid p,o\big)=P\big(f(c)<T(p)\mid p,o\big)\cdot P\big(f(c)<f^*\mid f(c)<T(p),\,p,o\big).
\]

这个等式精确成立，但它只是链式法则。下面的方法还依赖两个模型假设，它们不由等式保证。

- **\(h\) 只依赖 \(o\) 与 \(g\)。** 我们把第二个因子近似为 \(h_o(g(p))\)，其中 \(g\) 是 \(T(p)\) 与 \(f^*\) 的相对差距。超过参照的事件每路只有约 109 次，所以转化率只用这一个变量。只有 \(g=0\) 时，\(T(p)=f^*\)，两个事件相同，\(h=1\) 才精确成立。
- **一步事件代表价值。** 两个因子都只描述下一次尝试。拓展在后续精炼中的回报不进入分数。

选择 \(T(p)\) 作中间事件的阈值，有两个理由。

**第一个因子更稠密。** 同一批记录中，超过参照 9781 次，占 12.2%，是突破的 7.5 倍。每路约 109 个正例，而突破只有约 15 个。

**参照不奖励纯恢复。** 如果用 \(f(p)\) 作阈值，退步实现很容易超过自己，但这种恢复没有价值，因为参照祖先已经在候选池中。以 \(T(p)\) 为阈值，退步实现和它的祖先就在同一尺度上比较。\(p\) 是路径上最好的程序时，\(T(p)=f(p)\)。

## 4 方法

### 4.1 先选算子，再选节点

每次尝试按以下顺序决策。

1. **按固定比例抽算子。** Refine 0.45，Explore 0.30，Crossover 0.25。
2. **确定价值。** Refine 用**精炼价值** R。Explore 与 Crossover 共用**拓展价值** X。
3. **抽系数。** 从该价值的 \(P\) 与 \(h\) 后验各抽一组系数，并应用 4.2、4.3 节的方向约束。本次全部候选共用这组系数。
4. **选节点。** 对全部有效程序计算 \(S_o(p)=P_o\big(f(c)<T(p)\big)\,h_o(g(p))\)，取最大者，同分时随机选择。Crossover 的父代还需要另有个体的成绩不劣于中位数。
5. **选融合参考。** Crossover 的参考在父代确定后选择，规则见[机制2](机制2-轨迹引导的上下文与算子.md)。

全库只有单一源码时，Crossover 转为 Explore，比例不归一化。此时 Refine 仍为 0.45，Explore 实际为 0.55。这次尝试使用 Explore 的特征，`requested_operator` 保留原抽样结果。

每一步都对应一个需要。

**算子用固定比例。** 精炼的回报在本次评价中可见，拓展的回报常在后续精炼中才显现。跨价值比较节点需要把两种时间尺度换算到一起，这要求校准的多步预测。固定比例避开了这一换算，节点分数只在同一价值内比较。

**探索与融合共用一个价值。** 两者选节点时回答同一个问题：这个设计能否承载新思想。它们的区别在新思想的来源。共用模型使数据加倍。融合的基础超过率可以不同，所以 X 另有 `crossover` 指示项。融合能否成功还取决于两个算法是否互补，这是一对算法的性质，所以参考在父代确定后选择。

**探索来自系数的不确定性。** 汤普森采样从后验抽系数，再按抽到的系数贪心选择。证据少时，系数波动大，排序也随之变化。证据积累后，排序趋于稳定。探索强度因此由本路数据决定，不需要另设访问奖励或温度。

### 4.2 \(P\)：超过参照的概率

\(P\) 用两个相对量描述节点状态：

\[
g(p)=\frac{T(p)-f^*}{\max(|f^*|,10^{-12})},\qquad
v(p)=\frac{f(p)-T(p)}{\max(|f^*|,10^{-12})}.
\]

\(g\) 是轨迹参照与当前最好的相对差距，\(v\) 是当前实现相对轨迹参照的退步。\(v>0\) 的节点称为**退步节点**，\(v=0\) 且 \(g>0\) 的节点称为**落后节点**。

\(P\) 是加性逻辑模型，\(\operatorname{logit}P_o=\beta_o^\top x_o\)。特征按下表顺序排列。

| 字段 | 定义 | 为什么需要 | 系数方向 |
| --- | --- | --- | --- |
| `intercept` | 1 | 本价值的基础超过率 | 不约束 |
| `crossover`（仅 X） | 本次为 Crossover 时取 1 | 分开融合与探索的基础超过率 | 不约束 |
| `g_positive` | \(1\{g>0\}\) | 区分参照等于当前最好的节点与参照落后的节点 | 不约束 |
| `log1p_g_scaled` | \(\log(1+g/0.01)\) | 比较参照落后的节点之间的距离 | 不约束 |
| `v_positive` | \(1\{v>0\}\) | 区分路径最好的实现与退步实现 | \(\le 0\) |
| `log1p_v_scaled` | \(\log(1+v/0.01)\) | 比较不同的退步程度 | \(\le 0\) |
| `log1p_k_same` | \(\log(1+k_o)\) | 本价值此前未超过 \(T(p)\) 的次数 | \(\le 0\) |
| `log1p_k_other` | \(\log(1+k_{\text{other}})\) | 另一价值此前未超过 \(T(p)\) 的次数 | \(\le 0\) |
| `log1p_s` | \(\log(1+s)\) | 两种价值此前超过 \(T(p)\) 的总次数 | \(\ge 0\) |

轨迹经两条路径进入分数。祖先路径决定 \(T\)，再决定 \(g\) 与 \(v\)。从节点出发的直接尝试决定 \(k\) 与 \(s\)。

幅度特征在差距为 0 时为 0，并随差距平滑增大。0.01 是相对尺度常数，不由数据拟合。指示项把零点与正值分开，幅度项描述正值内部的变化。

系数方向由机制决定，理由有两条。第一，\(T\) 固定时，父代越差，子代需要越大的改进才能超过 \(T\)，所以退步两项不能提高 \(P\)。第二，同一节点上的失败只会降低对它成功率的估计，成功只会提高。第二条对两种价值都成立，所以 `log1p_k_other` 也不大于 0：精炼失败不会抬高节点的拓展分数。参照落后的节点可能有较多易得的改进，也可能本身较弱，所以差距两项不约束方向。

方向约束解决一个具体的失败模式。搜索早期系数接近先验。如果退步系数抽到正值，退步极大的节点就会得到接近 1 的 \(P\)。约束的做法是把抽样后落在错误一侧的系数置为 0。MAP 求解本身不加约束。

### 4.3 \(h\)：突破转化率

\(h_o(g)\) 估计超过参照的子代同时突破当前最好的概率。\(g=0\) 时，\(h=1\)。\(g>0\) 时：

\[
\operatorname{logit}h_o(g)=\alpha_o+b_o(\log g-c),\qquad c=\log(0.01).
\]

斜率为负时，它等价于对数逻辑斯蒂生存函数：

\[
h_o(g)=\frac{1}{1+(g/g_0)^\gamma},\qquad
\gamma=-b_o,\qquad g_0=\exp(c-\alpha_o/b_o).
\]

\(g_0\) 是一半超过事件能转化为突破的差距，\(\gamma\) 决定转化率随差距下降的速度。模型只有两个参数，因为 \(h\) 的训练事件少。

抽样后把 \(b\) 截断为不大于 \(-0.05\)，所以每次决策的 \(h\) 都随 \(g\) 单调下降。\(\alpha\) 不截断。

### 4.4 先验与在线更新

每路搜索从固定先验冷启动，不读取历史拟合参数。这样，机制可以直接用于没有历史的新问题。R 与 X 各自维护 \(P\) 和 \(h\)。

| 参数 | 先验 |
| --- | --- |
| \(P\) 的 `intercept` | \(N(\operatorname{logit}0.1,\,1.5^2)\) |
| \(P\) 的其余系数 | \(N(0,\,1^2)\) |
| \(h\) 的 \(\alpha_o\) | \(N(0,\,1.5^2)\) |
| \(h\) 的 \(b_o\) | \(N(-1,\,1^2)\) |

失败项的先验均值取 0。节点成功率集中在基础率附近，几次失败的信息有限，衰减速度由本路学习。

每次尝试在修复结束后产生一条学习记录。特征在决策时固定。

- **\(P\) 增加一行。** 最终程序有效且严格击败 \(T(p)\) 时，标签为 1。失败、无效、同分和退步都为 0。
- **计数更新一次。** 标签为 1 时 \(s\) 加 1。标签为 0 时，本价值的失败数 \(k\) 加 1。
- **\(h\) 只在标签为 1 且决策时 \(g>0\) 时增加一行。** 特征为 \([1,\log g-c]\)，标签为是否也击败决策时的 \(f^*\)。\(g=0\) 的事件不提供参数信息。

\(P\) 与 \(h\) 都用固定先验和本路全部训练行重求 MAP。求解用 Newton 迭代，以 Hessian 的逆作为 Laplace 协方差。只有实际执行的动作产生学习行，未选中的候选没有反馈。

恢复靠重放。程序按顺序读回 `attempt.record["selection"]`，重建计数与两个后验，不保存模型状态。每次尝试的随机数由种子与序号生成，不保存随机状态。记录保存截断后的系数与后验均值，原始抽样不落盘。

## 5 主张与检验

**主张。** 节点分数等于突破事件的概率并由本路结果更新时，预算会流向实际回报更高的节点，最终成绩优于 Base 权重。

这个主张是一条因果链，有三个环节：分数校准为事件概率，预算随分数流向高回报节点，最终成绩因此提高。三项检验各对应一个环节。

前两项使用同一份复查。复查在 90 路已有搜索记录上按实际动作冷启动回放：每次动作前用后验均值预测，再用实际结果更新；分配比例用抽样决策计算。复查不调用模型，未选中的候选不获得虚构反馈。

**分数是否校准为事件概率。** 检验量是按 \(g\) 分箱的预测与实测转化率，以及 \(S\) 十分位的预测与实测突破率。

- \(S\) 的排序有效。两种价值、四个进度阶段中，\(S\) 十分位与实测突破率的秩相关为 0.68–0.96。
- \(h\) 的绝对值偏高。0.1%–1% 相对差距的转化率，精炼价值预测 34%，实测 15%；拓展价值预测 27%，实测 13%。1%–10% 区间的预测也约为实测的 2 倍。这是待解决的校准问题。

**预算实际流向哪里。** 检验量是当前最好、落后节点和退步节点的获配比例，并与各组的实测突破率对照。

- 回放中，当前最好的节点获配 34%，落后节点获配 43%，退步节点获配 22%。
- 同一复查中，当前最好的实测突破率在两种价值、四个阶段都高于落后节点，为其 1.2–4.2 倍。
- \(h\) 只作用于 \(g>0\) 的节点，当前最好的 \(h\) 恒为 1。所以 \(h\) 偏高会直接抬高落后节点相对当前最好的分数。这个偏差不是全部候选的共同偏差，同一价值内的比较不能抵消它。

**最终成绩。** 主量是六任务上每任务三路平均的独立测试成绩。每路预算为 1000 次评价，其余条件见[实验条件](../../experiments/PROTOCOL.md)。比较对象是 `trajectory_scoring` 的开与关，关闭时使用 Base 权重，其余开关相同。这样，成绩差异只来自预算分配。只替换本机制的这项比较尚无结果。
