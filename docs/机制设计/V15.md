# TraceAAD V15：同投入竞争与设计层面的信息曝光

## 研究问题与核心认识

大语言模型驱动的自动算法设计（LLM-based automated algorithm design，LLM-AAD）中，选择同时决定哪个程序获得修改机会，以及哪些已有程序进入生成提示。这使选择压力能够通过上下文影响生成。当前高分程序更常被开发，也更常成为参考；其他方向即使得到机会，其后代仍可能沿用这些实现。

当前成绩还混合了算法设计与开发程度。一个只修改过几次的设计，与一个经过大量精炼的设计直接竞争，比较结果不能单独反映前者的开发价值。另一方面，展示其他程序的代码虽能传递有用计算，也提供了可以直接复制的完整实现。仅增加年轻方向的机会，仍可能把这些机会用于复现成熟方向。

**核心认识是：开发分配需要比较相近投入下的表现，知识共享则需要控制信息的表达形式。** TraceAAD V15 据此以同投入竞争分配谱系开发，以设计描述传递其他程序的计算思路。

## 同投入竞争：比较开发曲线上的对应位置

一个谱系（lineage）由一次无父代生成及其沿主父代关系派生的程序组成。谱系年龄 \(e_D\) 是已经建立的程序记录数，包含失败程序、修复与回访记录；未能解析建档的回复只进入全局生成预算。这个年龄提供可追踪的开发尺度，模型请求数和 token 成本另行统计。

设 \(b_D(r)\) 为谱系 \(D\) 的前 \(r\) 条记录中最好的有效训练成绩，成绩越小越好。持有全局最好程序的谱系记为 \(C\)。在检查点 \(r\) 上，挑战谱系满足

\[
b_D(r)\leq b_C\bigl(\min(r,e_C)\bigr)
\]

时继续保持活跃。检查点默认从五开始逐次加倍。冠军尚未获得足够记录时，使用其当前最好成绩作为参照；尚未到达首个检查点的有效谱系拥有初期发育机会。

下一次开发优先分配给活跃挑战者中投入最少的谱系；缺少活跃挑战者时开发冠军。谱系内部按程序质量和历史直接改进率选择父代。由此，年轻设计主要与成熟设计在相近开发位置的历史表现竞争，预算又能在缺少合格挑战者时集中到当前最好方向。

## 信息曝光：共享计算思路，减少直接复制材料

信息曝光（information exposure）让被修改的程序提供完整代码，其他程序提供设计描述与评价结果。形成历史用设计和结果呈现；交叉参考用文字描述其计算；后续初始化读取已有起点的设计与成绩。模型可以借用其中的思路，再将相关计算落实到当前程序。

设计描述位于回复代码之后，要求说明代码中决定输出的量、公式和参数值，以及本次修改。这样的表达把共享内容集中在具体计算上，使后续提示可以利用设计信息，而不必展示整份外来实现。设计说明是生成时记录的文本，程序是否合法、性能是否改善由执行评价确定。

## 新方向的建立与早期开发

新谱系在首个检查点前从自身最好程序出发，围绕主决策规则完成初期修改。停滞后，设计地图以已有描述引导从零构造新的起点，默认间隔为四十次生成。谱系表示程序来源，允许通过交叉借用其他设计的计算；它本身不判定思想身份。

同投入竞争与信息曝光共同服务于持续开发：前者减轻开发程度差异对机会分配的影响，后者减少不同谱系通过完整代码发生的直接复制。机制的关键检验是，新增机会是否形成有区别的有效实现，并转化为同预算下的算法改进。
