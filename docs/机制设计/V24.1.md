# V24.1

**V24.1 = V21＋带计算条件、可由后续轨迹修订的机制三。** 实现位于 [traceaad_v24_1](../../traceaad_v24_1/)，完整规格见[机制三](机制3-轨迹反思与经验学习.md)。旧 [V24](V24.md) 的代码、运行记录和实现说明保留。

保留每10次已评价非初始化尝试的调用周期、6条活跃经验、Explore 隔离，以及 V21 的选择、生成、修复与评价。修改反思的计算背景、经验条件与来源、更新方式和算子用法。

| 项目 | V24 | V24.1 |
| --- | --- | --- |
| 证据 | 最近10次简略卡片与旧笔记 | 未读事件的完整实现、父代形成一步、同起点最好与最近不同尝试、经验代表来源 |
| 改写与失败 | 大幅改写可只剩摘要，失败卡无代码改动 | 改写提供父子代码，失败提供实际评价代码与反馈 |
| 经验 | `idea`、`lesson`，每轮整体替换 | `id`、`idea`、`when`、`lesson`、`evidence_ids`，局部更新与归档 |
| 未读材料 | 反思后清空窗口 | 调用计数与未读事件分离，超限或失败后保留 |
| 使用 | Refine/Crossover 共读笔记 | 短条件经验服务当前计算的改进或参考计算的接入 |

事件使用尝试编号；一次修复后的最终版本贡献一个事件，全部实际评价仍按 Base 规则记账。旧经验版本留在已提交快照中，累计来源与归档条目留在经验状态中。恢复重放程序和审阅状态，不调用模型。方法、任务、配置或反思设置不一致时，在修改日志前拒绝恢复。

默认上下文49152 tokens，反思独立预留4096 tokens输出和512格式余量，输入上限44544 tokens。调度客户端按服务端 tokenizer 的聊天模板计数，不再使用字节上界；计数失败保留未读事件。每条经验当前回读一个代表父子事件，全部累计来源仍保存。正常周期尝试整批装入；超限时兼顾最早未读事件和本周期事件，余下材料继续保留。生成输出预算不变，无经验时的完整提示与V21一致。
