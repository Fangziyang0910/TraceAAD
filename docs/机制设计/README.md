# TraceAAD 机制设计

当前有两个方法。V20在Base上实现轨迹评分、轨迹引导的上下文与算子、轨迹反思与经验学习，代码位于[traceaad_v20](../../traceaad_v20/)。V21在Base上只实现轨迹引导的上下文与算子，代码位于[traceaad_v21](../../traceaad_v21/)。规格以实际代码为准。

| 文档 | 内容 |
| --- | --- |
| [V21](V21.md) | 只含上下文机制的方法：与Base的差异、沿用内容与运行入口。 |
| [V20](V20.md) | 完整方法：评分公式与在线更新、上下文选取、观察账本、开关、恢复与生成条件。 |
| [机制1：轨迹节点价值评估与预算分配](机制1-轨迹节点价值评估与预算分配.md) | 先算子后节点的选择、价值分解、在线更新。 |
| [机制2：轨迹引导的上下文与算子](机制2-轨迹引导的上下文与算子.md) | 祖先、子代、失败与融合参考的选取和呈现，三种算子、指令组合与 `analysis → code → design` 输出。 |
| [机制3：轨迹反思与经验学习](机制3-轨迹反思与经验学习.md) | 局部与学习反思、经验的形成与修订、多视角召回。 |
| [Base](../TraceAAD-Base.md) | V20、V21沿用的个体表示、任务模板、评价与修复流程。 |

文中 `fitness` 统一为越小越好的训练成绩；最终程序由训练成绩确定，独立测试只评价固定后的程序。
