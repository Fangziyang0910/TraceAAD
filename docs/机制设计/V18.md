# TraceAAD V18：以同龄竞赛和有限偏差搜索保留替代接续

## 研究问题与核心认识

大语言模型驱动的自动算法设计（LLM-based automated algorithm design，LLM-AAD）中，每次生成不仅产生候选算法，也产生一个接续选择：继续修改子代，还是回到父代寻找另一种修改。子代当前更好，说明它值得保存和优先开发，但这并不能说明父代的其他延伸已经失去价值。

当后续生成持续采用同一个早期高分子代时，一次局部选择就可能主导大量后续投入。新起点即使获得足够开发时间，也可能只有一条接续路径得到充分展开。因此，持续探索需要同时协调起点之间的投入，并保留起点内部重新考虑早期选择的机会。

**核心认识是：候选质量决定接续的优先顺序，保留替代接续则为纠正局部选择提供搜索空间。** TraceAAD V18 以同龄竞赛分配起点开发，以有限偏差搜索（limited discrepancy search，LDS）组织每个起点的后续生成。

## 同龄竞赛：让起点在可比开发年龄下竞争

每个不同的有效起点对应一个开发任务。任务维护自己的最好程序、历史最好成绩曲线和可继续展开的状态。年龄是分配给该任务的开发请求数，初始程序对应年龄零；开发中的无效回复、执行失败和重复候选同样消耗年龄。建立起点的请求计入全局预算。

设 \(b_D(a)\) 为任务 \(D\) 在年龄 \(a\) 时已经发现的最好训练成绩，成绩越小越好。持有全局最好程序的任务作为冠军。检查点为五、十、二十……；达到检查点的任务在同龄表现不差于冠军时继续参与竞争，持平仍可继续。参照缺少相应年龄历史时，等待仍可开发的冠军补齐历史；冠军已无可用接续时，暂缓该次比较。

机会优先分配给年龄最小的合格任务，同龄按创建顺序选择。任务成绩由其全部已评价分支中的最好程序决定，因此一次替代分支发现的改进也能成为该起点的开发成果。

## 有限偏差接续：优先利用成绩，同时重新考虑早期选择

开发状态记录当前程序与一次具体的生成位置。对有效且源码不同的父子比较，搜索保留两种接续：沿子代继续的 `FOLLOW`，以及从父代重新生成的 `RETRY`。当前成绩较好的一侧优先，同分优先父代；另一侧记为一次偏差。低分子代因此仍可作为替代接续得到进一步开发。

LDS 限制一条接续路径选择非优先侧的次数，使搜索先遵循已有成绩，再系统地尝试少量不同决定。深度窗口默认从 \(H=2\) 开始，允许的偏差数为

\[
D(H)=\min\!\left(H-1,\left\lfloor\log_2 H\right\rfloor\right).
\]

窗口完成后深度增加一。同一偏差轮次优先重新考虑较早的替代，使被早期选择遮蔽的路径有机会重新展开。读取已经展开的状态复用已有结果；真正的 `RETRY` 产生新的模型请求。

生成上下文沿实际采用的祖先路径提供程序变化与评价结果。尚未采纳的有效尝试以单独的差分和结果出现，帮助模型提出不同修改。搜索据此保留两类经验：已经形成当前程序的改动，以及从当前位置尝试过的其他改动。

## 有限生成条件：把开发机会留给新的候选

替代接续只有在能够提出新候选时才有价值。完全相同的有效源码不能再次建立零龄任务；重复结果仍评价和计费，并关联已有来源。源码身份按换行与首尾空白规范化后确定。

搜索还按“生成操作与父代或参考源码”累计连续未产生有效新候选的次数。无效回复、复制父代，以及同一父代已经提出过的有效源码均进入计数；默认连续三次后关闭该生成条件。有效且此前未从该父代产生的不同程序会清零计数，其成绩暂时较差仍可形成新的接续。尚无有效起点时，初始化保留十六次请求额度。

无新候选的重试保持原接续地址，不增加接续决策深度。搜索优先使用其他开放接续，停滞或缺少合格任务时尝试新起点；全部生成入口关闭后保存最好程序并结束。全局预算统计实际模型请求，包含初始化、发散、失败和重复。

保留替代路径会占用原本可用于当前优质程序的开发机会。该方法的核心科学问题是，这些替代路径能否发现足够有价值的后续改进。检验应对齐实际请求预算，并控制生成提示，观察替代接续的收益能否补偿这一机会成本。
