# V23.1：Base 加机制1

V23.1 与 [V22.1](V22.1.md) 共用新版[机制1](机制1-轨迹节点价值评估与预算分配.md)的 [selection.py](../../traceaad_v22_1/selection.py) 和 [runtime.py](../../traceaad_v22_1/runtime.py)，各运行独立维护选择池和统计状态。代码位于 [traceaad_v23_1](../../traceaad_v23_1/)。

父代、算子与交叉参考由机制1一次确定。选择使用真实冠军改善、近期质量状态匹配、轨迹相似度修正和 Base 锚定再分配；首评、实际评价成本及选择状态恢复与 V22.1 相同。它不含机制2或反思。

生成侧自11月9日起直接继承当前 [Base](../TraceAAD-Base.md)：演化生成只读当前算法的代码、自包含设计与成绩，交叉增加选定参考的设计与成绩；不提供祖先、已有子代、失败子代或此前分析，也不追加轨迹指导。初始化、一次修复和 `analysis → design → code` 输出沿用 Base，均保持原有行为。机制1仍利用轨迹分配预算，生成侧不使用机制2。
