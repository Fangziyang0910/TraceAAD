# V21

定版日期：2026年11月7日（北京时间）。**V21 是 Base 加机制2的最终版，正式名称统一为 V21。** V21 在正式 Base 上只加入[轨迹引导的上下文与算子](机制2-轨迹引导的上下文与算子.md)。代码位于 [traceaad_v21](../../traceaad_v21/)。

正式实验批次为 `20261105c_v21_co6`，结果见[V21实验结果](../../experiments_result/traceaad_v21c/)，对照批次为 `20261105_base_co6`。批次ID和存储路径用于定位原始记录。

V21 要检验一个问题：**只改变模型读到的材料、被要求做的决定和输出顺序，搜索能否找到更好的算法？** 它不含反思和经验，也不改预算分配，所以结果只反映上下文机制。

## 与 Base 的差异

| 项目 | Base | V21 |
| --- | --- | --- |
| 输出顺序 | `analysis → design → code` | `analysis → code → design` |
| 长度提示 | 两三句，且最多100英文词或200中文字 | 相同 |
| 历史卡 | 分析、设计、成绩 | 相对父代的结果、设计、提议的修改；子代卡另有程序算出的改动 |
| 当前卡 | 分析、设计、成绩、代码 | 成绩和代码；Explore 只有代码 |
| 各算子的材料 | 共用 | Refine 看祖先、子代、失败；Crossover 看子代、失败、参考；Explore 只看当前代码 |
| 提示中的代码 | 原文 | 去掉注释和文档字符串，修复提示除外 |
| 祖先窗口 | 最近 8 条 | 最近 3 条 + 成绩变化最大的 5 条 |
| 子代窗口 | 最好 + 最近 | 合并相同尝试后，最好 + 最近 |
| 失败窗口 | 最近 2 条 | 合并相同尝试后，最近 2 条 |
| 融合参考 | Base 参考池中均匀抽取，只给设计与成绩 | 同一池内先合并只差常数的程序，再均匀抽取，给设计、成绩、完整代码和最后一步的改动 |
| 算子指令 | 按算子说明修改任务，并有轨迹指引 | 一句材料说明加两三句算子要求；Explore 列出通用方法大类，并说明现在不必胜过当前代码 |

## 沿用 Base

- 父代选择与算子比例。
- 初始化和修复的流程与文本，失败信息的处理。
- 评价器、评价预算与停止条件。
- 程序库不去重。去重只作用于提示中的视图。
- 模型采样与最大输出长度。

## 不包含

评价后反思、经验形成与召回、轨迹评分、嵌入服务。

## 记录

每次演化尝试在 `attempt.record["context"]` 保存实际展示的祖先、子代和失败编号，Explore 这些都为空；参考编号在 `reference_id`。恢复时按 `attempts.jsonl` 追加记录重建，与 Base 相同。

## 运行

入口见[实验入口](../../experiments/traceaad/README.md)，使用 `--method v21`。正式对照使用当时同一冻结源码中的 Base；`20261031_base_schema_co6` 使用的是更早的父代选择和失败信息，不作为对照。当前 Base 已改为静态算法上下文，不能用当前 `--method base` 替换历史对照条件，边界见[Base 说明](../TraceAAD-Base.md)。

## 比较口径

机制二检验按算子的设计问题提供轨迹材料与指令，能否在相同预算下找到更好的算法。正式比较为六任务×三种子，每路 1000 次评价。每路固定训练成绩最好的程序，再比较独立测试成绩在各任务上的三路平均值。

对照使用相同模型、父代选择、算子比例、评价与预算，差异为上下文组织、算子指令和输出顺序。因此，该比较评价整套生成机制，不能单独归因于祖先、子代差分或某句提示。

生成文字与实际代码的一致性、决策未变的程序及重复修改可用于解释结果。单步回放和短冒烟各自只支持其实际检查的行为，不替代完整搜索的效果比较。原始过程证据见[研究记录](../记录/2026-W45.md)。
