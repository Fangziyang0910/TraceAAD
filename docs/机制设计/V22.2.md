# V22.2：V21.1 加新版机制1

V22.2组合当前Base、上一版机制2（同[V21.1](V21.1.md)）与新版[机制1](机制1-轨迹节点价值评估与预算分配.md)。代码位于[traceaad_v22_2](../../traceaad_v22_2/)。它与[V23.2](V23.2.md)直接共用选择器、轨迹收益估计、轨迹参考与反馈恢复实现，运行状态各自独立。

基础质量权重是与Base相同的纯Boltzmann权重和选择温度。机制1根据近期可比轨迹的真实冠军改善与实际评价成本修正预算，再用当前算法及最近三步形成轨迹的嵌入选择交叉参考。参考候选池与Base一致，没有family或计算结构的额外筛选；缺少合格参考时C的基础机会并入E。

生成侧直接继承V21.1，保留其初始化、轨迹上下文、算子任务、输出顺序、修复和评价。V22.2不含反思与条件经验。

## 默认完整机制与参考消融

统一入口为`--method v22.2`或`v22_2`。正式入口默认开启轨迹嵌入参考，不需要另加开关。`--no-trajectory-reference-embedding`显式切换为共同候选池中的随机参考，用于参考部分的消融；轨迹收益修正仍然运行。直接Python调用需要注入`reference_embedding=encoder`来启用完整参考机制，传入`None`表示随机参考消融，核心搜索不自行创建远程客户端。

模型设置、缓存、用量和实际参考记录均保存。嵌入异常直接报告，不自动改用随机参考。选择器沿用`base_anchored_champion_yield_v3`，算法的收益估计与V23.2一致。

- V23.2与V22.2比较：机制1相同，只增加机制2。
- Base与V23.2比较：静态生成相同，只增加完整机制1。
