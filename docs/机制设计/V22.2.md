# V22.2：V21.3 加机制1

V22.2组合Base、[V21.3](V21.3.md)的机制2与[机制1](机制1-轨迹节点价值评估与预算分配.md)。代码位于[traceaad_v22_2](../../traceaad_v22_2/)。它与[V23.2](V23.2.md)共用选择器、轨迹收益估计、轨迹参考与反馈恢复实现，运行状态各自独立。

基础质量权重是与Base相同的纯Boltzmann权重和选择温度。机制1根据近期可比轨迹的真实冠军改善与实际评价成本修正预算，再用当前算法及最近三步形成轨迹的嵌入选择交叉参考。参考候选池与Base一致；缺少合格参考时搜索报错，不改换算子。

生成侧继承V21.3，保留其初始化、轨迹上下文、算子任务、输出顺序、修复和评价。V22.2不含反思与条件经验。

## 完整机制与参考消融

统一入口为`--method v22.2`或`v22_2`。入口默认开启轨迹嵌入参考。`--no-trajectory-reference-embedding`切换为共同候选池中的随机参考，用于参考部分的消融；轨迹收益修正仍然运行。直接Python调用需要注入`reference_embedding=encoder`来启用完整参考机制，传入`None`表示随机参考消融。

模型设置、缓存、用量和实际参考记录均保存。嵌入异常直接报告，不改用随机参考。选择器为`base_anchored_champion_yield_v3`，收益估计与V23.2一致。

## 对照与恢复

- V21.3与V22.2：机制2相同，只增加机制1。
- V23.2与V22.2：机制1相同，只增加机制2。
- Base与V23.2：生成相同，只增加机制1。

共同实验条件见[实验协议](../../experiments/PROTOCOL.md)。原生配置保存`method=traceaad_v22_2`、`mechanisms=[1,2]`、生成协议、共同选择条件、选择器设置与实际参考设置，恢复时逐项核对。

测试位于[tests/v22_2](../../tests/v22_2/)，覆盖同一状态下与V23.2一致的实际动作、随机参考消融、完整嵌入参考、首评、预算、反馈与恢复。
