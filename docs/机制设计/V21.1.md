# V21.1：当前 Base 加机制2

V21.1在当前[Base](../TraceAAD-Base.md)上加入[轨迹引导的上下文与算子](机制2-轨迹引导的上下文与算子.md)。代码位于[traceaad_v21_1](../../traceaad_v21_1/)，入口为`--method v21.1`或`v21_1`。

父代、算子和参考选择直接继承Base：纯Boltzmann父代采样、固定R/E/C比例、共同质量池内均匀随机参考，无参考时C转E。V21原有的忽略常量取值后按计算结构分组、排除父代同组的参考筛选已删除。程序库和轨迹材料的组织仍按机制2工作。

机制2只决定生成时的材料、指令和输出协议：Refine读形成路径与同起点改动，Crossover读同起点改动和所选参考，Explore只读当前代码。保留源码规范化、实际差分和`analysis → code → design`输出。初始化与修复复用当前Base的公共实现，初始化保留机制2的规范化代码视图；不再维护旧Base提示副本。

## 比较口径

Base与V21.1共享父代和参考分布、算子比例、模型采样、评价、预算与最终选择。两者的差别是机制2的生成材料、算子任务和输出顺序，比较检验这套生成机制的整体增量。

V21.1与V22.2之间仅增加新版机制1；V21.1与V24.1之间增加最新机制3。当前组合与对照关系见[版本索引](README.md)。
