# V21.1：当前 Base 加V21.1版机制2

V21.1在当前[Base](../TraceAAD-Base.md)上加入V21.1版机制2，以[traceaad_v21_1](../../traceaad_v21_1/)的代码为准。当前机制2见[正文](机制2-轨迹引导的上下文与算子.md)，版本关系见[版本与机制](实现说明.md)。入口为`--method v21.1`或`v21_1`。父代、算子和参考选择与Base相同。

## 比较口径

Base与V21.1共享父代和参考分布、算子比例、模型采样、评价、预算与最终选择，比较检验V21.1版机制2的整体增量。V21.1与V22.2之间只增加机制1；V21.1与V24.1之间只增加机制3。

## 记录与恢复

原生配置保存`method=traceaad_v21_1`、`mechanisms=[2]`、`generation_protocol=trajectory_algorithm_context_v1`、`reference_rule=quality_pool_uniform_v1`，以及选择规则、温度、任务和完整配置。恢复先核对这些条件，再修复日志并重放。旧V21运行使用当时冻结源码。

测试位于[tests/v21_1](../../tests/v21_1/)。四任务批次`20261109_v21_1_co4`已于11月9日23:43启动12路，见[队列记录](../记录/2026-11-09-四任务阶段与36路补位队列.md)。历史结果见[V21](V21.md)。
