# 版本与机制

三个机制的设计只在各自的正文中维护：[机制一](机制1-轨迹节点价值评估与预算分配.md)、[机制二](机制2-轨迹引导的上下文与算子.md)、[机制三](机制3-轨迹反思与经验学习.md)。本页说明每个保留版本使用了哪个机制。

所有版本共用Base的评价、预算、修复和Boltzmann基础质量权重。未启用机制一时，交叉参考在共同质量池中均匀随机选择。V22.2与V24.1的生成侧继承V21.3。

可直接形成的对照：

- Base与V21.3，V23.2与V22.2：检验机制二。
- Base与V23.2，V21.3与V22.2：检验机制一。
- V21.3与V24.1：检验机制三。
