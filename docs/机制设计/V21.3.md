# V21.3：当前 Base 加当前机制2

V21.3在当前[Base](../TraceAAD-Base.md)上加入当前的[机制2](机制2-轨迹引导的上下文与算子.md)。代码位于[traceaad_v21_3](../../traceaad_v21_3/)，入口为`--method v21.3`或`v21_3`。父代、算子和参考选择与Base相同。

## 与V21.2的区别

只改一处：每个演化步骤都用规范化父子代码的完整差分呈现实际改动，3行上下文，不设相似度阈值。失败子代也给差分；参考形成步骤与其他步骤使用同一种卡片；无法解析的代码比较原始文本并标明。算子指令、展示条数、选择规则和`analysis → code → design`协议与V21.2相同。

## 比较口径

Base与V21.3检验当前机制2的整体增量；V21.2与V21.3只差实际改动的呈现。`--reference-code`在融合参考材料中另给平铺的完整源码，检验它相对按形成步骤组织的代码是否还有作用。

## 记录与恢复

原生配置保存`method=traceaad_v21_3`、`mechanisms=[2]`和`generation_protocol=trajectory_design_reasoning_full_diff_v1`；`--reference-code`运行为`trajectory_design_reasoning_full_diff_v1+reference_code`，两者恢复时互不接续。`attempt.record["context"]`的字段与V21.2相同。测试位于[tests/v21_3](../../tests/v21_3/)。
