# V23

2026年11月7日（北京时间）。**V23 = Base＋机制1。** 它与V22（Base＋机制1＋机制2）构成生成流程对照。代码位于[traceaad_v23](../../traceaad_v23/)。

V23完整继承Base的初始化、祖先/子代/失败历史、算子指令、代码呈现、一次repair与`analysis → design → code`输出及JSON Schema。Base本来已有的历史材料保留。它不使用机制2的按算子组织上下文、Explore隔离与`analysis → code → design`输出。

机制1与V22共用[selection.py](../../traceaad_v22/selection.py)和[runtime.py](../../traceaad_v22/runtime.py)，不复制算法。各次运行独立建立选择池、模型和局部计数。父代、算子和融合参考由机制1一次性确定，Base提示直接使用该参考，不重新抽取；因此Base原有的父代评分、算子概率与融合参考政策由机制1替换。

使用九维特征、分算子可用率与连续收益、预测尺度±3倍的稳健残差更新、16点两步前瞻、最多29个第二步候选、family与最佳异family参考政策。可运行的退步节点继续保留。实际每轮只执行一步，预算按真实评价计费；恢复校验方法、完整配置、任务、选择设置与尺度。具体公式和近似见[机制1](机制1-轨迹节点价值评估与预算分配.md)。
