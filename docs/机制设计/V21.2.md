# V21.2：当前 Base 加V21.2版机制2

V21.2在当前[Base](../TraceAAD-Base.md)上加入V21.2版[机制2](机制2-轨迹引导的上下文与算子.md)。它与当前设计（[V21.3](V21.3.md)）只差实际改动的呈现：父子相似度低于0.5时只报告改写规模，参考的改写步骤改列仍保留的新增行，失败子代不给差分。代码位于[traceaad_v21_2](../../traceaad_v21_2/)，入口为`--method v21.2`或`v21_2`。父代、算子和参考选择与Base相同。

## 比较口径

Base与V21.2共享父代和参考分布、算子比例、模型采样、评价、预算与最终选择，比较检验机制2的整体增量。

`--reference-code`在融合参考材料中另给完整源码，其他条件不变，用来检验完整源码是在帮助正确实现，还是在诱导复制。

## 记录与恢复

原生配置保存`method=traceaad_v21_2`、`mechanisms=[2]`和`generation_protocol=trajectory_design_reasoning_v1`；`--reference-code`运行为`trajectory_design_reasoning_v1+reference_code`，两者恢复时互不接续。`attempt.record["context"]`保存实际展示的祖先、子代、失败、参考形成步骤（`reference_steps`）和探索记录（`explorations`）。测试位于[tests/v21_2](../../tests/v21_2/)。
