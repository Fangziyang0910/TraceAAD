# TraceAAD

研究如何利用自动算法设计搜索中获得的轨迹与反馈经验，改善后续决策，提高有限预算下发现和改进优质算法的效率。

轨迹是多轮搜索的过程，包括全局时间线、程序演化与探索竞争。轨迹是经验的来源和组织方式，反馈是其中的内容，后续决策是用途。经验如何表示、组织和使用，仍由具体问题与实验决定。

[当前研究问题](docs/04-研究认识与构想/研究主线与问题.md)说明目标与关键未知量。[研究文档](docs/README.md)按问题查找方法、结果和历史材料。

运行命令、批次状态与结果位置见[实验入口](experiments/README.md)。新实验条件见[实验规范与共识](docs/08-实验规范与共识/README.md)，历史实验按启动配置和源码快照解释。搜索实现位于 `traceaad/`，比较方法位于 `baselines/`。

当前评价统一按越小越好解释 `fitness`。历史文档保留当时的计分方向，不能直接混入当前汇总。格式说明见[结果格式](experiments/infra/SEARCH_FORMAT.md)。
