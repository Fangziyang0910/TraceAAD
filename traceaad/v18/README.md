# V18：同龄竞赛与有限偏差搜索

实现依据：[机制设计稿 v1.0](../../docs/TraceAAD：同龄竞赛与有限偏差搜索.md)。V18 是独立的搜索策略，复用公共程序评价、结果格式与原子检查点。

- 外层以具体起点的开发任务为单位，在年龄 5、10、20……按历史最好质量与当前冠军同龄比较。冠军参考不足时等待；冠军变化后重新判定资格。合格任务按年龄、创建顺序选择，冠军也参加排序。
- 内层在每次有效且源码不同的父子比较后保留 FOLLOW 与 RETRY。成绩较好者优先，同分优先父代；另一接续记一次偏差。窗口从 `H=2` 开始，`D=min(H-1,floor(log2(H)))`，窗口完成后深度加一。同一偏差轮次优先早期替代。
- 程序、开发状态、开发任务分开存储。读取已展开状态不调用模型；RETRY 创建新状态，真正重新生成。路径经验只沿实际采用的程序祖先读取，本地重试反馈不展示未选子代的完整代码。
- 默认五个有效根、最多十六次初始化请求。建根成本只计全局预算，任务年龄从零开始。全局改进与上次发散之后均已满四十次请求，且至少剩六次请求时发散。
- 普通聊天 API 只需输出完整 Python 源码，不使用 JSON、思想标签、行为签名或额外反思请求。任务模板只提取接口与文档说明，不展示模板函数体。
- 生成提示遵循公共实验协议，不提供实例数量、规模、种子和时间预算。实际失败的诊断信息仍进入对应尝试的反馈。

## 预算、异常与恢复

`budget` 统计所有模型请求，含初始化、Diverge、API 故障、解析失败、无效程序、超时与重复。`generate(..., retry_limit=0)` 关闭共享生成器的隐藏重试；失败后由下一次明确获配的状态重试。源码仅按换行与首尾空白规范化比较，重复候选仍评价和计费。

这一预算口径是 V18 设计的明确要求，与历史版本“未返回程序的接口故障不消耗生成预算”不同。训练实例、任务执行限制和最终选择继续采用[公共实验协议](../../experiments/PROTOCOL.md)。全部任务按仓库惯例保存越小越好的 `fitness`；`request.raw_score` 保存评价器原值，`request.quality=-fitness` 保存设计稿使用的越大越好质量。`objective=maximize` 对自定义评价器的原值取反后存入 fitness；当前六任务使用默认 `minimize`。

每次请求发送前保存预算预留及开发状态，收到回复后先保存程序与调用，再执行评价。评价调度器中断时恢复评价，不重发模型请求；发送边界中断、无法确认服务端完成情况的请求保守计费，并记录 `interrupted` 与未知用量。计数摘要沿用公共用量估算规则，逐调用的原始 `usage` 仍保留，不把缺失用量称为实测值。

`resume.json.state.v18` 保存配置、提示版本、任务、状态树、遍历栈及待完成请求。同配置、同提示版本恢复；拒绝将历史版本或不同参数续接为 V18。`max_seconds` 在请求之间检查；正在执行的请求仍由 API 和任务评价超时约束。恢复一个已经取得回复的请求时先完成评价，再冻结结果。

所有有效程序参与最终选择，包括替代分支、重复回复和暂停任务中的程序。同分取最早程序；不重评、不用测试集重新选择。独立测试沿用公共入口。

## 入口

```bash
uv run python -m experiments.traceaad_v18.run --task tsp_construct --dry-run
uv run python -m experiments.traceaad_v18.launch_host \
  --batch BATCH_NAME --suite co6 --repeats 3 --budget 1000 \
  --backends server3 --eval-workers 8 --output-tokens 8192 \
  --scheduler-socket /tmp/traceaad-1003/scheduler.sock
```

批量入口默认只预览，`--launch` 启动搜索。正式批次使用冻结快照及“搜索 → 冻结结果检查 → 独立主测试”的流水线，具体命令写入批次清单。

四组消融通过 `--no-same-age`、`--no-lds` 组合；`--no-early-first` 改为晚期替代优先。其余初始化、发散、提示与评价相同。`--context-tokens` 为输入与输出共同的上下文上限；默认 32768，先删最旧本地反馈，再删最旧路径片段，保留任务、接口、当前源码及成绩。必要内容仍放不下时报告 `prompt_too_large`，不发送超限请求。

Python 调用方可传 `initial_programs=[Program(..., status="valid", fitness=原始成绩)]` 使用已经评价的起点，最多 `roots` 个。它们只在新运行导入，其原始元数据另存于 `request.acquisition`；来源成本须由调用方提供并在比较时保持一致。

## 验证与日志

当前提示版本为 `v18-context-2`。路径历史采用 AST 重排后的源码差分，去掉注释与格式变化；完整父代保持原文并放在历史之后。局部尝试明确标记复制、改善、退化与同分，并说明未采纳子代的错误不代表当前父代无效。Develop 要求作出具体算法改动，Diverge 将当前最好程序标为参考并要求改变主要决策计算。已省略模板函数体时，也移除任务说明中“已提供 DSATUR／Giffler-Thompson 起始代码”的不实提示。

输出要求为无围栏的完整源码。兼容正常结束但漏写闭合围栏的回复，只移除外层围栏；源码、接口及执行检查照常进行。`finish_reason=length` 仍拒收，不补写或修复代码。该修订通过408项测试；18组定向配对中，结构重复13→3，超越父代1→4，两组均18/18有效。[审计与配对记录](../../experiments_result/analysis/v18_prompt_20261029/README.md)保存抽样范围、原始调用和评价。

`20261029_v18_co6` 使用 `20261029_traceaad_v18_final` 的原冻结源码；其中额外提供实例数和运行限制的提示偏离公共协议。按用户要求，该批已停止并保留全部结果与恢复点。新批次 `20261029_v18_context2_co6` 使用 `20261029_traceaad_v18_context2_frozen`，以 `v18-context-2` 从零启动18路，各1000次模型请求；不回填旧批结果。使用当前源码恢复旧提示版本会明确报错；旧运行仍应使用自己的冻结源码恢复。[重跑记录](../../experiments_result/traceaad_v18/launch_20261029_context2/)保存源码校验、配置、停止边界及启动证据。

[机制测试](../../tests/method/test_v18.py)覆盖原稿的十二项检查以及接口故障、无效值、真实执行超时、发送与评价中断、上下文预算、最大化目标和消融；[入口测试](../../tests/experiments/test_v18_entry.py)核对六任务条件及18路参数传递。

`program.request` 记录来源任务和状态、0/1 地址、窗口深度、偏差数、提示程序与局部尝试编号、提示及源码哈希、同龄参考快照、结果状态、原始成绩、质量、完成后年龄和全局最好程序。完整提示、回复、模型、采样参数与用量在 `calls.jsonl[.gz]`；评价及 CPU/墙钟计量在公共事件中的 `evaluations`。`summary.json.v18` 汇总任务曲线、状态数、建根/开发/替代/重复请求数。
