# TraceAAD V13.1

V13.1 对应[何时重用修改主稿](../../docs/TraceAAD：从设计轨迹中学习何时重用修改.md)。它独立于 V13：冻结操作、语义参数、绑定策略和条件，不再按谱系封禁失败，也不在线改写已有规格的含义。

## 执行与证据

- 宿主先均匀选择初始化路线，再在路线内按公共温度规则抽取有效父代。五个有效根程序形成不同路线。路线随子代继承，父代选择不读取变换收益模型。
- 前十六次独立自由修改结果建立并冻结强度为 2 的任务先验和正增益尺度。根初始化不计入这十六条记录；完全重复的缓存结果不计作独立暖启动样本。
- LLM 只负责自由修改、提取规格、匹配绑定、按规格编辑及独立核验。每个阶段有独立输出约定。宿主代码负责选择、记账与模型更新。
- 规格包括操作、固定参数、不变量、绑定策略与最多三条冻结的收益条件。静态条件由模型对执行前源码求值，并保留可定位的源码证据；不能确认则记未知。运行时条件需要实际固定探针测量，本版未装配通用运行时探针，因此此类条件记未知，不能靠源码猜测计时或运行计数。这不影响执行前提匹配，也不把条件未知当作假。
- 新父代与规格分批匹配，完整父代源码和本批规格是必要上下文。同一不可变程序与规格的绑定、条件与拒绝结果缓存；轨迹只给自由修改提供可选的近期证据。超限先移除可选历史或缩小规格批次，归纳超限则缩减比较目录，保留实际父子改动。
- 重放仅能改动绑定区间。独立核验检查操作、依赖、不变量和固定参数；至多一次同操作修复，修复仍以原父代为基准。随后使用公共训练评价器验证任务合法性与计算约束。执行失败只更新有效执行概率，不更新条件性能成功率和幅度。
- 规格冻结后显式选择的重放才进入信用。自由修改发现或事后识别出的同类修改仅作来源。归纳时不做拆分归功，也不改写旧规格；参数或绑定策略不同的操作有独立身份。入库前独立核对规格是否覆盖整个来源差分，漏项时至多重写一次规格；来源核对不增加性能证据。
- 每个变换并行使用全局、各单条件与距离衰减谱系模型。Beta–Bernoulli 与 Gamma–指数模型闭式更新；结果出现前的预测分布用于更新模型权重。未知条件使用全局预测。Thompson 选择依据是执行概率 × 改进概率 × 改进幅度。
- 每十轮至少两轮自由修改、至多一轮主动诊断。诊断只看新增执行的期望正增益均值分歧。合格对照要求轨迹关系、同角色绑定和已有合规重放；已知条件变化仅作同分优先依据。AST 位置沿主父代路径经无歧义语句对应映射，跨分支经共同祖先映射；映射不明则不作配对，仍可普通重放。
- 带符号 D 只用于配对解释与记录，不作为第三条独立样本。直接父子记录为局部交互；多步和跨分支记录为背景差异。机会频率、触发次数、回退原因与各变换的前瞻重放覆盖均写入结果。
- 完整评价协议固定在同一运行内。以规范化 AST 和运行签名缓存有效与失败评价，复用结果不再次增加统计样本；同一父代、规格与绑定不重复尝试。历史失败不会阻止新父代上的尝试。
- 至少三个不同父代上的合规实例，若能形成同一角色化 token 模板并逐一复现实际改动，则启用确定性重写。模板执行器创建新版本，旧版记录保留，信用与权重重新开始，避免混合执行器可靠性。无法唯一匹配的模板记录执行失败，不临时改用另一个执行器。

## 预算、恢复与产物

单路默认 1000 次候选机会、最多 8000 次模型请求。初始化、无效修改、诊断和修复均计入；相同机会数不等于相同评价数或 token 数。所有模型请求、失败及中断槽位均记录。接口实测 tokens 与缺失 usage 分开报告。阶段响应、待评价代码、评价回执与随机状态支持恢复；只能以同源码、同配置恢复，不能续接 V13 状态。

继承的 `operators`、`attempts_shown`、`progress_shown` 不参与 V13.1 选择。新增默认值为：24k 输入、8192 输出、匹配每批最多 4 项、诊断分歧阈值 `1e-4`、谱系衰减 `0.5`、确定性改进容差 `1e-9`。实际评价、实例与计算预算沿用[公共协议](../../experiments/PROTOCOL.md)，不进入生成提示。

`resume.json` 的 `state.v13_1` 保存规格、来源、独立重放、模型权重、配对与缓存。`transformations.json` 可在同任务的新运行导入，携带冻结尺度、先验及条件证据；旧记录标为 external，不能用旧节点编号参与新谱系。`paired_replays.json` 保存实际 D 与背景关系。最终选择仍为训练最优有效程序，测试独立执行。

```bash
.venv/bin/python -m experiments.traceaad_v13_1.run --task tsp_construct --dry-run
.venv/bin/python -m experiments.traceaad_v13_1.launch_host \
  --batch 20261026_v13_1_co6 --suite co6 --repeats 3 --budget 1000 \
  --max-model-calls 8000 --backends server3 --eval-workers 8 \
  --scheduler-socket /tmp/traceaad-1003/scheduler.sock
```

启动前做配置预览、行为测试和真实模型源改动正控制。正式批次使用冻结源码与公共资源池，另行串接主测试，不能将正控制解释为迁移收益证据。
